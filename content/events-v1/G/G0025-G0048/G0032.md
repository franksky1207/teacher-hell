## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 代替家人接送的祖母聽說導師中午常在班上處理問題，開始留意他何時出教室，也順路問他是否吃過飯。孩子嫌她每次等老師讓他更晚回家做家事，說著說著在門口和祖母吵起來。 |
| 核心衝突 | 祖母真的想關心老師，也不想孩子把接送當催促家人做事；孩子盼能準時回家，卻不願在老師面前講出家裡的分工。 |
| 導師困境 | 導師可接住關心並簡短收尾、另約不影響接送的寒暄時機，或請兩人先私下談返家安排，再向學校提出本人願說的需要。 |
| 故事獨特性 | 親師往來中的體貼，意外使孩子感到在家校兩邊都要等候。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「老師，飯吃了沒？」祖母在接送處又停下，孩子把書包一甩：「每次都等，回去又說家事沒做！」她臉沉下來：「關心一下也不行？」平常都是她照顧、接送，學校怎麼離校她一向很配合。你往旁邊讓路，沒再把兩人留住。祖母看你一眼，低聲說：「我以為十分鐘沒差。」孩子抓著背帶，不肯繼續講家裡的事。她卻還望著你，像在等你先回答有沒有吃飯。

| A | 簡短回答祖母的問候，讓兩人先回去。 | false | 導師已簡短接住問候，立即送兩人離開。 | 不再延誤但衝突未談。 |
| B | 另外約不耽誤接送的時間，願意再來聊就來。 | false | 導師已另約不影響接送的自願寒暄時間。 | 保留關係但需另排。 |
| C | 請兩人先自己談好返家時間，再說學校需要配合什麼。 | false | 導師已請兩人先私下確認返家時點，只回報學校需配合處。 | 尊重家庭但資訊有限。 |
