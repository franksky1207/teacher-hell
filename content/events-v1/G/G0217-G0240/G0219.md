| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 任課同事固定和跑團跑，見大家都加速便跟上。後來試過較慢配速反而能完跑，開始留意剛加入的導師每回何時掉隊。 |
| 核心衝突 | 點破掉隊可能讓導師不再想去，默默放慢又會犧牲同事自己的訓練。 |
| 導師困境 | 可各跑各的、約只同跑前段，或接受同事的慢跑示範。 |
| 故事獨特性 | 長期跟著隊形跑的人，靠慢下來第一次看見他人。 |
