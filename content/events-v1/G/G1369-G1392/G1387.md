## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師與導師私交極好（`5-2`），平時非常留意導師在班務上的每項進度（`12-2`），但處事極講「表單回條沒收齊絕不算結案」的原則（`1-4`）。本週他發了一張本科實驗／習作檢核家長簽名條，全班已經交回三十六張，只剩四名同學忘記帶回來；這名原則派好友今天從早上開始每節下課都來辦公室催促導師（`10-2`）：「哥／姐，那四張簽名條到底什麼時候交？科內規定今天三點前要統計完，你幫我盯一下他們打電話給家長啦！」 |
| 核心衝突 | 親近又講原則的好友同事把原本屬於本科回條催繳的工作不斷轉向導師，但那四名學生家長白天都在上班、不可能為了張小回條立刻送到學校。 |
| 導師困境 | 看在好友交情與他的原則份上自己花午休一一打電話向四名家長確認口頭同意並協助紀錄補件（幫好友在三點前結案，導師卻平白失去午休且替別科收尾）；笑著提醒好友這是他本科回條、先交三十六張並在表上註記四張明日補齊（守住原則彈性與自身休息，這名執著當日結案的好友卻急得在辦公室一直看時鐘）。 |
| 故事獨特性 | 沒有誰擺爛不寫作業，寫出「差四張家長簽名條」時，講原則的好友同事與導師之間為了今日三點死線的辦公室催繳拉扯。 |
