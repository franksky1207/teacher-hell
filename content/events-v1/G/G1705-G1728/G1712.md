## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校內球場的短場練習開始前，學生開心地替兩組排了自己選的熱身歌，想親自把一首從頭播完。他發現門邊的音箱把等候者都吸到入口，兩隊竟同時找不到讓位方向。他先停播通知導師，說願從原來堅持的場邊整首改成移到場外畫線處，只是自己很想讓晚到的同學也聽見副歌。 |
| 核心衝突 | 通道要先恢復，歌曲最受歡迎的段落卻會讓場內的人往回聚。學生介意的是還能不能親手安排一段共有的歡呼。 |
| 導師困境 | 場地確認安全後，可短播保留辨識度的副歌並讓等候者先在安全區站好，沒完整播完但同學仍聽得到；或完全改為場外由學生帶短節拍，讓動線不靠音箱引導，學生失去最想讓別人聽見的原曲段。 |
| 故事獨特性 | 原以為播給朋友聽，卻把一大群人都叫到入口，需重新選擇想聚集的是聲音還是人。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：短場練習還沒開打，student_a興高采烈地抱來小音箱想幫兩組播自己排的熱身歌，沒想到門邊音箱一響，等候的同學全聚在入口處，兩隊人馬進退不得直接卡成一團。
- **P02｜旁白**：student_a一看通道被堵住，趕緊自己先把音樂按停、把大家疏散開來，才跑過來找我，手裡還抱著音箱有點捨不得。
- **P03｜student_a**：老師，通道我先清空了！我們可以移到場外畫線那邊……可是我原本想整首放完給晚到的幾個同學聽副歌，這樣是不是得切掉了？

| C | 「這首別用大音箱放給全場了，音箱放安全區桌邊轉成低音量，想聽的同學經過時自己靠過去聽一下。」 | false | 將音箱改為安全區桌邊定點低音量播放，不集合人群而由學生分散經過聆聽。 | 徹底避免人群同時聚攏，但少了大家一起聽歌歡呼的群體感。 |
| D | 看他乖乖先按停清空通道、抱著小音箱卻一臉失落，明明只是想讓晚到的朋友也聽見那段副歌，我有點捨不得這份熱情被澆熄，乾脆先站到場外畫線後面拍兩下手：「線後面劃好了！老師幫你盯門口不准堵人，副歌放下去，我們在這條線後面一起歡呼！」 | true | 因不捨學生熱心被潑冷水，導師親自站至場外安全畫線處擔任門口動線把關並帶頭鼓掌，讓student_a安心播放副歌。 | 成全了學生想共有歡呼的心意又守住通道安全，但導師得全程站在畫線旁盯人。 |
