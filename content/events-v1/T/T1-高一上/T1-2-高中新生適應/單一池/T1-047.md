## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 第一週銜接練習都順利完成的學生，第二週希望導師替自己爭取全面免做，覺得繼續練習沒有意義。 |
| 核心衝突 | 照顧已熟練者與保障課程完整性都合理，單次順利卻不足以推出所有內容都已會。 |
| 導師困境 | 如何請相關科任依實際學習證據評估替代任務，同時避免由導師承諾本科豁免？ |
| 故事獨特性 | 不比較班排名；焦點是以初期熟練證據要求改變學習程序。 |

## 5｜R1～R8共用結果、結算與4×8因果矩陣

### R1｜他其實只會其中一章

- **玩家可見結果**：{{student_a.name}}核對後發現自己熟練的是國中接觸過的部分，新內容還沒有做過。他說想把免做改成先問能否換題。
- **客觀後果**：熟練範圍被具體限定
- **合法底層增減**：student_a:9-3:+2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-2,-1

### R2｜科任只同意部分替代

- **玩家可見結果**：相關科任依本科評估決定讓他在特定練習上選進階題，而不是長期免做。{{student_a.name}}雖有點失望但接受條件。
- **客觀後果**：本科部分替代經任課核定
- **合法底層增減**：student_a:9-3:+2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-2,1,-1

### R3｜同學說這是不公平特權

- **玩家可見結果**：有人質疑為什麼{{student_a.name}}能做不同題，他自己也不想被當成老師偏愛。你説明差異安排須由本科依需求決定。

- **合法底層增減**：student_a:8-1:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,-1,-1,-1
