## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 下班後的晚間私人時間，導師抱著一大籃剛洗好的冬衣來到巷口二十四小時自助洗衣店。在等待最後一台大型烘衣機剩一分鐘結束時，有主見（`4-3`）的導師順手把自己的洗衣籃擺在機門前椅子上，轉身去換零錢機投幣不過三十秒——回頭竟看見一名剛進門的陌生中年男子把導師的籃子往旁邊挪了一格、自己把衣服塞進那台烘衣機並按下啟動鍵！條理分明（`3-1`）的導師雖然明知「放籃子並沒有正式排隊效力、對方剛進門也未必看出這台有人在等」，當下火氣仍直衝腦門（`2-1`），偏偏自己平時極怕在公共場所跟陌生人當面爭執（`6-4`）。 |
| 核心衝突 | 私人生活裡遇上先後順序模糊又略顯粗魯的搶機插曲，導師明知對方未必故意或未必認「籃子佔位」，卻在「壓下火氣怕吵架而乾等下一台」與「上前條理說清楚討回先來後到」之間內心天人交戰。 |
| 導師困境 | 深吸一口氣走過去條理清晰地向對方說明「剛才我去換零錢、那籃是我先等這台的」（說清楚先來後到、也有機會讓對方道個歉或轉用剛空出的旁邊小台，卻要冒著對方回嗆「放個籃子誰知道」而把洗衣服變成街坊口角的風險）；咬牙把一肚子火吞下去、默默拎著籃子坐去角落等旁邊另一台烘乾（完全避開衝突維持風度，但整晚原本安排好的休息時間全毀、回家還在氣自己連句話都沒敢說）。 |
| 故事獨特性 | 完全離開校園與教師職稱的純粹大人街坊日常，寫出連平常在教室能鎮住四十個學生的老師，下班遇到無賴路人時也一樣怕吵架又氣得要命。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：換零錢機吐出最後兩枚硬幣時，那台大型烘衣機已轉起來。我的籃子被移到旁邊。
- **P02｜陌生男子**：這台空的，我就用了。
- **P03｜旁白**：我腦中已排好三句話：我先來、我去換錢、你挪了我的籃子。但牆上沒有籃子排隊的規定。
- **P04｜導師**：那個籃子……
- **P05｜旁白**：他低頭滑手機。我攥著發熱的硬幣，剩下半句卡在喉嚨裡。
