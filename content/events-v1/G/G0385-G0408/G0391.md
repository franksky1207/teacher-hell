## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長手上有一盒工作用的高品質畫筆，聽孩子說課堂效果不夠好就衝動帶去。導師據此宣布每組都可混著使用，家長當場把其中幾支拉回，要求下次先試各筆用途再分。 |
| 核心衝突 | 共享能讓學生比較媒材，但把高品質當萬用會毀掉畫筆，也會教錯媒材的差別。 |
| 導師困境 | 可只取家長認可的幾支做短試、全數退回改用校用品，或按用途設一個由教師負責的比較桌。 |
| 故事獨特性 | 資源足以開出新的教法，只有知道何時不該用才是真正學會。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「等一下，這支不是拿來攪顏料的。」家長伸手扶住紙盒，幾支細筆在裡頭碰出輕響。孩子說課堂畫不出想要的效果，他一時熱心，把自己平常用的筆帶來了。你剛說可以分給各組，他便抽回其中兩支。「這個毛碰到那罐會壞掉。我先留幾支給你們試，知道要畫什麼再分，好不好？」桌上的顏料還沒開，學生已把椅子搬近，等你說這盒筆到底怎麼用。
