## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日睡眠不足的本班任課教師，對導師先前兩度借走自習課處理班務心懷不滿，但因極度討厭當面起衝突，口頭上每次都說沒關係，卻在辦公室默默盯著導師每節課的進出動向，最後在茶水間忍不住向別科老師酸了一句「某班導師時間真是多」，話剛好傳回導師耳裡。 |
| 核心衝突 | 表面客氣的同儕把不滿壓成暗中盯梢與茶水間風涼話，讓職場關係變得尷尬難解。 |
| 導師困境 | 直接找對方攤牌問清楚，對方大可否認並反怪導師太敏感；裝作沒聽到繼續借課，這股暗火遲早燒到學生課堂表現上。 |
| 故事獨特性 | 沒有激烈爭吵，卻精準呈現辦公室裡「當面都說好、背後盯一舉一動」的疲勞職場張力。 |

### 開場
- **P01｜旁白與當場對話**：「某班時間真多。」茶水間那句傳回來時，他還在笑著說沒關係。連日沒睡好，你兩次借自習處理班務，他口頭答應，後來卻總看你幾點出教室。你已把自己借課的紀錄與該補的部分向原窗口釐清，沒拿傳話逼他認。他低頭沖杯子：「你不是還有班要忙？」水早就滿過杯口。
