# T2-001～030 跨日共用池時間語意複查與修正（2026-11-23）

## 問題根因

`T2-1:before` 30 篇共用 **2027/03/31、04/01、04/02、04/07、04/08** 五個合法抽選日。`quota_date` 只記創作配額分配，不是故事唯一演出日期。正式 V1 上線後，部分文字卻把配額日當唯一發生日，尤其 T2-030 寫明「4/8 最後一天」及「明天比賽」，T2-029 與 T2-019 亦有指定日期／次日含義。此為**內容時間合法性錯誤**，不應只靠配額日或四碼機械檢查放行。

## 全批審查範圍

逐篇檢查 30 篇的標題、四欄摘要、四碼故事用途、開場 P01～P03、四個教師選項短句／已完成事實／取捨、R1～R8 標題／正文／客觀後果，以及 AVG 結果頁。

- 30 篇 × 5 合法日逐日確認：故事並無**一定在比賽前一天**、**明天就要上台**、**活動前最後一次彩排**或**指定 4/7～4/8 發生**之未另加播放條件的情節。
- 所有故事保留 2027/04/09 的正式活動日與 `T2-1:before` 池歸屬；不把單場班呼與校歌合一比賽拆成兩場。
- 不改 `quota_date`：五天每天分配六篇為**創作配額**，不等於每天限定六篇只在該天播放。
- 30 篇 AVG JSON 仍可解析；**240/240 結局的正文與 AVG 分頁文字逐字一致**。
- 原教師 V3、四碼增減、種子、八 R 編號及 4×8 權重不變。本次修的是敘述時間歧義，不是故事結算規則。

## 驗證邊界

本次以 GitHub 逐檔讀取 30 篇、解析原稿 AVG 並比對 240 個結局，確認日期鎖定用語與正文／AVG 無偏差；新增 Node 回歸測試由本 PR 的 Story tooling checks GitHub Actions 執行驗證，以 CI 結果為準。

跨日時間相容性為**語意審查**；regex 測試只能防止已知模式復發，不足以代替未來所有故事逐日閱讀。若未來另設實際播放日條件，必須公開寫進合法資格及回歸測試，不可暗改共用池故事的先決條件。
