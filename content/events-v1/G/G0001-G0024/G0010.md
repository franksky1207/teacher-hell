## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長臨時替孩子送餐，看到班規要求中午不要為取餐離開樓層，便希望導師讓自己的孩子在樓梯口領取。 |
| 核心衝突 | 家長在意餐點可食及照顧安排；學生既想接受照顧，也不想讓同桌認為私人請託能跳過共同規則。 |
| 導師困境 | 導師可依校內收件流程、核對必要例外或與家長找下次可持續的交接方式，眼前餐點與安排公平都需顧及。 |
| 故事獨特性 | 親師對規則的爭議起於交付路徑，不涉及餐費或餐點評比。 |

### 開場
- **P01｜旁白與當場對話**：電話那端傳來保溫袋拉鍊聲。「我都送到了，叫他到樓梯口拿一下就好。」家長越說越急。孩子站在教室門邊，看著同桌又看你：「我想吃家裡的，可是不要說我有特權。」值勤人員確認餐點可依既有收件流程轉交，家長卻怕等到飯冷。你先說明不能讓學生自行越過樓層規定，會由成人核對可行交付方式。家長停了一秒：「那你告訴我，現在這袋到底交給誰？」
