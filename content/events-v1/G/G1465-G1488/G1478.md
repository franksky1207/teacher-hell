## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長家裡經濟負擔沉重（`7-2`），近期因孩子升學進度而極度焦慮（`2-2`），但他為人頗有同理心（`1-3`），知道導師一個人帶四十名學生也非常辛苦。今天他鼓起勇氣打電話來，先誠懇地體諒導師這陣子的辛勞（`1-3`），接著卻還是忍不住焦慮地對導師的教學深度提出質疑（`2-2`、`8-2`）：「老師我知道你很忙，可是我們家真的沒辦法送孩子去外面的昂貴補習班（`7-2`），你平常只帶基礎題複習，這樣怎麼跟人家有補習的比？學校能不能下課後多留大家半小時？」 |
| 核心衝突 | 家長的專業質疑並非針對老師偷懶，而是源自「沒有校外資源」的深層焦慮，讓導師在「守住合理工時」與「替弱勢家庭多做一點」之間掙扎。 |
| 導師困境 | 坦誠向家長說明學校正課與課間輔導的整體規劃、並整理免費的校內圖書館資源或優質公益線上課程給孩子自學（實質協助家庭又不讓導師工時無止境膨脹，但家長當下仍覺得少了老師親自盯著不夠安心）；還是為了安撫這名焦慮又體諒你的家長，答應這幾週自己下班後額外多留二十分鐘開一桌免費問問題時段（溫暖接住家庭困境，卻讓導師自己的體力與休息時間持續透支）。 |
| 故事獨特性 | 沒有任何火藥味或投訴威脅，寫出「有同理心的弱勢家庭家長」在補習軍備競賽下的無助質疑與導師的心軟兩難。 |
