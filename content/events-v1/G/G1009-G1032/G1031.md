## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日處理校內活動與獎懲案件累到快虛脫的學務處生輔組長（`2-3`），平時對獎懲比例有自己的原則（`1-4`），也願意跟導師彈性協商（`10-3`）。這次在導師準備正式送出某位學生的「小過懲處建議單」前，他找來導師介入懲處建議的提案階段（`12-3`）：「老師這案子一旦依小過建議正式送出，依校規下週就得排程召開學生獎懲委員會審議，我這週真的累到快扛不住再組會了；依基準這件事改提兩支警告也合比例，如果你願意把建議單改列兩支警告，我初審後就能依較簡便的行政簽核流程陳請主任與校長核定，不用等下週再開一次大會議好不好？」 |
| 核心衝突 | 過勞組長並非蓄意包庇，而是在法定程序與比例原則內選擇較省事的行政簽核路徑，要求無核定權的導師在提案階段主動把懲處建議降為兩支警告。 |
| 導師困境 | 體諒同事疲勞而將自己的懲處建議單改列兩支警告陳報核定，原本期待校方給出明確警惕的受害同學或家長多半質疑導師高舉輕放；堅持維持原小過建議並請組長依程序排入獎懲會審議，這名疲憊又自認已依原則協調的組長心裡難免記上一筆導師不體諒行政辛勞。 |
| 故事獨特性 | 明確區分「導師提案建議、組長初審協調、獎懲會或行政主管正式核定」三層權責，寫出基層行政在負荷過重下如何合規地「選省事程序」卻讓導師背負取捨壓力。 |
