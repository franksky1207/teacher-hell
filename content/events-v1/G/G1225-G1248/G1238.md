| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班事務或班務股長（`9-3`）這學期沒參加社團、課餘時間餘裕頗多（`11-2`），做事執行力極強（`3-3`）。但上週因為導師當著同學面指正過他漏抄一筆班會紀錄，他一直記在心裡對導師心存不滿（`5-4`）。今天輪到他負責收齊並核對全班的聯絡資料或作業封面格式，這名有的是時間又賭氣的股長刻意啟動「零彈性高標準」，只要有同學字寫歪一點、或日期寫成西元而非民國，當場全部退回重寫，還冷冷說「是老師教我們做班務要一絲不苟的」，搞得全班下課怨聲載道跑來告狀。 |
| 核心衝突 | 有空閒且心懷不滿的幹部拿「高執行力與老師自己的高標準」當武器反向卡死全班同學，讓導師夾在「公開壓下他的吹毛求疵」與「默許他借題發揮折騰全班」之間。 |
| 導師困境 | 當面叫這名股長收手、直接宣布「這批瑕疵不用重寫、老師自己收就好」，雖然立刻解救全班同學，但這名記仇的股長恐怕冷笑一聲覺得「果然老師自己講一套做一套」，以後對班務更陰陽怪氣；先把他叫進辦公室私下溝通化解上週心結再請他放寬標準，在談完之前這節下課全班的資料依然卡在他桌上發不下去。 |
| 故事獨特性 | 幹部沒有偷懶不做事，反而是「太認真、太有空、照你的標準做到百分之兩百來故意搞僵全班」，極具真實校園反抗味。 |
