## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生口才極佳（`3-1`），家裡全家都很支持他發展校外才藝或競賽（`7-1`），談起事情來很有協商彈性（`10-3`）。這學期他入選了某個校外正規藝文／體育培訓，每週固定一天下午需要請公假或事假離校練習。但學校規定請假必須提前三天交家長簽名紙本，他常因為培訓單位臨時改時間來不及簽，今天下課竟然自己用電腦打了一張「長期彈性請假承諾書」跑來找導師商量修改請假程序（`12-1`、`3-1`）：「老師我爸媽完全支持（`7-1`），以後只要來不及提前交，可不可以讓我先口頭跟您報備、隔天再補簽？如果真的不行我也可以叫我媽改成每週固定早上去警衛室先留條子啦！（`10-3`）」 |
| 核心衝突 | 聰明又會說話的學生自己設計了一套「半合法切結書」試圖繞過學校三天前送件的程序，導師雖欣賞他的主動協商，卻無權私自修改全校學務處的請假門禁規則。 |
| 導師困境 | 笑著誇獎他很有行政創意，但明確告訴他「導師無權自訂長期切結書，學務處還是得照規定提前送件、或由家長當天依急事補假程序親自致電確認」（守住校規與離校安全，但原本以為能搞定一切的學生有點洩氣）；還是帶他一起拿著這份想法去問生輔組／學務處能不能針對長期校外培訓生申請「專案學期公假表」（善用校內正規專案管道替學生解套，但要多跑一道跨處室申請手續）。 |
| 故事獨特性 | 學生沒有翹課也沒有撒嬌，而是像個小大人一樣拿著「自製切結書」跟導師條理分明地談制度彈性。 |
