## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 手頭寬裕、平常極度迴避在辦公室起衝突的本班任課教師，內心其實質疑導師最近推的早自習讀書計畫太花時間、壓縮到本科進度，但他當面從不講，只是一直默默觀察導師班的早自習動向，最後竟然自己花錢買了一套線上題庫帳號私下發給班上幾個前段生：「你們自己回家寫，別跟導師說。」 |
| 核心衝突 | 怕衝突的同事不跟導師溝通教法分歧，反而用「私下送前段生資源、還交代保密」的方式架空導師安排。 |
| 導師困境 | 拿到帳號的學生回家寫完不小心漏嘴問導師題目，導師若當場去辦公室問這名科任老師怎麼回事，對方一定尷尬否認到底；若假裝不知道，班上沒拿到帳號的中後段學生心裡又會不平衡。 |
| 故事獨特性 | 沒有任何公開爭吵，卻透過「只私下發給前段生、還叫學生保密」把職場暗潮與資源落差寫到骨子裡。 |

- **P01｜旁白與當場對話**：「你們自己寫，別跟導師說。」這句比題庫網址還先回到你這裡。他手頭寬，買得快，對早自習讀書計畫卻一直不肯當面講，只默默看你班用了多少時間。你們已把授權、可用範圍與學生該有的公平支持接好，不讓前段生替老師守秘密。他看著付款畫面：「我又不是要害他們，至少這個有題目。」
