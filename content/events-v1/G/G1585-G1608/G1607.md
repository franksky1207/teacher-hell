## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長平常其實認同導師訂的班級規範（`9-1`），只是這陣子工作負荷重到快撐不住（`11-1`）。今天晚上他加班回家已經九點，孩子拿出一張某科或班級發的「家庭生活觀察與親子訪談學習單」，要求家長簽名還要一起找照片貼上去；累壞的家長看到這張作業瞬間怒火中燒（`2-1`、`11-1`），直接打電話來質疑導師的出題專業（`8-2`）：「老師你的班規我都很配合（`9-1`），但這種作業根本都是在折磨加班的家長吧！你們老師出題前都不想想大人幾點下班嗎？」 |
| 核心衝突 | 過勞家長把對「親子作業」的積怨一次爆發在電話裡，質疑導師不食人間煙火；偏偏這類作業原本用意是促進親子互動，卻真的常變成家長負擔。 |
| 導師困境 | 先誠懇同理他的加班辛勞、當場直接准許這名學生免附照片且改用「自己觀察家中環境」完成即可（立刻消弭家長怒氣並展現務實彈性，但沒跟其他也加班的家長統一說明怕不公平）；還是道歉安撫後，隔天一早直接在班群與教室統一宣布「這張觀察單不強制親子合照、可改由學生自己寫自己的觀察」（既解決所有忙碌家庭的真實痛點，又維持全班標準一致）。 |
| 故事獨特性 | 沒有誰不負責任，寫出台灣雙薪過勞家長面對「名為親子同樂、實則考倒家長」的學習單時的真實怒吼。 |
