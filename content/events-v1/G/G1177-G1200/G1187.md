## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師這週同時支援跨年級監考與段考審題，累到耐性見底（`2-3`），平時最怕跟同事鬧得不愉快（`6-4`）。今天上課時，他沒力氣像平常一樣慢慢勸導兩個在分組裡一直小聲講話的學生，一時衝動（`1-2`）直接當堂宣布把導師班原本排好的「跨科分組名單」拆掉重配、還把這兩人硬塞進另外兩組。下課導師一進班發現原本刻意錯開衝突同學的分組被打亂、跑去問他時，這名怕起衝突的同事嚇了一跳，急忙賠笑彈性協商（`10-3`）：「對不起我這週真的太累沒耐性才當場拆掉！不然我這節下課幫你重抄貼回去，或下週換我多幫你們班看一節早自習補償好不好？」 |
| 核心衝突 | 疲憊衝動打亂同事班級分組的老師用「急忙道歉加補償勞務」來化解衝突，反而讓原本氣憤被打亂安排的導師不知該嚴肅究責還是吞下這份虧欠。 |
| 導師困境 | 順著他的賠笑與彈性補償讓他重貼一張修正名單、甚至收下他代看早自習的補償，但已經在課堂當眾被拆過一次又貼回去，那幾名原本被錯開的學生馬上猜出端倪起鬨；板起臉當場拒收補償並嚴肅要求他以後不准動導師班任何名單，這名原本就累垮又極度怕吵架的同事恐怕整個禮拜見面都低著頭閃躲。 |
| 故事獨特性 | 寫出教師辦公室裡「累到失去管教耐性而當堂拆組的同事，事後用過度補償來迴避衝突」時，受害導師反而不好發火的微妙職場人際。 |

- **P01｜同事**：我太累，沒耐性才拆。幫你重抄貼回，或下週我看一節早自習，好不好？
- **P02｜旁白**：你先接妥必要分組更正和安全支持，不拿他代班當交換。兩個原先錯開的衝突同學又碰到一起，他這才知道名單不是隨便排。

- **P04｜旁白**：他笑得很快，手已去拿新紙。你說現在還不用重抄，他僵了一下，問除了說對不起，還能怎麼跟你合作，不讓下節又一樣。
