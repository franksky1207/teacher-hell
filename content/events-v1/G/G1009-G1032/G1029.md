## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師家裡配偶全力支持他教職工作（`7-1` 讓他平時少為家務煩躁），平常十分配合導師的班務調度（`9-2`），也一向迴避在辦公室當面跟同事起衝突（`6-4`）。但今天他整理實驗室時，發現導師班學生把喝剩的手搖飲杯全塞進後方儀器櫃，當場火冒三丈（`2-1`），卻因不想當面開罵傷和氣而一言不發，只直接照程序在交給衛生組查核的《專科教室使用紀錄簿》寫下「某班遺留飲料垃圾未清、建議依規扣整潔分」並送交學務處，導師直到午休看見衛生組公告扣分名單才知道出事了。 |
| 核心衝突 | 平常配合度高又怕衝突的專科同事用「不當面溝通、直接上報紀錄簿扣分」表達無聲憤怒，讓導師連先在班內補救的機會都沒有。 |
| 導師困境 | 立刻拎著學生去向專科老師賠不是並詢問以後能否先傳訊提醒，這名怕衝突的同事恐怕低頭只回「我是照學校公事簿登記流程走」；吞下這筆扣分回班上嚴懲亂塞飲料的學生，全班卻覺得專科老師沒先講一聲就送扣分太無情。 |
| 故事獨特性 | 與私下放糖果暗示不同，寫出怕衝突同事「嘴上不吵架、但公事紀錄簿一筆不漏直接送學務處」的職場冷處理。 |

### 開場
- **P01｜旁白**：午休公告上已列扣分，你才知道儀器櫃裡那排飲料杯。同事把紀錄簿放回架上，沒有看你。
- **P02｜同事**：我照程序寫。以前調什麼我都配合，這次杯子在機器旁邊。
- **P03｜旁白**：必要查明與安全清理已接續，你也不要求他刪掉真實紀錄。他說家裡再怎麼有人幫忙，也不代表自己有空替別人的學生收飲料。
