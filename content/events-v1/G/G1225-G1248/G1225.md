## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長這陣子工作剛好告一段落、白天時間餘裕非常充足（`11-2`），但前幾晚忙著處理家中瑣事睡眠不足、身體累積深層疲勞（`2-3`）。這兩天他看到孩子放學回家連夜在剪紙板、做班級成果展示要用的手工立體道具，憑自己多年職場帶專案的經驗判斷（`3-2`），認定「成果展示根本不看道具精緻度，花八成時間做這個投資報酬率太低、純粹在做白工」。因為時間多又累到沒耐心慢慢溝通，他連續兩天來電催促導師（`10-2`）今天立刻進班喊停這組的手工道具製作、叫大家把時間省下來專攻報告內容——偏偏那整組同學就是很享受一起動手做道具的樂趣，並沒有誰偷懶或被壓榨。 |
| 核心衝突 | 有空閒卻因疲勞失去耐心的家長把職場「精算投資報酬率」的經驗套進青春期校園活動，反覆催促導師去澆熄學生其實樂在其中的手作熱情。 |
| 導師困境 | 順著家長的催促今天進班要求這組停掉手工道具製作、把時間全改回背稿與修簡報，雖然讓這名焦躁的家長安心覺得老師懂效率，原本開開心心一起剪紙板培養默契的幾個學生當場興致全無；向家長說明高中生從試錯與手作中累積的團隊樂趣同樣重要、不宜強行喊停，這名有空又疲憊的家長恐怕認定老師不尊重實務經驗、繼續頻繁來電追問進度。 |
| 故事獨特性 | 沒有偷懶組員也沒有人際排擠，寫出把職場「低效白工」經驗帶進校園的家長與享受手作過程的青少年之間，完全不同的價值節奏碰撞。 |
