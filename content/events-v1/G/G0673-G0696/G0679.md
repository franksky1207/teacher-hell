## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生每天替父親讀債務催繳信，最敬重導師曾當眾承認算錯分數。他看到導師在點名時跳過一位總遲到的好友，把自己看見的情況主動告訴對方，又直接找導師追問為何已點完卻沒記。 |
| 核心衝突 | 好友以為老師放他一馬，現在反而要面對朋友在替他記帳。 |
| 導師困境 | 導師補登符合實況但得承認自己剛才避開了，當面說明自己想先讓學生坐下則有讓其他人重新討論遲到處置的代價。 |
| 故事獨特性 | 在家總讀到「逾期」的人，對一句沒交代的寬容反而格外敏感。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：他先把看到的漏記告訴好友，才來問你：「剛才點完了，為什麼沒寫？」每天替父親讀催繳信，「逾期」兩字他看得很熟；最敬重的卻是你以前敢當眾承認算錯分數。這次你讓那位常遲到的學生先坐下，忘了把後段處理說清。你按實況補正、完成必要說明後，他仍沒走。「我不是要盯他，可是他以為你放過了。」
