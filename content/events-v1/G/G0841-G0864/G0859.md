## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 負責班費記帳的學生跟導師關係親近，這週準備檢定考累到不行仍扛著班務沒放手，跟導師商量時也很有彈性：「老師我這週太累，明細先拍照傳給你對、紙本下週補寫好嗎？」導師點開照片卻發現他累到把兩張自己昨天買手搖飲的發票也夾進去算總額了。 |
| 核心衝突 | 親近又盡責的總務學生在極度疲勞下交出混亂帳目，讓導師在「體諒彈性」與「公款嚴謹」間為難。 |
| 導師困境 | 立刻私訊圈出那兩張飲料發票要他重拍重算，怕這已經快累倒的學生緊張到整晚睡不著；先替他扣掉差額自己重算完，又等於替班務把關標準開了後門。 |
| 故事獨特性 | 沒有人想貪污班費，純粹是過勞學生與導師彈性協商時鬧出的「手搖飲混帳」烏龍。 |
