## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長家裡最近因為照顧開銷而經濟負擔沉重（`7-2`），平時雖高度肯定導師的教學專業（`8-1`），但對導師先前某次直言的語氣一直有些私人不滿（`5-4`）。昨天班上發了一張需要家長簽名的「自願課後加強班意願與預估費用單」，導師想讓學生先帶回家討論就沒先在班群預告。今天這名家長看到要繳錢的單子立刻打電話來問責（`12-4`）：「我承認你教得很好（`8-1`），但這種要花錢的單子沒先在班群公告就叫孩子帶回來，萬一學生自己亂勾報名誰負責？請你交代清楚怎麼把關！」 |
| 核心衝突 | 家長對導師專業肯定與私人不滿並存，加上家庭經濟敏感，讓他針對「未先線上預告自費意願單」直接向導師要求解釋把關機制。 |
| 導師困境 | 立刻在班群補發完整明細並坦率向該家長致歉沒有同步線上預告、同時承諾所有自費報名單據一律須家長親簽與線上雙重確認（徹底回應問責並守住把關，但等於承認自己原本流程有疏漏、還要額外做雙重核對）；還是冷靜向他解釋該單本來就白紙黑字註明「未經家長親簽絕不扣款或報名」、請他不必過度擔心（守住原本防呆設計與教師立場，卻讓這名本就不滿的家長覺得老師在卸責敷衍）。 |
| 故事獨特性 | 寫出私校家長「對老師專業肯定、卻對私人態度不滿」加上經濟壓力下，對自費項目知情流程的尖銳問責。 |
