## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生贊成導師原本要求不同意須說清楚，看到朋友都沒舉手便跟著不舉，一分析才發現大家是在等領頭者出聲。他原想重做整次班內遊戲規則選擇，聽老師說時間不足，改提只重問唯一有歧見的一條。 |
| 核心衝突 | 程序照舊，群體卻把同時安靜當成了共同意見。 |
| 導師困境 | 可重新命名雙方方案後只重問一條，消耗剩餘遊戲時間；也可本次依既有規則不改，下次等各自先想完再議，代價是這回有選擇的人仍沒被聽到。 |
| 故事獨特性 | 學生從自己的沉默推斷班上全員可能都在等。 |
