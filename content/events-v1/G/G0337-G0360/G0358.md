## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家中同住者輪夜班，學生放學後要保持安靜不能開燈唸書。他注意導師總在下課用一張低桌整理，便帶同學清出下課可用的共同練習桌。幾個同伴想把它留給自己的小組，鬧到他也要有約才可坐。 |
| 核心衝突 | 提議者也需要座位，做過清理不等於有專屬權；把桌直接收掉則會讓靠這裡學習的人再失一個地方。 |
| 導師困境 | 可採公開輪用、分開小組和靜坐時段，或不再保留特殊桌但讓需求轉到合法空間。 |
| 故事獨特性 | 由使用困難者開出來的公共空間，最後有可能先把他排除。 |
