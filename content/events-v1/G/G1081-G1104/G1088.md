## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生因拒絕跟著同學在課堂起鬨而遭小團體冷落。家長連日加班又趕著搭機出差，疲憊不堪（`2-3`），昨晚仍與家人陪孩子討論，肯定他不必為了合群而違背自己的判斷（`7-1`）。家長自己也不認同遇到摩擦就要求孩子先低頭的做法（`6-2`）。登機前二十分鐘，他致電督促導師今天就與孩子商量一個遇到起鬨或排擠時可自行求助的方式（`10-2`），還希望導師每天主動關心一次，因為出差期間自己無法隨時接電話。孩子先前卻曾向導師表示，不想被同學看成需要大人特別保護的人。 |
| 核心衝突 | 家長支持孩子獨立判斷，卻因疲勞與即將出差而急於建立密集的成人關懷安排；孩子希望保有自行求助的自主性，不願被特別照顧的身分曝光。 |
| 導師困境 | 先了解孩子意願與排擠程度，依需要啟動適當輔導及校內處置，並確認出差期間可聯絡的監護人。若與孩子約定低調的固定關懷時間，家長較安心，但孩子可能感到被監看，導師也須持續投入時間；若與孩子共同約定自主求助訊號及可接觸的校內支持者，並依實際情況追蹤，較能維持孩子的自主感，卻可能讓希望每天得到確認的家長不安。兩種安排均不得忽略持續排擠或安全風險。 |
| 故事獨特性 | 登機前的限時督促不是要求公開裁決，而是家長一面支持孩子不從眾，一面因無法陪伴而想增加成人保護；導師須在關懷密度與學生自主性間取得平衡。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：電話那頭先響登機廣播，接著是家長壓低的聲音。
- **P02｜家長**：我只剩二十分鐘。他不跟著鬧是對的，我們家都這樣跟他說。可是我飛出去，你每天能不能主動問一下？
- **P03｜旁白**：必要求助和校內支持已接妥，另有可聯絡的監護人。你想到孩子昨天說：『不要每節下課都叫我，大家會看。』
- **P04｜導師**：問的方式，我想先聽他自己。
- **P05｜家長**：我不是叫他低頭，我是怕沒人記得。
- **P06｜旁白**：拉鍊聲很急，他說等一下要關機，又問你今天能答應多少。
