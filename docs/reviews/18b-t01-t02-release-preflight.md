## 二、已核實的法規與制度邊界（官方來源）

1. **補考／重修與學分**：依 [高級中等學校學生學習評量辦法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=H0060060) 第10～12、14條，學期補考原則上一次，核准請假者得補行考試或其他評量；重修、補修有開班門檻與取得學分的個別規則。**重修三人報名不等於學校尚未決定開班**，也不能憑不及格推定正式未取得畢業證書；需觀察真實個人紀錄、正式公告與時點。
2. **成績與個資**：依 [個人資料保護法](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=I0050021)，成績及能直接／間接識別學生的學籍資訊需要核對利用目的與公開範圍；學校已核定措施、考卷、截圖與個人說法不可混成已查證事實。法規如有部分修正條文尚未施行，須按遊戲實際年度及生效狀態查驗。
3. **疑似校園性別事件**：依 [性別平等教育法](https://edu.law.moe.gov.tw/LawContent.aspx?id=FL030508) 第22條及 [校園性別事件防治準則](https://edu.law.moe.gov.tw/LawContent.aspx?id=FL034837)，符合疑似校園性別事件的知悉情境有立即依校內機制通報及權責調查要求；單純學生對課堂笑話不舒服並不等於已判定構成校園性別事件。故事需判斷是否進入法定疑似門檻，不能讓玩家抽選決定是否免除必要程序。
4. **升學程序**：以 [大學甄選入學委員會](https://www.cac.edu.tw/) 當學年度招生簡章核對繁星校內推薦／申請入學結果、個人報到與放棄程序。推薦不等於錄取；一階通過不等於最後錄取；家長也不能憑空代替學生完成正式程序。校內推薦排序、公告及更正還須依學校合法公布程序核實。
5. **分科與分發**：依 [大學考試入學分發委員會官方重要時程](https://www.uac.edu.tw/flow.htm)，各年度正式登記志願與放榜日應以該學年度考分會最新公告為準；例如考分會目前公布的116學年度時程列出116年8月1日至8月4日登記、8月13日放榜。**不能以特定學年度日期推定2029年日期**。三年制第一屆暑輔起始2026年的畢業後時程尚未納入首發生涯，因此`T02-07-17`及分發放榜後劇情仍必須隔離，不能用學期中的草稿志願表冒充正式登記。

上述是**風險定位與必要前提**，不是判定清單內每篇故事違法。遊戲故事中的科任、行政、導師行動應依實際權責與已知證據逐件確認。
