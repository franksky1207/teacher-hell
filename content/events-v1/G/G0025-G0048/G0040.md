## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校內行政同事觀課後很欣賞導師帶討論，為給私校內部教學交流多一個示範，希望導師立刻在下一堂再演一次；學生卻說上一堂是真吵起來，現在只想休息。 |
| 核心衝突 | 被看見的有效教學值得分享，但把自然討論演成成功示範會耗掉學生的休息和真實回應。 |
| 導師困境 | 導師可拒絕重演、只分享成人能重現的教法，或等學生另一次真正想談的課再邀觀課，須承受行政期待及學生疲憊。 |
| 故事獨特性 | 行政想複製教學亮點，現場學生卻仍在消化剛發生的分歧。 |

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「太好了，下一節再來一次吧！」觀課的行政同事還興奮地拿著筆，教室裡已有人趴下：「剛剛是真的在吵，不要再演了。」你沒答應動下一節課，先讓學生下課休息。同事說想留一個教學交流示範，不是拍熱鬧，還想看你怎麼帶。聽見他誇那段，你忍不住笑，回頭卻看到學生連椅子都懶得挪。「那你哪時候方便？」他打開行事曆，筆尖停在下一節。
