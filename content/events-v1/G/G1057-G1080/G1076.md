## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 總務或校安職員這陣子排班空檔時間較充裕（`11-2`），校園防跌安全意識很高（`9-4`），也非常支持導師禁止學生在走廊追逐奔跑的立場（`10-1`），但個性向來迴避跟老師或學生當面起衝突（`6-4`）。上午他巡邏發現導師班外走廊有一塊磁磚微微翹起可能絆倒人，不想進教室打斷上課、也怕大聲提醒讓學生緊張，只默默在角落放了兩個迷你反光錐就走人、也沒留字條通知導師。結果鐘響全班一湧而出，走在前排沒看腳下的兩個學生差點把小三角錐踢飛絆倒在翹起磁磚上。 |
| 核心衝突 | 怕衝突的安全職員用了太低調的「無聲警示」，反而在人潮洶湧的下課動線製造了新的絆倒風險。 |
| 導師困境 | 立刻跑去找這名好心的同事確認到底什麼時候能圍起來修好、並委婉提醒下次一定要當面或傳訊跟導師說一聲，這名最怕衝突的同事多半紅著臉連連道歉覺得自己沒做好；自己先在教室門口用大張海報紙貼出顯眼封鎖線並提醒全班改走後門，雖守住安全卻得一直替總務處擔著門前動線改道的麻煩。 |
| 故事獨特性 | 沒有誰忽視安全，反而寫出「太怕打擾別人、把安全標示放得太客氣」在高中生下課人潮面前差點反效果的現實感。 |
