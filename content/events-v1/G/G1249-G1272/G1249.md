## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學校總務修繕工友對校園防滑安全意識極高（`9-4`），看到導師班這週有位學生腳踝扭傷拄拐杖來上課，心裡十分同理不捨（`1-3`），今天一早便主動投入人力（`11-3`）把導師班教室門口的階梯防滑條重新壓實鎖緊、還搬來一個簡易拐杖靠架放好。但因為上週導師曾當眾催過他「水龍頭怎麼修那麼慢」，他一直對導師心存不滿（`5-4`），全部弄好後連招呼都沒打就轉身離開，只在講桌留了一張字條：「給受傷同學用的，免得又被說動作慢。」 |
| 核心衝突 | 心軟又盡責的基層同事一方面默默替導師班學生做好安全防護，另一方面又用冷臉留字提醒舊怨，讓導師在受惠道謝與化解尷尬間無所適從。 |
| 導師困境 | 立刻拿著飲料或親自跑去總務休息室當面跟這名工友誠懇道謝並順便為上週催修語氣致歉，怕這名還在氣頭上的老同事臉更臭、丟下一句「不用客套」更尷尬；只當沒看見那張帶刺字條、僅叫學生自己去謝謝阿伯就好，這名辛苦幫忙又心裡有疙瘩的同事恐怕認定導師擺架子不領情。 |
| 故事獨特性 | 沒有誰推卸責任，寫出基層校工「心疼孩子受傷就默默修好，但對老師的氣還沒消」的可愛別扭人情味。 |
