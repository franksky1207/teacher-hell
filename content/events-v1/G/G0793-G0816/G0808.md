## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 私校評鑑與招生簡報前夕，高層要求各班繳交成果亮點牆。教務處職員雖然也焦慮評鑑沒過會被檢討，但判斷評審早看膩了拿獎狀排排站的照片，不願跟風做罐頭版面，主動找導師協調合作，想把導師班上「做失敗但過程超好笑的實驗紀錄」放進大廳展板。 |
| 核心衝突 | 行政職員想靠真實有趣的反差突圍評鑑，導師卻擔心學生出糗畫面被校方拿去公開展示。 |
| 導師困境 | 答應提供素材，得先說服學生接受自己的失敗瞬間變成招生大廳看板；拒絕合作，職員又得趕在死線前交出另一套毫無特色的罐頭照片交差。 |
| 故事獨特性 | 私校評鑑壓力下，行政人員主動提案反套路，把「招生包裝」與「學生隱私面子」擺在同一張桌子上談。 |
