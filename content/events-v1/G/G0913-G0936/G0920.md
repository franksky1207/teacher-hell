## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生住在離學校步行五分鐘的自家老宅，家庭生活多年安穩且阿嬤與父母平日都會在家照應，先前也告訴過孩子「帶同學來大客廳寫作業沒關係」（`7-4`）。他口條流暢（`3-1`）、與導師關係親近（`5-2`），在班上很有號召力（`6-1`）。這天放學後他一口氣邀了十幾位同學去家裡客廳趕分組報告，自己傳訊跟導師開心報備（`5-2`），但其中幾位同學沒先跟自家父母說清楚，家長見孩子沒照時程到家紛紛打電話來問導師人在哪。 |
| 核心衝突 | 學生在自家長輩同意下熱心提供大客廳招待同學，卻因同儕各自沒向家裡報備，讓導師在未親眼確認實際名單的情況下接到家長追問電話。 |
| 導師困境 | 先直接打電話請同學家裡的阿嬤或父母幫忙逐一點名確認誰真的在客廳，再回覆各家家長，雖然穩妥卻讓親近的學生覺得老師連他的話都不信；只把學生回報的訊息轉述給家長並要求學生立刻各自打回家報備，萬一中途有人其實沒走進去而去別處逛街，導師也無從擔保。 |
| 故事獨特性 | 把「住校旁有長輩在家且開放客廳的穩定家庭條件」寫成放學後聚會的真實親師確認難題，不靠一句「叫大家回家」收尾。 |
