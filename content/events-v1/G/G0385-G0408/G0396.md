## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長平日晚間工作與共同照住家安排撞期，多次打進學校都要重新解釋。他有自己的工作壓力，提出把逐人轉接改為一次受理並回電。 |
| 核心衝突 | 學校沒法要求每位來電者反覆轉接，教職員也不能因此兼做全天窗口。 |
| 導師困境 | 可在職權範圍內答一次、請合規承辦改排或承認本日辦不了。 |
| 故事獨特性 | 家長求的不是多一通電話，是確定不必把同一段私事重演。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：電話接起來，家長先問：「不好意思，我又要從頭講嗎？」背景有人在催他出門上晚班。他前兩次談到一半就得換人接手家裡的照顧，這次剛說到住處共用的房間，聲音又低下來。「我不是要現在就有答案。我只剩這幾分鐘，能不能下次有人接得上？」你翻開先前留下的重點，裡面還有兩處沒問清楚；桌上的下班提醒亮了。
