## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班衛生或班長（`9-3`）全力支持導師「週五放學前清空桌面抽屜以便徹底清掃」的立場（`10-1`），講話做事極具條理（`3-1`）。今天早自習後他拿著一份寫得清清楚楚的三點檢討表進辦公室要求修改實施時段（`12-1`）：「老師，放學前大家忙著收書包又趕校車，抽屜都亂塞一通！我建議改成週五午餐前十分鐘就先清空抽屜檢查完，下午打掃速度一定快兩倍！」 |
| 核心衝突 | 條理分明又挺導師的幹部提出高效率改期案，但若午餐前就清空抽屜，下午還有兩三節正課的課本沒地方放、全堆在桌面或地上反而更容易弄亂。 |
| 導師困境 | 順著他條理分明的提案本週試辦「午餐前清空抽屜」（鼓勵幹部理性思考管理流程，但下午正課時全班課本堆在腳邊或桌上疊成小山、科任老師進班看了直搖頭）；當場條理點出下午還有三節課要用的實際動線問題、維持放學前清空但把時間提前五分鐘開始（守住下午課堂桌面整潔，這名自認算得無懈可擊的幹部卻有點不服氣）。 |
| 故事獨特性 | 沒有誰想偷懶，寫出「只算到清掃效率、沒算到下午還要上三節課」的高中理性派幹部可愛盲點。 |
