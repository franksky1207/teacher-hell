## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師生活與教職環境安穩（`7-4`），一向支持導師的立場（`10-1`），但對自己的課堂與作業節奏很有自主想法（`4-3`），同時極度迴避與行政處室發生正面衝突（`6-4`）。前幾天某處室試辦一份非強制的學生學習自評表，導師跟這位同事溝通過都覺得不必增加學生無謂負擔，這名同事也口頭支持導師的看法（`10-1`）。沒想到這名怕衝突的科任（`6-4`）私下為了不得罪行政，轉頭竟然在自己課堂上照自己的步調默默多印一份發給學生填寫（`4-3`），害學生滿頭霧水跑來問導師到底要不要寫。 |
| 核心衝突 | 同事表面支持導師卻因衝突迴避而做出兩套作法，讓學生無所適從，導師夾在揭穿同事矛盾與替同事收拾混亂之間。 |
| 導師困境 | 直接私下找這名科任問清楚、請他把班上統一的填寫標準講明白（立刻釐清學生無所適從的混亂，卻讓這名極度迴避衝突又重視自主的同事非常尷尬）；還是自己出面在班上幫同事圓場、把多出來的那份表單併成極簡版讓大家兩分鐘勾完（替同事保住台階與職場和平，卻讓導師自己與學生平白多做一份原本說好不做的表單）。 |
| 故事獨特性 | 寫出教師職場上常見的「私下說好一起擋掉無謂表單、結果有人怕得罪處室自己偷偷做了」的尷尬默契破裂。 |
