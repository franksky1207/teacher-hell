## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一位看太多社會新聞而極度重視孩子安全的家長，因為在親師溝通後非常肯定導師的應變專業，溝通起來又順暢愉快，竟養成每週固定打電話給導師「請教專業建議」的習慣——從補習班走廊照明到選修課怎麼挑，一聊就是半小時還意猶未盡。 |
| 核心衝突 | 家長對導師的高度專業肯定與良好溝通，反而變成了無法拒絕的長期時間黑洞。 |
| 導師困境 | 直接告知自己很忙請她長話短說，怕澆熄這位原本超好溝通的家長信任；繼續每週陪聊半小時，導師自己的備課與休息時間正被悄悄吞光。 |
| 故事獨特性 | 親師關係極好、沒有任何衝突，卻因為「太肯定你」而讓導師陷入甜蜜的負擔。 |
