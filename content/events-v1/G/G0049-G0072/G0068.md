| 固定欄位 | 故事摘要 |

| 事件起因 | 下樓時一名學生故意跨過兩階向同學炫耀，後面真的有人學，他自己差點踩空，還向導師說班上都走得來。 |
| 核心衝突 | 當場有人必須阻止跟做，若只公開抓帶頭者，學生可能把制止視為要他認輸，繼續向同伴表演。 |
| 導師困境 | 導師先停止危險行為，再決定如何讓他當面收回示範、私下談及影響，或讓另一位同學協助大家重新排好。 |
| 故事獨特性 | 事實上已被自己的示範嚇到的人，為了同儕地位仍嘴硬。 |
