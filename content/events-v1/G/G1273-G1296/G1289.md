# 過勞卻擅用雲端表格的家長自製「班務懶人包」反貼出舊日期

| 欄位鍵 | 填寫值 |

| `quota_date`｜配額歸屬日 | 無 |

## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家境寬裕的家長（`7-3`）對數位工具與雲端表單極為熟練（`3-4`），平時也非常關注導師在班群發布的每則消息（`12-2`）。但這週他公司加班連軸轉累到頭昏眼花（`2-3`），嫌班群訊息洗版太長不好找，昨晚就自己動手把導師近一個月的公告抓進一份公開雲端儀表板連結、一早丟進班群熱心喊「大家看我整理好的一鍵總表比較快！」——結果疲勞之下他漏看了導師前天更正的兩項繳交日，把舊日期標成紅字置頂了。 |
| 核心衝突 | 疲勞卻自信的數位熟手家長好心替全班做訊息懶人包，卻因為漏看更正而把錯誤舊日期廣泛傳給其他家長，導師必須即時止血又不想傷了這名累壞家長的好意。 |
| 導師困境 | 直接在班群公開點出那份家長自製雲端總表裡有兩項日期錯了、請大家以導師原始公告為準並請他撤下連結（最乾淨徹底避免誤會，但這名熬夜加班還抽空熱心做表的家長當場在全班家長面前很沒面子）；私訊請這名疲憊家長自己修改雲端表同時只在班群發一條「部分日程有微調」的柔和提醒（給足家長台階下，卻要冒著家長還沒改完前已經有別人照舊日期行事的風險）。 |
| 故事獨特性 | 沒有人惡意造謠，寫出當代家長群最常見的「熱心工程師／主管家長幫老師整理班務 Notion／試算表卻弄錯版本」的數位時代烏龍。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：你在群組明確更正兩個日期，貼回原公告。家長的儀表板連結還在上一則，他私訊說昨晚太累漏看更新。
- **P02｜parent_a**：我只是想大家別一直往上翻。那兩格我改掉就好吧？
- **P03｜導師**：日期得明確更正，也要處理舊版不能再誤導。不是把紅字換掉就沒人照舊了。
- **P04｜parent_a**：我知道。這東西做得很快，丟掉也可惜。老師你平常有更新就提醒我一下？
- **P05｜旁白**：他又把原始表編輯畫面傳來，你看見自己的公告正變成另一份待維護工作。
