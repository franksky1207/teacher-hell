## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師這學期課表較鬆、時間餘裕相當充足（`11-2`），平時在辦公室看起來總是心情愉悅（`2-4`），遇到事務也願意跟導師協調合作（`10-4`），但其實心裡一直對上次導師沒等他對齊成績單就先送件留有一點不滿（`5-4`）。今天導師臨時需要找同事協調對調一節自習監考，這名有空的同事立刻笑咪咪走過來答應幫忙（`11-2`、`2-4`、`10-4`），卻在收尾時笑著補了一句帶刺的話（`5-4`）：「沒問題呀我時間最多了，哪像老師你上次急著送件都不等我，這次我一定配合到底啦！」 |
| 核心衝突 | 同事嘴上笑著答應合作、實際也在幫你，卻順便用微笑包裝舊怨酸你一句，讓導師陷入「要假裝沒聽懂」還是「當場把結解開」的尷尬。 |
| 導師困境 | 順著他的話先坦率把上次急著送件的行政死線誤會誠懇解釋清楚並致意（趁機解開積怨讓合作不再帶刺，但可能把原本輕鬆的對話氣氛變嚴肅）；還是笑著打哈哈帶過這句酸話、單純就這次監考協調向他道謝（維持表面辦公室和氣並順利解決眼前的事，但這根刺還是留在兩人之間）。 |
| 故事獨特性 | 沒有大吵大鬧也沒有拒絕合作，純粹寫出台灣教師辦公室裡最真實的「笑著幫你忙、順便笑著酸你一句舊怨」的職場微妙空氣。 |

【待填：階段三AVG】

### 開場
- **P01｜teacher_a**：沒問題，我時間最多。哪像你上次送件那麼快，連我都不用等。
- **P02｜旁白**：他笑著接過普通自習調換需求，還替我翻到有空的那格。我先把必要課務核定和照看接續說清，不把一句沒問題當流程全成。
- **P03｜導師**：你還在意上次？
- **P04｜teacher_a**：沒有啊，我這不是很配合嗎。
- **P05｜旁白**：他的笑一直在，我的謝謝卻卡在那句沒有和很配合之間。
