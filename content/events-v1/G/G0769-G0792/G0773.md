## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生敬佩導師教他如何把零散句子接成演說，答應公開朗讀就覺得要說完，幾天都主動留意導師是否會來聽。到場發現主任搶先拿他最開頭的一句當招生標語，他氣得想把原來致謝老師的那句也略掉。 |
| 核心衝突 | 學生越想讓導師聽到自己的話，越生氣這句先以校方名義被人說過。 |
| 導師困境 | 導師可請學生照自己的稿子從頭再講，承擔同一句話在兩種意圖下重複；也能讓學生跳段，放掉兩人曾最得意的銜接。 |
| 故事獨特性 | 校方把一句話看成漂亮成品，作者才發現要等的人一直是教會自己怎麼說的人。 |
