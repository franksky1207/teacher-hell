## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長事業長期步上軌道、生活作息安穩（`7-4`），近期將業務交給合夥人後時間餘裕非常充足（`11-2`），內心十分渴望在家長圈中被認可為「最消息靈通、最替班上搶先機的熱心家長」（`4-4`）。每天早自習前或午休，他只要在學校網站或外校交流佈告欄瞄到任何兩個月後的跨校營隊、講座或參觀預告，就立刻截圖傳訊督促導師（`10-2`）：「老師你看官網剛貼了這個預告，趁別班導師還沒看到，你今天能不能先幫我們班開表單搶登記或把名額留起來？」其實學校根本還沒公布各班報名辦法。 |
| 核心衝突 | 有閒又愛搶先功勞的家長把「學校遠期行事曆預告」當成限時搶購，天天督促導師提前幫班上私下卡位，與校方統一作業步調完全脫節。 |
| 導師困境 | 順著他的熱心提前去教務／學務處幫這名家長問「能不能先幫本班留幾個名額」，承辦同仁多半覺得莫名其妙、甚至反感導師帶頭搞特權搶跑；禮貌回覆他目前還沒開放報名、請等正式通知即可，這名時間多又渴望被誇讚眼明手快的家長難免掃興，甚至自己跑去家長群先發「我已經提醒老師幫大家注意名額了」讓導師下不了台。 |
| 故事獨特性 | 不是行政人員催表單，而是「太有空又想當班群消息王的家長」把校網遠期預告當成搶頭香來催老師卡位，呈現私校家長資訊焦慮的另一面。 |

- **P02｜旁白**：他近期把業務交給合夥人，早自習前和午休都能巡一次網站。你說只是兩月後預告，沒有名額可替誰留，必要正式資訊會公平提供。
- **P03｜家長訊息**：那總能先準備吧，我在群裡已說我們班最先知道。
