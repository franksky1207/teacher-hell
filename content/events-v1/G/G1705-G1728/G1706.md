## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生看教室內畫錯的字一直沒人擦，手邊有自己買的大橡皮，一時衝動把共同草稿擦去一截。怕原作者生氣，他先來找導師，希望以後大家在擦前先畫可刪區，自己卻拿不出完整舊稿。 |
| 核心衝突 | 導師看得到他想避免第二次，原作者最想要的卻是先補回第一次。 |
| 導師困境 | 可請作者挑回要重寫的段、讓學生協助，代價是兩人要當面回看；或把原稿殘片留在原處再開一份，原作者仍須決定是否從頭。 |
| 故事獨特性 | 一塊原為修錯買的橡皮，讓學生第一次希望先保留錯字。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：下課才過三分鐘，student_a就捏著一塊被削去一角的大橡皮溜進辦公室，低著頭小聲承認自己剛才看班上共用草稿裡有幾個錯字一直沒人擦，一時手癢順手一大塊擦了下去。
- **P02｜student_a**：老師……我以為那段是廢稿，結果擦完才發現我根本背不出來原本寫了什麼！原作者等一下進教室看到一定會生氣……以後大家擦之前可不可以先畫好可刪區啊？
- **P03｜旁白**：他一隻手緊緊攥著那塊大橡皮，既想立馬訂個新規矩避免下次再犯，又明顯不敢自己走回座位面對原作者。
