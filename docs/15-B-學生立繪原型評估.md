## 1. 原型成果

第一輪使用一張橫向整合概念圖，呈現四名**虛構美術樣本**的日系動漫風臺灣高中制服半身形象（兩男兩女），並以其中一名女生示範六種表情，以及制服、運動服、便服三種服裝方向。

原型最初透過 ChatGPT 圖像產生，原始圖檔存在本輪對話附件／交付 ZIP；**目前尚未納入 GitHub 儲存庫**。圖片上的角色姓名、個性說明、勾選完成項目均為圖稿中的示意排版，不能視為正式人物資料或工程驗收證據。

視覺觀察：
- 優點：整體人物線條與色調相近，臺灣高中白襯衫＋深色配件的制服語彙可行；四名學生在髮型、髮色、眼鏡與體態上有初步區別。
- 不足：圖中人物姿勢及構圖尚不一致，且只有整張平面點陣圖，部分示意角色與服裝、表情相互連在一起；沒有臉／髮／身／衣的透明獨立圖層。
- 六種表情為**同一張概念稿中的六個小肖像**，並不是可由正式故事 `expression` 驅動的可替換圖層。且原圖的表情標記與視覺情緒不必然一一準確，需要逐圖人工核對。
- 三種服裝僅為概念對照，不是能與相同身形、同錨點無縫置換的獨立服裝圖層。原圖上的「可擴充40人」只是設計方向，**沒有經過40人相似度或組合容量測試**。

## 3. 接下來的最低可行工程／美術步驟

1. **先確認美術風格**：本次整合圖僅作初步視覺方向參考。正式學生素材不得照搬圖上具名虛構人物、其性格標籤或「完成」宣告。
2. **產出真正可分層的至少一名學生樣本**：要求一致畫布、頭身比例、透明背景、固定髮／臉／服裝定位錨點；逐圖比對是否能無縫疊合。單張完整角色肖像不能冒充可換裝部件。
3. **完成兩名學生 × 六表情的獨立素材**：每張不改換角色臉型、髮型、服裝與錨點。先做圖片品質人工檢查，再進程式接線。
4. **共用部件實驗**：在至少四名學生上測試有差異的髮型／身形／配件與服裝；避免同班人物近乎同臉，不保證素材小樣本自動推廣到40人。
5. **測真實顯示**：接到現有 `web/story-scene.js` 的顯示層原型，維持 `page.cast`、六表情、最多兩人、電話禁顯遠端、旁白不洩漏資訊，再測手機直式／桌機橫式、遮擋與回頁。僅在小型原型成功後擴大量產。
