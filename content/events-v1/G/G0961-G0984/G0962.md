## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長因家中長輩與配偶全力支援照顧其他家人（`7-1`），自己這陣子工作調度後時間餘裕充裕（`11-2`），能隨時配合學校任何時段到校。今天他看見私校發下來的多元選修分組結果不符預期而火冒三丈（`2-1`），親自衝來學校找導師彈性協商（`10-3`）：「老師我時間很自由，不管你們教務處要補哪張表或哪天面談我都能配合，但這個選修組別這週勢必要幫我換掉！」 |
| 核心衝突 | 家長用充裕的個人時間配合度作為談判籌碼，對著已定案的校內選修分發結果強力施壓要求翻案。 |
| 導師困境 | 幫他跑一趟教務處看能不能用空餘名額硬喬換組，其他同樣沒抽中第一志願的家長知道後多半跟進抗議；照校規堅持分發已鎖定不能改，這名時間多到能天天來校門口「溝通」的家長恐怕真的每週報到。 |
| 故事獨特性 | 寫出有家族後援又時間充裕的家長，如何把「隨叫隨到」變成學校行政最頭痛的溝通壓力。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：家長把選修單拍在桌上，保溫杯蓋滾到了你的筆筒邊。
- **P02｜家長**：我太太跟長輩都說家裡交給他們。我哪天來都可以，要補什麼我補，你們總要幫我想辦法吧？
- **P03｜導師**：申覆期限在這裡，但有時間來，不會多一個名額。孩子自己最想上哪一門？
- **P04｜家長**：他說現在這組也可以。那是他怕麻煩！
- **P05｜旁白**：你將單子轉回他面前。他把散落的杯蓋擰緊，又問明天早上你有沒有空陪他去教務處。
