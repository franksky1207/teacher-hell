## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生與另外兩位同班同學住在同一條巷口、長年固定結伴搭公車上下學（`7-4`），彼此早有默契。但他個人原本就容易在陌生社交場合焦慮（`2-2`）、很需要待在熟悉圈子裡的心理安全感（`4-2`），加上平時與導師關係親近（`5-2`），面對下週即將抽籤打散的分組專題，下課便私下跑來拜託導師：「老師我們三個平常上下學都在一起比較自在，能不能別拆開我們？跟不熟的人一組我真的會緊張到發抖。」 |
| 核心衝突 | 習慣與固定鄰居同學結伴的焦慮學生依賴導師交情求特權，與班級公平抽籤分組的原則相撞。 |
| 導師困境 | 念在親近與他真的焦慮而暗中保留他們三人同組，其他被拆散的同學多半很快看出端倪；堅持一律抽籤不能破例，這名學生恐怕在整場分組活動裡陷入明顯退縮。 |
| 故事獨特性 | 寫出「同巷口固定通勤小圈圈」與「個人社交焦慮」疊加後，學生在面對正常分組打散時產生的真實退縮與求情。 |

### 開場
- **P01｜旁白與當場對話**：三個人搭同一班公車多年，誰忘帶卡都知道先看哪個口袋。他說到下週抽組，手卻抖起來，和你熟才敢低聲求別拆。你已接好必要支持，也說其他兩個人的意思要各自問，不能替他們全答。他往門外看一眼：「我不是不想跟別人好，我真的會不知道說什麼。」抽籤紙還沒折。
