## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日排全校跨班選修與補課表累到快虛脫的教務處課務組職員（`2-3`），平時非常信任導師（`5-1`）也肯定導師的控場專業（`8-1`）。今天突然有位外聘兼任教師臨時請假，他抱著課表來跟導師彈性協商（`10-3`）：「老師我知道你週五下午那節本來是空堂，能不能先幫我代看一節自習？下週我把你最討厭的那場高三／週六前監考幫你換掉！」 |
| 核心衝突 | 行政端在突發缺工時用「私下調換監考人情」來換取導師犧牲空堂代課，讓合法調度變成職場人情交易。 |
| 導師困境 | 點頭答應代看一節換掉下週討厭的監考，雖然看似划算但這週原本要用來改考卷的空堂直接沒了；婉拒並請課務組照正常代理順位找人，這名信任你又快累垮的同事現場實在很難立刻生出別人。 |
| 故事獨特性 | 沒有官僚壓迫，真實呈現私校課務組與教師之間「空堂救火換監考」的辦公室地下交易日常。 |
