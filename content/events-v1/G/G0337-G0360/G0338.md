## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長晚班後仍替孩子做閱讀練習，堅持文章可改但不能替孩子寫。看到導師把家庭共讀當代作，帶來兩份自己用的例字，願意當場示範怎樣只陪不代。 |
| 核心衝突 | 公開示範可證明實際協助，卻不該變成每戶家庭都需出席的清白測驗。 |
| 導師困境 | 可請學生本人試讀、只讓家長說明兩個漏字，或收回已有的代作推論。 |
| 故事獨特性 | 家長想留下誠實的那幾個錯字。 |
