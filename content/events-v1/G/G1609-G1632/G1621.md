## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長最近工作轉為彈性自由業，時間餘裕相當充足（`11-2`），口才表達極為流暢（`3-1`），非常重視孩子與家庭的自主學習安排（`4-3`），態度也很有協商彈性（`10-3`）。今天他打電話來用極為客氣有禮的語氣商量（`3-1`）：「老師，我現在下午比較有空（`11-2`），我們家很重視自主探索學習（`4-3`），想說這學期能不能每兩週挑一個週五下午請事假帶孩子去看展或做田野調查？當然如果當天有考試或重要班務我們都可以配合改期！（`10-3`）」但普通上課日頻繁定期請事假，不僅會讓孩子漏掉週五正課進度，也會影響校內全勤與請假規範觀感。 |
| 核心衝突 | 有錢有閒又極度重視自主教育的家長，態度好到無可挑剔地提出「定期請假去校外探索」，挑戰傳統高中生週五下午的在課紀律。 |
| 導師困境 | 先問學生本人想不想去、目前有哪些課不能漏，向家長說明正式申請、出缺席紀錄與評量規定，核准由權責人員辦理。可和家長把探索改排非上課日，代價是可配合的場次較少；或協助家庭就個別日期依規申請，家長需保留被駁回或改期的空間，學生也須評估缺課對學習的影響，導師不承諾固定批准。 |
| 故事獨特性 | 沒有誰逃學偷懶，寫出「新時代自由業家長想用定期請事假實踐自主探索」與高中體制課表的溫和碰撞。 |

### 開場
- **P01｜旁白**：第四節下課，parent_a打來電話，語氣客氣得像在跟客戶提案。
- **P02｜parent_a**：老師，我現在轉自由業下午比較有空，我們家很重視自主探索，這學期能不能每兩週挑一個週五下午請事假帶他去博物館做田野調查？有考試或重要班務我們都能配合改期！
