## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 下班後的晚間私人時間，導師與幾名校外老友約去玩大型實境密室逃脫。進最後一間昏暗機關室時還剩十二分鐘，同行朋友都懶得硬想、想直接按對講機拿免費提示（`6-2`），偏偏平日好勝（`4-1`）、解謎執行力極快（`3-3`）的導師堅持不跟大家妥協拿提示，只差最後一道密碼就能刷新場館本週「零提示通關」紀錄。正當導師全神貫注推算最後幾組符號時，一旁原本就睡眠不足的朋友突然扶著牆低聲說有點悶熱頭暈，其實只是想早點通關出去透氣，導師心裡立刻生出強烈不捨與同理（`1-3`）。 |
| 核心衝突 | 完全離開教師身分的私人娛樂場合中，導師在朋友突發頭暈時已先停手並通知工作人員協助其安全離場、確認休息區有其他同行友人陪伴照護且狀況穩定；真正的兩難在於朋友已安全離場後，面對場館允許續玩的最後十分鐘，好勝執念與想出去陪朋友的同理心互相拉扯。 |
| 導師困境 | 導師當場立刻停下解謎、通知工作人員依安全通道護送頭暈朋友先離開密室休息，並確認有其他同行友人陪同照看、狀況無礙；接下來的兩難在於（在場館允許剩餘玩家繼續挑戰的前提下）：徵得友人點頭後自己重返機關室靠剩餘時間硬解完無提示紀錄（圓了「零提示通關」的好勝執念，事後卻仍覺得自己把整團一起破關的樂趣丟下、心裡略感愧疚）；還是乾脆放棄本場紀錄、直接向工作人員結束遊戲陪大家一起坐在外頭休息區陪朋友喝水聊天（徹底顧全同伴情誼與體貼，卻與近在眼前的場館最佳紀錄擦身而過）。 |
| 故事獨特性 | 完全不涉及校園或任何師生關係，在先落實安全護送與照護安排後，寫出成年人在「留下來衝最後十分鐘無提示紀錄」與「提早結束陪朋友透氣」之間的私人抉擇。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：朋友已從安全通道到休息區，有人陪著，工作人員確認狀況穩定。你走到門邊，對講機說剩下的人仍能繼續。
- **P02｜朋友**：我沒事，坐一下。你不是剩最後一題？
- **P03｜旁白**：倒數還有十分鐘。桌上那組符號你剛有頭緒，另外兩個朋友問要不要乾脆拿提示，出去一起坐。
- **P04｜導師**：現在拿就不是零提示了。
- **P05｜朋友**：紀錄又不會跑掉……好啦，這週會。
- **P06｜旁白**：門一邊通向最後一題，一邊通向休息區，你的手還捏著沒放回桌面的線索卡。
