## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位校內常駐生輔或安全職員這學期業務量暴增、任務負荷極重（`11-1`），平常在各班間社交主動、跟導師和學生都很熟絡（`6-3`），但他自己本身極為講原則（`1-4`）且校園安全意識極高（`9-4`）。今天課間導師班幾名學生把書包貼牆整齊暫放在教室外走廊，自己站在旁邊討論小組報告；這名熟絡職員雖然累得要命（`11-1`），路過看見還是基於逃生通道淨空的安全原則（`9-4`、`1-4`）當場板起臉直接登記秩序扣點，讓在場學生覺得平常那麼熟還不給通融實在太硬。 |
| 核心衝突 | 走廊動線淨空原則上沒有錯，但現場書包確實貼牆排整齊且人在旁邊看顧、僅暫放幾分鐘，熟絡同事在高負荷下按死原則開單讓導師夾在中間。 |
| 導師困境 | 先立刻請學生把書包全部搬進教室（遵守安全通道規範），再私下找這名熟絡同事商量這次能否改為口頭勸導免予扣點（顧及學生感受與班級榮譽，但這名講原則的同事可能覺得導師在利用交情求情）；還是直接認下這次扣點、當場向全班強調「走廊就是連貼牆暫放都不行」（守住同事的執法原則與職場信任，卻讓覺得委屈的學生對導師與職員抱怨連連）。 |
| 故事獨特性 | 不是不講理的陌生稽查員，而是「平常跟大家很熟絡的職員在過重負荷下反而公事公辦照原則開單」的職場與安全尺度碰撞。 |
