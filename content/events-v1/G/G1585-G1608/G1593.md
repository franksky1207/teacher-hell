## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位校內常駐教師同事手頭寬裕（`7-3`），校園安全意識極高（`9-4`），一發現好用的東西就愛在辦公室到處推薦傳播（`8-4`），待人也很有協商彈性（`10-3`）。前兩天下雨走廊地磚有點濕滑，這名同事安全警覺大發（`9-4`），昨晚自己掏錢網購了三大捲工業級強黏防滑條（`7-3`），今天一早就在教師群組狂推銷（`8-4`），下課還抱著一捲跑來導師班門口笑著商量（`10-3`）：「老師你們班轉角最滑了，我這捲分你，今天下午我幫你貼滿一排！你想貼橫的直的都可以照你意思！」但總務處明文禁止私自在磨石子走廊貼強膠貼條，撕除時會整片毀損校產。 |
| 核心衝突 | 熱心又大方的同事為了安全要幫你貼走廊，但一旦貼下去就會違反校產管理規定，導師必須攔住這份充滿善意的公產毀損危機。 |
| 導師困境 | 笑著感謝他的安全意識與大方，明確攔下強膠防滑貼、說明總務處禁止私貼以免日後除膠毀損地板，改約他一起向總務處申請公發可拆式止滑墊（守住校產管理與真正安全，但興沖沖抱著材料來的同事有點失落）；還是請他先收好這幾捲工業貼條、只暫時先借用總務處現有的立式防滑警示牌擺在轉角（快速處理眼前濕滑風險，卻沒用到他買來的材料）。 |
| 故事獨特性 | 沒有誰想違規，寫出「有錢又有安全意識的熱心同事拿著工業級強膠來幫你改造走廊」的辦公室善意危機。 |
