## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平日回家常替長輩顧店的學生，把「借來的傘沒能還」寫成虛構故事，原打算只讓班上讀到主角把借條留在門縫。導師在班讀前已向小組說這是努力終有回報，兩位同學便拿粉筆寫出大團圓續篇送給他，還勸他家裡的事都會好起來。他被當成要接受祝福的人，氣得脫口要求老師換篇。 |
| 核心衝突 | 他並未要求改一句原文，導師的解讀已使同學把虛構角色當成他的生活，進而公開安慰他。單換示範仍會留下這種誤讀。 |
| 導師困境 | 可撤回選文，由導師當班說明自己先把虛構故事和作者處境連在一起，學生不用解釋家庭，原本準備續篇的同學則要收回好意；也可獲學生同意，匿名把同學所寫續篇當另一種結尾，讓全班比較什麼需要被解決，代價是作者得接受仍有人喜歡他不想寫的終點。 |
| 故事獨特性 | 需要收回的是同學已經送到桌上的安慰，故事不是一次文字修改。 |
