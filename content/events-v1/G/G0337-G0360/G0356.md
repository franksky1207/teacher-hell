## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 教務同事連續接手平日缺課、主動找導師說可再帶一次暖身。主管隨後把這些次數當作他還能接課的證據，導師也署名支持。教務同事拿著自己累計的代課時間來問，為何一次支援會變成主管考核中的「常態可調度」。 |
| 核心衝突 | 導師不更正就會被引用成班導也認同的既成事實，當天撤走支援又會讓學生失去已說好的短課。 |
| 導師困境 | 可完成當日短課但收回署名，請教務按實際聘任和排課區分臨時與固定，或拒絕以個人考核交換班上課時。 |
| 故事獨特性 | 私校願意接班的人，一次次被拿來證明缺人也能運作。 |
