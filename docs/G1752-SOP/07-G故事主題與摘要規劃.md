# G1752 專屬 SOP｜07 每批24篇故事主題與摘要規劃

> 先規劃，再依[02](./02-G故事創作主流程.md)正式創作。每批現有`故事主題與摘要規劃.md`僅已預填故事ID、固定種子及四碼，**不是已完成的故事或驗收**。G不設T的創作時段引導、活動前後池、特定日配額。

## 一、每批規劃前

1. 打開本批規劃MD，依[`data/g1752-fixed-seed-assignments.json`](../../data/g1752-fixed-seed-assignments.json)核對24個`Gxxxx`及原四碼；**種子唯一權威是JSON**，規劃MD中四碼只是唯讀副本。
2. 讀[`data/g1752-tag-statistics.json`](../../data/g1752-tag-statistics.json)，用T648固定與已核准G的整體標籤比例判斷題材方向。每批不設標籤配額，規劃標籤僅預估、不得先寫入正式統計。
3. 對照T及G已規劃／已核准故事的核心衝突、教師處置與結果特色，避免只換人物、換名稱或換場景。

**跨批查重的唯一簡表**：規劃MD與正式Markdown仍是內容來源；施工前需建立一個**可重建的衍生索引**`data/g1752-story-topic-index.json`，每筆只存`storyId`、規劃／核准狀態、摘要中的核心衝突、教師處置焦點、故事獨特性、標籤及來源文件路徑。其T資料可從已封存T故事／索引初次提取，後續**不每批重掃T648**；G每批規劃完成或已核准故事修訂時只更新受影響條目。此索引只加速初篩，**不取代原規劃MD或正式故事，也不另維護第二套故事**；疑似重複才讀對應全文。**索引工具及初始檔目前尚未建立。**

## 二、每篇規劃MD必備內容

| 欄位 | 需要真正寫出的內容 |
|---|---|
| 故事ID／固定種子／四碼 | 從唯一映射讀取，禁止為劇情需要重新配對 |
| 預定標題、事件起因 | 可具體發生的臺灣高中導師生活事件，不依賴T專屬時間節點 |
| 核心衝突、導師困境 | 真正相衝的立場、代價與可供教師選擇的不同處置 |
| 故事獨特性 | 明確指出與其他T/G的區別，不是制式模板換皮 |
| 四碼因果 | 四個種子碼各自合法的持有人及如何在人物／行動／後果發揮作用 |
| 人物配置 | 需要的常駐數值NPC槽位、各自立場／權限／知情／在籍條件；情境人物不硬建立持碼槽位 |
| 必要前提／演出限制 | 只在合格上課／寒暑輔日成立；必要年級、身分及知情另列，不寫T活動日期歸屬 |
| 規劃題材標籤／狀態 | G01～G11預估標籤、待複核或規劃通過；**不得冒充正式故事驗收** |

本批24篇先全部填入真實摘要與人物構思、逐篇核對固定四碼，並做一次**本批與跨批查重**；不合理就改主題與情節，**不換S種子、不強制配類別**。24篇規劃確認後才進入六選三、四R、AVG、58庫等正式創作。

## 三、規劃、正式故事及驗收的界線

- 規劃資料與正式故事分開：`故事主題與摘要規劃.md`只能放摘要與角色／四碼用途；不預先生成空白`Gxxxx.md`，也不把規劃標籤計入正式帳本。
- 正式五區塊格式以[03](./03-G五區塊範本.md)為準；內容與兩網站發布驗收只依[04](./04-G品質與驗收.md)；批次及首批四篇試產只依[05](./05-G種子批次與試產.md)。
- 若正式故事創作改變核心摘要或人物條件，**同步修訂本批規劃及衍生題材索引的受影響條目**；不因摘要調整更換ID或固定種子。
