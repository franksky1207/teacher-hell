## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長回條只註明想私下談，學生希望導師不要當眾追問；教師需在家長日前決定是否保留安靜空間。 |
| 核心衝突 | 需要先掌握談話性質以安排，又不能要求家長在公開回條揭露私事。 |
| 導師困境 | 如何用最低限度私訊確認議題類型與所需協助，並在不知道細節時界定可承諾範圍？ |
| 故事獨特性 | 不是遇到秘密就立刻聯繫家庭，而是會前分流所需資訊的最小程度。 |
