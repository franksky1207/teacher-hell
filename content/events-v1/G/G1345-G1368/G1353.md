## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師這週排課寬鬆、課間時間餘裕充足（`11-2`），對自己本科教學進度極負責任（`1-1`）且非常有主見（`4-3`），但上個月因為導師在公開會議婉拒他臨時借自習課而對導師心存不滿（`5-4`）。這兩天他藉著「負責把重點講完」為由，明明自己下節沒課，卻在鐘響後照樣站在講台上硬拖了五分鐘才下課，害導師班學生連續兩次來不及上廁所、還差點在下一節別科老師課上遲到。 |
| 核心衝突 | 有空堂、負責卻帶著心結的科任用「拖堂五分鐘講課」來展現教學主權，直接擠壓了學生的下課休息權與下一堂課的準時銜接。 |
| 導師困境 | 下課直接走去這名同事座位旁誠懇卻明確地提醒「鐘響後拖五分鐘已經害學生趕不及下一堂課，請準時下課」（守住學生下課權益與下一堂課秩序，但這名本就對導師心懷不滿的同事恐怕反咬一口「我那麼負責多講五分鐘還被你嫌」）；先私下找下一節的科任老師打招呼寬容兩分鐘緩衝（暫時避免與這名記仇同事正面衝突，卻讓全班學生繼續犧牲珍貴的十分鐘下課）。 |
| 故事獨特性 | 沒有誰擺爛，寫出大學／高中老師最真實的「下課鐘響還一直『我再講最後兩句就下課』拖滿五分鐘」背後的職場心結與責任藉口。 |
