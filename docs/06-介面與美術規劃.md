## 正式三年制開局與完成操作

開局依序為：選三個本機存檔格之一→選簡單／普通／困難（第20／10／1年任教）→教師與合法前史／能力→選任教九科→最終確認→依六月結算界線從所選年份暑輔第一天開始。三年總評沿原N7六權重**30／25／15／15／10／5**及SS～F，但僅使用本局三年正式來源並另校準尺度，不平均年度分數。三年結束後**唯讀資料留在原三存檔格之一**，未覆蓋／刪除前可查完整結局及歷史，玩家可先匯出備份；確認覆蓋後舊完整世界不保留。**三年模式不建立獨立生涯紀念或第四槽**；原11-E的30年紀念程式保留但不在正式三年模式觸發，亦不得阻擋覆蓋三年完成局。


### UI-2 立繪下緣銜接修正（2026-11-14）
- 手機實際預覽指出人物立繪下緣恰好停在對話框頂端，形成腳部／腿部「懸空硬切」感；這是**畫面定位與遮擋層次**問題，不應因此改小人物或依教室背景透視強制縮放。
- 固定角色畫布與錨點，下緣**延伸到半透明底部對話框後方**，形成可見的大腿到前景覆蓋的自然過渡；左右角色及旁白、普通對話、四選項、確認共用同一固定位置，不因內容切換變高／變低。
- 保留原始頭身與學生間身高校正、人物正常不透明度，以及非說話者僅亮度降低；不改正式劇情事件／存檔。手機與桌機應各以適當的固定 CSS 基準線避免硬切，不把 PNG 透明外框誤當場景地面。
- 本次是局部 CSS 修正，手機與桌機實際效果仍須以最新版預覽驗證，不能僅因程式合併便宣稱視覺已通過。


### UI-2 桌機橫式人物獨立高度校正（2026-11-14）
- 使用者在約 1648×900 桌機橫式預覽確認：兩名人物僅露出上半身，腿部被底框遮住；**手機直式和桌機橫式不可共用同一條人物縱向定位基準**。
- 在保持人物原始畫布縮放比例、身高校正及左右站位不變的前提下，橫式採獨立較高的固定定位，讓人物大腿有機會出現在對話框上方；短橫式視窗另做高度保護，避免頭頂被切。直式既有定位不變。
- 一般對話、旁白、四選項與確認狀態皆使用各裝置對應的相同固定錨點，人物不得因選項框出現而改變位置。半透明對話框始終在人物前景，遮住立繪下緣，不得浮空硬切。此為需桌機視覺重新確認的 CSS 修正，不宣稱已實機通過。

### UI-2 手機直式站位精準校正（2026-11-14，取代前次過度下移）
- 由使用者兩次手機截圖比較，原可看見大腿的直式版僅在立繪末端與底框之間有約一小段空隙；PR #39 將立繪大幅下移造成大腿被遮住，不符合預期。此次**恢復原有大腿可見高度，僅自該基準下移約 20px**，使下緣微幅延伸進底部對話框後方，不再用「把整個人拉低」處理懸空。
- 手機直式固定立繪垂直定位，不隨旁白、一般對話、四選項或確認改變；**桌機橫式獨立高度規則不受本次修正影響**。人物縮放、原有身高差異、說話者亮度、表情及劇情操作不變。
- CSS 調整需經手機畫面核對，不能只憑靜態檢查宣稱視覺已通過。

## 現行權威規格｜三年制操作與第15批正式 UI 美術（整合至 2026-11-14）

> 本節統整 2026-11-05 第三階段操作決議、11-06～11-07 實機修正及 2026-11-14 正式 UI 四組 35 項美術選擇。**已定案的是視覺方向與操作契約，不代表 UI 已完成或驗收。** 下方 2026-11-01 的逐題原始規劃作歷史參考；如文字有衝突，以本節及較新的實機修正、正式程式契約為準。美術**只調整呈現**，不得改寫正式世界、事件、能力數值、三槽存檔、劇情知情界線及校曆。

### 一、統一視覺系統（35 題：1～8、17）
- **風格與全域半透明原則**：現代精緻日系 AVG；全遊戲主視覺為**深藍＋暖金**，暖金用於細線、重要標題及選取回饋，不讓大片金色與裝飾干擾劇情。**整套 UI 以半透明、能感受到人物與背景仍在畫面中的面板為共同設計語言**，涵蓋首頁、劇情與決策、功能按鈕與狀態區、課表、筆記本、存檔、設定、確認及結算；不是只讓對話框透明，也不是把畫面鋪滿不透明色塊。劇情採深藍半透明框＋白字，資料採米白／淺灰半透明面板＋深色字，兩者使用同一套圓角、線條、間距及色彩層級。**各面板不強制同一透明度**：背景明暗、閱讀密度及重要性不同時，可調整遮罩、對比或輕度模糊；需閱讀大量文字、成績或危險確認的區域可提高遮蔽程度，仍維持整體通透感。以實際字體可讀性、人物臉部／表情與場所辨識度為準，不預設固定透明百分比。
- **控制項**：圓角矩形按鈕、細緻邊線、柔和陰影與適度裝飾；不同情節不改變按鈕代表的正負含義。一般 UI 操作僅有提亮、漸入、平順頁籤等**輕量動畫**。校園元素只適度融入日期標記、分隔、細節符號，不把遊戲做成公文或完整校務系統。
- **字體**：遊戲標題、重要章節可有特殊字體風格；長篇劇情、選項、成績、日期、細小資訊一律用清楚易讀的中文字體（黑體為主）。實際字型、授權、色碼、透明度、精確大小與留白須在視覺原型中依手機與電腦可讀性定稿，現階段不虛構成已核准的數值。
- **資產原則**：優先使用 CSS、SVG 與少量必要裝飾，不為每個按鈕或框線額外產圖；延續既有正式資產單一來源、按需載入和限量快取，不複製美術圖庫。

### 二、首頁、三槽與新生涯（5、9～10、24、27～29）
- **首頁**：使用現有核准的**校門口背景**，不另製大型專用首頁插畫。標題「教師荒謬地獄」為精緻日系標題、帶少量荒謬幽默細節；四入口固定「繼續遊戲／選擇存檔／遊戲說明／設定」。使用**半透明選單面板**承載按鈕，桌機標題與選單整體置中；手機標題在上、按鈕在下半部，必要時對背景局部加遮罩確保可讀。
- **三槽**：採**橫幅存檔卡**，桌機三槽橫列、手機縱列；呈現玩家教師姓名、年資、任教科目、遊戲日期與年級進度、進行中／完成。已完成檔原槽唯讀；不設第四槽或獨立三年紀念；覆蓋、刪除、匯入／匯出仍有正式驗證與安全確認。
- **建立教師**：**精緻分步表單**，既有合法順序為選存檔槽→難度（簡單／普通／困難，分別 20／10／1 年資，遊玩均三年）→教師姓名／前史與六能力重抽→選九科任教→總確認。難度以**三張資訊卡**呈現（手機可縱向排列），能力以**六條橫向能力條＋整數數字**呈現，不以雷達圖取代，且不能手動修改數值。顯示層數字四捨五入，能力條仍可依原始精度；重抽、前史與科目均取正式合法來源。
- 選科顯示每週 18 節、實際任教班數（國英數 3 班、地歷物化 6 班、公民生物地科 9 班，依當前正式任教科目規則）、必教導師班，不提供課表反覆重抽。最後總確認含難度、年資、能力、前史、科目、存檔槽及校曆起點，可返回前步；建立後鎖定。新局暑輔第一日才播放約 2～3 頁校門／校園開場，續玩不重播。

### 三、主畫面、狀態與課表（14～15、18～19）
- **情境優先**：仍為第一人稱導師視角的 AVG，不做管理儀表板、不顯示玩家自己立繪。主畫面固定「課表／筆記本／選單」三入口，皆使用**圖示＋文字**；手機右側縱列、電腦右上橫列。上方兩行顯示日期、星期、年資、年級、學期、週次、當下時段及必要班級，不預告下一節。
- 六項當前狀態以**細長條＋名稱＋四捨五入整數**顯示，手機 3×2、桌機左側直列；進入劇情／決策時隱藏。點狀態區仍可查看六項長期能力與六項當前狀態。長條使用原始值，顯示取整不回寫數值。
- **課表**：**精緻校園課表**，淺色底與清楚格線，採**文字為主、圖示＋少量低彩度分類色**辨識授課及特殊活動；不用大片花色。手機及電腦皆顯示週一至週五完整八節、單雙週可切換，不改成單日，也不要求水平捲動。空堂**不顯示任何文字**。授課格顯示正式班級，點格看完整資訊；班名依現行忠孝仁愛信義和平勤樸，單週週五 6／7 節空白，雙週週會／班會、考試、特殊活動及高三週六日程依正式校曆呈現。手機五欄閱讀性須用原型實測。

### 四、劇情、決策與提示（2、11～13、16、32）
- **一般對話**：使用**適中高度**的深藍半透明固定底框，白字與細框；姓名用**獨立浮動小框**（只顯示玩家已知姓名）。一般敘事完整呈現、上一頁／下一頁、末頁「結束」；劇情長文**分頁不捲動**。當頁沒有選項時，不顯示也不預留獨立選項區，優先讓人物、表情與背景成為視覺主體；手機／電腦依臉部與文字可讀性調整構圖，不強求同樣像素高度。
- 場景與最多兩位 NPC 仍依正式圖片及已知演出投影：一人居中、兩人左右。**說話者維持正常亮度及 100% 不透明度；非說話者僅稍微降低亮度，不降低人物透明度；旁白時兩人都恢復正常亮度。** 切換說話焦點時只做柔和明暗變化，**不因發言而放大、縮小或移動人物**；身高、體型與相對高度依既有學生立繪身高校正規則，不另創 UI 比例。手機側重臉與上半身、桌機可呈現較完整半身；場景／人物入退場仍可依原契約短淡入淡出，不增加場景名稱卡、骨架動畫或逐格動作。
- **整合式決策對話框（取代舊版「選項獨立浮在場景／底框上方」）**：當頁有事件選項時，**同一個底部半透明對話框稍微增高，框內上方只呈現必要的簡短情境／提問，下方直接容納選項及「確認選擇」按鈕**，不再另外浮出一大塊選項面板、不堆疊兩個完整框，也不切換獨立決策頁。內部選項使用深色半透明圓角按鈕、選取只提亮，不以色彩暗示正負後果；仍保留手機最多 **2 欄×4 列**、桌機最多 **4 欄×2 列**，選完可改、同頁確認後才鎖定，不新增二次確認視窗。決策頁以**短題幹＋易懂的選項文字**減少垂直占用，必要的較長敘事放在前面的正常劇情分頁，**不得刪除判斷所需資訊、偷改選項意義或刪減正式選項**。仍須立即完整呈現、**不分頁／不捲動選項**，不靠縮小到難讀的字體硬塞。單純無事件活動維持原先快速單點執行、正式事件優先。
- **結果與通知**：日常非關鍵提示用**輕量浮動通知**；需要閱讀的狀態增減與不可逆操作仍採可停留、可確認的視窗，不得因逾時消失而漏看。重大事件可適度改變**已揭露**情境的光影、漸入與節奏，但不得預告隱藏風險、暗示選項後果或改變交易時點。事件中開啟／返回課表、筆記本、選單不能推進時間，保留未確認選擇。

### 五、資料視窗、筆記本、學業與存檔設定（4、20～23、25～26）
- **資料呈現**：資訊面板採米白或淺灰**半透明底**、深色清楚文字，劇情背景及人物仍有適度存在感；資料密集時可增加面板遮蔽程度以確保辨識。手機資料視窗全螢幕、桌機浮窗；返回上一層與右上角關閉各有獨立語意，桌機外點關窗不得穿透底層。長名冊、成績矩陣、歷史內容可於**內容區**捲動，不改劇情不捲動的規則。
- **筆記本**：**精緻電子筆記本**，淺色紙張感、細分隔線與簡明頁籤。主分類「人物／歷史／待辦」；手機頂部分頁、桌機左側分類。人物的**學生／家長／其他人**為實機修正後的正式分類，保留姓名搜尋、名冊既有座號排序、已知紀錄及連結跳轉。人物頁採**摘要＋詳情分頁**，只變更閱讀層次，不刪原有資料，也不展示隱藏心理或數值。
- **關係圖**：採**以所選人物為中心的輻射式**關聯，僅顯示已知關係；點人物應可換中心或跳到人物資料。手機按觸控可讀性調整節點排布，不強迫擠成難以點擊的圓形。
- **學業**：**總表表格＋個人卡片摘要／細節**的混合呈現；手機按科目切換全班，桌機九科矩陣；個人先九科摘要、再看正式已產生的平時／段考／學期／學分。可切已生成學期，不填造尚未生成的成績，不建立第二套計算來源。歷史時間／事件兩入口、已知資訊、待辦期限與合法處理條件全部維持原規則。
- **設定與警告**：設定與遊戲說明使用清楚的**淺色面板**。刪除存檔、覆蓋及其他不可逆操作使用**醒目邊框＋警示圖示＋明確文字**，不只依賴顏色，也不省略原有確認與 CAS 保護。完成槽只可查閱結果、人物、歷史與學業，不可再玩或重抽。

### 六、通訊、結算、失敗與終章（30～31、33～35）
- **通訊**：電話採**現代手機通話外觀**，但不顯示遠端人物立繪、遠端背景或未公開資訊。即時訊息、公告、郵件、新聞使用**共用框架＋局部辨識差異**，不實作完整聊天或新聞軟體。
- **回顧**：學期／學年採**年度故事回顧**視覺，以重要事件卡、能力變化、精緻統計配合既有分頁；學期為「重要事件→六長期能力變化→中性總結」。學年仍須先演正式結果劇情，再依既定順序顯示年度結果、12 面板、事件及結語；只取實際世界資料，失敗重試仍受正式權限控制。
- **失敗**：用**沉靜克制**的深色畫面與短轉場，讓劇情文字承擔重量，不把所有失敗做成相同的強烈動畫，也不改正式失敗條件。
- **三年完成**：用**溫馨故事終章**的校園場景與適度動畫呈現「帶完一屆」的感受，但情緒不可覆蓋真正的劇情結果。正式順序仍為總評／等級→結局與學生結果；畢業資格顯示「符合畢業／符合修業證明／尚未完成修業」人數，再查各類名單；完成存檔仍在原槽唯讀。

## 一、設計目標與範圍
- 將美術呈現從遊戲開發早期就納入架構，避免日後由純文字全面改裝時發生大型重構。
- 重點是場景、人物互動與敘事，而非動畫精細度；優先把開發成本放在事件、因果、NPC關係與記憶。
- 輕量2D場景式AVG、第一人稱導師視角，**不顯示玩家自己的立繪**；不使用3D、骨架動畫、逐格肢體動畫。
- 故事系統、客觀事實、知情資料與美術資源分開；不得透過表情、剪影或演出揭露玩家不知道的真相。

## 二、畫面構圖與出場人數（已確認）
- 電腦橫式、手機直式皆支援，透過同一套素材與響應式排版調整位置、尺寸、裁切，不建兩套人物素材。
- 同畫面 **最多兩名 NPC**：零人可顯示背景／旁白／資訊；一人置中；兩人左右分站；角色交替可退場與入場，仍留場的人可重新置中。
- 退場是畫面演出，不等於人物在事件客觀歷史上離開現場。
- 人物出入場只採簡單平移、淡入淡出；對話中更換靜態表情、姿勢，不做連續肢體動作。
- 手機兩人同場的實際可讀性、文字遮擋及裁切留待原型測試，不能假設已經驗收。

## 三、學生立繪、表情、姿勢與服裝（第二大項定案）
- **核心定位**：美術為事件、人物關係、數值與敘事服務。採精緻、吸引人的**日系動漫畫風**，但學校制服、設備、場景、制度及日常細節遵循臺灣高中生活；不追求純寫實肖像，也不採脫離臺灣校園的奇幻日式制服。
- 學生採彩色**頭部至明確可見下半身／裙褲的靜態立繪**；每屆40人優先維持高辨識度。臉型、身高感、體型、髮型、髮色、眼鏡等有合理多樣性；可以有動漫美型特色，但不要求人人俊美，也不以外觀暗示隱藏數值、性格或命運。
- 採 **40 位學生各自獨立的完整六格 PNG 人物原型**，同一學生五類圖集均維持可辨識的臉型、髮型、體態與年齡感。三年劇情與重新讀檔保持同一人，不使用部件組合或換裝拼貼。
- 不強制每學年改畫髮長、髮型或眼鏡；不同服裝可自然改變髮型整理及配件，人物核心辨識特徵仍須一致，不因讀檔或換衣而重新換臉。
- 基礎表情固定**平靜、開心、生氣、難過、驚訝、尷尬**六類。情緒強弱主要靠劇情文字、語氣與既有少量共用視覺效果，不強制另做多級表情素材；表情只呈現可見反應，不洩漏真實內心。
- 六格人物表情及姿勢可自然變化，缺少特定表演時可用中性站姿／文字等不矛盾的替代演出，不建立骨架或逐格動畫系統。
- 服裝共 **5 類獨立完整六格 PNG**：夏冬制服、夏冬運動服各六表情，便服單張六種不同衣服的正向活動情境。服裝依合法已知情境選圖，不在遊戲中重新抽衣、拼接圖層或整圖換色；不建立衣櫃或換裝數值系統。
- 每類圖集均為固定尺寸、真正透明的完整人物圖。便服六格分別對應三次校外教學及畢業旅行三天的六套不同衣著；不採部件換裝、共用衣服貼片或整體濾色。

## 四、非學生 NPC 與畢業生（第二大項定案）
- 家長、其他教師、行政、校外人士**全部使用深色共用半身剪影**；不因重要性、登場次數或好惡改用彩色立繪，不替每位成年人創作專屬立繪。
- 使用少量可重用輪廓與外觀特徵（髮型、眼鏡、身形、外套輪廓等）組合，使不同人有適度辨識度；**同一人物外觀固定**且不受畫面重入或存檔讀取影響。剪影不預告善惡、立場、身分秘密或事件重要性。
- 學生在校時為彩色立繪；**畢業多年後重逢則使用具原人物特徵的共用成年剪影**，不製作每位畢業生的成年彩色立繪。姓名、關係、過往事件與資料延續；畢業後的遭遇與變化由實際歷史和劇情決定，不預設好壞。
- 重逢時身分可立即認出，也可透過自然對話稍後確認，**不強迫玩家從歷屆人物猜名字**；確認前不偷顯姓名或過往紀錄，確認後才依已定案筆記本規格提供可選的「查看過往紀錄」功能。
- 剪影素材精確數目不在本輪定額；以可辨識、可共用、負擔可控為原則。

## 五、背景、時間與情境畫面（第二大項定案）
- 採**較豐富的細分背景**，**約30個場所背景為規劃目標，不是硬性上限或立即確定的30張名單**；教室、辦公室、走廊、輔導室、行政空間、校園公共場所、住宅及校外等按實際事件需求分配。背景可供30年重複使用，不按事件逐張製作。
- 實際地點按**玩家所在位置、劇情、行動與已知情況**選取，不把事件主題或活動類別硬綁單一圖片；電話事件沿用導師所在地而非通話另一端。
- 常見／常實際到訪的場所優先專用背景；罕見場所（如醫院、法院、補習班、特殊校外活動地點）先檢查是否真的在玩家視角現身，再按情節選適當共用場景。若沒有合理圖片，使用**中性背景＋明確文字**，不拿學校教室冒充法院或急診室。背景清單須隨未來事件內容整體檢視調整，不因單一事件無限增加。
- **不製作晴天、陰天、雨天等天氣版本，也不建立天氣美術特效需求**；天氣可由文字交代。
- **保留白天、傍晚、夜晚的共用明暗及合理室內照明**：晚自習的教室可以開燈、晚上在家也有室內燈光；依實際時間與劇情，不將所有夜間室內場景一律變黑。優先沿用同張背景，不為每個時段重畫。
- 有人物時依既定上限最多兩名 NPC 輪替顯示，其他群體活動與反應由精確的旁白／對話表達，不將少數反應擴大為全班。**無人發言或登場**時只顯示背景與符合當下工作、家居、假日及時間的簡潔生活情境敘述；普通活動仍單點快速推進，不強制冗長劇情。
- 現場對話使用背景／立繪／文字框；電話、群組、社群、新聞、公告等沿用既定可重用資訊視窗而非每則製圖。不得用畫面揭露玩家尚未知悉的真相。

## 六、事件演出與美術契約（方向已確認；細節待實作驗證）
- 事件系統產生可觀察情境，提供標準化演出標籤（人物、站位、表情、姿勢、服裝、場景等），**不直接在事件內容綁定圖片檔名**。

## 七、預製素材、統一畫風與智慧下載（第二大項定案）

- 課表、筆記本、選單於對話及選擇中仍可開啟，覆蓋在場景上，關閉後保留原頁及尚未確認的選擇；開關不耗時，不改變事件。電腦使用浮動視窗，手機**全螢幕覆蓋視窗**，有明確關閉鍵；可點外部關閉的視窗，外點只關閉、不穿透推進劇情或選項。對話期間隱藏常駐狀態區。

## 十三、1-3 場景、人物、遠端通訊與特效（定案）
- 更換場景以短暫淡出／淡入；純表情變化不額外轉場。NPC入／退場採簡單平移淡入淡出；實際在場而非此頁焦點者可不顯示。多人現場依說話者及敘事焦點輪替最多2人；說話者正常亮度、旁人微暗，旁白時兩人正常亮度。表情隨劇情合理調整，翻回舊頁時一併還原；演出不揭露NPC隱藏心理。
- 電話交談保留導師當下場景、顯示通話UI與姓名，**不顯示遠端人物立繪**。即時通訊採聊天氣泡及短訊息分頁，每頁可有數則、依可讀空間決定；顯示可辨認的真實已知身分（如「某學生媽媽」），非家長A/B/C；未知身分不能憑空揭露。時間、已讀／未讀／未回覆只在情節需要時出現，不建完整即時通訊模擬。回覆依既有單選決策。
- 公告、電子郵件、新聞共用文件式閱讀機制，依類型變換外觀、標題及來源；長文分頁。多人齊聲以「部分學生」「在場家長」等符合實際人數的群體稱呼與旁白表示，不將少數誇成全體。劇情少量共用閃白、輕震動、亮度及停頓效果，不使用劇情音效、環境音效或真人配音；背景配樂的種類及機制已於第八大項定案，見本文件後段。
- 事件開場**不顯示事件標題／內部類別**，結束**不顯示系統成功失敗或結局評語**。對話或情節可以自然交代已知結果。

## 十四、1-3 歷史筆記本、畢業生及學期回顧（定案）
- 筆記本維持人物資料、歷史紀錄、待辦三區；**歷史紀錄僅「時間」與「事件」雙頁籤，不設人物索引頁籤**。時間預設本學期，能切換歷屆學年／學期；事件集中顯示同一事件各階段的完整歷史。搜尋涵蓋事件名稱、摘要、詳細內容、相關人物姓名／身分，預設本學期，可改全部學年。忘記關鍵字仍能依時間瀏覽；搜尋人物不等同歷屆人物名冊。
- 一般日常活動不留下流水帳；僅有意義事件、決策及發展，在**每個劇情階段完成時**即時寫入。摘要記行為，詳細歷史保存玩家當時實際選擇的選項原文，未選選項不必保存。跨學期累積事件只保存一個事件本體，在有發展的每個學期均可找到，開啟後看到各學期全部歷程；不因跨學期而中斷或重新生成。
- 不公開事件引擎的進行中／已結束、後續機率或尚未知情事實；客觀事實、各人物說法、尚待查明事項必須分開，不以幕後結果假充玩家已知。保留既有筆記本分層回顧的設定，但玩家可見的當下敘事及主動提示不得偷渡隱藏情報。
- 畢業生的資料與歷史保留30年，**不顯示歷屆學生／家長總名冊**，一般人物清單以目前相關者為主。畢業生依關係歷史可低頻重逢；確認身分後，劇情直接提供**可選的「查看過往紀錄」**，以覆蓋視窗檢閱該人物與導師的已知歷史，關閉原地返回，不耗時間、不強制閱讀，不揭露畢業後未知生活。過往事件仍可經時間及事件查找。
- **每學期最後一次期末考當日全部劇情／決策結束後自動顯示學期回顧**，閱讀並按「結束回顧」繼續，報告永久保留供日後查閱。包含本學期代表性事件摘要（可連到完整歷史）、**六項長期能力期初／期末／淨增減**（含零變動）、簡短中性學期敘事結語；不放六項當前狀態、最高最低值，不顯示能力成因公式或導師好壞評價。
- 代表事件依**綜合重要度公式**排名，參考事件數值影響（正負皆可）、累積發展、持續程度、涉及人物／關係、玩家決策與實際歷史影響；重要度只供篩選，不回寫任何遊戲數值。用固定入選門檻、本學期新增影響為主＋歷史輔助、不強制類型／正負平衡；不單憑資深教師狀態波動小就低估事件，也不因資深直接加成。達標不足10件全部入選，原則取前10名，但**第10名與之後同分者皆入選，無硬性10件上限**；單一累積事件本學期只佔一席。期末統一計分；公式、各權重、門檻及穩定同分呈現等技術細節交由Codex依N1～N8設計、自驗。未入選者仍保存於完整歷史。
- 歷史文字資料30學年完整保存且不自動刪除／舊學年摘要化；大量資料採按需載入、可匯出備份之適當本機儲存方案（優先評估IndexedDB而非受限的localStorage）。雲端帳號／同步目前不做，只預留日後版本擴充可能；每裝置3個本機存檔槽，跨裝置手動匯出匯入。

### 主畫面與時間資訊
- 顯示完整目前日期、星期、教師任教第幾年、所帶年級、上下學期、校曆第幾週及目前時段／科目／授課班級；**不自動預告下節**，玩家可自行開課表。背景與場景按實際對話、人物活動和劇情自動切換，不把活動項目對應到唯一固定地點；時間及室內外照明按情境變化；天氣可文字交代，不製作天氣視覺變體。
### 劇情閱讀與場景
- 劇情短頁、文字一次完整顯示，不做打字機、不捲動；明確上一頁／下一頁；最後一頁需點**結束**，不允許對話框空白點擊誤結束。空白處點擊可在非最後頁前進；回看同一階段時還原當頁所有視覺狀態，決策確認後不可跨界回翻。NPC說話者正常亮度、另一人稍暗，旁白兩人正常；多人依對話焦點輪替最多兩人，僅用簡單淡入／移動，場景切換短淡出入。
- 沒有 NPC 時可用場景＋旁白。電話使用通話面板但不繪遠端對象；聊天訊息顯示可辨識的已知學生／家長名稱，氣泡一頁可多則而非固定每則翻頁，必要時才顯示訊息時間、已讀狀態；公告／郵件／新聞共用文件式介面，外觀依類型調整。群體發言使用符合事實的群體稱呼，不硬替所有人畫立繪。事件不顯示開場標題、結束不評斷成敗。只製作少量共用視覺特效；**不做劇情音效／配音，背景音樂依第八大項已定案規格處理**。
### 操作及視窗
- 每個事件節點3～8項單選，可在同一事件階段出現多個決策；先選再按確認，鎖定後不重抽。**手機2欄×最多4列／桌機4欄×最多2列，按實際數量排列不補空白按鈕**；不改成選項分頁或捲動。一般活動單點執行，只有真正選擇決策才需確認。長選項文字自動折行與尺寸調整，工程須保證最小尺寸可讀。
- 課表、筆記本、選單在**對話與尚未確認選擇時也能開啟**，全程保留劇情頁與選取狀態，開關不耗遊戲時間。**手機採全螢幕浮動覆蓋視窗**，桌機採適當大小的浮窗；按×關閉，桌機可點窗外關閉；手機全螢幕以明確關閉控制返回（沒有可點的窗外區），不得意外點到底層對話或選項。對話期間六狀態列隱藏。
- 每個事件階段完成後統一顯示**有變化的六項當前狀態淨差額**，無變化不彈出；按繼續或點窗外關閉，外部點擊僅關閉不觸發底層互動。待辦按遊戲時間適度提前提示，逾期主動提醒但不宣告失敗；新歷史在筆記本入口顯示小圓點，不額外跳提示。狀態接近失敗門檻可使用模糊身心警訊，**不給精確危險數字或公式**。
### 裝置與資料
- 手機**只支援直式**、桌機橫式；兩者共用同一遊戲規則與功能。瀏覽器支持時優先嘗試真正鎖定直式；不支持時橫放顯示「請將手機轉為直式」並阻止橫式遊玩，恢復直式即續原狀；不另設手機橫式排版。桌機鍵盤便利操作屬可選工程細節，不改功能規則。
- 手機／桌機各自本機三欄存檔、手動匯入匯出轉移，不做當期雲端功能；保留未來擴充可能。手機全螢幕筆記本可查歷史與學期報告，相關內容以docs/04為準。

## 十七、第八大項：背景音樂、設定與遊戲體驗（2026-11-01 已定案，取代舊待議文字）
- **背景音樂七類，初期每類一首**：①一般校園、②衝突、③重大事情、④在家、⑤遊玩、⑥溫馨／感動、⑦荒謬／幽默。這是七首起步的規劃，正式曲目尚未尋找、下載或製作。參考《文明戰線》方式找適合的網路免費音樂，須逐首確認允許公開網頁遊戲使用、必要署名與修改／散布授權；免費不等於可任意使用。
- **配樂依實際場景及劇情氣氛切換**，不單以正負面事件分類判斷，不得洩露玩家未知的事實。情境改變時自然淡出前一首、淡入下一首；相同曲目連續適用時不中斷重播。重大事件也播放符合情境的音樂，**不另外規定刻意停音或靜音**。不做劇情、環境、通知音效與角色配音。
- **所有畫面均有小型背景音樂控制**，包括最初進入畫面、主選單與正式遊玩。喇叭圖示點一下開、再點一下關；旁邊的小箭頭展開／收起音量滑桿，不讓滑桿常駐遮擋畫面。開關及音量自動保存，關閉時記住原音量、切換畫面不重設。新玩家預設開啟，依瀏覽器規範於首次有效使用者互動後開始播放；往後沿用保存設定。不另彈首次詢問框，也不需從設定頁操作音樂。
- **固定字體及統一介面風格**：不設大／中／小切換、自由字級滑桿、深色／明亮模式或跟隨裝置切換。針對手機與電腦螢幕做適當字體及布局調整，維持既有固定、不捲動、逐頁對話框，不因額外字級選項增加翻頁。場景本身的日夜照明仍照原規劃。
- **新手說明與遊戲說明**：第一次遇到特定操作（事件決策、空堂活動、人物資訊、筆記本等）時提供簡短提示，閱畢不反覆顯示，玩家可到既有「遊戲說明」重新查閱。說明含操作、六項長期能力、六項當前狀態、人物關係、事件選項及學年挑戰的基本概念；不公開48項底層隱藏數值、NPC底層狀態、抽選公式、機率、最佳攻略或未知真相。提示不消耗遊戲時間、不得建立固定教學事件或改變原抽選。
- **三種正式難度（2026-11-05取代原單一難度）**：簡單／普通／困難＝任教第20／10／1年；不另加難度倍率，首版仍僅私立高中。
- **沿用原有非即時操作及回顧規則**：不另設暫停按鈕或離開分頁的繼續提示；沒有玩家操作便不推進時間與對話。保留上一頁／下一頁及既有歷史筆記本，不增加跨已確認決策的逐字對話回顧；不提供已讀快轉、自動播放或跳至下一個選項。玩家可按原本翻頁速度閱讀，選擇確認後仍不可撤回。
