## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生擔心照顧者在家長日只聽到剛開學的片面印象，請導師先讀自己寫的高中期待，卻不想全文交給家長。 |
| 核心衝突 | 學生希望被理解，導師不能擅自公開來增加說服力，也不能承諾只說好話。 |
| 導師困境 | 如何與學生確認可轉述範圍及必須由本人說明的部分，決定是否改約親子共同談話？ |
| 故事獨特性 | 與首池024作品展示不同，重點是會前授權導師作家庭溝通中介。 |

### 開場（依自然閱讀長度分頁）

- **P01｜旁白**：{{student_a.name}}放學時拿了一封寫給家長的短文給你，說想讓家裡知道自己對高中的期待。他把紙折回信封，又問：「如果我只同意說一句，你會不會不小心把後面也講出來？」
- **P02｜旁白**：他卻又急著補充：「老師，拜託不要把整篇都給他看，我還沒準備好。」
- **P03｜旁白**：星期六即將見到照顧者，你能協助轉述什麼、不能承諾什麼，得先讓本人明白。
