## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生佩服導師用逐步提示教同學，見導師以最快同學的答案判全桌懂了，想到同桌剛才差點哭，又怕自己下輪也被這樣叫起來，氣得當場打斷。 |
| 核心衝突 | 專業肯定和當面發火同時成立，學生想知道那套好教法還肯不肯用到自己這桌。 |
| 導師困境 | 可從原例重教，代價是最快的一桌須等；或讓每桌先寫自己卡住的一處，導師再只教重疊處，但仍有人須個別補問。 |
| 故事獨特性 | 學生不是討厭導師在教，而是第一次對教不到自己這桌生氣。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：課堂練習剛講完一題，這桌最快那位同學大聲報出答案，我點頭說了句「很好全桌都過關囉」，才正要轉去下一桌，student_a卻猛地舉手打斷我。
- **P02｜student_a**：老師等一下！他一個人懂不能算全桌都懂吧！你剛才教前面那桌還會一步一步提示，我們這桌有人還沒看懂你就要跳過去了喔？
- **P03｜旁白**：他聲音裡帶著火氣，旁邊那個同桌緊緊捏著筆、眼眶都紅了；可最快那一桌正等著聽下一題。

### 四個最終教師選項

| 選項ID | 玩家可見短句 | emotional | 教師已完成的客觀行動 | 優點及代價（不顯示玩家） |

| A | 我問全班剛剛這題還有誰也只聽懂一半的舉個手或比個暗號，確認人數後決定重講還是分桌帶。 | false | 先進行全班理解度真實普查，再依比例決定全班重講或桌邊補救。 | 跟不上又怕丟臉的學生未必敢在全班面前舉手承認自己沒懂。 |
| B | 我當場停下來用原來那題的逐步提示法在這桌重教一遍，不跳過任何沒懂的人。 | false | 立即於該桌重行以逐步提示法講解原例，確保未理解學生獲得支持。 | 已經懂且進度最快的那一桌得停下來乾等。 |
| C | 我笑著承認剛才自己偷懶跳太快，轉頭把紅筆塞給已經聽懂的那位同學：「換你當這桌小老師從第一步慢慢帶一遍，我就站在旁邊幫你抓漏！」 | true | 大方承認自身跳步疏失後，邀請該桌已理解學生主導逐步帶練、由導師站旁即時補漏。 | 既不用全班停下來乾等，又能讓懂的同學現學現賣，只是那位同學突然當小老師有點緊張。 |
| D | 我先點頭接下他的提醒說「你講得對，老師跳太快了」，請大家先自己試寫下題兩分鐘，我馬上坐到他同桌旁邊小聲重教一次。 | false | 先給予其他組別兩分鐘自主試寫，導師即時坐下進行一對一低壓力補救教學。 | 同桌被老師特地坐過來教，雖然聽懂了卻還是有點不好意思。 |
