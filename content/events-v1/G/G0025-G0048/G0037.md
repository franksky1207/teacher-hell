## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生在任課課堂甩門，家長到校了解後發現孩子聽見笑聲才離席，導師走向他時也同時被誤認為是在全班面前追究。家長原先想質問導師，談到一半才聽出兩人以為的是不同時刻。 |
| 核心衝突 | 家長想替孩子討回尊嚴，老師要處理離開教室的安全及教學中斷；兩種關切都會被孩子聽成大人替他決定感受。 |
| 導師困境 | 導師先確認學生安全，可等他能說再安排修復談話，也可先分開處理全班笑鬧及任課老師的課堂需要。 |
| 故事獨特性 | 甩門使每個人都以為自己是被拒絕的那個，衝突來自現場不同的情緒時點。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：家長坐下就問：「你為什麼要在全班面前追他？」你先確認學生現在在安全、有成人照看的位置，再按自己親見的順序說明。家長講到孩子回家的版本，忽然停住：「他說的是笑聲以後，不是你走過去以後？」兩個人原來各抓住不同的一秒。他仍質疑你的處理，也說家裡能陪孩子安定，但不要再替孩子說已經沒事。安全已確認，甩門帶來的課堂中斷和被笑的難受，卻不能混成一個問題。
