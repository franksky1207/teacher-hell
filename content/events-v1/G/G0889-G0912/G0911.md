## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 非常信任導師處置能力的輔導室同仁，平時資訊傳達很主動，但今天因為觀察到某位學生昨晚家庭或情緒狀況不穩而有些焦慮，早自習前趕來主動跟導師同步觀察細節，順便要求導師今天暫時修改「早自習公開點名登記遲到」的班務程序，改為私下個別關心就好。 |
| 核心衝突 | 輔導端出於專業保護要求暫緩公開班規程序，卻可能讓不知情的其他同學覺得那位學生有特權。 |
| 導師困境 | 立刻配合取消今天公開點名、改用傳簽單低調處理，雖然保護了該生情緒卻可能引起其他常被點名的同學疑問；堅持照舊程序登記再私下補輔導，焦慮的同仁會擔心當眾點名成為壓垮學生的最後一根稻草。 |
| 故事獨特性 | 跨處室合作裡「保密原則」與「班級公開規範一致性」的微衝突，重點在兩位老師互信下的程序微調。 |
