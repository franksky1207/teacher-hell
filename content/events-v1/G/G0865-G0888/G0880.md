## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一位需輪班並照顧家人的家長平常很願意配合導師協調，但這天接到學校通知「週五下午四點前必須家長本人到校親簽領回某項紙本申請」，因為白天根本請不出假而火冒三丈，打電話給導師要求修改這個僵化的領件程序，改由孩子代領或線上拍照確認。 |
| 核心衝突 | 學校為防弊訂出的白天親簽規定，對輪班與高照顧負擔的家庭成了變相刁難。 |
| 導師困境 | 幫家長向行政端爭取破例由學生代領，承辦人員一定推說出事導師要負責；照規定告訴家長只能請假來簽，等於逼這個已經快撐不住的家長跟學校翻臉。 |
| 故事獨特性 | 從輪班家長的真實請假困境，揭開校內「一切以家長白天親到為準」行政程序的盲點。 |

### 開場
- **P01｜旁白與當場對話**：電話那頭先問能不能請假，隨即自己答不能。他輪班還顧人，平常願意跟你一項項分工，這次卻聽到週五四點前必須本人來，火全上來。「孩子代拿不行？我拍照確認也不行？」你已把原期限和誰能核准說清，不替他填同意。他停一下，說現在真的離不開：「老師，我們總要有一個能做的辦法。」
