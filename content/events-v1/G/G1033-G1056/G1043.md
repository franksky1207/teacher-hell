## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名家境寬裕、零用錢充足的學生（`7-3`）平時一向認同導師訂的「課堂與自習禁止使用智慧手機與連網平板」班規（`9-1`）。這週他在網路開箱影片輕信評測網紅說的「這款最新電子墨水掃描翻譯筆沒有上網瀏覽器，全臺高中考場跟課堂都算純文具」（`8-3`），花了好幾千元買來後，立刻拿著產品說明書找導師要求修改班規細則（`12-1`），希望正式把「不連網電子翻譯筆」列為課堂合法自習工具。導師一看說明書其實內建離線萬字詞庫與整段語音朗讀，並不合校內單純紙本字典標準。 |
| 核心衝突 | 守規矩的學生花大錢買來踩在規定灰色地帶的新型學習工具，讓導師不得不在「守住班規單純性」與「不打擊學生自學熱情」間做制度界定。 |
| 導師困境 | 破例修改班規允許這類離線掃描筆進課堂，下週其他家境寬裕的同學多半跟進買進各種高階離線學習機、平白拉開教室工具落差；直接依電子產品規定禁止攜入課堂，這名平時乖乖交出手機、花自己的錢買工具想讀書的學生難免大受打擊。 |
| 故事獨特性 | 緊扣「電子墨水掃描翻譯筆」的當代校園新灰色工具，寫出守規矩學生如何用財力與網路開箱資訊來談判改班規。 |

### 開場
- **P01｜旁白**：學生把翻譯筆的盒子放得很輕，像怕你直接說不。他指著沒有瀏覽器那一頁，旁邊還印著離線詞庫與朗讀功能。
- **P02｜學生**：我就是認同不能連網才買這支。網紅說全臺都算文具，好幾千耶。
- **P03｜旁白**：你們已核對現行校規，不能把開箱說法當所有課堂考試許可。他沒有收盒子，改問能不能正式改細則。你的紙本字典就在盒子旁，厚得像另一種年代。
