## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位資深數學科任教師多年來家庭經濟與居住環境長年安穩無虞（`7-4` 使其平時手邊備齊許多高品質教學小工具），平時非常認可導師帶班的認真專業（`8-1`），但最受不了學生上課連圓規三角板都不帶。今天進導師班上課又遇到五六個學生忘記帶作圖工具，他氣到眉頭緊皺（`2-1`），卻還是回辦公室拿出自己合法自購的備用鋁合金圓規與直尺借給大家上課（`11-4`），下課直接把盒子拍在導師桌上：「老師我認可你帶班才幫你救場，但這組上個月已經被別班弄丟兩支了，放學前你幫我一個個追回來交給我！」 |
| 核心衝突 | 認可導師又自費備品的資深同事在氣頭上替導師班解圍，卻順手把「追回私人教具」的保管責任直接丟回導師身上。 |
| 導師困境 | 下課立刻逐桌清點追回每一支圓規三角板、少一支就自己掏錢買新的賠給同事，平白多出一樁物品追討苦差；笑著請同事以後乾脆沒帶就照平時成績扣分不用借，這名認可你又好心出借私人教具的同事恐怕覺得導師連幫忙追回工具都不願意。 |
| 故事獨特性 | 沒有誰想偷東西，寫出資深教師「邊罵學生沒帶工具邊掏私人教具借用，下課再要導師當回收窗口」的真實辦公室日常。 |
