## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校內資訊組職員技術上手極快（`3-4`），但因為上次導師遲交數位設備盤點表而一直心存不滿（`5-4`）。今天早自習時整層樓教學網路突然大當機，他三兩下追查後台發現問題竟出在導師班教室後方角落被前人或學生私接了一台舊式分享器造成 IP 衝突，當場火大（`2-1`）衝進辦公室找導師協調處理（`10-4`）：「你上次盤點表都不好好看清楚現在出事了吧？整層樓老師都在等網路，你現在跟我過去教室確認後把那台拔掉重配！」 |
| 核心衝突 | 原本就對導師有微詞的技術職員抓到真實的教室設備違規，藉著緊急搶修合作的機會當面把火氣與舊帳一起端出來。 |
| 導師困境 | 立刻放下手邊早自習事務陪這名火大的同事跑去教室配合拔線重設、順便乖乖挨唸，班上早自習秩序一時無人看顧；請他先依技術權限直接進教室處理、等下課再來找導師了解是誰插的線，這名本就不滿你的同事恐怕直接把「某班私接設備害全層斷網」記進週報呈給主管。 |
| 故事獨特性 | 行政與導師的合作建立在「一個真技術出包＋一筆舊怨」上，寫出校園數位基礎設施出事時的真實火藥味。 |
