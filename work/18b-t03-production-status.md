## 真正未完成的品質工作（不能用數量代替）

- 本次快照共 804 個選項；其中含加權多結果的選項約 6、具直接或加權數值變化的選項約 10、包含第二個故事階段的稿件約 3。**這些不是要求各件都改數值／加長劇情的配額**，而是提醒不能一律只留下「轉達需求／尚待確認」，造成選擇無實際差別。依個別故事因果逐件做必要的文字、世界事實、數值和有條件變化修訂。
- **T03-05** 轉出入、休復學、轉班等情境必須以正式在籍／異動紀錄、適當年級及現行遊戲名額為前提。故事中口稱『轉入』『復學』不會自動建立合法學籍；沒有精準資格接線及真實世界佐證者保持隔離。
- **T03-06** 長期缺課後返校故事必須存在對應的合法缺課／返校歷史；不可讓從未長缺課的學生隨機遇到『返校』事件。正式請假與依法休復學不能混淆。缺精準前因時保持隔離。

- 工程狀態由**最新相同提交 SHA 的 GitHub Actions**精準驗證，不以較早成功跑次或成功生成 JS 代替；尚未完成完整內容放行、resolver、候選與正式進度整合。**禁止自動升 ready、合併、部署。**
