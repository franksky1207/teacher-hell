## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 在職值勤者見導師把紅貼貼在暫不能用的階梯入口，轉頭又讓熟悉的學生從旁邊過，因雙重信號發怒。職員希望分流能持續可查，察看後願從要求全部禁用改成只依成人明確放行。 |
| 核心衝突 | 一次便利例外會教給後方學生一個錯誤規則，整段封閉也會把已確認可走的人留在原處。 |
| 導師困境 | 可收回教師私下例外、用明確可知的單一指示，或由權責人暫停全段重新確認。 |
| 故事獨特性 | 安全問題出在學生看見貼紙和成人示範互相矛盾。 |
