## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長帶孩子來問自習問題，聽到另一名同學不敢走進辦公室，提出願站旁邊陪入。他本人的回家分工讓可用時間很有限。 |
| 核心衝突 | 陪進去有助力，成人卻不能藉此知道另一個孩子的私事。 |
| 導師困境 | 可由其他合法成人接手、讓他只陪到門口，或協助原學生自行選擇何時進。 |
| 故事獨特性 | 家長看見別人需要，但幫完仍須按時處理自己的家務。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：辦公室外，家長本來只陪自己的孩子來問自習安排，卻停在另一個學生旁邊。「你要進去嗎？我可以陪你走到門口。」那孩子沒往前，也沒說不要。家長看了看時間：「我晚上還得回去接手家裡的事，不能坐太久。」你先把談話移離其他人聽得見的地方，確認沒有需要立即處理的危急狀況。家長把包包換到另一肩，自己的孩子也站起來，三個人都在等下一句。
