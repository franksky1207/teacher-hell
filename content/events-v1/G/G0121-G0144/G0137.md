## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 有號召力的學生聽同伴說家裡照顧換手就能延後返家，信以為真，留下幫同學找遺失的作業，回神發現原本家務仍在等他。 |
| 核心衝突 | 同學因他的投入跟著停下，幫忙找變成所有人都要待到找到。 |
| 導師困境 | 導師可終止集體尋找、限定自願範圍，或協助學生即刻聯繫家人並交回責任。 |
| 故事獨特性 | 原先自己能多留的假設，使學生無意間成為留住全班的人。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「我家有人接了，我能留下。」帶頭學生這樣一說，其他人也停下來幫找作業。過一會，他收到家裡訊息，臉變了：「可是他不是說有人換手？」原來只是信了同伴轉述，照顧的事仍在等他。你先讓他本人核對返家安排，說離校時間不能一直往後拖，也沒讓誰翻同學私物。失主說不必全部找，他反而急：「都陪我留了，怎麼好意思先走。」一群人站在桌邊，還沒決定哪些東西先收。
