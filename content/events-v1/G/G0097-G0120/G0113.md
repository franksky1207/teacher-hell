## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生平時由家人幫忙顧家中店面，才擠得出三分鐘在導師面前把口頭報告練一遍，結果報告開場像街坊叫賣，講到第三句全班都在笑。 |
| 核心衝突 | 熟悉的生活節奏能讓報告更自然，但笑聲會把本人轉回不敢使用原聲的狀態。 |
| 導師困境 | 可示範如何保留節奏而轉變情境、請本人再試一種開頭，或把笑聲先停在全班都知道的安全範圍。 |
| 故事獨特性 | 生活裡會的說話方式，搬進教室竟同時成為強項和笑點。 |
