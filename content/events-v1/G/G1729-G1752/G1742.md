## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 任課同事下班累得把私人共讀聚會看成有人自願帶稿，與導師情感親近又有意一起幫聚會備材料，卻希望導師改掉聚會原定共讀自己作品的決定，因為他一聽「稿」就會開始逐字改。他到現場才承認本來最想帶的是一篇不用修改的笑話。 |
| 核心衝突 | 兩人友情靠一起笑成形，現在稿子一展開就像自己主動加班。 |
| 導師困境 | 可保留共讀、限定只說讀後感並容他自己選篇，代價是其他人得放掉修改；或與參與者改玩即席接句，未讀稿的人改有位置，原準備者失去朗讀。 |
| 故事獨特性 | 累的不只是想休息的人，也是想找回自己不必挑錯的耳朵。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：下班後的私人共讀聚會剛要泡茶開聊，幾個朋友已經翻開桌上的筆記準備按原訂計畫共讀作品。平常總愛幫聚會備材料的subject_teacher今天卻一臉疲倦地靠在椅背上，連紙袋都沒打開。
- **P02｜旁白**：他趁大家拿杯子時拉了我一把，苦笑著把紙袋往我手邊推了推。
- **P03｜subject_teacher**：我今天實在太累了，一聽到「稿」字腦袋就自動開始逐字抓錯……其實我本來最想帶來的只是一篇不用改的笑話。今晚能不能別共讀我那篇了？
