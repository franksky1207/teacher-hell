## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 任課教師住處管線漏水，連夜等師傅，疲倦得開錯班級門。他出來後主動告訴導師自己剛把第一題講給隔壁班聽，堅持兩班都改用同一題的不同數字，免讓學生因他的錯受罰。校方巡堂正好看見他折返，行政以為他答應多接一班。 |
| 核心衝突 | 一場誤闖同時變成試題失誤和一筆看似自願的代課。 |
| 導師困境 | 導師當下向巡堂說明會使錯題一事曝光；先處理學生考前疑問又可能讓同事的「自願」直接排進代課表。 |
| 故事獨特性 | 睡不飽的教師先交代對學生有何影響，沒想到校方唯一看見的是他多走進一個班。 |
