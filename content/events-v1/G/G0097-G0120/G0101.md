## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平時與導師有說有笑的學生，見導師被插嘴惹煩後把全班一起罵，終於頂回去。導師稍後收回連坐，學生也開口支持。 |
| 核心衝突 | 導師被批評難免想護面子，但學生把抗議和支持分開，處罰頂嘴會抹掉不同意見。 |
| 導師困境 | 可先承認自己罵過頭、分別處理干擾與語氣，或請學生待情緒穩定後一起談如何回到課堂。 |
| 故事獨特性 | 最敢阻止導師的人，也是第一個支持他改口的人。 |
