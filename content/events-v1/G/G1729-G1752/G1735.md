## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生在家長期替親人分擔收站工作，平日在班上很能帶同伴，見導師示範紙模型的搬運方法，質疑是否能讓手空不出來的人照做，願親自幫導師試另一種步驟。同學開始跟喊原方法根本沒用，他卻知道家中也有人最愛那一套。 |
| 核心衝突 | 他想讓教法認得不同處境，聲援越大卻越像把別人的做法說成笨。 |
| 導師困境 | 可讓他自己並列兩種適用情況，代價是得當場替剛批評的版本說話；或由導師帶全組用相同初始條件逐項試，會占掉別組說明時間。 |
| 故事獨特性 | 把家裡一種方法拿來當異議的人，最後還要替家裡另一種習慣辯護。 |
