## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 圖書館這名職員平時十分敬重導師正派認真的為人（`5-3`），不愛跟風處室其他人「把待報廢舊書擺在地下室積灰塵不管」的消極習慣（`6-2`），同時內心非常渴望在師生面前獲得「最會活化資源」的肯定（`4-4`）。今天早上執行力極強的他（`3-3`）沒先問過需求，一口氣推著推車送來三大箱擦得乾乾淨淨的書放到導師班閱讀角，滿臉期待等導師誇獎——結果導師一翻，全是十五年前舊課綱的厚重題庫與過時參考書，學生根本沒人想翻。 |
| 核心衝突 | 敬重導師又想展現活化資源績效的同事抱來三大箱不合時宜的舊書，讓導師卡在「直接退回傷了熱心同事的期待」與「硬收下來佔爆教室後方書架」之間。 |
| 導師困境 | 笑著收下這三大箱舊書暫放教室角落幾天再低調處理（保住這名敬重你的同事顏面，卻讓原本就窄的教室閱讀角被過時題庫塞爆、圖書股長抱怨沒位放新書）；當場坦白點出課綱早已改版好幾輪、這批書學生真的用不上，請他依程序辦理報廢或轉送回收（守住教室空間與實用性，這名推著三大箱汗流浹背來討誇獎的同事當場神情落寞）。 |
| 故事獨特性 | 寫出校園圖書館淘汰舊書時「同事一番苦心擦乾淨送來、卻是十五年前舊課綱題庫」的尷尬職場善意。 |
