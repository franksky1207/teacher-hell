## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家中長輩以陪看路線和提醒動線支持學生，學生想自行完成普通校內找點練習，辨認某段有維修路障而主動繞開。他連日注意導師站在哪個地方看自己，走到安全處才坦白想在沒有老師視線的位置也能完成。 |
| 核心衝突 | 對孩子有實際幫助的觀察，也讓他以為獨立只能發生在老師看得到時。 |
| 導師困境 | 可在核可可視範圍改成教師延後跟進，代價是少些即時提示；或換成學生自行標記路線、老師核對後再走一次，失去原本這回首次的成果。 |
| 故事獨特性 | 有安全意識的人要求自主，具體要求是老師何時再抬頭。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：校內找點練習剛繞過前面那塊施工警示牌，student_a就很警覺地主動繞開維修區走進核可的安全步道——他家裡長輩平常都會陪他看路線，所以安全意識一直很好。只是他走了兩步又回頭瞄我一眼，腳步忽然停在樹蔭下。
- **P02｜student_a**：老師，你這幾天都站在那個轉角看我走到哪裡……我已經有自己看路障繞開了。如果老師一直看著我，我會覺得好像還是有人在帶路。
- **P03｜旁白**：他抓著地圖紙角小聲補了一句：「這段明明很安全，我可以自己走，但你可不可以先不要一直看？」

| B | 「你剛剛自己看懂路障繞開已經很獨立了！今天先在這裡安全收工記一筆，明天我們挑一條沒有施工的純安全段讓你自己走。」 | false | 先肯定其安全繞行表現並結束本日路段，另約明日於無施工變數之安全區進行無教師跟隨練習。 | 最穩妥避開今日施工區風險，但今天這次獨立找點就得先停在半路。 |
| C | 聽他連日盯著我站哪裡、走到安全處才小聲求我「別一直看」，我忽然明白這孩子在家也被長輩小心翼翼護習慣了才更想自己走一次，心裡又酸又好笑，直接把紀錄板塞進包包、轉身走上旁邊視野最好的涼亭台階拿水壺晃了晃：「好啦！老師上台階喝水乘涼看操場風景，安全區你自己去闖關！」 | true | 因體會學生渴望掙脫過度保護的心情，導師收起紀錄板退上視野開闊的旁側涼亭台階喝水歇腳，改以遠距全場目視看顧取代近身尾隨。 | 在嚴守校方安全看顧前提下給足他不被盯梢的自主感，但老師得在台階上全程目視盯緊、不敢真的滑神。 |
| D | 「那你先把接下來要繞開施工區的安全路線標在地圖上給我核對過，對完你自己去走一次。」 | false | 請student_a預先於地圖標記安全繞行路線經教師核對後，再行獨立完成路線。 | 確保全程安全無虞再放手，但失去了原本這回「首次即興獨立找點」的成果。 |
