# 隱藏數值、事件引擎與平衡
> 48 項基礎數值與 0～100 尺度已於 2026-10-31 定案；事件權重、公式及精確波動幅度尚未定案。

## 第四輪：確定數值門檻與30年平衡（2026-10-31）
### 初始化
- **第一學年新手長期能力六項平均40、總和240**，六項可在0～100極端分布，不限定單項落在窄區間、不設固定角色原型。由底層48項適用數值生成／約束一致，開局前無限重抽能力組合，正式開始後鎖定；不得因重抽增加總額。
- **六項當前狀態固定初始**：體力100、精神100、抗壓100、聲望40、熱忱100、情緒100。面板仍是底層數值的衍生結果；聲望40不能取代不同人物各自的評價。
### 崩潰雙標準 v1.0
| 六項當前狀態 | 綜合權重 | 單項危機門檻（含） |
|---|---:|---:|
| 體力 | 20% | ≤30 |
| 精神 | 25% | ≤35 |
| 抗壓 | 20% | ≤30 |
| 聲望 | 5% | ≤20 |
| 熱忱 | 15% | ≤25 |

- 加權分數70～100一般、55～未滿70初期警訊、40～未滿55明顯危機、25～未滿40高度危機、未滿25極度危機；**單項門檻與綜合區間並行**，但同一事件不得重複抽兩次／重複結算。
- 達標只提高或開啟合資格危機候選池，**不直接失敗**；聲望單項偏向外部人際／職務危機，不能等同身心崩潰。內部耗竭可能導致無法繼續任教，外部解聘／撤換等按客觀事件及程序獨立判定；部分重大危機可無最後求援機會直接失敗。
- **長期能力不直接加權崩潰分數**，而是影響事件處理成功率、狀態消耗及恢復效率；年資效果透過能力及狀態穩定性，不再另加直接保護。高能力亦可能開啟高期待、高責任的更難候選事件，但不能讓同一事件因能力高反而更難處理。
### 事件衝擊、自然變化與回血
- 單一事件對當前狀態變動的**非硬性參考區間**：日常約1～5、一般約5～12、重大約12～25、極端約25～50，合理情況可更大；正負雙向，並非每項都變。同日多事件可累積，無單日保護上限；每個事件只結算一次。每日仍有有限、可隨機的狀態連動，不能同輪無限循環；歷史不重複計分。
- 玩家可在合理空檔主動休息、請假、求緩、求援、諮商及安排私人活動，耗費時間並由數值／候選池決定結果；不因當前狀態低就鎖住合理行動，僅客觀事實、權限／時間限制可排除。
- 週末休閒的結果約**70%～80%傾向至少一項相關狀態有利恢復**，不等於每項都回升；下班後、寒暑假、旅行、陪家人、在家興趣活動亦可恢復，偶有意外負面或學校小事件。長假累積回復潛力較大但不自動滿血；歷史與未結問題仍在。
### 難度驗收
- 私立高中第一版，未來公立高中兩模式共用核心。兩者目標**第一學年單次挑戰通關率約20%、第30學年約60%**（以後者作資深難度上限方向），僅供長期大量模擬校正，**不寫死過關抽籤、不為維持難度懲罰玩家**。私立主要提高工作密度與時間衝突，公立主要提高部分事件處理難度。實際初始能力、狀態及事件分布要共同驗證。


## 已定案：12 類 × 4 項＝48 項共用隱藏數值（2026-10-31）
- **12 個分類、每類 4 項、合計 48 項；代碼和名稱已定案。每項 0～100，數值越高表示該特質／狀態程度越高，不等於越好。** 這是社會互動遊戲的規格，不是科學心理測量。
- 48 項是**全遊戲共用字典**，不是每個人物都具有 48 項，也不是每一個數值都要以人物個人為持有者；關係、群體、班級、組織與外部事件可持有相應欄位。

### 人物與事件引用
- **35 類人物／身分標籤的各自 4～6 項主要引用欄位已於 2026-10-31 定案**，完整逐類對照表見 `01-世界角色與記憶.md`；同一人物可兼任身分，共用欄位而非重複建立數值。4～6 項為角色基準配置，不限制事件額外跨人物及環境引用。
- **事件可跨不同人物、不同人物類別與環境／關係持有者抓取相關數值**；每個事件小主題固定引用3項主題共用核心＋3項小主題附加數值；歷史另作資格及敘事條件，不額外逐筆加權。不可誤設為單一角色必須擁有事件所需全部欄位。
- **事件共用六項加權公式**，各小主題獨立配置六項數值的權重、方向與跨人物來源，不固定核心與附加的權重比例。事件抽選採直接加權隨機，暫不另加事件分數隨機R；困境傾向倍率K仍待測試，不為每個事件另寫演算法。
- 事件累積**依類型、當事人、時間、結果與知情**紀錄，避免只存一個無差別總次數；角色身分、職權、客觀事實、目標、承諾、時間不強制塞入 48 項。

### 數值變動與隨機性
- 所有變化限制在 **0～100**；人物數值可受事件、時間與**隨機波動**影響。例如 50 隔天變為 70（隨機 +20）是允許的，尤其短期情緒；長期人格或能力一般較穩定，但重大經歷可造成較大調整。
- 暫定共通形式：`新值 = clamp(舊值 + 事件變化 + 隨機變化, 0, 100)`。**實際波動幅度、頻率、各欄位的穩定度與權重尚未定案**，不代表 48 項每天強制擲骰改值。
- 除數值波動外，事件抽取、NPC 自主反應、玩家選擇結果仍可各自隨機；先遵守事件資格、合法權責、資訊與歷史，且**每次確認只結算並保存一次**，不得重整重抽。
- 相似欄位分工：1-1 責任感不同於 3-3 執行能力；2-2 焦慮不同於 7-2 家庭負擔；6-3 群體凝聚力不同於 9-2 合作氣氛；10-1 支援意願不同於 11-3 人力充足。可推算的客觀工作及時間資料優先從紀錄取得，再換算 0～100 的遊戲用指標，避免重複來源。

## 第一階段：人物數值來源與初始化（2026-10-31 已確認方向）

### 玩家面板：6項長期能力＋6項當前屬性
- **48項共用隱藏數值才是事件、人物行為與世界更新的底層資料**；玩家面板12項僅從適用於玩家本人及其處境、評價的既有數值換算顯示，不另儲存、也不回頭參與事件加權。玩家看不到底層48項；同一來源可重複被多個面板項目引用，權重與換算公式全部暫緩，由後續Codex統一設計並驗收。數值方向不必一律正向。
- **六項長期能力**穩定性高，主要取玩家本人的能力及相對穩定特質；重大經歷可改變，年資提供逐漸趨緩的成長傾向。來源對照如下：

| 玩家能力 | 底層引用（代碼） |
|---|---|
| 教學能力 | 3-1、3-2、3-3、3-4、1-3 |
| 班級經營 | 3-1、3-2、3-3、1-3、6-1、3-4、1-4 |
| 溝通協調 | 3-1、1-3、3-2、3-4、1-2（反向）、6-1 |
| 行政應對 | 3-3、3-2、3-1、3-4、1-4 |
| 危機處理 | 3-2、3-3、3-4、1-2（反向）、3-1、1-3 |
| 情緒調適 | 3-4、3-2、1-2（反向）、1-3、1-4 |

- **六項當前屬性**採統一兩字名稱，依個人、生活、工作條件及他人評價動態呈現；可正負變動，波動速度依屬性而異：

| 玩家屬性 | 底層引用（代碼） |
|---|---|
| 體力 | 2-3（反向）、11-1（反向）、11-2、7-4、7-2（反向）、11-3 |
| 精神 | 2-3（反向）、2-2（反向）、2-1（反向）、7-4、11-1（反向）、11-2、7-2（反向） |
| 抗壓 | 3-4、3-2、1-2（反向）、7-4、7-1、11-3、1-4 |
| 聲望 | 8-1、8-2（反向）、5-3、5-1、5-4（反向） |
| 熱忱 | 4-1、2-4、9-3、11-1（反向）、2-3（反向）、7-4、7-1、11-2 |
| 情緒 | 2-1（反向）、2-2（反向）、2-3（反向）、5-4（反向）、7-4、11-1（反向） |

- 「情緒」定義為**當前情緒穩定程度，越高越穩定**，不是情緒強度；不開心不等於失控。「情緒調適」是較長期能力，不同於當下情緒。「聲望」彙整**有來源的不同人物／群體對玩家的定向評價**，不是玩家自評，也不抹平個別立場；體力、精神、情緒較易短期波動，熱忱與聲望通常累積較慢，重大事件例外。
- **年資與實際經歷共同作用**：玩家始終為同一高中之導師，年資可使六項長期能力緩慢提升、前期較顯著而後期趨緩，但並非固定每年加分、更非必定成功；經歷、選擇及重大事件可形成個別差異或退步。年資也降低**當前狀態正、負兩方向的短期波動**，對熟悉的一般事件尤然；重大事件仍可劇烈影響。年資穩定性不得削弱事件對其他人物、關係、客觀責任與世界的實際影響，不自動提高聲望。所有效果須先作用於適當的底層資料，再重新換算面板，**不得額外在面板疊加年資分數**。
- 此對照為已選定的**引用類型／方向草案**，非固定公式；例如原則性、同理心及生活支持的影響不保證線性或單向。詳細權重、初始值、波動週期與係數全部保留給整體公式設計。


### 第二階段：數值變動與世界連動（已確認原則）
- **統一核心：所有已發生的事件及具實質影響的NPC行為，均在發生／結果確定時完成一次數值更新判定**，即時更新受影響的人物、A→B定向關係、家庭、班級、群體或環境的48項適用欄位；可以判定為無須改值，不能硬性每項都加減。同步保存客觀歷史、當事人、時間、知情範圍、結果與事件狀態。往後抽選行為／事件直接使用**最新數值**，不得把同一歷史再次加分、扣分或重複套用既有結果；歷史僅用於資格、因果、知情、時序、未結事件與文字回收。累積事件必須符合真正相關的歷史條件，不可單憑高不滿推斷曾有申訴。
- **事件後果採「主要影響＋有條件擴散」**：先影響直接當事人，再依目擊、實際接觸、合理資訊傳播與知情條件影響他人，可即時或延遲。旁觀學生／家長等逐人依自身特質、關係、現況及隨機性反應；同一處置可有人支持、有人反對、有人無感，也可尊重與不滿同時上升。不得讓不知情者憑空改變評價，亦不強制全班同向變動。延遲影響不保證爆發；未結事件後續與新增事件分開管理。
- **NPC自主行為無須額外一套完整生活模擬**：適用人物的48項狀態合理隨機波動，再依身分、情境、關係及資訊等條件，以既有50種行為與事件池判定行為及後果。玩家無法預知每個學生當下狀態；NPC彼此可在背景中行動，即使玩家尚未知道。不需每人每日強制抽一次行為；隨機不能捏造未發生的客觀歷史。
- **每日自然更新一次＋實際事件／行為即時更新**：短期情緒疲勞較易波動，人格、能力、動機較穩定，定向關係及聲譽由互動／歷史逐漸改變，班級與工作環境依情境變動；允許自然維持不變。自然更新可參考個人現況、相關人物、家庭／班級環境及合理隨機，不需逐分鐘更新全部NPC，也不讓同日互相套算無限連鎖。
- **導師的長期能力是年資優勢的主要表現**：年資及實際經歷已透過底層數值反映在六項長期能力，**家長反應主要受導師六項長期能力相關的底層因素影響**；**學生反應可受導師全部六項能力＋六項當前屬性所代表的底層因素影響**。二者仍受各自人格、歷史、親師／師生關係與合理隨機性影響；不額外對家長或學生施加「年資直接加成」，也**不把12項衍生面板分數再次加權**。接觸、具體行為、既有關係或可信傳播才可使導師影響落到特定人身上；家長亦會影響學生，親子關係可雙向變化。
- **班級／群體以隨機變化為主，歷史改變當前數值及後續事件資格**：班級秩序9-1、合作氣氛9-2、群體凝聚力6-3、群體排他傾向6-4等由適當群體持有，並受導師、學生、相關行為／事件影響；可呈現穩定或混亂，但不另建立獨立「混亂值」。過往已結事件不永久額外扣分，未結或尚有相關因果的歷史可開啟合理後續；班級數值不代表40位學生全都同方向反應。

### 第三階段：多候選池、時間成本與資訊傳播（已定案）
- **統一運作順序**：讀取適用的48項當前數值＋客觀條件與歷史資格 → 組成多個合格候選池（事件、50種行為、人物反應、消息傳播、玩家選擇後果） → 分別依相關數值權重與隨機抽取 → 鎖定客觀事件及結果 → 依玩家知情範圍生成文字 → 即時更新相關數值與客觀歷史。不得讓文字劇本預先決定結果再倒推數值。
- **每次只抽合理候選項**：硬性身分、時間、地點、權責、知情、未結事件及承諾／歷史條件先篩選；數值控制傾向而非固定行動。同人同情境可有不同反應，無行動與平靜亦可抽到。可有多個候選池而不需合併為單一萬用池；每項不可反覆重抽以求戲劇效果，已結算不重複套用。
- **輕量時間限制（已選方案B）**：保留事件內實際時間推進、截止時間及事先承諾，事件處理成本占用時間，並依實際結果更新工作負荷11-1、時間餘裕11-2、人力支援11-3、工作資源11-4，以及疲勞2-3、焦慮2-2等相關數值。不同事件可能同時發生；玩家無法同時親自完成衝突事項，可延後、拒絕或轉交，而對方是否接受／協助仍進候選池判定；不做逐分鐘的複雜排程介面。時間流逝中NPC及未結事件自行發展，不保證變糟。
- **傳聞、聲譽與搞事**：不同角色及群體各自持有正面聲譽8-1、負面聲譽8-2等適用評價；傳播由8-3採信、8-4傳播、6-1影響力、定向信任／尊重／不滿及實際接觸路徑等共同加權。消息可如實、遺漏、誤解、誇大、惡意扭曲、不被相信、遭澄清或未傳播；須分離**客觀發生事實**與**人物知悉／相信的版本**。即使高信任者也可能不合理搞事，僅權重較低；傳播及反駁可能成敗不一，結果更新受影響數值與歷史。無須模擬每則一般閒聊。
- **公開資訊的層次**：玩家六項長期能力＋六項當前屬性精確顯示0～100，皆是48項適用底層資料的衍生顯示，不另產生第二套演算回饋；其餘NPC、關係、家庭、班級、群體、行政／環境等底層數值不對玩家公開，只能以合理可知的文字、行為、對話、觀察及筆記本已知歷史間接理解。不同角色的內在觀點不因玩家面板聲望彙整而合併。
- **留待Codex**：候選池的權重、時間成本幅度、資訊傳播節點／停止機率、失真模式、資訊可見度與衍生面板對照的具體算法，統一規格化後測試；現階段只確認邏輯，不假設程式已存在。

### 行為讀取與演算原則
- 事件指定相關人物與情境，從不同人物／關係／群體取得行為所需的4～5項數值；**不能把行為讀值限制在發起者一人身上**，也不用讓每個角色擁有全部48項。

- 行為與事件可使用共用取值／加權核心；背景行為形成歷史時同步更新相關狀態數值，可能令累積事件符合歷史資格，但不保證必然升級。
- 具體角色來源綁定、事件資格、權重係數、波動參數**留待事件分類與公式階段**；現階段不增加新數值或專用公式。人物資料、法律權責與事件知情仍須合理。

- 同一類歷史必須保留涉及哪些人物／群體、時間與後續結果；已解決、仍待處理、已澄清等狀態可改變其事件資格、劇情回收及當前數值更新，不另逐筆加歷史分數。
- **不採歷史紀錄逐筆加減或先前討論的85＋（−15～+15）歷史分數方案**；相關歷史仍可作累積事件的必要資格、知情、已解決／未解決與劇情回收條件。精確狀態更新幅度、數值衰退及資格門檻尚未定案。
- 50種行為可形成歷史並即時改變當前數值；直接事件無須指定歷史，累積事件必須先符合相關歷史條件。兩者使用同一組六項加權計算及共同候選池；不因屬於累積事件就另外加歷史分數。

## 每日新事件與共用加權流程（本輪設計方向）
1. 每日先隨機決定新增事件數量，允許0件；即使沒有新事件，也呈現日常互動，並另行推進已存在的事件。
2. 對直接與累積小主題一併檢查人物、時段、知情及事實等資格；累積小主題另需符合指定的歷史條件。每個小主題只屬於一種類型，不複製直接／累積兩版。
3. 合資格小主題讀取3項主題核心＋3項小主題附加數值（可跨人物與行為引用），依小主題自己的六項係數加權。概念式：B＝Σ(wᵢ×Xᵢ)，Σwᵢ＝1；方向轉換依事件設定，Xᵢ為0～100。
4. 以B為基礎抽選權重，依需要乘困境傾向倍率K：W＝B×K；K的分組、倍率及嚴重度差別尚未定案。暫不另加事件抽選用隨機R；依W進行加權隨機抽取，不固定選最高分。
5. 抽中的事件及玩家選擇／NPC反應各依合資格結果判定一次、保存；結果同步更新相關當前數值與60項歷史紀錄，未結事件可繼續發展。每日多次抽選的重新驗證與去重細節尚未定案。

## 平衡原則
- 單一小主題固定讀取6個相關欄位，來源可跨人物、關係、群體／環境；48項字典不代表每個人物都持有全部欄位。
- 小事件有合理影響幅度，重大事件需有足夠原因才可產生大變動。
- 不讓事件每週重複套用一次性效果，避免無限正回饋與數值雪崩。
- 短期情緒可衰退；重大關係與事件記憶保留。
- 結果資格與結果機率獨立判斷；不可能事件直接排除。
- 玩家可透過理解人物而改善策略，但不得存在跨所有情境的固定最優選項。
- 用單一事件、整個學年、跨學年生涯三種尺度驗收，除頻率外還須看人物一致性及因果合理性。

## 未定案
事件分類與公式、權重、跨人物讀取來源、各項隨機波動範圍及更新週期、模擬測試指標。35類人物與50種行為均已個別完成48／48涵蓋。48 項名稱、代碼及 0～100 尺度已定案。

## 教師行動決策核心 v0.2（2026-10-29）
從三個代表情境（手機管理、行政減量、家長 LINE 聯絡）歸納五項共通能力，**屬於既有事件引擎的延伸，不另建五套獨立系統**：
1. **情境與權責**：先判斷客觀事實、校規、誰有權處理、資訊是否已有，以及是否存在特殊需求。
2. **單選式複合處理**：正式遊戲每一決策節點只選一個選項，但一個選項可包含多個相容且有先後關係的行動；需檢查其條件依賴。
3. **規則與約定記憶**：追蹤玩家／人物已公告的規範、承諾、個別例外與各人的知情範圍，避免把事實全塞入好感度。
4. **人物自主反應**：玩家行動不能直接指定家長、學生或主任一定接受；人物依性格、壓力、目標、權限、歷史反應。
5. **合理後果與長期因果**：既有條件決定可能後果，合理行動不保證好結果，日後可以回收事件記憶。

### 單選選項內部的複合行動約束
- 行動可分為查證、溝通、執行、後續追蹤，但這只是內部通用分類，**非強制玩家每次完成四步**。
- 例如「先向家長確認」後的「有限許可」必須等待前項結果；不能無視確認結果自動發放許可。
- 同一個單選方案內不得同時包含「今晚完全不回訊」與「今晚立即回訊」等互斥動作。
- 原則與例外分開，特殊需求即使與違規行為並存，亦不得自動取消必要協助；處置仍須依實際規範與比例原則。
- 單選方案中若包含多項行動，須由預寫條件、行動順序及文字資源處理，**不得依賴即時 AI 自由補故事**。

### 技術與驗收邊界
數值數量、組合數、勾選數不能等同有意義的劇情量；應測試前置條件、互斥、角色知情範圍、已建立約定、跨年記憶與因果一致性。

## 事件觸發、排程與機率（已定案方向）
- 事件採**日常獨立＋長期連鎖**兩類；獨立事件可在預寫條件成立時衍生成連鎖，連鎖可解決、淡化、等待回收，不是每個事件都要升級。
- 事件觸發可結合**時間節點、人物狀態、歷史因果與日常隨機**；此四項是事件條件來源，而非彼此孤立的四套引擎。
- **先檢查硬條件，再計算合理結果機率，最後抽取本次結果**。即使完全相同條件與選項，也必須允許合理的不同結果；絕不以隨機推翻既有事實、角色知情範圍、合法權責及歷史。
- 一次選擇可以產生一項主要結果與多項彼此相容的附帶或延遲後果，不能不經條件檢查任意拼接。
- 機率不預先向玩家公開。具體機率值、權重公式、可否調整與測試指標**未定案**。
- 事件排程要避免近距離重複的無意義題材；同一歷史的合理後續不能被簡單冷卻阻擋。背景世界事件量不等於需要玩家親自決策的事件量。
- 學年採**困境高頻的每日事件抽選＋事件內動態時間**；0件新事件日仍有日常劇情，舊事件可繼續。短／中／重大事件分配及每日件數機率尚未定案。

## 單次決策的不可逆及一致性（已定案）
1. 玩家看到一個固定、前提已確定的事件與 **3～8 個單選選項**。
2. 玩家未確定選項前，重整或關閉後必須恢復**同一個事件及選項畫面**，不得趁重新載入變更候選事件、條件或抽取結果。
3. 玩家確認後只執行**一次**相關條件與機率判定，並將所選行動、實際結果、人物／世界變化、筆記歷史及下一階段進度一致保存。
4. 保存成功後才能呈現已確認的後果或推進；重整、重開及返回上一頁不得重選、重抽或重複發放效果。結果閱讀頁重新進入時可從該段開頭恢復。
5. 同一遊玩歷史中已決定的結果固定。壞結局按既有規則重試**當前學年**時，恢復學年起點狀態，形成另一段嘗試，不可疊加失敗嘗試的能力或獎懲。
6. 純本機瀏覽器儲存可保證**正常重載與關閉重開**下的一致性，但無法阻止刻意刪除資料、回復舊備份；跨裝置一致還需同步或匯入方案，尚未決定具體技術。

## 教師職涯能力及評價（已定案）
- 新生涯從第 1 年開始，同一高中任教，年資／在校資歷合一；上限**暫定 30 學年**。
- 年資按學年自然增加；六項長期能力既受經歷和選擇影響，也受到年資的緩慢、趨緩成長傾向影響；年資亦降低當前狀態正負短期波動，但不保證成功、不消除重大衝擊。
- 家長、學生、同事及行政對教師各有評價和記憶，影響事件資格、對話及機率；不得合成一個必然決定一切的「聲望」。

## 困境品質、學生覆蓋與多方因果（已定案原則）
- 困境優先、完美無代價的走向稀少；不可把所有選項強行判定為失敗，也不可因玩家變強而無理由提高懲罰。
- 每個單選決策節點**必有至少一個情緒選項**，其結果與其他方案一樣按人物、條件、歷史及機率判定。
- 事件可由學生↔學生、家長↔家長、家長↔行政、教師↔行政、跨班乃至校外多方互動形成；各角色可在玩家不介入時持續行動。
- 玩家可選擇處理、延後、拒絕或轉交，依當時權責與事件情況提供有意義的方案；不處理不代表時間停住、問題必定惡化或必定無責。
- 班級以40人起始，三年內每位實際帶過的學生都應有合理、實質困境及導師互動；出場頻率、事件規模、先後次序不設固定年度比例。事件可同時涉及多名學生，各有不同影響。
- 同一情境可突發、有跡可循或背後已有玩家未知的原因；機率允許意外，但不得創造矛盾的過去。
- 不同事件可能同時等待處理並互相影響；**處理順序及時間成本可以構成困境**，但不另做複雜的逐時行事曆／排程管理遊戲。
- 學生故事覆蓋機制、權重與避免末期集中補事件的具體演算法仍未定案，不能把討論中的年度人數示例當固定門檻。

## 加權觸發事件與年度生存（現行設計方向）
1. **世界與時間**：讀取教師／學生／家長／行政、關係、組織、知情、未結事件、寒暑假及歷史。
2. **事件資格**：先排除與身分、時間、權責、知情、事實相矛盾的事件；不能用隨機產生不可能的事情。
3. **事件加權抽取**：只對合資格事件依相關數值與情境計算權重並抽取；無需抽最高權重，亦可抽到平靜、意外轉機、負面或中性的事件。
4. **人物自主反應**：長期個性、當下情緒／負荷、主觀誤解、群體及偶然性改變人物行動機率；**人物可以不理性，世界事實必須自洽**。
5. **玩家選擇及結果**：按既有 3–8 個單選方案進行另一次條件及結果權重判定；選定結果一次鎖定保存。
6. **世界更新與後續**：改變相關數值、記憶、責任、待辦、危機進度及延遲事件；可緩和、延宕、消失、升級或連鎖，不能強制一律升級。
7. **終局檢查**：由具體事件鏈及相容的終局條件構成年度失敗，而非在學年末對數值加權平均後突然 Game Over；年度生存指數可供內部分析，但**不是直接判死的機制**。
- 必須區分**事件出現機率／人物行動機率／玩家選擇後果機率**，各自有資格條件及權重。高年度失敗風險是整體設計及測試目標，**非每年固定淘汰率**。數值與能力改善應確實有幫助，但不保證成功，也不為維持難度強行懲罰資深教師。
- **已定案**：12 類×4 項的 48 項名稱、代碼、0～100 尺度；**仍未定案**：精確隨機波動及權重公式、各失敗終局資格、事件庫與測試目標。不能把此前純示範的權重、通關率、危機數量視為正式參數。

## 學期事件重要度：呈現層數值工程約束（2026-11-01 已定案）
- 學期重要事件由**獨立的回顧篩選用途**之綜合重要度公式排序，僅使用既有引擎合法產生的數值變化、決策、事件進展、涉及人物及歷史因果，不得反向更改 N1～N8、事件抽選權重、人格、關係或失敗判定；不以單純負面程度或教師六項狀態的淨損失充當全部重要性。
- **本學期新增影響為主要依據，既往歷史僅作輔助**；避免舊累積事件反覆霸榜；同一事件同學期占一席、正負中性與事件類型不強制均衡。年資／長期能力降低狀態波動，不得因此系統性低估資深教師所經歷事件；亦不直接因年資加分。持續天數與多項相關性須限制無意義灌分及重複計數。
- **固定入選門檻**；過門檻者依重要度排名，未滿10件全列，超過10件通常取前10，但第10名分數相同者全入選，允許超過10件。於期末統一計算，需保留足以回溯分數的階段資料；具體權重、標準化與門檻交由 Codex 依現有公式自行設計與驗證，不擅自指定常數。
- 重要度分數、內部排序、事件是否仍可觸發、NPC 隱藏數值均不得在玩家的學期回顧與歷史頁曝光；回顧只列已發生的玩家可知內容。**學期回顧只呈現六項長期能力期初／期末／淨增減**，六項當前狀態僅用於日常階段結算與既有失敗機制，不列學期回顧。
