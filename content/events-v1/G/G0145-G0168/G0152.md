## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 教務同事一度用加派成人解決旁班抱怨，見自己下次入班時學生一片死寂，反而想推導師換成不同方式，說那樣安靜很讓人火大。 |
| 核心衝突 | 人力調度可以壓下噪音，未必能讓學生理解何時可以討論。 |
| 導師困境 | 可先承認原有懾住人的效果，再談撤回成人、調整課堂任務，或保留只在需要時進班。 |
| 故事獨特性 | 要求維持秩序的人，是最早對完全無聲感到不對勁的人。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：門一推開，最後一個講話的學生也把嘴閉上了。教務處安排來協助秩序的同仁站在後門，整間教室只剩冷氣聲。他換過兩次站的位置，連你問問題都沒人抬頭。下課後，他把椅子推回牆邊：「隔壁現在應該沒意見了吧。可是我來，大家就不會上課了？」走廊上的抱怨已暫時停下，下一節的協助方式卻還沒定。他只剩十分鐘能跟你談。
