## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生家境優渥、零用錢充裕（`7-3`），天生性格開朗整天心情都很愉快（`2-4`），平常對導師的安排非常配合（`9-2`），只是特別喜歡看到大家開開心心誇獎他（`4-4`）。這週班上要用班費辦一次簡單的月度慶生或段考後小獎勵，導師事先交代總務只買每人二十元左右的平價餅乾，避免造成經濟壓力；結果這名學生今天下午興高采烈地自己掏錢多買了兩大盒高檔連鎖千層蛋糕或馬卡龍提進教室（`7-3`、`2-4`），還笑嘻嘻地對導師說：「老師我完全照你說的下午發，只是幫大家加碼一下，這樣大家一定更開心對不對！」（`9-2`、`4-4`）讓旁邊原本只買平價餅乾的總務跟幾名家境較緊的同學頓時有些尷尬。 |
| 核心衝突 | 學生完全沒有炫富惡意，純粹是開心想分享又想被大家喜歡，卻無意間讓原本平價平等的班級小活動出現經濟落差與人情壓力。 |
| 導師困境 | 先笑著感謝他的大方，但請他把這兩大盒高檔甜點先冰起來、留到放學後他自己約幾個好朋友慢慢吃，教室裡還是統一吃班費買的平價點心（守住班級經濟平等與活動單純性，但一片熱心想讓大家開心的他當場有點掃興）；還是這一次先借花獻佛一起分食並明確向全班約定「下不為例，以後班級活動一律不能個人額外加碼高價食物」（保住現場歡樂氣氛與他的面子，卻得承受部分家長事後得知的觀感風險）。 |
| 故事獨特性 | 沒有誰想炫耀，寫出富裕家庭孩子「開開心心請客加碼、卻沒察覺這會讓平價班費顯得寒酸」的成長盲區。 |
