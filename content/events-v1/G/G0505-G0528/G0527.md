| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生見同桌一直不敢自己向教師提出需要，體諒又焦慮直接出主意會害他被追問。學生主動約他午休在空教室做一次練習，想由自己決定只扮導師、不要替他設答案。同桌真的開口後，反問能否把同一場演練變成錄音直接交出去。 |
| 核心衝突 | 演練降低恐懼，錄下來會留下本來只供兩人試錯的內容。 |
| 導師困境 | 可讓同桌自行提一段願重錄的話、接受只交自寫句子，或保持演練不外傳並讓本人另選渠道。 |
| 故事獨特性 | 故事的轉折發生在試說已成功之後，兩人要決定練習素材能不能變成正式求助。 |
