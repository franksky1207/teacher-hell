## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 未到場家長看到其他家庭拍的家長日資料，才發現內容很多，但自己只能用低流量手機，打不開整份高畫質檔。 |
| 核心衝突 | 相同檔案不等於相同可及性，導師也不能把個別取用需求公開作為受助身分。 |
| 導師困境 | 如何提供可用的文字重點或校內紙本取得方式，決定哪些資訊需立即補到、哪些可後續查詢？ |
| 故事獨特性 | 重點是接觸機會結束後的資訊可及性，非家庭不重視參與。 |

### 開場（依自然閱讀長度分頁）

- **P01｜旁白**：未到場的{{guardian_a.name}}收到家長日照片，卻一直打不開其中的高畫質說明頁。
- **P02｜旁白**：訊息裡附上停在讀取中的畫面：「我的手機流量不多，只想看這星期要注意什麼，不能只傳文字嗎？」
- **P03｜旁白**：資料已經提供不代表每戶家庭都看得見。你既不能要求他再回到結束的活動現場，也不能公開宣布是哪一戶設備不方便。

## 5｜R1～R8共用結果、結算與4×8因果矩陣

### R1｜這四行我看得到了原來明天只要注意

- **玩家可見結果**：「這四行我看得到了，原來明天只要注意其中一件事。」家長先核對急迫的日期，再問其餘資料能否日後取得。他不必下載完整照片證明關心孩子，也不用向班群解釋設備限制。
- **客觀後果**：家長先核對急迫的日期，再問其餘資料能否日後取得。
- **合法底層增減**：guardian_a:7-3:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-1,-2,1

### R2｜紙本可以留學校嗎我下班順路去拿

- **玩家可見結果**：「紙本可以留學校嗎？我下班順路去拿。」你核實合法領取時間，沒有叫其他學生代傳私訊。家長選擇自己能配合的方式，雖然未立刻看到所有頁面，已分得清哪些事項不能延誤。
- **客觀後果**：你核實合法領取時間，沒有叫其他學生代傳私訊。
- **合法底層增減**：guardian_a:8-2:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,1,0

### R3｜我不是不關心只是檔案一直轉不出來

- **玩家可見結果**：「我不是不關心，只是檔案一直轉不出來。」你問的是缺了哪一項資訊，而非手機品牌。對方終於敢明白說出需求，原本反覆道歉的訊息開始變成能解決的問題。
- **客觀後果**：你問的是缺了哪一項資訊，而非手機品牌。
- **合法底層增減**：guardian_a:10-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,1,-1

### R4｜如果有純文字我可以存著慢慢對

- **玩家可見結果**：「如果有純文字，我可以存著慢慢對。」家長把公開事項存進備忘錄，又問某條是否適用自己孩子。你區分共通說明和個別條件，避免把別人拍下的照片當成家庭專屬答覆。
- **客觀後果**：家長把公開事項存進備忘錄，又問某條是否適用自己孩子。
- **合法底層增減**：guardian_a:11-3:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,2,0,-1

### R5｜不要在群組說是我拿不到好不好

- **玩家可見結果**：「不要在群組說是我拿不到好不好？」你改用所有家庭都可選的文字與紙本公告，不標示提出需求的家庭。家長仍擔心他人猜測，但願意繼續追問往後要在哪裡看更新。
- **客觀後果**：你改用所有家庭都可選的文字與紙本公告，不標示提出需求的家庭。
- **合法底層增減**：guardian_a:7-3:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,0,-1,-1

### R6｜請孩子帶回紙本可以嗎他可能不知道

- **玩家可見結果**：「請孩子帶回紙本可以嗎？他可能不知道我要看哪一頁。」你說明公開摘要可由正式管道領取，須本人確認的事項仍留給照顧者處理。家長先讀文字，再決定是否領紙本，沒有把孩子變成代辦窗口。
- **客觀後果**：你說明公開摘要可由正式管道領取，須本人確認的事項仍留給照顧者處理。
- **合法底層增減**：guardian_a:8-2:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-1,-2

### R7｜好不容易打開了才發現照片旁有別人

- **玩家可見結果**：「好不容易打開了，才發現照片旁有別人家的留言。」家長暫停轉寄，改使用不含個資的正式摘要。原本要分享的好意留下來，卻不再讓旁人的私密內容跟著流出去。
- **客觀後果**：家長暫停轉寄，改使用不含個資的正式摘要。
- **合法底層增減**：guardian_a:10-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-1,-2

### R8｜原來不一定所有人都要下載同一個檔

- **玩家可見結果**：「原來不一定所有人都要下載同一個檔。」他選擇文字版完成核對。你也記下日後更新須同步提供可讀版本，這不是為某戶家庭額外開特例，而是讓原本公開的資訊真的能到達。
- **客觀後果**：他選擇文字版完成核對。
- **合法底層增減**：guardian_a:11-3:-1
