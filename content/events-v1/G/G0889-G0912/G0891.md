## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 負責班級投影設備的學生剛學會學校新裝的無線投影系統，平時很願意投入人力處理班務，但個性極易焦慮、總怕上課前突然連不上線被罵。結果每次下課十分鐘，他都提前把整套設備反覆測試三遍、不准任何要上台報告的同學靠近講台插隨身碟，弄得大家緊繃到不行。 |
| 核心衝突 | 認真負責的電器股長因為過度焦慮設備出包，反而把講台變成全班的禁區。 |
| 導師困境 | 請他放寬心讓同學自己插隨身碟測試，焦慮的他恐怕整節課都盯著螢幕坐立難安；全面支持他統一收檔代播，他又得每節下課犧牲休息時間幫全班收檔案。 |
| 故事獨特性 | 寫出班級裡「太盡責又太焦慮」的設備管理者，把預防出錯變成另一種同儕壓力。 |
