## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 教務處教學資料承辦職員對業務極負責任（`1-1`），這學期同時兼顧多項報表已經累到眼眶發黑（`2-3`）。昨晚他在跨校行政交流群輕信一則「主管機關下月將無預警抽查各私校班級彈性學習與輔導紀錄」的未查證誇大傳聞（`8-3`），今天一早立刻撐著疲憊身軀跑來連環督促導師（`10-2`）：「老師我知道你們也忙，但這批表格這週不先補齊上傳，萬一真的被抽到我實在扛不起！」即使導師提醒那是未經公文證實的群組傳言，過勞又怕出事的他依然不肯鬆口。 |
| 核心衝突 | 行政端因過勞與責任感放大了網路未查證抽查傳聞的恐慌，將「預防性自保」的補件壓力轉嫁給第一線導師。 |
| 導師困境 | 體諒這名累壞的同事而熬夜先把還沒到正式截止日的班級紀錄全部提前補寫上傳，自己原本的備課與改卷時間被狠狠壓縮；婉拒提前補交並堅持只依校內正式公文時程辦理，這名責任感重又疲憊的同事整週都得在焦慮失眠中度過、甚至直接向上層回報導師不配合防災備查。 |
| 故事獨特性 | 即使當場點破只是未經證實的傳言，行政人員的責任焦慮與過勞狀態依然讓「提前補件」的職場壓力真實存在。 |
