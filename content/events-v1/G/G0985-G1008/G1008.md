## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 私校招生組職員對今年新生註冊率感到十分焦慮（`2-2`），憑經驗判斷「再不搶先固樁，原本有哥哥姊姊在本校就讀的國中端弟妹就會被別校獎學金挖走」（`3-2`）。他不但主動在全校行政群組貼出各校搶人動態表（`8-4`），還連續兩天跑來辦公室督促導師（`10-2`）：「老師你班上那三個家裡有國三弟妹的家長，你這週務必打電話去推薦他們報我們學校！」 |
| 核心衝突 | 私校招生焦慮讓行政端把導師的親師信任關係直接當成招生業務推廣管道，要求導師替學校拉弟妹入學。 |
| 導師困境 | 硬著頭皮在電話裡跟家長推銷本校升學多好，平常建立的純粹親師信任感瞬間染上業務味；婉拒並說自己只負責帶好目前在校生、招生請由專業組別打電話，焦慮的職員恐怕直接向主管回報導師缺乏私校危機意識。 |
| 故事獨特性 | 直擊臺灣私校特有的「兄姊帶弟妹續讀」招生壓力文化，與一般表單催辦截然不同。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：招生職員第二次拿著他校獎學金表來找你，紙角已被捏軟。他指著那三戶有國三弟妹的家庭。
- **P02｜職員**：再不先聯絡就被挖走了。家長信你，一通電話比我講半天有用。
- **P03｜導師**：家庭資料不能就這樣拿去推銷，也不能替弟妹保證入學條件。
- **P04｜旁白**：他嘆了口氣，說只想知道你這週願意多幫什麼。群組又跳出一間他校說明會資訊，他立刻看了過去，連你的回答都差點漏掉。
