# 教師荒謬地獄｜課表與臺灣校曆規劃

> 2026-11-01 使用者已確認規格彙整。此文件是長期維護的「授課課表、學校時段、休假及考試」單一來源；跨系統摘要見 docs/00，人物事件邏輯見 docs/02～04。尚未實作。下文「原則、優先、約」與「必須、固定」刻意區分。

## 一、任教科目與班級（已定案）
- 新生涯開始時玩家自己選科目，開放 **9科**：國文、英文、數學、地理、歷史、物理、化學、公民、生物。地球科學不開放玩家選取／擔任導師，仍可存在於其他老師授課及學生課表。
- 所有玩家科目 **每週18節正式授課**；國英數3班×每班6節；地理歷史物理化學6班×3節；公民生物9班×2節。
- 玩家 **必須教自己的導師班**。導師班與其他任教班級同等隨機安排節次，不偏向上午、第一節或最後一節。
- 任教班級原則隨學生升級延續，畢業才由新班替換；同一學年上下學期班級原則不重抽。科目在特定年級實際是否開課、任教9班可否涵蓋三年級與導師班等須由排課器確保可行，不能產生不可能課表。

## 二、正式課表演算法約束（已定案）
- 每學期自動產生一次課表，玩家無法自由調整或重新抽取。課表確定後存檔，重新載入不得改變。
- 每週18節優先平均到星期一～五，原則每天3～4節。不同班可連兩節；老師連續授課三節（尤其上午2～4、下午6～8）盡量避免而非硬性禁令。
- 國英數 **每一任教班每週6節、五天分配1／1／1／1／2**；同班同日兩節禁止相鄰，優先一上午一下午，排不出才分在同半天。
- 地理歷史物理化學每班3節分在3個不同上課日；公民生物每班2節分在2個不同上課日；同一任教班同日最多一節。
- **星期五第6、7節固定不排正式授課**：單週是玩家的一般空堂（學生仍照其課表上其他科目）；雙週第6節週會、第7節班會或校方活動。週會班會可與前後正式授課相鄰；不計入每週18節。
- 課表演算法以滿足硬限制為先，平均與避免教師連三節、同班雙節分上下午為軟優先；若無解須回報設計衝突，不可默默少排或挪動固定節次。

## 三、學校日與操作時段（已定案）
- 平日以日期、星期、學期、年級及早自習、第1～4節、午餐、午休、第5～8節推進；留校日再有晚餐、晚自習1～3。操作介面不使用HH:mm或分鐘模擬。
- 正式授課節次通常上課；其他時段可按地點與當下權責選活動：備課、休息、處理合資格待辦等；無事件也有簡短生活文字。
- 一個時段原則一件主要行動；極少特殊情形占用兩節。活動與事件結算後直接推進，避免重複「安排／下一節」點擊。每日新事件0～5，先抽件數再分配合理時段；累積事件可跨日與新事件並行，不因此無限增加一時段行動數。
- 放學後統一進入返家階段，最多處理一件事情：系統安排的居家事件，或玩家在沒有事件時選私人活動／合資格待辦。不能在家進行不合理面對面學生訪談。

## 四、各年級留校與高三星期六（已定案）
- 高一留校：星期二、四（2天）。高二：星期一、四、五（3天）。高三：星期一、二、四、五（4天）。留校包含晚餐、晚自習3節；導師留校是固定制度而非每日隨機事件。
- 高一高二正常星期六、日休假；高三 **正常星期六到校7節自習**，導師多負責考試、自習管理與導師事務，不視為7節正式授課。
- 高三星期六在遊戲中壓縮為 **上午（第1～4節）／下午（第5～7節）** 兩時段；上午最多1件、下午最多1件新事件；無事件可安排合理活動；之後依返家階段規則。
- 星期日、一般週末休假日、國定假日與補假皆採 **上午、下午、晚上** 三時段。高三星期六遇國定假日亦放假，**不模擬**私校連假改日補自習。

## 五、寒暑假與寒暑輔（最新規則取代早期規劃）
- 暑假約8週，**前3週休假、第4～7週暑輔（4週）、最後1週休假**；暑輔從星期一開始，期間按平日8節作息，每週18節正式授課；暑輔開始即生成新學年上學期課表，正式開學沿用。
- 寒假約3～4週，配合實際農曆春節及補假。**寒輔僅1週，固定於下學期正式開學之前一週**，不是期末考後一週；寒輔星期一開始，8節作息，每週18節正式授課，生成下學期課表，開學直接沿用。
- 寒暑輔開始及兩學期正式開學 **皆訂星期一**。國定假日或補假一律優先休息。寒輔若碰春節則調整下學期起始位置以避免衝突。
- 寒暑輔與一般學校日逐時段遊玩；**不採舊規則的寒暑輔按週、週末兩天合併、假期數週直接快轉**。非輔導課假日以上下午晚上操作。

## 六、30年動態校曆及官方假日（已定案的設計原則）
- 以臺灣現行國定假日、補假及學校法規作為演算法基礎；網頁可透過支援農曆的日期工具計算每年農曆春節（實作時應驗證年份、時區、閏月與跨裝置一致性）。
- 原則：國定假日落星期六補前一個工作日、星期日補後一個工作日；春節適用相關特殊法定安排。未來官方可能調整，不能宣稱預知未來30年官方行事曆。遊戲不為假日補課。
- **開學星期一、春節與假日優先**，以此合理安排寒暑假後再推算學期週數；上學期約21週、下學期約20週只是目標／參考，**非強制固定週數**。實際校曆由網頁在新學年生成並保存，不能每次載入重算。
- 學期以可排定的星期一至期末考星期五作完整教學週計算；確切年度日期碰撞與休假法規邊界屬實作驗證事項，不能為滿足週數挪走國定假日。

## 七、定期評量（已定案）
- 每學期三次段考。第一次以 **第7週** 為基準；第二次上學期以 **第14週**、下學期以 **第13週** 為基準。前兩次各於該週安排 **連續2個上課日**，不得落在休假日。
- 第三次即期末考，固定 **學期最後一週星期三、四、五**，為連續3天。
- 因春節或實際開學導致20／21週調整時，前兩次考試週次合理連動修正；遇假日必須調整日期並保持合法上課日。學期與考試日曆生成後存檔固定，不允許重新抽取。
