## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班副班長或總務股長（`9-3`）平時非常信任導師（`5-1`），也高度肯定導師帶班的條理專業（`8-1`）。這陣子他同時扛了班務統計、社團成發籌備又遇上多科進度落後，整個人負荷重到快撐不住（`11-1`）。今天午休前他悄悄把導師拉到辦公室角落，紅著眼眶小聲求援：「老師我相信你才敢直說⋯⋯我這兩週每天中午都在幫大家收表對帳，自己數學跟英文快不及格了，能不能讓我暫停職務一週先救功課？」 |
| 核心衝突 | 極為盡責且信任導師的幹部在「班務責任」與「自身課業崩盤」間達到極限，導師必須照顧這名過勞學生的學業與身心，但臨時找人代班一週又怕同學推託。 |
| 導師困境 | 立刻答應讓他卸下本週全部班務專心念書、由導師自己或另尋熱心同學暫代一週（真正救了這名過勞信任你的好幹部，卻平白增加導師自己中午收表對帳的工作量）；先幫忙把最耗時的表單收尾工作接手大半、只讓他保留簡單點名名義免得他覺得愧疚失職（試圖減負又不中斷職務，但這名已經極度疲憊的學生只要掛著職務名義心裡依然放不下）。 |
| 故事獨特性 | 沒有誰擺爛卸責，寫出高中班級裡最常被忽略的「最乖最可靠幹部其實快被班務壓垮」的真實師生信任求救。 |

### 開場
- **P01｜旁白**：他把帳本放到桌角，小聲得像在請假離開全班。
- **P02｜student_a**：我相信你才講。我一週不當副班長行不行？數學英文都快不行，中午每天還在收。
- **P03｜導師**：必要休息和減負先接好，不會因找不到人就叫你撐。
- **P04｜student_a**：可是名字還掛著，他們就一直問。
- **P05｜旁白**：我把帳本移到自己這邊。他的手離開封面，眼睛卻還跟著它。
