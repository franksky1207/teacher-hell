## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師平日下班後開心地跟老友約在巷弄熱炒店聚餐，同理大家平常上班累不想動腦點菜，加上很想在朋友圈裡當個「最貼心周到」的聚會擔當，便提前到達並主動跟店員點好整桌老友們以前最愛的隱藏版肉類招牌菜，還發訊息向大家預告。結果朋友一入座才不好意思小聲說，其中一位最近因健康檢查改吃素了。 |
| 核心衝突 | 導師出於貼心與想被稱讚的心意提前點好整桌菜，卻因為少問一句近況而把素食老友晾在滿桌肉菜前。 |
| 導師困境 | 立刻再加點三道素菜並笑著說剩的肉自己打包明天帶便當，荷包大失血且吃得超撐；不好意思地請那位老友只挑旁邊一兩道配菜湊合吃，自己心裡又過意不去。 |
| 故事獨特性 | 沒有職業病或出糗翻車，純粹寫朋友太久沒見、好心提前點菜卻撞上飲食習慣改變的聚餐小插曲。 |
