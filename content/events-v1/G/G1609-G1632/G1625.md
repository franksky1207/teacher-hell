## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生性格極講原則（`1-4`），學習適應力極快（`3-4`），平時也完全認同導師訂下的手機管理規範（`9-1`）。昨天早自習導師在講台上因為突然收到行政急訊，沒先跟全班解釋就直接低頭拿著私人手機回訊了三分鐘；這名講原則的學生看在眼裡，心裡瞬間對導師產生「只准老師滑、不准學生看」的強烈不滿（`5-4`、`1-4`）。今天他雖然依然照規定交出手機（`9-1`），卻用超快的文字編排力（`3-4`）自己印了一張寫著「班級手機公約適用對象含導師本人嗎？」的小紙條夾在週記裡交上來抗議。 |
| 核心衝突 | 導師當時確實是處理公務急訊卻沒口頭說明，讓重視原則的學生抓到把柄寫紙條抗議雙標，導師要在「坦率承認疏忽說明」與「澄清教師公務權限」間拿捏。 |
| 導師困境 | 趁早自習直接在全班面前坦率笑著說明昨天是因為有處室急件才看手機、以後老師在講台用手機也會先講一聲，並私下肯定這名學生敢對事不對人（示範真正平等守規與氣度，但得在全班面前先認一次疏忽）；還是私下把他叫來辦公室解釋昨天是在回急件公務、教師原本就有聯絡公務需求而非雙標（守住教師公務與班規的合理差異，但講原則又不滿的他心裡還是覺得老師在找理由）。 |
| 故事獨特性 | 反轉「學生違規被老師抓」的套路，寫出「原則派學生抓包老師在講台低頭看手機、寫紙條抗議大人雙標」的真實教室尷尬。 |
