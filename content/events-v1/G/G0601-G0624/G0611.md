## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 值日生明知只剩幾分鐘自由用，仍提議把全組時間拿來賭哪桌先完成。見最慢的一桌被迫留著、其他人都想走，他反而氣導師也說照輸贏算，願由原先輸組包做改成各桌補完實際未清區。 |
| 核心衝突 | 班級已享受競賽，現在取消負擔可保住不被強迫留下的同學，卻也讓發起人必須承認自己先設了會傷人的遊戲。 |
| 導師困境 | 可廢掉輸家的加罰並由原區收尾，或留下一次不計輸贏的整理紀錄。 |
| 故事獨特性 | 學生由設計一個別人會輸的局，改成親自撤回自己占到的便宜。 |
