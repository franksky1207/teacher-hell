## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生口才極佳、邏輯清晰（`3-1`），跟導師互信度極高（`5-1`），這學期因為免修部分選修或課表空檔多、時間餘裕很充足（`11-2`）。他覺得班上每天早自習紙本點名與登記缺交作業太沒效率，今天下課拿著自己做好的簡易線上掃碼表單來找導師，三言兩語講得頭頭是道（`3-1`），要求把早自習登記流程全面改成由他用私人手機掃碼統計（`12-1`）：「老師你這麼信任我（`5-1`），我時間也多（`11-2`），交給我一定比紙本快三倍！」但這會讓單一學生長期掌握全班同學的出缺席與作業紀錄在私人手機裡。 |
| 核心衝突 | 最信任的學生提出看似高效率的數位流程改革，導師必須在「拒絕私人手機收全班資料」與「如何不澆熄他的改革熱情」間平衡。 |
| 導師困境 | 肯定他的效率頭腦，但明確婉拒用私人手機收集全班紀錄，改請他幫忙把現有紙本登記表重新排版成「分排快傳格式」試辦一週（守住學生個資與權限紅線，但這名想大展身手的學生覺得新點子被退回）；還是改用導師自己的公務帳號建立不記名座號表單、只授權他在早自習結束後幫忙對照紙本勾選（保留數位效率與信任感，但導師每天得花額外時間管理帳號與覆核）。 |
| 故事獨特性 | 不是學生偷懶，而是時間太多的可靠學生拿著「數位自動化提案」來挑戰學校的個資與紙本慣例。 |
