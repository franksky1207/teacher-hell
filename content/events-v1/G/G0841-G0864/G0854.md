## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師多年獨居、生活環境與每日行程極度規律且容不下模糊地帶，非常認同導師「自習課不准任意放人」的明確規範。連上四堂課累到不行的他經過自習教室時，抓到兩個學生拿著導師預簽的空白公假單在走廊晃，疲勞加上受不了這種「沒照規矩填妥」的破例作風，直接拿著假單來辦公室問責導師：「說好不放人，這兩個是怎麼回事？」 |
| 核心衝突 | 導師自己為了省事留的彈性措施，被追求生活與規則絕對明確、又疲憊的同事當場抓包問責。 |
| 導師困境 | 坦承是自己太忙先預簽讓幹部視情況填，等於在規矩派同事面前自打嘴巴；推說學生自己亂拿還沒核准的單子，又會害兩個學生無端背上偽造文書嫌疑。 |
| 故事獨特性 | 把「老師偶爾也會貪圖方便預簽單據」的真實漏洞，撞上生活極度秩序井然、最討厭模糊地帶的疲憊同儕。 |

- **P01｜旁白與當場對話**：「不是說自習不放人？」他把兩張空白公假單放在桌上。連四堂後聲音很沙，多年獨居養成的規律，連這格沒填都受不了；他一直認同你自己訂的留班規範，才更氣這兩張預簽。學生已回到合法照看，單子停用、來源也說清。他沒再追人，指著你的簽名：「所以你想讓誰來決定那個空格？」
