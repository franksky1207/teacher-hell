## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 自己創業、工作負荷極重但家庭經濟寬裕的本班家長，很怕在親戚與家長圈裡顯得比別人差，出錢幫孩子報名了高價海外遊學營隊面試，卻因為公司事務太忙沒空自己盯，連日打電話與傳訊督促導師趕快把「導師推薦函」寫好給他，甚至暗示「老師我時間很緊，你寫個大概我請秘書潤稿補完就好」。 |
| 核心衝突 | 家長用充裕財力與秘書代勞思維催逼導師交出推薦函，卻踩到教師親筆推薦的誠信界線。 |
| 導師困境 | 為了趕在他的期限內交差而隨便寫幾句交給家長秘書去「潤稿」，萬一最後寫得跟孩子在校表現完全不符，署名負責的還是導師；堅持照實慢慢寫且不准外包潤稿，這位忙碌又急著要面子的家長恐怕直接跳過導師去找主管施壓。 |
| 故事獨特性 | 修正為家長本人持有充裕家庭資源，呈現高負荷企業主家長「把推薦函當成秘書外包件」的荒謬催促。 |
