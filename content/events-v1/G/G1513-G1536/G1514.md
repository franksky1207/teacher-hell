## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位剛調來學校不久的常駐行政組員適應力極快（`3-4`），天生自來熟、社交極度主動（`6-3`），一有新公文或消息總愛第一時間跑來向導師報信（`8-4`），也很樂意主動替老師跑腿分擔（`11-3`）。昨天跨處室協調某項私校評鑑與招生支援輪值時，這名新人聽見有人缺人手，沒先問過導師本人，就憑著對導師的熱心順口幫忙「喬好了」，今天早上還笑咪咪衝來導師辦公室報喜：「老師你放心，我幫你跟教務處說好了，週五下午那場你會去支援！」 |
| 核心衝突 | 熱心又沒有惡意的新同事越權替導師接下額外苦差事，導師若否決會讓新人在跨處室面前極度難堪，若吞下則是自己平白多背一份工作。 |
| 導師困境 | 先私下溫和但明確地告訴他「以後行程一定要先問過本人」，再自己硬著頭皮吞下這場週五支援（保住新人的熱忱與跨處室和氣，但導師自己的備課與批改時間被無端吃掉）；還是請他今天內自己回去跟教務處更正「導師那天有原定班務無法支援」（守住職權界線並讓新人學會職場分寸，卻讓剛想表現的新人當場臉紅委屈）。 |
| 故事獨特性 | 不是主管硬派工作，而是被「過度熱情自來熟的新同事」擅自幫忙答應後才來報喜的辦公室無奈。 |
