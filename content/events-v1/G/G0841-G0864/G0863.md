## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師好勝心強、自認有責任把班級介紹簡報做到像樣，看到行政端發下來強迫套用的公版母片醜到不行、字還全擠在一起，氣得自己熬夜重做一套超精緻版本直接交出去，沒想到主任驚為天人，隔天早會竟直接宣布「以後全校各班都請這位導師幫大家套用這個新版」。 |
| 核心衝突 | 導師自己出於憤怒與成就動機做出來的私房精品，瞬間變成行政端順手徵召的無償全校公差。 |
| 導師困境 | 當場笑著硬接下幫全校調版面的工作，接下來一週下班時間全沒了；立刻起身說明自己那套只能給單班用、沒辦法套全校，又得承受主管覺得你小氣不配合的眼神。 |
| 故事獨特性 | 私校職場經典悲劇「能者過勞」的起源：誰叫你自己嫌公版醜還真的做出更好的。 |
