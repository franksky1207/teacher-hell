## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學校健康中心校護連日處理全校季節性發燒與腸胃通報累到聲音沙啞（`2-3`），但她對校園傳染病防護安全意識極高（`4-2`），平時配合導師班務節奏（`9-2`），也非常支持導師在班上推動勤洗手戴口罩的立場（`10-1`）。今天得知導師班隔壁出現發燒請假個案、需加強一般接觸面衛生但尚未達須專業人員穿防護衣封區消毒之程度，累到分身乏術的她改在下課前先把校方核可、明確標示低刺激成分與操作須知的日常環境清潔擦拭噴霧（僅供成人或依說明擦拭門把與課桌表面，不讓學生混用或接觸強效漂白藥劑）與抹布送到導師桌上，拜託：「老師我真的快站不住了，這瓶安全配好的日常清潔液跟你依說明幫門把擦一擦、再拍照回傳給我存查好不好？」 |
| 核心衝突 | 疲憊又極盡職責的校護在區分一般環境擦拭與專業消毒後，把「親自依說明擦拭門把與拍照回報」的額外工作轉交給導師，讓導師在承擔額外勞務與要求行政另派支援之間取捨。 |
| 導師困境 | 既不能讓學生在未確認安全條件下操作藥劑，也不能在有接觸風險時直接拖延到放學才處理；因此導師面對的兩難在於，親自依安全須知接手把門把與公用桌面擦完拍照回傳給校護（必須自己吃下額外清潔工時並調整當節開課前幾分鐘的節奏），還是婉拒這份轉交、請校護或總務處另派行政人力到場支援完成（不自己扛額外清潔與拍照，卻讓這名累垮的校護同事當場陷入人手真空與無法按時回報的焦慮）。 |
| 故事獨特性 | 明確區分日常安全擦拭與專業化學消毒，排除學生誤觸藥劑與延後拖延的選項，把真實兩難留在「導師自己吃下額外工作替累垮校護救火」或「請行政另派支援」。 |
