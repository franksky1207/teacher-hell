## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生家庭經濟吃緊（`7-2`），平時非常認同導師訂的「作業不准拖延、各人準時獨立完成」班規（`9-1`），做事手腳俐落（`3-3`）。昨天下午美勞／專題作業繳交前，鄰座同學不小心打翻水毀了自己的特殊磅數底紙，現場又來不及重買；這名學生一時衝動講義氣（`1-2`），直接把家裡好不容易買給他自己用的最後一張昂貴專用畫紙拆下來送給對方趕工，結果今天輪到他自己要繳交同規格作品時，手邊只剩普通影印紙完全不符合課堂規格。 |
| 核心衝突 | 守規矩、有義氣卻經濟吃緊的學生因一時衝動把珍貴材料讓給同學，導致自己面臨缺交風險；導師既不能隨便放水破壞科任作業規格，又不忍讓這名善良的孩子受罰或被迫再花家裡錢。 |
| 導師困境 | 從辦公室備品箱找出一張規格相近的剩餘樣紙私下給他應急完成作品（保住他的作業分數與義氣，卻怕其他學生看到誤以為忘帶材料都能跟老師拿免費紙）；嚴守「自備規定規格」原則請他回家設法補齊或先與科任商量延一天繳交（守住規定公平性，卻讓這名昨晚剛為了幫同學而犧牲自己材料的孩子自責又不敢跟家裡開口要錢）。 |
| 故事獨特性 | 沒有誰欺負誰，寫出家境不寬裕卻講義氣的高中生一時衝動「把最後一張好紙讓給別人、害自己開天窗」的純真與心酸。 |

- **P01｜旁白**：學生把普通影印紙攤平，說那張厚紙昨天已經給同學。
- **P02｜student_a**：他水打翻，快交了，我就拆給他。昨天我還幫他裁好，想說我今天再……
- **P03｜導師**：家裡有別張嗎？
