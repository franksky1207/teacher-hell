## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生怕新來的人接班務會不知自己站哪裡，實際替班級動線畫示意，不斷問導師何時貼到班內。他要求改成先讓各人自己看圖再集合，等第一名同學看不懂時，又急著親自站到原位示範。 |
| 核心衝突 | 想透過流程讓大家安心的人，自己最怕暫時離開指引位置。 |
| 導師困境 | 可讓新手依圖試一輪並由老師收回饋，會有一段笨拙停頓；或把圖留到下一次，先由學生交給一名新手共同示範，少了獨立檢驗。 |
| 故事獨特性 | 繪圖的人不只怕他人不會，也怕自己真正被圖替代。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：student_a這幾天連著催我三次把那張他親手畫的班級動線示意圖貼出來，還堅持這次不要先口頭集合，改成「大家自己先看圖再就位」。圖剛貼上黑板旁，第一位來接班務的新手同學站在門口盯著箭頭看了半天還是眉頭緊鎖。
- **P02｜旁白**：student_a原本還在一旁等著驗收成果，一看對方猶豫，腳尖一轉就急著衝過去要自己站上講台邊示範。
- **P03｜student_a**：欸不是那邊啦、你看這個箭頭……老師我先幫他示範站一次好了，不然等一下大家要集合了！

### 四個最終教師選項

| B | 「集合時間快到了，今天這輪你先交給他、你們兩個一起站著帶一遍，下一次再單獨測圖。」 | false | 暫時恢復由student_a與一名新手共同示範帶走一遍，將獨立看圖測試延至下次班務。 | 今天集合流暢不耽誤時間，但還是沒能獨立檢驗新圖好不好懂。 |
| C | 看他嘴上催我貼圖、人家一卡住卻又忍不住衝過去代站，我心想這孩子又急又捨不得放手，乾脆走過去輕輕拉住他肩膀往後退兩步：「好啦總設計師，現在手背後面不准動！讓新同學自己照圖走，走錯了老師陪他一起迷路！」 | true | 因覺得學生護圖心切又捨不得放手很可愛，導師半開玩笑地按住student_a不准代站，陪著新手依圖摸索。 | 溫和守住了新手獨立試錯的空間，但student_a站在旁邊急得直搓手。 |
| D | 「新手先退後看圖三十秒，接下來我故意完全照圖上箭頭走一遍，讓你自己看會撞到哪裡。」 | false | 由導師親自完全依示意圖箭頭實走一遍，讓student_a直接看見他人依圖行動之盲點。 | 讓繪製者親眼看見問題最不傷新手自尊，但導師照錯箭頭走顯得有點滑稽。 |
