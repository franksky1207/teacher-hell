## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班圖書股長（`9-3`）對班級圖書角的運作很有自己的自主想法（`4-3`），平時對班上同學也很有同理心（`1-3`）。導師原本訂下「早自習沒通過單字小考的人，當天課間不得借閱圖書角課外書」的激勵規定，這名股長發現幾位英文基礎較弱的同學幾乎整學期都借不到書、下課只能呆坐發呆，這天直接跑來介入導師的班級獎懲管理決策（`12-3`）：「老師這樣他們永遠看不了書，我們圖書角是給全班看的，能不能改成只要有抄寫訂正一遍就能借？」 |
| 核心衝突 | 重同理心與圖書自治權的幹部挑戰導師原本用來「綁定學業達標與課外閱讀權」的管理手段。 |
| 導師困境 | 採納他的建議放寬為「有訂正就能借」，原本為了搶借熱門小說而拼命背單字的中段班同學恐怕馬上失去動力；堅持原本的達標門檻不放寬，這名替弱勢同學發聲的圖書股長覺得老師把閱讀權利當成懲罰工具。 |
| 故事獨特性 | 沒有誰違規，寫出班級幹部對「把課外閱讀權當成成績籌碼」這件事提出的制度反思。 |

- **P03｜學生**：那以前為了借書拼命背的人，會不會罵我？
