## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長日有人分享願提供家裡多出的合法用品，會後另一位家長私問自己無力供物，是否以後不適合對班務提建議。 |
| 核心衝突 | 資源貢獻可以感謝，家長參與與孩子權益不能依捐物排序；回應時也不可點名家庭財力。 |
| 導師困境 | 如何明確分開提供資源與參與決策，並處理當天感謝話語是否讓人誤以為有優先權？ |
| 故事獨特性 | 不是尚未決定要不要送點心，而是集中接觸後形成的階序感。 |

## 5｜R1～R8共用結果、結算與4×8因果矩陣

### R1｜原來我沒有捐東西還是能問班級的事

- **玩家可見結果**：「原來我沒有捐東西，還是能問班級的事。」家長提出早已想問的交通安排，終於不用先替自己辯解。提供用品的家庭也沒有因此失去應得的感謝，兩件事得以分開。他並未立刻在群裡發長篇文章，只先詢問學校原有的正式流程。發言權與採納權分開後，焦慮也不再全綁在捐贈上。
- **客觀後果**：家長提出早已想問的交通安排，終於不用先替自己辯解。
- **合法底層增減**：guardian_a:5-3:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,1,-1

### R2｜我以為上次大家鼓掌就是覺得捐得多

- **玩家可見結果**：「我以為上次大家鼓掌，就是覺得捐得多比較重要。」你回看當天的致謝用語，承認可能讓人誤會。補充說明後家長仍有點不好意思，但開始相信參與討論不用先拿出資源證明。家長重新讀了致謝公告，知道自己不是唯一可能誤會的人。你選擇修正措辭，而不是要求他別多心或公開證明經濟能力。
- **客觀後果**：你回看當天的致謝用語，承認可能讓人誤會。
- **合法底層增減**：guardian_a:7-3:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,2,0,-1

### R3｜別告訴別人是我說的我不希望孩子被

- **玩家可見結果**：「別告訴別人是我說的，我不希望孩子被問家裡怎麼了。」你以普遍原則說明參與資格，不提個案。家長沒有立即加入討論，卻知道自己的疑問不會變成班級裡可供辨認的話題。後來他說想以後再提出建議，你沒有催促。願意參與不代表一定要在今天開口，保留安靜也應是可以被尊重的選項。
- **客觀後果**：你以普遍原則說明參與資格，不提個案。
- **合法底層增減**：guardian_a:9-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,0,-1,-1

### R4｜如果不捐也能參與那我可以提出一個

- **玩家可見結果**：「如果不捐也能參與，那我可以提出一個小建議嗎？」對方從旁觀轉為提供一項可行動線建議，卻不要求一定採用。你將建議交回正式討論程序，讓其價值靠內容而非家庭能供應什麼來判斷。提出建議後他特別確認不會因為沒提供物品就被擱置。你承諾照正常流程評估，而不是保證這個意見必然通過。
- **客觀後果**：對方從旁觀轉為提供一項可行動線建議，卻不要求一定採用。
- **合法底層增減**：guardian_a:12-3:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-1,-2

### R5｜有家長說他願意提供很多東西你卻一

- **玩家可見結果**：「有家長說他願意提供很多東西，你卻一點都不感激嗎？」你肯定資源支持，也澄清不能交換學生待遇。家長看見兩種立場可以同時存在，仍擔心其他人未必如此想；她決定先觀察後續做法。你沒有用一戶家庭的物資需求要求另一戶退出。兩種貢獻仍可被感謝，但沒有任何孩子因此享有額外待遇。
- **客觀後果**：你肯定資源支持，也澄清不能交換學生待遇。
- **合法底層增減**：guardian_a:5-3:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-1,-2

### R6｜我不能幫忙出物品可是活動要人手時

- **客觀後果**：家長自行提出另一種可能的參與，沒有被要求補償。
- **合法底層增減**：guardian_a:7-3:-1

### R7｜如果家長日的捐物名單要貼出來沒捐

- **玩家可見結果**：「如果家長日的捐物名單要貼出來，沒捐的就更明顯了。」你檢視公開感謝是否取得同意且不形成排名。名單改為適當致謝方式，部分家庭希望保留具名謝詞，討論仍需尊重各方意願。經討論後，公開感謝沒有附上家庭資源的比較表。捐贈者仍能保留被感謝的心意，未參與者也不用面對一張排名。
- **客觀後果**：你檢視公開感謝是否取得同意且不形成排名。
- **合法底層增減**：guardian_a:9-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-1,-2,1

- **玩家可見結果**：「我想先問一件孩子真正需要的事，不談捐不捐。」家長轉向班務問題，你依既有職權提供可確認的答覆。這次沒有把資源當成入場券，也沒有因為談公平就承諾所有提議都會被接受。他問完後停了一會兒，說終於不怕自己像局外人。這不是因為老師答應了所有要求，而是問題可以不附帶捐物條件。
- **客觀後果**：家長轉向班務問題，你依既有職權提供可確認的答覆。
- **合法底層增減**：guardian_a:12-3:-1
