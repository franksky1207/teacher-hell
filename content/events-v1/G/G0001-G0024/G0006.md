## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 普通放學時轉雨，最後一把借用傘被負責清點的學生留給排在後面、須步行到公車站的同學；先來借的人已寫完登記。 |
| 核心衝突 | 遵守先來先借便於預期，先給路途暴露較長的人更合乎當下安全，但學生無權擅改規則。 |
| 導師困境 | 導師須處理當下等候與到站安全，同時在維持順序、協調共走一段及取得雙方同意讓位間衡量。 |
| 故事獨特性 | 單一可借物的優先順序同時牽涉登記承諾和離校路段。 |
