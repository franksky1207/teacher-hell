## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長背後有家族長輩與配偶共同關注支持（`7-1`），說話條理溫和（`3-1`），性格極度迴避與人起正面衝突（`6-4`）。最近他跟家人討論孩子最近的課業練習方式後，對導師在班上推行的某項重點整理方法產生了專業疑慮（`8-2`）；但他生怕直接開口會讓導師難堪或起摩擦（`6-4`），今天打電話來用了整整十分鐘客氣鋪陳與讚美（`3-1`），繞了三個大彎才小心翼翼地問出來：「老師，我們家裡討論過覺得這樣練是不是比較慢，還是我們外行誤會了？」 |
| 核心衝突 | 怕衝突的家長把全家族的專業質疑包裝成超客氣的自我檢討，導師若順著含糊帶過會讓誤解持續，若挑明解釋又怕嚇到這名高度避開衝突的家長。 |
| 導師困境 | 直接溫和幫他把話點明、用具體學習成效邏輯耐心解釋這套練習方法的設計用意（徹底釐清家族的專業疑慮，但這名極力迴避衝突的家長當場緊張連連道歉）；還是先順著他的客氣話肯定家人用心、另外提供一兩份補充參考方向讓他自己依孩子狀況選用（讓怕衝突的家長立刻安心收尾，卻沒能真正正面解開他對教學專業的疑問）。 |
| 故事獨特性 | 不是家長怒氣沖沖來挑毛病，而是「極度怕吵架的家長繞了一大圈讚美後才敢吐出全家的專業質疑」的微妙親師對話。 |

### 開場
- **P01｜parent_a**：老師你真的很用心，我們全家都知道。也許是我們外行，只是……這樣整理是不是比較慢？
- **P02｜旁白**：他鋪陳十分鐘，終於把問題放到桌上，聲音反而更輕。我先確認自己聽到的是對方法的疑慮，不是要他繼續道歉。
- **P03｜導師**：可以直接問，慢在哪一段？
- **P04｜parent_a**：不是要挑毛病啦，我怕講得不好。
