## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 福利社補貨時間近來天天變，學生原本固定下課去買早餐，便主動拉兩位同學改等側邊小門。他聽人說送貨結束前也能走進去，見手推車倒退出門才立即請兩人停住，並想收回自己說過「知道近路」的話。 |
| 核心衝突 | 需要的是可預期的午餐取得方式，不能讓同儕善意把運貨動線變成學生入口。 |
| 導師困境 | 可請學生自行撤回邀約、改採開門後才取餐，或讓授權窗口處理未能按時購食的需要。 |
| 故事獨特性 | 同學追隨的是發起者顯得熟門熟路的邀請，不是一個想練獨立通勤的請求。 |

### 開場
- **P01｜旁白與當場對話**：側門的手推車往後退出來，學生伸手攔了同行兩人。「先不要過去，真的看不到。」你把他們帶離運貨動線，他還回頭看那扇小門。「有人說送完前也能進。我平常下課都買得到，最近每天開的時間不一樣。」他原本說知道近路，還拉了同學來；現在兩個人空著手，等著他交代。「老師，我是不是要先跟他們講，我根本沒問過？」福利社正門仍沒開。
