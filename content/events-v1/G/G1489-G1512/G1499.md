## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長在家長圈很有群體影響力（`6-1`），背後有家族長輩撐腰支持（`7-1`），先前曾因為導師處理一次班務的態度讓他心裡累積了不少不滿（`5-4`）。前天班上發了一項普通上課日的校外學習活動或自由閱讀通知，這名本就有怨氣的家長拿給家裡長輩看過後越想越氣（`7-1`、`2-1`），竟直接在沒有導師在場的家長私下群組裡帶頭大罵導師考慮不周（`6-1`、`5-4`），結果今天早上有另一位好心的家長把那段火藥味十足的對話截圖私訊轉給了導師。 |
| 核心衝突 | 導師意外看見家長在私下群組帶頭開砲的截圖，若直接點名去問會暴露截圖來源並激怒對方，若完全不處理怨氣又會在家長圈繼續發酵。 |
| 導師困境 | 不提任何截圖的事，直接在公開大班群把該通知的彈性參與原則與替代方案補充說明得清清楚楚（用公開透明安撫多數家長並隔空降溫，卻沒能真正修補與這名帶頭家長的對立）；還是找個不相干的日常聯絡理由主動致電這名家長順便探問他對近期通知有沒有建議（正面拆彈聽取意見，但敏感的家長很可能立刻猜到是私群對話走漏而更火大）。 |
| 故事獨特性 | 寫出教師最常遇到也最棘手的「家長私下小群截圖流進老師手機」的真實親師暗流。 |
