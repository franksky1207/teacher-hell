## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 班務生怕導師看到自己忘收器材，敬重老師一向願意收回自己講錯的話，仍衝動先把同伴的東西塞進同一袋。他主動點交實物才發現原先按人分好的東西被混在一起，且兩位同伴都不確定哪一件是自己的。 |
| 核心衝突 | 想把班務做快，最後需要向同伴承認自己把最快的辨識方法拿掉了。 |
| 導師困境 | 可用原先已有的自願標記分出能確認部分，其餘走既有失物流程；或等所有經手人到場再點交，部分物品今天拿不回去但誤領機率較低。 |
| 故事獨特性 | 最怕被說不可靠的人，第一次得把公開承認混放當成真正的班務。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：下課鐘響前，student_a怕我看到他還沒把班級器材收齊，急急忙忙把桌邊散落的東西全塞進同一個大袋子裡。等他拿來講桌點交時，兩位同伴湊過來一看卻全都傻眼——原本按人分好的同款物品全混在一起，誰也分不清哪件是自己的。
- **P02｜旁白**：一向最怕被說不可靠的student_a臉漲得通紅，卻想起我平常說錯話也會當面收回的樣子，硬著頭皮沒把袋子藏起來。
- **P03｜student_a**：老師……是我剛剛急著收才全部塞進同一袋的。現在他們兩個都認不出來哪件是誰的，我先不能亂發對不對？

| A | 「大家先把百分之百確定沒撞款的拿回去，剩下長得一模一樣的那兩件我貼上暫存條，下節下課問過借出人再定。」 | false | 先行發還無爭議物品，僅將完全同款之爭議物件貼條暫存並於下節課間向原借出者查證。 | 縮小爭議範圍不用整袋卡死，但下節下課還得再處理一次。 |
| B | 「對，沒確認前不能亂發。你先用原本就有的自願標記分出能確定的部分交還，認不出來的走既有失物待領流程。」 | false | 依既有標記先行發還可確認歸屬之物品，其餘未確認物件依既有失物流程留存待領。 | 立刻發回能確定的物品又守住交接規範，但剩下那幾件得跑失物程序。 |
| C | 「把袋子裡的東西全攤在空桌上，讓兩位同伴各自先寫下『自己那件上有什麼折痕或記號』，對得上再領。」 | false | 請兩位同伴先行描述各自物品之特徵細節，經比對吻合後始予發還。 | 用客觀特徵記憶核對取代亂猜，但得現場多花幾分鐘檢查細節。 |
| D | 看他最怕被說不可靠、此刻卻紅著臉站在講桌前學著認錯承認把東西塞混了，我心裡一陣欣慰又想替他留點台階，直接拿張空白紙鋪在講桌上：「認錯比硬拗可靠多了！來，我們三個現在當場把袋子倒出來一件件對特徵，沒對出來以前誰都不准亂拿！」 | true | 因欣慰學生勇於認錯，導師當場鋪紙於講桌陪同三人逐件比對特徵，嚴守未確認不交付原則。 | 溫柔護住了他的可靠感與勇氣，但導師整段下課時間都得耗在講桌旁當失物鑑定員。 |
