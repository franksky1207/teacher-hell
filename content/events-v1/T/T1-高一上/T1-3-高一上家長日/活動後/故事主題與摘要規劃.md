## 二、整池主題規劃

本池尚未分配種子。正式分配完成後，依當次有效紀錄填寫。

正式分配後，每篇複製以下空白小節。種子 ID 與四碼依[固定種子總表](../../../../../../docs/事件四數值三層平衡種子2400組.md)及正式分配紀錄填寫。

```markdown
### 單篇規劃

- **正式故事 ID**
- **種子 ID**
- **種子原四碼**
- **預定故事主題**
- **事件起因**
- **核心衝突**
- **導師困境**
- **故事獨特性**
- **T 專屬理由**
- **規劃狀態**
```

## 三、整池檢查原則

- 說明核定時段如何改變資訊、行動、責任或後果。若移到一般日常仍可原樣成立，重新檢查 T／G 分類。
- 核對臺灣高中情境與人物資格，讓原四碼實際參與故事因果。
- 比較同池與跨池的題材及教師抉擇，辨認實質重複。題材、角色類型與情緒比例維持創作自由。

詳細規則見[共用創作 SOP](../../../../../../docs/story-production-v1/03-故事創作精簡SOP.md)、[品質契約](../../../../../../docs/story-production-v1/05-故事品質與驗收契約.md)及本池時段創作引導。
