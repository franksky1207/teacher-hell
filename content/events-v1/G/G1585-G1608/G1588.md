## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長非常願意為班上投入時間人力（`11-3`），性格極講原則（`1-4`），平時也十分緊盯導師的班務進度（`12-2`）。這週班上舉辦一次普通上課日的家長愛心支援活動（如整理班級二手書或圖書分類），原本排好兩位家長志工上午九點一起到校門口報到。結果這名家長推掉自己的事準時到校（`11-3`），另一位家長卻因為睡過頭放鳥遲到快四十分鐘，讓他在校門口乾等一肚子火（`2-1`、`1-4`），一進辦公室就對導師開砲（`12-2`）：「老師你排志工表到底有沒有在確認啊？大家的時間都是時間耶！」 |
| 核心衝突 | 準時出力的高原則家長受了委屈把火氣出在導師身上，導師既要安撫他的怒氣、又得處理另一位遲到家長的尷尬收尾。 |
| 導師困境 | 先誠懇向他致歉自己沒能在今早多做一次行前提醒、立刻自己捲起袖子先頂上協助他完成開頭工作（第一時間消氣並展現導師擔當，但導師自己的備課時間被直接吃掉）；還是先向他說明昨天其實已有發通知提醒、現在立刻聯絡該名遲到家長確認狀況並請他先決定是否改期或由另一位老師協助（釐清責任歸屬不亂背黑鍋，但在氣頭上的原則派家長覺得導師在推卸責任）。 |
| 故事獨特性 | 不是家長不幫忙，而是「熱心準時來幫忙的志工家長因為被其他家長放鳥，氣到把帳算在導師頭上」的真實志工糾紛。 |
