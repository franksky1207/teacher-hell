## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 父親為了處理家族店收攤留下的物資，長期要面對兄姊互怪。他很想孩子肯定自己的美術本領，看到孩子畫到一半便質疑導師只教一種版畫手法，願自費提供可合法使用的老店招紙料。孩子拿到紙才發現父親一直捨不得的是紙背他自己歪斜的簽名。 |
| 核心衝突 | 父親一心想讓自己有用，卻在最想送出去的材料上留下不願看見的署名。 |
| 導師困境 | 導師可示範反用紙面留下那個字，讓父親的私心進到成品；或另用紙，接受家長會覺得其專長被客套打發。 |
| 故事獨特性 | 最想得到孩子肯定的人，看到作品要留下自己早年的瑕疵便縮手。 |
