## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生在導師下班後才參加的小型社區拼圖活動遇見老師，看到導師卡在藍天就愉快地插手，為了在一群陌生人前站穩，願實際坐下幫拼，卻衝動把自己印象中的邊角交給隔桌。導師才發現他把兩盒拼圖混成一盒。 |
| 核心衝突 | 兩個人都想找回各自剩下那一片，也都捨不得那張已拼出來的怪天空。 |
| 導師困境 | 可與主辦一起拆出異色塊，少掉一次原定拼圖時間；也可先請兩桌合拍一張經同意的成品紀錄再拆，會讓本來想低調的學生承認混片。 |
| 故事獨特性 | 導師在私人興趣裡真正想保留的是一片拼錯的天空。 |

### 開場
- **P01｜旁白**：下班後難得溜來社區小型拼圖活動放空，居然在桌邊遇見student_a。他看我卡在整片藍天，興沖沖坐下來幫忙，還帥氣地拿了兩片邊角遞給隔桌。
- **P02｜旁白**：隔了十分鐘我們兩桌同時缺最後一片——我低頭一對盒蓋色號，才發現這小子把兩盒完全不同的藍天混成一盒了。
- **P03｜student_a**：老師……這片塞進去顏色超合的耶！可是原本那兩盒好像都少一塊了怎麼辦……
