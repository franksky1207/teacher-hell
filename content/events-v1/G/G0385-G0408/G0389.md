## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生跟著同桌合買球衣，家裡租約續簽又要補押金，他已答應先把原本零用留給家裡。得知全團折扣會受自己退出影響，他起先氣得要大家乾脆一起取消，直到導師不公開追問家計才同意只談自己的份。 |
| 核心衝突 | 集體折扣有實際損失，但不能逼不同意的人補貼其他人的價格。 |
| 導師困境 | 可不再允許班內下單、讓自願者接受新價，或在有權處理前暫停一切收款。 |
| 故事獨特性 | 家庭要他先留錢應付押金，和他原本買得起一件衣服可以同時成立。 |

### 開場
- **P01｜旁白與當場對話**：球衣單上他已勾過尺寸，現在卻說要退。家裡續租得補押金，他答應先留零用，不是原本連一件都買不起。跟著同桌下單時誰都沒想到折扣會連動，他一急喊那就全部取消，看到你沒公開問家計，才願意只談自己的份。校內續收款已停，既有訂單由當事人和適當成人核對，不讓任何人被逼補別人的價差。他把勾號擦淡：「他們還能照自己想的買吧？」
