## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長誤信某分享組稱旁聽能提升孩子口說，主動提議借自己的錄音資材，要求導師改成每次都可在旁即時聽。 |
| 核心衝突 | 家長追求實質變好，長期被旁觀卻可能讓學生只練自己不會被笑的內容。 |
| 導師困境 | 可邀家長看自願展示、拒絕持續錄音，或只分享學生自行選可見證的作品。 |
| 故事獨特性 | 想提供好工具的人，順便把自己也插進了課堂。 |
