## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家裡很支持他探索新方法、自己學習適應力也超強的學生，昨天在網路上學到「番茄鐘配白噪音」讀書法，覺得效率驚人，今天早自習前一時衝動就跑來找導師，興奮地要求修改班上早自習「桌面淨空不准戴耳機」的程序，改成大家可以統一戴耳機聽白噪音專心讀書。 |
| 核心衝突 | 學生用新學到的正面學習法挑戰舊班規，卻沒考慮到教室裡耳機背後根本無法管理誰在聽什麼。 |
| 導師困境 | 直接答應試辦開放戴耳機，不出三天一半的人都在裡面偷聽流行歌或追劇講話；一口回絕並強調舊規定不能改，又像在打擊學生主動改善讀書效率的熱情。 |
| 故事獨特性 | 學生不是想偷聽音樂摸魚，而是真的學了一套效率方法來跟導師談班規改革。 |
