## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 玩家導師這陣子連續上課加上處理雜務，整個人疲勞到連聲音都沙啞了（`2-3`）。今晚回到住處，老家家人或親友因為支持與關心導師（`7-1`），特地打電話叮嚀「別再滑工作群組了，今晚早點關燈睡覺！」偏偏導師自己平常對班務參與度極高、大小細節都習慣親自過目（`9-3`），又習慣主動把指示傳達清楚（`8-4`）；睡前剛好看見班級幹部傳來一則「明天教室掃地少兩支拖把」的瑣碎小訊息，疲勞的手指已經點開對話框準備打一長串遠端指揮。 |
| 核心衝突 | 一邊是家人真實的關心與透支的身體，一邊是導師自己放不下的「事必躬親班務參與習慣」，在睡前手機螢幕前拉扯。 |
| 導師困境 | 聽家人的勸把這條非緊急訊息先放著不回、明天早自習進班再現場處理，立刻關掉手機去睡覺（練習在極度疲勞時適度放手與自我調適，但放不下心的自己躺在床上還是容易胡思亂想）；還是花二十分鐘打字把明天早上誰去總務處借拖把、怎麼登記的步驟全部交代清楚才肯睡（滿足自己對班務的掌控感，卻讓珍貴的休息夜晚又被工作切碎）。 |
| 故事獨特性 | 從教師自己的視角出發，寫出「不是學生或主管半夜逼你回訊息，而是老師自己太愛管班務、連累壞了都忍不住在睡前遠端指揮」的職業習慣拉扯。 |
