## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家境寬裕、跟導師極為親近的本班學生，平時對說出口的約定很有責任感。上次段考前導師隨口激勵他「如果你這次進步十名，老師就陪你在操場跑五圈」，考完他確定自己達標後，立刻動用零用錢買好全新運動飲料與護腕，每天下課開心地跑來辦公室催進度：「老師你這週哪天下午有空？我裝備都準備好了喔！」 |
| 核心衝突 | 導師當初隨口開的熱血支票遇到認真的富足學生，變成每天準時來追討體力債的甜蜜折磨。 |
| 導師困境 | 硬著頭皮換上運動鞋陪他跑完五圈，以導師最近疲勞的膝蓋跟體力明天大概直接鐵腿；笑著改口請他喝飲料抵掉跑步，又顯得老師自己說話不算話。 |
| 故事獨特性 | 沒有任何表單或家長贊助，純粹是「家境優渥又親近你的學生」買齊裝備天天來催導師兌現體能承諾。 |

- **P01｜旁白與當場對話**：護腕還沒拆，他已帶來第三次。「我知道說好就要算數，老師也一樣吧？」他和你親近，家裡給的零用錢夠買整套，這回一達標就自己準備好。你已確認承諾和原成績，不拿忙當沒說過，也把安全與時段條件講清。他把飲料退回自己的袋子：「不用收這個，你告訴我哪天就好。」桌上仍沒有確定時間。
