### AVG區塊的實際鍵名示意

插入第4區指定位置的唯一 `avg` 程式碼區塊必須為**合法JSON**，有 `opening.Pxx`（其鍵與開場可見分頁對應）及`results.R1～R4.pages`；每個R有非空分頁。下例僅示範結構，不代表一篇完整可驗收的故事：

```avg
{
  "opening": {
    "P01": {"scene": "school:classroom", "enter": ["student_a"]}
  },
  "results": {
    "R1": {"pages": [{"speaker": "student_a", "text": "【本篇R1實際台詞】"}]},
    "R2": {"pages": [{"speaker": "student_a", "text": "【本篇R2實際台詞】"}]},
    "R3": {"pages": [{"speaker": "student_a", "text": "【本篇R3實際台詞】"}]},
    "R4": {"pages": [{"speaker": "student_a", "text": "【本篇R4實際台詞】"}]}
  }
}
```

**硬規則**：固定種子與四碼來自[`data/g1752-fixed-seed-assignments.json`](../../data/g1752-fixed-seed-assignments.json)，上述G0001四碼及示範標籤、選項情緒位置均非正式創作決定；真實標籤需依故事內容判定。恰四選項、恰一情緒；A→R1、B→R2、C→R3、D→R4，四R數值與因果依[01](./01-G數值與固定結果.md)及[04](./04-G品質與驗收.md)。六選三真實候選、四份R因果及非零變動理由放進本篇**驗收JSON**，不建第六區，不放入玩家故事。G不得有T的4×8矩陣、R5～R8或V3 A～E。
