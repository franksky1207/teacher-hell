## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生半夜躲在被窩追直播，午餐睏到一句話也不想講。家中長輩知道後要求他當晚當面交手機；桌邊同學還等著他像平常一樣講主播梗，便開始模仿他的沉默。 |
| 核心衝突 | 他不願向同學交代家裡的處分，也不願繼續被當作餐桌表演。 |
| 導師困境 | 可當場收住玩笑不說原因、讓學生自己決定是否承認昨晚的事，或另談他是否願意向家人提出可持續的用機安排。 |
| 故事獨特性 | 昔日的笑話需要表演者今天願意再演一次；疲累與該不該交手機不是同一個決定。 |

### 開場
- **P01｜旁白與當場對話**：便當才打開，同桌就學他垂著眼睛不說話，幾個人等他接下一個主播梗。他昨晚躲在被窩追直播，午餐時睏得連筷子都拿反；家裡已說今晚要當面交手機，這件事他只私下告訴你。你先制止拿人吃飯的模樣取笑，沒有說出原因。他把椅子往內挪：「你說過，吃飯不用表演吧？」同學還不知道他今天是真的不想說。
