## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位校內常駐總務／或安全支援職員對導師一向非常敬重（`5-3`），但自身校園安全意識極高（`9-4`）、對環境風險的判斷冷靜精準（`3-2`），而且做人極講原則（`1-4`）。今天導師班為了下午一節普通的班會小戲劇表演，向社團借了一把高折疊梯與大型木箱暫放在教室講台側面，導師覺得只放一節課沒關係；但這名職員巡堂經過看見後（`9-4`、`3-2`），雖然語氣依然客氣敬重導師（`5-3`），卻寸步不讓地堅持（`1-4`）：「老師不好意思，這個梯子沒固定又靠著走道，萬一下課同學追逐撞倒會砸傷頭，就算只放一節課現在也要先搬出去！」 |
| 核心衝突 | 高梯必須撤離，代價是學生得在班會開始前決定要重排動作，還是犧牲今天的完整演出。 |
| 導師困境 | 先由有權責及適任的校方人員安全收合、搬離並歸還或入指定庫房；維持通道暢通，師生不攀高。導師可留足場地安全檢查時間後改成純平地演出，讓同學現場重排那段最難的走位；也可今天只演前半段並讓原組說明未演片段，保住其餘組別時間，但原組苦練的高潮演不成。 |
| 故事獨特性 | 沒有誰擺架子，寫出「對你超客氣敬重、但碰到安全原則一秒都不肯通融的硬派職員」與教室活動的現場碰撞。 |
