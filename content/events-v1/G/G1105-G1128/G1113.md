## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長昨天聽孩子抱怨班上掃地區域一學期固定不換、自己連兩學期都被抽到外掃區廁所，家長越想越氣（`2-1`），今早一時衝動（`1-2`）直接請假衝進學校找導師，一邊捲起袖子說「如果不換區，我這週六或放學親自投入人力來幫我孩子刷廁所行不行」（`11-3`），一邊強烈要求導師立刻修改班上固定掃區分配程序（`12-1`），改成每月全班大風吹輪調。 |
| 核心衝突 | 護子心切又衝動的家長用「親自來校代勞」作為抗議籌碼，正面挑戰導師為了管理穩定而維持的掃區固定制度。 |
| 導師困境 | 立刻點頭答應改採每月輪調掃區，原本抽到教室內掃區的三十個同學多半覺得好端端為什麼突然要輪流去掃廁所；嚴正拒絕家長進校代掃並維持原制度，這名氣頭上又衝動的家長恐怕直接打去學務處投訴班級掃區分配黑箱不公。 |
| 故事獨特性 | 家長不是嫌掃廁所髒要花錢請人，而是氣到說「要就我親自來刷、不然你就給我改輪調」，把教室管理變成家長現場施壓。 |
