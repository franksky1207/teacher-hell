## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生可支配的家用布料使班上桌面場景很漂亮，他親手縫成並想打出第一次得意舞臺效果，請導師把展示改成讓所有人走過看。試放時卻發現布一動就容易讓人誤認平面可踏，自己決定撤下地面版本。 |
| 核心衝突 | 作品最打動人的是近看，真正可用的展示方式偏偏要從桌邊看。 |
| 導師困境 | 可把布固定在桌面並縮小一次觀看人數，耗更多輪次；或拍細節在教室展示，失去原樣觸感，成品可完整收好。 |
| 故事獨特性 | 執行力強的人第一次完成的成果，是把做得最像地面的東西從地面撤掉。 |
