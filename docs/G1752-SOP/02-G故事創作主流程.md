# G1752 專屬 SOP｜02 三階段橫向創作主流程

> 唯一創作順序：**73批×24篇摘要規劃（已完成前置） → 階段一：全庫開場與選項 → 階段二：全庫結局與數值 → 階段三：全庫AVG與驗收 → 24篇授權晉升與雙預覽發布**。固定四碼、四個專屬R、不使用T八R／32格／V3。原稿格式與草稿保存以[03](./03-G五區塊範本.md)、數值以[01](./01-G數值與固定結果.md)、階段檢查／驗收／發布以[04](./04-G品質與驗收.md)、批次管理以[05](./05-G種子批次與試產.md)為準，不另寫第二套規則。

## 階段零｜固定種子與摘要規劃（已完成前置）

1. 73批×24篇共1,752篇已依[`data/g1752-fixed-seed-assignments.json`](../../data/g1752-fixed-seed-assignments.json)固定`Gxxxx`、`Sxxxx`及四碼，並依[07](./07-G故事主題與摘要規劃.md)完成摘要規劃與全庫輕量總檢。
2. 正式創作沿用既有規劃，不更換種子或擅改核心構想；僅在階段一～三發現真缺陷時，依[04](./04-G品質與驗收.md)與[07](./07-G故事主題與摘要規劃.md)定向回修。

## 階段一｜開場與選項（73批×24篇）

依73批、每批24篇順序完成全庫1,752篇的開場與選項草稿（於同一份`Gxxxx.md`建置第1～4區文字骨架，詳見[03](./03-G五區塊範本.md)）：

1. **自然開場與選擇前對話**：根據已核准摘要，從人物、知情與場景出發撰寫自然開場與選擇前對話；確認事件起因、人物動機、核心衝突與導師必須選擇的理由。人物可自己表達的資訊不由長旁白代講。
2. **彈性篇幅參考**：以T648九篇抽樣（開場平均約162字）為品質參考，G開場暫以**約140～200字**為彈性參考；情緒鋪陳較多者可自然延伸至220～250字，簡單日常或幽默故事可更短。不為字數灌水，亦不縮成摘要。
3. **確認必要前提與演出限制**：
   - 核對合法日期、日型、觸發時段、必要年級與學期、人物在籍／在場／知情條件、場景與發生時間是否一致，以及目前遊戲操作是否具備相應觸發時段。G不得冒用T專屬校曆節點。
   - **G11 題材與時間界線**：G11「導師私人生活與自我調適」以教師下班後私人時段為主要演出時間，但不限定必須回家；合理的校內午休、休息時間及早晨私人事件可以保留，主要屬於校務的故事不得只因貼有G11就強制移至晚上。G11是題材分類而非時間分類，不為標籤重寫合理摘要或強制保留不合理分類。合法上課日晚間G11事件不額外增加當日0～5件總數的規則，仍依[共用事件02第四節](../story-production-v1/02-事件分類與時間資格.md#四tg每日抽件類別優先與故事一次性設計工程狀態分開)為準。全體G01～G11（含多標籤）均須依故事實際前提安排時間；未來與T/P共同接入引擎時的統一排程檢查，只引用共用事件02第四節，不在本SOP另訂一套。
4. **六選三＋情緒候選與固定A～D**：
   - 先寫**六個互不重複的普通候選＋一個合理的情緒候選**；真正隨機抽三個普通候選，再與情緒候選真正洗牌固定為A～D，保存完整抽選證據於本篇驗收JSON。不可為方便寫結局自行挑選或重排。
   - 四個選項各有不同的已完成客觀事實、考量及代價，皆能自然發展出對應結果；避免「三個明顯愚蠢選項配一個標準答案」，但不要求四選項同樣理性，亦保留情緒選項的衝動、失言、逃避或犯錯可能。
   - 涉及學生安全、法律、查證及教師權責的必要程序，應作為共同前提，不得設計成可任意放棄的選項。
5. **簡短記錄四條「後果可行方向」**：對應A～D各記一條簡短方向於驗收JSON，涵蓋：(1)可能形成的客觀後果、(2)相關人物可能產生的自主反應、(3)該行動可能帶來的主要代價。僅作為階段二因果銜接依據，**不預寫完整R、不鎖死人物反應**。
6. **階段一停止界線**：不製作完整R1～R4、不配置58庫、不進行NPC或玩家底層結算、不製作AVG。

## 階段二｜結局與數值（73批×24篇）

依73批、每批24篇順序，承接階段一已固定的A～D（補齊`Gxxxx.md`第5區，詳見[03](./03-G五區塊範本.md)）：

1. **固定映射與故事先行**：固定**A→R1、B→R2、C→R3、D→R4**。先確立完整故事因果，再配置數值；不得為了數值方便倒編人物行為。
2. **R1～R4完整結果與自主反應**：
   - 撰寫玩家可見劇情、人物自然反應與實際客觀後果；彈性篇幅參考為**每個R約140～200字**（對照T九篇抽樣平均約149字），情緒較多者可自然延伸至220～250字，簡單日常可更短。
   - 每個R至少應有一項由對應選項造成、可與其他結果區別的實際事實或關係變化；不得只是同一結尾換句話說、換數值或換情緒。不強制四個結果分別對應最好、較好、較差、最差，不增設好壞配額。
   - 人物反應須符合立場、知情、自主性及已發生事實；不得偷偷推翻選項已完成的客觀行動，亦不得將尚未發生的資訊傳遞當成既成事實。
3. **58庫與原固定四碼結算**：
   - 依[01](./01-G數值與固定結果.md)為各R挑選合法且同篇不完全重複的58庫玩家四狀態（精神、熱忱、情緒、掌控），不建立第59組，不要求58組使用次數平均。
   - 依原種子四碼與[共用人物01](../story-production-v1/01-人物數值與四碼資格.md)處理合法NPC及玩家底層非零增減，並將因果理由記入本篇驗收JSON。
4. **階段二停止界線**：不製作AVG，不進行正式核准或雙預覽發布。

## 階段三｜AVG與驗收（73批×24篇）

依73批、每批24篇順序，將前兩階段已完成的原稿轉換為自然AVG演出並完成最終驗收：

1. **唯一AVG JSON與分頁轉換**：依[03](./03-G五區塊範本.md)於第4區`### 開場`前寫入全篇唯一合法`avg` JSON，包含`opening.Pxx`及`results.R1～R4.pages`（各R獨立播放）；分頁依自然對話節奏決定，不固定頁數，避免角色朗讀旁白或跨頁重複。
2. **素材與演出合法性**：沿用既有合法背景、音樂、學生六表情、成人六姿勢、人物進退場及遠端`phone/chat`演出；同場至多兩位NPC；玩家可見內容不露出`avg`程式碼。
3. **原稿一致性與定向回修**：AVG以演出轉換為主，不重新發明劇情；可為自然對話與分頁節奏潤飾文字，但若更動重大事件、已完成行動、人物知情或結局事實，須同步定向回修正文、數值與驗收證據，確保單一正式Markdown與AVG完全一致。
4. **完整驗收、授權晉升與雙預覽發布**：依[04](./04-G品質與驗收.md)完成單篇與整批24篇機械及語意驗收，取得使用者授權後整批晉升`content/events-production-v1`，依[06](./06-T648固定標籤基準與G動態統計.md)正式入帳一次，並同步更新故事全文預覽頁與測試中心AVG（S5交付；正式`main`遊戲引擎接線另行授權，不冒稱S6）。
