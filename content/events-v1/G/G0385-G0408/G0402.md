## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長帶孩子來問自習問題，聽到另一名同學不敢走進辦公室，提出願站旁邊陪入。他本人的回家分工讓可用時間很有限。 |
| 核心衝突 | 陪進去有助力，成人卻不能藉此知道另一個孩子的私事。 |
| 導師困境 | 可由其他合法成人接手、讓他只陪到門口，或協助原學生自行選擇何時進。 |
| 故事獨特性 | 家長看見別人需要，但幫完仍須按時處理自己的家務。 |
