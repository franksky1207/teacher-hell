## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名個性開朗（`2-4`）又非常信任導師（`5-1`）的學生，平時對身體健康與體態保養頗為重視（`4-2`）。昨晚他在影音平台輕信某健身網紅「每天空腹高強度波比跳三百下接冷水沖腳，一週瘦三公斤最安全有效」的極端偏方（`8-3`），今天一早興沖沖跑來找信任的導師炫耀自己昨天熬夜偷練完，還打算體育課前帶幾個好朋友一起照跳——導師一眼就看見他走路微微一拐一拐、腳踝已經紅腫隱隱作痛，他卻笑著說「沒事啦老師，網紅說越痠越有效」。 |
| 核心衝突 | 導師必須立刻停止這名信任自己的學生繼續運動、送健康中心並通知家長，但學生當場急著求情「別告訴管很嚴的媽媽我半夜偷跳」，甚至可能在班級社群抱怨老師小題大作。 |
| 導師困境 | 導師當場停掉他今天的體育課活動、請校護檢查並依規定通知家長；接下來的兩難在於，這名原本信任老師卻被媽媽管得很嚴的學生哭著哀求「別把熬夜跟網紅偏方的細節講出來」，甚至在班群發限動怪老師太嚴格、害他被同學笑，導師該把熬夜亂練的前因後果據實告訴家長以防再犯，還是只告知腳踝扭傷請就醫以保住這份師生信任？ |
| 故事獨特性 | 把青少年追求體態的網紅誤信與運動傷害處置結合，安全處理毫無妥協，真正的難題落在「通知嚴格家長時該不該揭露熬夜偏方細節」與「被學生在班群抱怨」的信任考驗。 |
