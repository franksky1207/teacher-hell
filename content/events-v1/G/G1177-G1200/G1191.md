## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班數學或英文科任教師對學生學習進度極負責任（`1-1`），平常一向配合導師的班務安排（`9-2`），也非常支持導師嚴格管理早自習與正課準時進班的立場（`10-1`）。導師班這學期原本訂了一條常規：前堂遲到者須在下課十分鐘站到走廊寫三行遲到反思單，且正課鐘響時無論寫完與否都必須立即進班上課、絕不由風紀阻擋，未寫完部分改於放學補交。今天這名科任在預備鐘前就提早進班準備發小考卷與收作業時，剛好看到兩個學生為了趕寫最後兩行而直到上課鐘響才慌張拎著書包進座，連帶打亂他發卷核對節奏，令他對這項規定產生專業質疑（`8-2`），下課直接來找導師商量調整。 |
| 核心衝突 | 高度配合又挺導師管教立場的負責同事，從「課前準備與上課節奏」的角度質疑導師把寫反思單放在課間十分鐘容易讓學生踩點壓線進班；導師必須守住「正課鐘響學生一律正常進班、絕不侵占科任授課時間」的原則，同時解決課間罰寫收尾拖延的問題。 |
| 導師困境 | 順著同事的專業意見把「下課走廊寫反思單」全部改到放學統一補寫（徹底清空課間走廊寫單對預備鐘前發卷的干擾，但原本靠下課即時處理才壓住的拖延風氣恐怕很快死灰復燃）；改為規定「下課鐘響後前五分鐘寫完即止、預備鐘一響一律收單進教室、未完部分放學補寫」（守住正課受教權與科任課前準備時間，卻得多出「追討未完成反思單放學補交」的班務追蹤工時，這名負責同事也仍覺得不如直接全改放學省事）。 |
| 故事獨特性 | 明確確保正課鐘響一律進班、不由風紀阻擋受教權亦不侵占科任授課時間，寫出同事精準指出「課間寫單收尾卡到預備鐘發卷」時的教學節奏討論。 |
