## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家中長輩以陪看路線和提醒動線支持學生，學生想自行完成普通校內找點練習，辨認某段有維修路障而主動繞開。他連日注意導師站在哪個地方看自己，走到安全處才坦白想在沒有老師視線的位置也能完成。 |
| 核心衝突 | 對孩子有實際幫助的觀察，也讓他以為獨立只能發生在老師看得到時。 |
| 導師困境 | 可在核可可視範圍改成教師延後跟進，代價是少些即時提示；或換成學生自行標記路線、老師核對後再走一次，失去原本這回首次的成果。 |
| 故事獨特性 | 有安全意識的人要求自主，具體要求是老師何時再抬頭。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：校內找點練習剛繞過前面那塊施工警示牌，student_a就很警覺地主動繞開維修區走進核可的安全步道——他家裡長輩平常都會陪他看路線，所以安全意識一直很好。只是他走了兩步又回頭瞄我一眼，腳步忽然停在樹蔭下。
- **P02｜student_a**：老師，你這幾天都站在那個轉角看我走到哪裡……我已經有自己看路障繞開了。如果老師一直看著我，我會覺得好像還是有人在帶路。
- **P03｜旁白**：他抓著地圖紙角小聲補了一句：「這段明明很安全，我可以自己走，但你可不可以先不要一直看？」

### 四個最終教師選項

| 選項ID | 玩家可見短句 | emotional | 教師已完成的客觀行動 | 優點及代價（不顯示玩家） |

| A | 「我不跟著你走，也不一直對著你背影下指令。老師留在這個視線看得到全段的安全區起點定點看顧，你繞完回來報到；如果有遮蔽就先停下不繼續。」 | false | 於經確認可從起點全程目視且能即時介入的核可安全區，導師採起點定點看顧、不貼身跟隨或口頭指路；如有視線遮蔽或無法即時介入，立即停止此安排改回合規看顧。 | 學生不再感到老師一路貼身盯梢，但起點視野必須連續可及、老師仍須全程留神；一旦有遮蔽就不能繼續獨行。 |
| B | 「這段安全區完全沒施工，我直接去前面終點安全線的椅子坐著看著你走完，不拿板子也不跟在你後面，讓你自己走最後一格。」 | false | 於完全安全且無施工干擾之核可段落讓student_a獨自完成最後一格找點，教師改於終點安全線處靜坐遠距目視看顧、不隨行也不作筆記。 | 既嚴守目視安全看顧責任又拿掉被緊跟的壓力，但僅限於這一小段安全區域。 |
| C | 「如果不想要老師跟著看，你找一位同學結伴在安全範圍內互看完成，老師退到外圍安全線等你們。」 | false | 徵得student_a同意改以同儕結伴於核可範圍內互相照應完成，導師退居外圍安全線看顧。 | 拿掉教師盯看的壓力又兼顧安全，但他得接受這次不是完全一個人走。 |
| D | 聽他連日盯著我站哪裡、走到安全處才小聲求我「別一直看」，我忽然明白這孩子在家也被長輩小心翼翼護習慣了才更想自己走一次，心裡又酸又好笑，直接把紀錄板塞進包包、轉身走上旁邊視野最好的涼亭台階拿水壺晃了晃：「好啦！老師上台階喝水乘涼看操場風景，安全區你自己去闖關！」 | true | 因體會學生渴望掙脫過度保護的心情，導師收起紀錄板退上視野開闊的旁側涼亭台階喝水歇腳，改以遠距全場目視看顧取代近身尾隨。 | 在嚴守校方安全看顧前提下給足他不被盯梢的自主感，但老師得在台階上全程目視盯緊、不敢真的滑神。 |
