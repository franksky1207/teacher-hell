## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日處理全校學生個案累到不行的輔導或學務職員（`2-3`），先前對導師沒即時回報班級異動一直心有不滿（`5-4`）。今天他憑自己觀察判斷導師班某位學生最近情緒波動大（`3-2`），懶得再等導師回覆便直接在跨科教師聯繫群主動發了一則「請各科任課老師近期多留意該生課堂狀況」的提醒訊息（`8-4`），結果不知情的科任老師進班時眼神都盯著該生看，讓原本沒想公開的學生當場崩潰問導師誰說的。 |
| 核心衝突 | 過勞且對導師有微詞的職員跳過導師直接對科任群發提醒，好意預防卻引發學生隱私被曝光的二次傷害。 |
| 導師困境 | 立刻私下找這位職員抗議「沒先問我跟學生就發群組太越界」，原本就對導師不滿的職員恐怕直接回嗆「是你自己平時回報太慢」；先安撫學生說老師們只是例行關心，學生根本不信大家突然同時盯著他看。 |
| 故事獨特性 | 寫出跨處室資訊傳遞「跳過導師直接廣播給科任」造成的隱私與信任撕裂。 |
