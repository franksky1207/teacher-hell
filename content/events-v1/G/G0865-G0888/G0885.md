## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校護或生輔教職員很有同理心、校園安全意識高，做事又極具自主主見。看到導師班上扭傷腳的學生還在爬樓梯上四樓專科教室，他沒先跟導師商量便直接介入班務安排，親自帶學生開了一張「本週電梯臨時通行證」，還順便交代導師：「這週你們班的掃地工作他也先不用去了，我剛跟他說好了。」 |
| 核心衝突 | 跨處室職員出於同理與安全直接替導師免除了學生班務，讓導師失去重新調度掃地人力的緩衝。 |
| 導師困境 | 當場補一句「其實他可以坐著擦講桌或管點名」以免其他學生覺得不公，怕被職員當成不通情理的冷血導師；完全照職員決定放行，這週該區的掃地缺額就得導師自己找人頂。 |
| 故事獨特性 | 兩邊都為受傷學生著想，但職員「做好人做全套」直接替你把班務也免了。 |

### 開場
- **P01｜旁白與當場對話**：卡先開好了，人也不再爬樓梯。校護看他扭著腳還往四樓走，親自帶去辦通行，接著很有主見地說這週掃地不用了。你已按健康需要接好安全、照看與必要班務調整，沒叫學生證明還能做。校護卻又補：「我跟他講好了。」你的輪值表還在手上，現在要談的是誰接哪一段，不是傷腳配不配休息。
