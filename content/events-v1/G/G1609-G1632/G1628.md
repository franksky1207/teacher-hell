## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生在班上極有群體影響力（`6-1`），非常信任導師（`5-1`），平常也總是全力支持導師的決策（`10-1`），只是他自己很有主見與自主需求（`4-3`）。今天班會討論段考後的輕鬆小活動，導師原本提案「利用最後一節班會課安靜看半部短片、喝杯平價紅茶」，這名高人氣學生立刻帶頭鼓掌力挺導師（`10-1`、`5-1`），接著話鋒一轉憑著自己的主見當眾替全班加碼（`4-3`）：「大家都很挺老師嘛！那飲料跟點心我們就自己投票訂高檔披薩跟炸雞，順便再多加一場抽獎好不好？」全班瞬間被他點燃歡呼附和（`6-1`）。 |
| 核心衝突 | 挺你的高人氣學生用「支持老師」當開場白，一秒把低預算短時間的小活動綁架成高預算、會吵到隔壁班的大派對，導師當場喊停超掃全班興。 |
| 導師困境 | 笑著拍手等大家安靜下來，明確把加碼部分拉回原本的平價飲料與不吵鬧原則、「老師謝謝你們這麼捧場，但我們只有一節課而且隔壁班還在考試／自習，下次期末再辦大的」（守住預算平等與校園秩序，但被當眾踩煞車的人氣學生有點下不了台）；還是同意保留他提議的抽獎小遊戲增加趣味、但食物依然維持原本平價預算（接住他的創意與自主參與感並保住和氣，卻仍要多花力氣控制現場音量）。 |
| 故事獨特性 | 沒有誰反對老師，寫出「最挺老師的班級人氣王一開口幫你捧場、結果差點把整個班會課變成失控同樂會」的現場掌控考驗。 |
