## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一位家裡開小吃攤、照顧與生計負擔都很重的家長（`7-2`），做人極講「受人點滴一定要回報」的原則（`1-4`）。昨天導師放學後多留半小時幫他孩子補救弱科，他今天一早二話不說就在自家攤位多煮了一大鍋合法衛生的熱湯與小菜（`3-3`），中午親自提著大保溫桶送到學校想給導師與全班加菜（`11-4`），偏偏校方明文規定未經申請與留樣檢驗的外來手作熟食不得分發給學生食用，校內也沒有供外來熱食留存分裝的合規條件。 |
| 核心衝突 | 生活辛苦卻極講人情的家長親自煮了整鍋熱食回報老師，但校內無合規接收、分發及保存條件；導師須在當面婉拒與另約合規方式承接心意之間取捨，避免讓家長再增加負擔。 |
| 導師困境 | 當面說明校內無法接收整桶熱湯，請家長保持原容器帶回並自行依食品保存條件妥善處理，導師親自送他到校門口道謝，卻得面對家長白跑一趟的失落；或在同樣不接收整桶熱食的前提下，提議改日依校方規範事先協調可接受的少量餐點，讓家長有機會完成心願，但也可能讓原本只想道謝的家長再次花錢備料、增加生計負擔。 |
| 故事獨特性 | 沒有炫富也沒有附帶要求，寫出小攤販家長最樸實沉重的人情回報撞上現代食安與保存限制時，大人之間如何在「守規矩」與「不糟蹋對方心意與成本」間兩難。 |
