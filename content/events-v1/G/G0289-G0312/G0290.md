## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長努力存錢想讓孩子自己挑蛋糕，孩子卻堅持買同學正在合訂的流行款。導師曾制止校內集體訂購，家長趁上班前空檔來要求說明，還以為教師認為家裡慶祝太奢侈。 |
| 核心衝突 | 制止班內收款有理，導師若把奢侈說出口，就侵入家人真正辛苦存出的選擇。 |
| 導師困境 | 可說明原決定範圍、承認曾把買不起說成不該買，或把慶祝選擇完整交還家庭。 |
| 故事獨特性 | 導師一次制止團購的措辭，差點被帶回家當成生日規則。 |

- **P01｜旁白與當場對話**：「我們存那筆錢，不是每天都能買。」家長上班前只剩幾分鐘，仍拿著你制止班內合訂蛋糕的訊息來問。她原想讓孩子一年自己挑一次，孩子卻想跟同學買流行款；你那句不要弄這麼奢侈，被帶回家像成了老師不准慶生。校內收款已依規定停止，沒有人被逼著出錢。她把手機放低：「你是在說團購，還是在說我們家不該買？」
