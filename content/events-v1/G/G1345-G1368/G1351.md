## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班學藝或班長（`9-3`）平時非常信任導師的帶班出發點（`5-1`），但對導師最近在早自習推行的「依座號每天輪流兩名同學站起來帶讀公告與短文」作法產生專業質疑（`8-2`）。今天早上剛好輪到一位極度內向、一站在眾人面前就臉紅發抖的女同學，這名幹部看在眼裡心生深切同理心（`1-3`），下課立刻跑來找導師商量能不能免除這名同學的輪值、改由他這個幹部代唸就好。 |
| 核心衝突 | 體貼又信任導師的幹部替內向同學爭取免除公開發言，導師則卡在「訓練膽量的一致常規」與「避免讓膽怯學生在全班注視下過度緊張」之間。 |
| 導師困境 | 答應讓這名幹部以後私下幫那位易怯場的同學代唸（立刻解救了女同學的焦慮並肯定幹部的體貼，卻可能讓其他同樣害羞的同學跟著要求免站立帶讀）；向這名幹部解釋這項練習正是為了幫大家慢慢適應開口表達、改成讓女同學坐著唸或兩人一起合唸而非完全免除（在訓練與減壓間折衷，這名心疼同學的幹部卻仍覺得老師有點固執）。 |
| 故事獨特性 | 沒有誰嘲笑誰，寫出班級幹部對內向同學的溫柔保護欲，以及導師在「鍛鍊表達」與「保護心理安全」之間的教學拿捏。 |
