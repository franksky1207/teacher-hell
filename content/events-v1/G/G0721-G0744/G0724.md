## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生有家中剩下的厚紙版，想做同學騎單車用安全帽的漫畫立架。另一名同學以為戴上安全帽便能在校門旁試騎，他看到便主動告訴同組那段路車多且不准借道，協調一人只在平地扶車、一人畫下真實比例。漫畫畫完，車主嫌額頭被畫太大，要求把帽沿往上移。 |
| 核心衝突 | 為了站得住、看得清而保留的真實帽位，成了被畫者最討厭的地方。 |
| 導師困境 | 導師可讓畫者保留正確示範並自行畫一張美化版送人，得花額外時間；也可讓成品改成不具辨識性的剪影，失去原來最逗的表情。 |
| 故事獨特性 | 畫出安全戴法之後，真正被嫌棄的是自己的臉。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：漫畫立起來，車主第一句卻是：「我額頭哪有那麼大？」畫者才剛協調好扶車和量比例，也把那段車多、不准試騎的限制主動告訴同組。你們守在允許的平地，只做靜態作品。家裡的厚紙版都裁好了，最逗的表情卻把帽位畫得很真。「帽沿再拉高啊。」車主伸手比了一下，畫者看向你，沒有立刻改。
