## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 總務處水電與校安職員安全意識高、執行力極強，今天巡檢走廊消防栓時發現導師班學生把拖把桶跟掃把全塞在消防栓箱門前，當場火大，立刻自己動手把整排掃具清出來堆在教室後門，接著衝進導師室督促：「今天放學前一定要讓學生改位子，我下班前會再來複查！」 |
| 核心衝突 | 總務職員果斷排除了消防隱患，卻也把整堆濕答答的掃具直接倒在教室後門逼導師限期另覓空間。 |
| 導師困境 | 立刻犧牲半節班務或下課叫學生把掃具搬進教室內角落，雖然合規但整間教室都是抹布味；請總務處先幫班上找另一個合法走廊凹槽，氣頭上的職員根本沒打算等。 |
| 故事獨特性 | 沒有火災發生，但安全職員「當場動手清障礙、限期今天複查」的硬派作風讓導師立刻得解決空間難題。 |
