## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日排全校跨班選修與補課表累到快虛脫的教務處課務組職員（`2-3`），平時非常信任導師（`5-1`）也肯定導師的控場專業（`8-1`）。今天突然有位外聘兼任教師臨時請假，他抱著課表來跟導師彈性協商（`10-3`）：「老師我知道你週五下午那節本來是空堂，能不能先幫我代看一節自習？下週我把你最討厭的那場高三／週六前監考幫你換掉！」 |
| 核心衝突 | 行政端在突發缺工時用「私下調換監考人情」來換取導師犧牲空堂代課，讓合法調度變成職場人情交易。 |
| 導師困境 | 點頭答應代看一節換掉下週討厭的監考，雖然看似划算但這週原本要用來改考卷的空堂直接沒了；婉拒並請課務組照正常代理順位找人，這名信任你又快累垮的同事現場實在很難立刻生出別人。 |
| 故事獨特性 | 沒有官僚壓迫，真實呈現私校課務組與教師之間「空堂救火換監考」的辦公室地下交易日常。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：課務職員把兩張表疊在一起，指著你週五的空堂。他眼下很黑，昨天排好的補課表還沒收。
- **P02｜職員**：你進班我最放心。幫我一節，下週那場你最不想去的監考，我想辦法換掉。
- **P03｜導師**：正式調度照規定。監考也不能你一句話就算換了。
- **P04｜旁白**：他點頭，說目前照看已有人暫接，只問你願不願意多幫這一次。你那節原本排了自己的備課，課本都夾好頁碼了。

| B | 我可以替他寫這次調課通知的草稿，不再多接一班。 | false | 自願依已確認課務資訊製作調課通知草稿，交權責者審定，未自行發布。 | 分擔文書但仍需自己花時間，不能補上看班人力。 |
| C | 我只能幫前面可用的短段，後面得先接好人。 | false | 提出有限時段自願支援方案，須權責者確認完整成人交接後才執行。 | 保留部分備課，增加交接安排。 |
