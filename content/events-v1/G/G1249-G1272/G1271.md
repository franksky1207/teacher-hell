## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班數學或理科任課教師長年居住學校旁、家庭生活安穩（`7-4`），但這學期同時兼任跨年級段考命題與新課綱研習彙整，工作負荷極為沉重（`11-1`）。導師班向來鼓勵學生在考前複習週拿各種不會的題目向老師發問，但這名同事對這項開放作法產生強烈專業質疑（`8-2`），認為一堆學生拿補習班冷僻偏題來問，不僅拖垮他正課基本題複習進度，自己過勞之下也沒心力在台上一直拆解偏門技巧。今天他正式來找導師要求修改這項考前問答約定（`12-1`），主張規定複習週發問一律只限課本與校內習作題目。 |
| 核心衝突 | 過勞且生活安穩的同事為了守住正課複習節奏並減輕臨場負擔，要求限制學生考前只能問課本與習作，讓「顧及基本進度」與「滿足想挑戰難題學生的求知欲」正面對撞。 |
| 導師困境 | 順著同事的要求在班上宣布考前複習課一律只准問課本與習作、補習班難題改放學再說，雖然讓這名過勞的任課老師鬆一口氣，幾個想拚高分、本來就靠課堂發問解惑的學生當場抱怨受限；婉拒設限並請他盡量開放發問，這名已經業務過勞又每週得應付冷僻難題的同事恐怕心生不滿、覺得導師完全不體諒任課老師的課務負荷。 |
| 故事獨特性 | 寫出高中段考前最真實的教學拉扯——「想拚進階題的學生」與「負荷過重只想守住課本基礎進度的科任老師」在發問範圍上的摩擦。 |
