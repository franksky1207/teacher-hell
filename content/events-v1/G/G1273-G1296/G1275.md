## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 總務處這名校安職員今天剛解決困擾全校許久的操場排水溝堵塞，心情開朗到極點（`2-4`）。他對校園防滑安全意識極高（`9-4`），向來也對走廊動線規劃很有主見（`4-3`），今天趁早自習前拿著幾條防滑墊與三角錐跑來找導師協調合作（`10-4`）：「老師我心情超好、順便幫你們走廊設計了一套『單行道雨傘甩水＋進門擦鞋區』！這週先借你們班前門外這塊地試辦看看好不好？」——問題是他那套動線把甩水區剛好畫在導師班前門正中央，早自習鐘響前四十名學生同時進門必定大塞車。 |
| 核心衝突 | 開朗主動又安全立意良善的同事帶著強烈主見來合作試辦防滑動線，但實測位置剛好卡死班級晨間進門瓶頸。 |
| 導師困境 | 順著他的好心情與合作意願先借前門外走廊試辦幾天（雖然守住防滑與同事的熱情，早上學生擠在門口甩水卡成一團肯定天天遲進座位）；明確指出前門動線太窄、請他改移到樓梯轉角大廳再試（避免塞車，這名剛修好水溝滿腔熱血想一展動線長才的同事當場像被澆冷水、興致大減）。 |
| 故事獨特性 | 行政同事不是來抓違規或催表單，而是心情大好主動來「推銷自創防滑動線」卻沒算準下課人流瓶頸的職場喜劇。 |

### 開場
- **P01｜旁白**：校安拿著防滑墊來，說排水溝終於通了，連今天的雨都順眼。三角錐還提在手上，他已指著你們前門畫起單行線。
- **P02｜staff_a**：四十個人這邊甩水、這邊擦鞋，一路進去，多順！借你們試一週？
- **P03｜導師**：四十個人同時來，前門這一小段會卡住。甩水也不能對著別人。
- **P04｜staff_a**：那再挪一點。我研究過的，先試才知道。
- **P05｜旁白**：鐘快響了，學生開始從樓梯上來，你先請他不要把錐筒擺進通道。
