| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 行政同事原很肯定導師用日常素材教學，看到他批准一攤食物試吃，親自調開動線後反問為何未問過其他班。 |
| 核心衝突 | 設計讓學生有參與感，公開分享卻不能先假定共同場地可用。 |
| 導師困境 | 可限回本班、撤掉食物只做說明，或向權責人補足許可後再做。 |
| 故事獨特性 | 支持教法的人第一次要求對教法已跨出的部分說明。 |
