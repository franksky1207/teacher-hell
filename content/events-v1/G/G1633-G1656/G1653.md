## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一向主動邀同學的學生原照導師安排主持新加入者的桌遊解說，拿自己可自由支配的午餐後空檔與導師商量如何把示範分給同伴。等人真的報上名，他才承認自己想當一次可以聽錯規則的新人。 |
| 核心衝突 | 最會開局的人不想永遠當公認的熟手。 |
| 導師困境 | 可讓另一名同學獨立開場並由原主持人當玩家，犧牲開桌速度；或讓他只示範首輪再交棒，把卸下角色的時間縮成半場。 |
| 故事獨特性 | 享受桌遊的學生從沒享受自己沒聽懂時可以問人的權利。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：午餐後的自由活動時間才剛開場，一向最會帶頭開局的student_a已經把桌遊盒擺好、把新來的同學全招呼入座了，卻突然拉住我衣袖小聲說。
- **P02｜student_a**：老師……人我都幫你揪齊了，但我今天可不可以不當主持人啊？我每次都在教規則，從來沒試過當一個連規則都聽不懂、可以一直問人的新人玩家耶……
- **P03｜旁白**：桌上坐著四個剛報名的新同學正等著有人開口講規則，離午休鐘聲只剩二十分鐘。

| B | 我跟他說今天先照原本排好的講完讓大家開局玩一次，明天那桌我保證幫他找別人開、換他當菜鳥。 | false | 今日維持原主持安排以確保新同學順利開桌，約定明日調換主持人。 | 他今天還是沒辦法當一次聽錯規則的新人，乖乖嘆口氣拿起卡牌。 |

| D | 我看他當慣了大家長突然想當一次傻傻的新人覺得又好笑又可愛，直接把說明書拿過來塞進旁邊會玩那位手裡說「今天准假！去當你的菜鳥玩家，等一下記得故意問笨問題」。 | true | 立即將說明書交由另一熟手同學主持，成全student_a今日擔任一般玩家的心願。 | 突然被塞說明書的那位同學愣了一秒才結結巴巴開始講規則。 |
