## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長最近剛好時間餘裕很多（`11-2`），對孩子通勤安全需求極高（`4-2`），一看到什麼風險就習慣立刻在群組廣傳（`8-4`）。這兩天校門口側面巷道進行自來水公司短暫管線施工，有圍籬也有義交指揮；這名家長因為有空（`11-2`），今天下午自己跑去巷口站著看了半小時、拍了一堆怪手與圍籬照片丟進班群（`8-4`、`4-2`），接著直接打電話來要求導師介入放學決策（`12-3`）：「老師那裡好危險，今天起這三天你們班全體提前十分鐘下課、改由你帶隊走後門出去好不好？」但學校後門平常放學不開放且沒有校車停靠，提前放學更違反課表規定。 |
| 核心衝突 | 有閒又高度焦慮安全的家長憑著現場照片要求導師擅改全班放學時間與動線，導師既要守住校方門禁與課表規定，又要化解他貼照片引發的家長群恐慌。 |
| 導師困境 | 清楚婉拒提前放學與私開後門，說明校門口已有義交與導護老師指揮、自己今天放學也會多留十分鐘陪學生安全通過前門路段（用實際行動確保安全並守住校規，但導師多耗了放學時間）；還是先向學務處確認施工期間的官方建議步行路線圖卡、直接貼進班群澄清現場有義交管制並呼籲家長接送避開施工側（用官方資訊降溫並守住課表時間，但這名有空又焦慮的家長可能明天繼續去巷口盯梢）。 |
| 故事獨特性 | 寫出「太有空去現場拍施工照」的家長如何憑著安全焦慮在班群製造緊張並試圖指揮放學動線。 |
