## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生第一週由導師協助了解借閱流程，第二週想自己完成，導師收到家長擔心後猶豫是否繼續陪到櫃臺。 |
| 核心衝突 | 孩子需要安全試做與被相信，家長的焦慮也不是要剝奪自主；成人陪伴太多可能抹掉自我完成感。 |
| 導師困境 | 如何確認學生已掌握必要步驟，安排有需要才求助的退路，並向家長說明實際範圍？ |
| 故事獨特性 | 不重演首次迷路；是由示範轉為獨立操作的撤援時機。 |
