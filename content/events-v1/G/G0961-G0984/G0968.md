## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生在班上極有號召力（`6-1`），平時積極參與班務（`9-3`），也非常支持導師推動「班級減塑少用免洗餐具」的決策（`10-1`）。為了讓忘記帶餐具的同學也能響應，他把自己家裡囤積未拆封的全新摺疊環保盒與環保杯帶來提供給全班借用（`11-4` 合法自有物資），一開始全班熱烈響應，兩週後卻有一半同學用完沒洗就直接塞回他的整理箱裡發臭長黴。 |
| 核心衝突 | 熱心又號召力強的學生無償提供自有物資支持環保班規，卻被同學的衛生惰性搞成一場災難。 |
| 導師困境 | 當眾追查這兩週誰借了沒洗並要求賠新的，原本大家開心的減塑風氣立刻變成互相推諉；幫忙把發臭的盒子直接打包丟掉並叫他別再借人，這名真心挺導師環保決策的學生既心疼物資又覺得好人沒好報。 |
| 故事獨特性 | 環保理想遇上高中生「借用不洗還」的真實生活習慣，讓熱心提供資源的學生當場崩潰。 |
