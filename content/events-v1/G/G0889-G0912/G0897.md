## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家境寬裕且有同理心的本班家長，聽孩子提到同學最近看黑板很吃力，接送時也看見其眼鏡明顯損壞，推測更換眼鏡可能有經濟困難。他向導師提出願意透過熟識眼鏡行支付費用，要求不要讓受助家庭知道出資者身分，甚至希望導師直接替孩子決定配鏡地點。導師尚未確認家庭需求與監護人意願。 |
| 核心衝突 | 家長希望匿名資助，卻試圖替另一家庭決定照顧方式；匿名出資與隱瞞受助家庭是不同的事。 |
| 導師困境 | 可先私下確認學生及監護人的需求與意願，再在校方核可管道中協調匿名資助，承擔較長的處理時間；也可婉拒指定店家與直接介入，改提供既有助學及視力照護資訊，但熱心家長可能覺得自己的善意被拒絕。未取得必要同意及校方核可前不得安排離校配鏡。 |
| 故事獨特性 | 匿名善意能否在尊重受助家庭選擇的前提下成立，而不是讓導師替第三方秘密決定醫療或消費安排。 |
