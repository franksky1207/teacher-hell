## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生家裡因長期外牆整修，一到固定錄音時段就響起鑽牆聲。他覺得自己負責班上共同朗讀必須完成，帶頭讓同伴也用生活雜音配一句，還不斷催導師決定何時聽第一版。導師按下播放，其他人的雜音已全被剪成他家的鑽牆聲。 |
| 核心衝突 | 能帶動大家的人，也最容易將大家的段落都做成自己的生活。 |
| 導師困境 | 導師可以保留共同錄音但請他親手換掉一半素材，耽誤聽稿；或先完整聽一次，接受全班以為導師特別喜歡他的版本。 |
| 故事獨特性 | 居家失序產生創意，創意開始主宰伙伴的作品，他才聽見同伴與自己的差別。 |
