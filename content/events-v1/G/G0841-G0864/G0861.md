## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 手頭寬裕、教學風格極具自主性的本班任課教師，自己花錢買了一套教學平板配件，擅長溝通的他把方案說得天花亂墜，主動免費提供給導師班上試用一個月，唯一條件是導師得照他設計好的「全無紙化作業流程」配合他的課，不得中途改回紙本。 |
| 核心衝突 | 同儕慷慨提供高價教學資源，卻附帶了剝奪導師班級調整彈性的自主條件。 |
| 導師困境 | 簽頭點頭讓學生免費體驗新設備，萬一班上有人家裡沒網路或設備當機時根本不能退回紙本；婉拒這份好意，又顯得導師排斥新教法、不給同事實驗舞台。 |
| 故事獨特性 | 同儕間的資源分享不是缺東西，而是「免費給你用但你得照我的教法走」的主導權交換。 |
