# H4 畢業典禮、學生離校與六月教師善後

基準為 H3 `5c2185472b6831cce805d7d3368692dfdf7c7616`。本批只處理 H4-A～E；沒有開始 H5，沒有合併 main 或部署 Pages。

## 正式入口

- 畢典沿用 `school-action` → `compileCampus` → 原事實／結果／N6／`finish-slot`。正式日期仍由 `assessmentCalendar(...).ceremonyDate` 提供：2029/6/1；上午、下午活動與晚上私人時間保留 H1 索引。全天新事件配額仍為零，活動階段停止正式續篇。
- 上午唯一 `campus-outcome.graduationSummary` 讀取 H2 `readSeniorAcademicReview` 與 H3 `readAdmissions`。班級資格分類、當時已公布的正備取與確認、最多三名代表的關係及實際事件接觸歷史共同構成敘事。未有審查來源者明示未知；修業證明、未完成與畢業分開，不以升學代替畢業。
- 代表互動沿原校務事實與 N6，記錄教師能力、工作／身心狀態、班級與少數個人關係。沒有40人輪流發言，沒有改寫分數、資格或錄取。代表不是預設「好學生感謝、壞學生改過」。
- 畢典跨到6/2時，在原交易追加 `aftercare-adoption`。`formalSlot` 與 `runtimeCalendarDay` 投影為 `aftercare`：無原高三課程、節數、考試、早晚自習或星期六自習用途；底層凍結日期／游標仍作歷史、招生及 T4 覆蓋證據。
- `nextAftercareOperation(world)` → 單一 `{type:'aftercare-week'}` routine 交易；`readAftercare(world)` 提供接續紀錄、進行中週、已完成摘要與下一步狀態。網頁提供畢典活動及「推進一週善後／繼續本週善後」按鈕；必要故事沿原介面操作。

## C方案與事件

每週固定從接續日起分成最多7日，到六月 `teacherTermEnd` 截斷。正常本屆為6/2–8、9–15、16–22、23–29；晚接手例如6/27則最後一段只有6/27–29。一個週命令最多走160個原合法時段，內部仍呼叫原 `finish-slot`／`advance-time`、自然日更新、機構期限、NPC、H2補救及H3招生程序；沒有改日期或第二套時間引擎。單一週草稿沿用既有 `withAcademicProjection`，避免每個內部時段重播整份學業；讀檔驗證仍獨立重播，並以原 `prepareWorldSequence` 比對完整世界及收據。

每週共享獨立 `aftercare:*` 事件群組，最多一件一般事件，不使用上課日0～5件抽選。內部每日保留原抽選決策證據以滿足 T4 的既有日期覆蓋；當週配額用完後只能留下零選取，不能每日重新取得額度。只有明示 `aftercare` 資格或既有重大危機／支持／必要行政資格能進入新事件候選，一般上課與普通班務壓力不會混入。`aftercareCatalogue()` 提供個別離校後聯繫及原重大導師事件，網頁在首次操作時正式登錄。

教師仍任教的高一／高二課程沿原固定課表在週內自動完成並留證，沒有取消其他年級授課；玩家不逐節操作。每日另保留一次原校務成果：週初行政交接，其餘為教師恢復；正式事件占用當前時段時不額外發放活動利益。週摘要輪替行政、補救／升學待辦、必要聯繫及任期交接重點，引用實際 sourceOrders、當週到期招生數與五月來源。不憑空宣布所有人畢業或錄取。原NPC早自習／午餐同班自動接觸在此階段停用；學生人物、學籍來源、家長、關係與歷史保留，個別實際聯繫仍可發生。

## 中斷、恢復與原子性

- `aftercare-week-start` 保存 weekId、日期區間、起始游標與來源前綴；到期故事、預約入場、未解決選項及重大危機停止推進，保留同一週。
- 處理原故事後，再呼叫相同公開驅動從目前游標繼續。故事 `finish` 仍能經原流程完成它占用的時段，不會重新上課。只有走完合法區間才產生一次 `aftercare-week-summary`。
- 既有 prepare／CAS／publish 完全保留；一個週命令內部為同一草稿與收據。故障不發布，重送同一request取原收據，過期同儕不能覆寫。中斷本身可發布並存檔／匯出，重載後續走原週。
- 新紀錄還原會校驗接續來源、合法週區間、原時段完整覆蓋、唯一摘要及摘要的學業／招生前綴。自動校務、NPC、學業與學期報告仍須原日誌／數值重播，另驗證週命令與真正 slot-complete 的所有權；不是放寬成任意內部操作。

## H2、H3與六月T4

H2五月評量、修習及資格快照不再計算；原補救到期檢查保留，不造時數或補發學分。六月6/4第八類、6/11分配、6/13確認、6/18分科準備仍在真實日期完成原H3學業日誌。七月正式分科、八月分發依然只有待辦，沒有結果。

六月最後原時段完成後停在6/29 `private`；先由原學期報告閱讀屏障，再由唯一 `settle-school-year` 執行年度／T4封存、三年結局及唯讀。週驅動不呼叫結算、不轉屆、不刪人、不另建完成槽。年度授課責任分母只排除接續之後已離校高三班級的課程，其他年級的原授課責任與成果保留；原授課成果、整年時段與每日決策覆蓋要求仍保留。

1. `campus-outcome.graduationSummary`：version、termId、reviewDate、sourceOrders、admissionsNodes、分類計數、學生資格／已公布升學／待辦，以及最多三名代表互動。
