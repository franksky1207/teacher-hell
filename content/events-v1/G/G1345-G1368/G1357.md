## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生這兩天因為明天專題分組上台報告而極度焦慮（`2-2`），平時在班上極有號召力（`6-1`）。今天午休他沒先問過導師便直接介入同組放學留校排練的時程決定（`12-3`），一呼百應揪了同組五個人想向導師借用放學後一小時排練，結果發現其中兩名組員要趕校車根本不能留那麼晚；這名學生立刻展現極高協商彈性（`10-3`）：「老師沒關係，我們不留一小時！我們就趁放學打鐘後、去校車集合前那十分鐘，六個人在教室外走廊快速順一遍台詞跟站位就好，絕對準時衝下去搭車！」 |
| 核心衝突 | 焦慮又擅長動員組員的學生把留校排練壓縮成「放學後十分鐘走廊閃電排演」，導師擔心這十分鐘講得太急反而讓大家漏掉書包或差點趕不上發車，但若完全不給練，這名焦慮的組長今晚恐怕緊張到睡不著。 |
| 導師困境 | 在確認校車於放學鐘響後十五分鐘發車、該年級當日無必須參加的留校課程、校方允許短時停留、全員同意且無須家長另等，並已確認校車集合截止時間及實際步行所需時間的前提下，准許他們由導師在場看顧於走廊最多順演八分鐘，依集合截止時間及實際步行所需時間提前結束，若無足夠餘裕即不安排（不准奔跑）（安撫報告前焦慮並接住他的彈性折衷，卻讓導師自己多留走廊緊盯分秒）；婉拒放學後走廊趕排練、請他們改用明天早自習前或線上語音各自順稿（徹底守住放學乘車從容與安全，這名好不容易才湊齊組員想練一遍的焦慮組長當場洩氣）。 |
| 故事獨特性 | 完全不涉及打掃分工，寫出高壓專題報告前夕「組長硬擠出校車發車前八分鐘走廊快排」的青春期焦慮與時間博弈。 |
