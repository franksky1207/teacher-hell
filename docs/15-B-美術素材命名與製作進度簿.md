> 更新：2026-11-13。第一階段 40 人夏季制服原有完成進度表保留不動；第二階段另採**逐人四類**的工作進度表。製圖技術與驗收程序完全沿用 [完整六圖 SOP](./15-B-完整六圖優先製作SOP.md)。

## 現行製作規則

- 40 位學生，男 001～020、女 021～040；每人 5 張六格圖集，總計 200 張；每張真正透明 RGBA、1536×2304 px、3×2 六格，每格 512×1152 px。
- 第一階段已完成 40 張夏季制服；**已核准夏季制服原圖是每個人後續四類唯一的外貌參考**。第二階段不是全班逐類生產，而是完成 001 的四類，再做 002，直到 040。
- 後續四類順序固定：冬季制服 `uniform-winter` → 夏季運動服 `sports-summer` → 冬季運動服 `sports-winter` → 便服 `casual`。前 3 類均六表情；便服為同一圖集六套不同衣服、六種開心活動情境。
- **每一套製作前都要實際重新讀取 GitHub `main` 上該生已核准的夏季制服六表情 PNG，以及本名冊中的該生原型設定**；完成後逐格與原圖核對臉型、五官、髮型、膚色、頭身／肩寬／體型及辨識特徵。不從剛完成的上一套繼承外貌。小幅自然差異可接受，若看起來不是同一個人就是重大缺陷，必須修正／重製，不能標記製圖自檢通過或使用者核准。其餘製圖技術 SOP 完全不變。
