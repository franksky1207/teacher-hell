## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 環保股長覺得負責整理教室窗台，就該收掉每個人的紙團，把自己的午休拿去清除。他想自己決定留下窗面大家畫的霧氣愛心，不料幫忙的人以為他趕著做完，順手把它整個擦光。 |
| 核心衝突 | 學生想保留的是誰也沒署名的圖，導師分不清是班級成果還是玻璃沒擦乾淨。 |
| 導師困境 | 可准股長帶全班在可移除紙上重畫，他得向班上承認原圖與自己有關；或只讓他把清掃完成，失去一段他自己有意安排的展示時間。 |
| 故事獨特性 | 全班不知道作者是股長自己，他打掃到最後才有藉口不讓原圖走。 |
