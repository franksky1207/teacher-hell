## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位校內常駐行政或科任同事這學期工作負荷爆表（`11-1`），但生活資源寬裕（`7-3`），天生性格開朗整天笑嘻嘻（`2-4`），也很樂於找導師協調合作（`10-4`）。今天兩位老師要共同交出一份跨班普通活動或評鑑摘要報表，這名同事自己忙到焦頭爛額（`11-1`），一早卻笑咪咪提著兩杯高檔手搖飲與點心走過來（`2-4`、`7-3`）：「老師我們一起合作（`10-4`），這杯請你喝！文字統整跟表格對照就麻煩你多扛一點，我等下把原始資料全部傳給你喔！」說完笑著揮揮手就走，根本沒等導師點頭。 |
| 核心衝突 | 同事用「笑臉＋請客」把不對等的校務分工順手推過來，收下飲料幫忙等於默默吃下過勞苦差事，退回又顯得太計較職場人情。 |
| 導師困境 | 笑著把點心退回去或明講「飲料先放著，但文字我只能寫我負責的那一半、另一半你還是得自己補」（守住合理分工界線不讓請客變買單，但原本笑咪咪的同事當場臉色尷尬）；還是這次先收下飲料幫忙把整份報表統整完、但同時約定「下次跨班彙整換你全權主筆」（用互惠輪替平衡這次的過勞吃虧，但導師今天自己的時間還是得被壓縮）。 |
| 故事獨特性 | 沒有誰擺爛擺臭臉，寫出辦公室裡最常見的「用一杯手搖飲和燦爛笑容把九成工作推給你」的溫柔陷阱。 |
