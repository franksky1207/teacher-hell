## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家中長年固定星期三由祖母等學生返家吃飯，近來祖母搬去和親人同住，剩下的幾回都約在這天。學生跟全組答應把試演也排星期三，轉身又去問導師，能不能不必當著大家說明自己為何改口。 |
| 核心衝突 | 一起完成演練是已答應的事，但家中最後能維持的固定相處也有期限。 |
| 導師困境 | 可給本人一段課內必驗的角色、拒絕為他單改整組時段，或讓組員自己選可替代的配置。 |
| 故事獨特性 | 居住變動使難得能再維持的固定日子與同儕承諾正面相撞。 |
