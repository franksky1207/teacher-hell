## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 任課同事一向在趕車前用同一集語音練習聽力，習慣留意導師是否已離開辦公室才戴耳機。最近月台改成臨時廣播，他因只顧聽一句反覆漏過班車，見導師竟在同一車廂才惱火自己什麼都沒察覺。後來願和導師各試一種既聽得見車訊又不打斷練習的方法。 |
| 核心衝突 | 同事想恢復每天能掌握的一段耳朵時間，導師可示範卻不能變成替他聽站的鬧鐘。 |
| 導師困境 | 可自試到站提示或改到候車前練，導師也可拒絕代聽、只陪兩人各自驗一次。 |
| 故事獨特性 | 共同面對的是聲音如何分配，沒有誰必須約在同一個入口。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：同事隔著車廂看到你，先愣住，再把耳機拔掉。「你也在？我剛才又漏一班，真的是……」他平常等你離開辦公室才戴上耳機，反覆聽同一段，最近月台改臨時廣播，熟悉的節奏全亂了。車裡可以坐穩，站訊也聽得清，他仍盯著播放器。「不要你替我聽站。我試提醒，你也試一種，我們看差在哪。」你自己的耳機線還纏在包裡。
