## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生相信導師答應把班內圖畫保留到下課。老師提前拿起板擦時，他衝動喊停，找來幾個平日聽他指揮的人，在畫者先前准許描摹的範圍內把輪廓描到紙上。作者回來看見大家捧著紙，說下半截尾巴是想擦掉後試畫別的，這群人原以為省了作者的功夫。 |
| 核心衝突 | 學生確實讓一部分原畫留下，卻把原作尚未完成的刪改當成成品。作者若當場擦掉，幫忙者會以為自己的時間全白費。 |
| 導師困境 | 可由導師承認提前清板，經作者同意把紙交回、只供本人繼續修改，幫忙者看不到最後留了什麼；或徵得作者同意把原作與同伴描稿分開展示，並清楚說描稿只是當時的紀錄，須額外安排位置，也讓作者面對兩個版本同時被評論。 |
| 故事獨特性 | 救下的是一個過程中的畫面，不能因此替畫者把修改結束。 |
