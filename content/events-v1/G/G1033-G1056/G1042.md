## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長自己每天傍晚得趕兩處接送小孩與照顧年邁父母（`7-2`），平時社交主動（`6-3`），放學常在接送區跟幾位同樣背負雙邊接送壓力的鄰居媽媽聊天，對大家十分有同理心（`1-3`）。最近導師常為了訂正小考把全班留到五點半才放人，這位家長便代表幾位快趕不上幼兒園／安親班關門時間的家長主動找進導師室，試圖介入放學留置決策（`12-3`）：「老師我知道你是為孩子好，但我們幾個真的五點十分就得趕去接小的，能不能先放這幾個孩子走？」 |
| 核心衝突 | 家庭接送時間的硬限制讓有同理心的家長串聯發聲，正面撞上導師「當日小考當日訂正完」的班級要求。 |
| 導師困境 | 答應五點十分先放這幾名學生回家、沒訂正完的改拍照回傳，其他沒人幫忙說話的同學多半覺得這幾個人有特權提早閃人；堅持全部留到訂正完才放人，這幾位接送時間卡死的家庭恐怕明天聯合向學務處反映導師留置超時。 |
| 故事獨特性 | 不是為了補習搶時間，而是雙薪／多孩家庭在傍晚「大孩放學 vs 小孩幼兒園關門」的真實接送死線衝突。 |
