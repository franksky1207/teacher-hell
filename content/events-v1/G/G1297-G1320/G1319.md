## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生家庭生計吃緊（`7-2`），平時對數位介面操作極為熟練（`3-4`），做人極講「不該看的不看、照規矩來」的原則（`1-4`），校園資訊安全意識極高（`9-4`）。今天下課他去講桌操作教室公用投影電腦時，發現前一位使用者忘了登出校務或個人雲端帳號，他一秒也沒多看，熟練地立刻協助安全登出並關閉視窗，隨後依安全程序向導師回報此漏洞以請資訊組提醒。不料旁邊兩名剛走進來的男生看到他跑去跟老師報告，竟笑他「裝什麼正義魔人、那麼死板」。 |
| 核心衝突 | 守原則且具備高度資安素養的學生做了完全正確的舉動卻被同儕嘲笑「愛打小報告」，導師必須肯定並保護這名學生的正直，同時在不點名傷人下導正班上的資安與同儕氛圍。 |
| 導師困境 | 在班上公開大力讚許他的正確資安處理並嚴正糾正那兩名嘲笑者的態度（守住原則是非，但把這名低調不愛張揚的學生推上風口浪尖、以後更怕被同學貼標籤）；只私下深深肯定這名學生做得極對，再找機會於班會用「不特定案例」宣導公用電腦登出安全（保護這名敏感自尊的學生不被針對，卻讓他心裡難免疑惑「為什麼做對的事還要低調委屈」）。 |
| 故事獨特性 | 沒有誰真的偷窺外洩，寫出做對所有資安程序的原則派學生反過來承受同儕「抓耙子」嘲諷時，導師如何保護正義者的微妙拿捏。 |
