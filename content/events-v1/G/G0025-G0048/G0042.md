## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生急著用紙條黏住外套壞掉的扣環，巡查前又貼字說明。旁人把這當成導師默許的制服處理方式，開始詢問何時會統一。 |
| 核心衝突 | 通融善意可避免學生因小故障難堪，公開標示又可能讓暫時例外變成他人對班規的期待。 |
| 導師困境 | 導師可私下確認修補時間、先給低識別度的臨時安排或請任課教師只知道必要例外，仍須留有一致依據。 |
| 故事獨特性 | 可見的自我說明同時揭露個人處境及誘發對規則的類推。 |
