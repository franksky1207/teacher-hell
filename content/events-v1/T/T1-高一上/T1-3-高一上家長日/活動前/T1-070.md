## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 本班家長希望在家長日製作自我介紹名牌，預留私人通訊帳號讓大家互加，有人回條勾不想公開，提議者請導師代問理由。 |
| 核心衝突 | 建立家庭互助網有益，但不參加私人社交不等於拒絕校務聯絡。 |
| 導師困境 | 導師要將正式通知與自願認識的名牌分開，還是先縮減可公開欄位，保留活動後自行交換？ |
| 故事獨特性 | 是家長彼此建立網絡的選擇權，非教師群組管理。 |

## 5｜R1～R8共用結果、結算與4×8因果矩陣

### R1｜名牌只留稱呼

- **玩家可見結果**：家長同意先把名牌縮成自願使用的稱呼，不預先印出帳號。原本不想公開資料的人願意參與自我介紹。雙方仍可以認識彼此，不必先交換私人聯絡方式作為入場條件。願意交流的人仍能留下聯絡方式，但不參加者不必為了進入教室而交出私人帳號。
- **客觀後果**：家長同意先把名牌縮成自願使用的稱呼，不預先印出帳號。
- **合法底層增減**：guardian_a:5-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-1,-1,-2

### R2｜有人不想說為什麼

- **玩家可見結果**：提議者詢問另一戶不公開的原因，對方只表示想保留私人空間。你沒有代替對方說明家庭情況，提醒個人選擇不需要向全班辯解。這道界線讓交流回到自願，而非互相比較。提議者知道自己能邀請，卻沒有權力要求別的家庭提出一份拒絕的理由。
- **客觀後果**：提議者詢問另一戶不公開的原因，對方只表示想保留私人空間。
- **合法底層增減**：guardian_b:6-3:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,-2,1

### R3｜家長先交換的是經驗

- **玩家可見結果**：兩位家長開始討論孩子適應高中作息的方法，後來才自行決定是否要留私人聯絡方式。你沒有要求把這些帳號交給導師保存。互助可以從聊天開始，不必用一張名單證明親近。其他家長也明白私人互動需要雙方同意，不是名牌上有資訊就能隨意轉傳。
- **客觀後果**：兩位家長開始討論孩子適應高中作息的方法，後來才自行決定是否要留私人聯絡方式。
- **合法底層增減**：guardian_a:8-4:+2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,-2,1

### R4｜正式通知仍須正常收到

- **玩家可見結果**：有人擔心不參加私人群組就收不到校務消息。你清楚區分學校正式通知與家長自願交友，讓不願公開帳號的家庭也知道如何取得必要資訊。這份安心比湊齊好友數更重要。即使有人完全不使用私人社群，校內正式通知與必要聯絡仍應照原有管道運作。
- **客觀後果**：有人擔心不參加私人群組就收不到校務消息。
- **合法底層增減**：guardian_b:9-1:-2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,2,1

### R5｜名牌被拍照轉傳

- **玩家可見結果**：有人把尚在規劃、寫著私人帳號的名牌樣張拍照轉傳，原主人擔心正式活動時會被不認識的人加好友。提議家長趕緊協助撤除，才意識到公開範圍不只眼前這間教室。你要求重新確認照片與名牌使用同意。會前籌備因此補上拍攝與公開範圍的確認，而不是只把問題推給被拍到的人。
- **客觀後果**：有人把尚在規劃、寫著私人帳號的名牌樣張拍照轉傳，原主人擔心正式活動時會被不認識的人加好友。
- **合法底層增減**：guardian_a:5-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-2,1,0

### R6｜提議者開始懷疑自己

- **玩家可見結果**：家長發現有人不願交換聯絡方式，以為自己的互助想法不受歡迎。你肯定建立交流的心意，也說明不參與不等於反對。他決定改成自由認識，不再要求大家先交出帳號。原本想促進互助的提議仍有可行的部分，只是不必以統一加入群組作為唯一方法。
- **客觀後果**：家長發現有人不願交換聯絡方式，以為自己的互助想法不受歡迎。
- **合法底層增減**：guardian_b:6-3:+2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,1,0,-1

### R7｜催加好友讓人尷尬

- **玩家可見結果**：討論時有人在公開場合催促每戶互加，拒絕的家長很快成為被注視的人。提議者也開始覺得像在推銷。你必須重新說明私人交流自願，正式聯繫不受影響，不能讓熱鬧變成壓力。他終於明白，真正的交流若讓人不敢拒絕，便和最初希望的自在氣氛相反。
- **客觀後果**：討論時有人在公開場合催促每戶互加，拒絕的家長很快成為被注視的人。
- **合法底層增減**：guardian_a:8-4:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,1,-1,-2

### R8｜認識不需要通訊名單

- **玩家可見結果**：家長最後準備簡單自我介紹，不再建立全班私人帳號表。願意繼續交流的人可以自行交換方式，不願的人仍能參加活動。你保留正式校務窗口，讓不同家庭有同等參與空間。名牌不必成為永久名單，活動結束後也不用由導師保管所有家庭的私人帳號。
- **客觀後果**：家長最後準備簡單自我介紹，不再建立全班私人帳號表。
- **合法底層增減**：guardian_b:9-1:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：2,0,-1,-2
