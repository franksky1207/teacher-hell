## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 教務處教學或註冊組職員對新版校務後台操作上手極快（`3-4`），一向不跟風辦公室「慢慢等大家最後一天壓線」的拖延文化（`6-2`）。這天距離系統關閉其實還有兩天，他看到後台統計只剩導師班和另外兩個班還沒按下「確認學習歷程勾選名單」，在位置上愈看愈火大（`2-1`），直接打校內分機來督促導師（`10-2`）：「這介面明明五分鐘就點完了，為什麼你們班還卡在待確認？你現在打開電腦，我在電話這頭一步步看著你按完！」 |
| 核心衝突 | 技術適應極快且講求效率的行政同事，把導師當場需要「跟幾位學生再次確認勾選意願」的實務時間當成單純不會按電腦的拖延。 |
| 導師困境 | 順著他的高壓電話指導立刻在電腦上先幫學生全按確認交差，萬一明天那兩位猶豫的學生跑來說要改選項目就得再去寫異動單；硬著頭皮頂住這名急躁同事的火氣說自己下午跟學生核對完才按，電話那頭恐怕當場記上一筆導師拖累全校進度。 |
| 故事獨特性 | 沒有表單紙本，寫出校務系統化後「行政看後台只剩一鍵確認、導師在現場還得先跟學生對完實質內容」的雙邊視角落差。 |
