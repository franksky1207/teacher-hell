## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師平常雖然都配合導師排定的調課與活動時段（`9-2`），但心裡其實對導師總把體能或班務活動排在他上課前一節頗有不滿（`5-4`）。今天他進班發現學生剛跑完操場滿身大汗、講話哄鬧完全靜不下來，當場火冒三丈（`2-1`），但向來迴避跟導師當面吵架的他（`6-4`）一句話也不跟導師提，只在黑板寫完頁數後自己坐在講台前冷臉沉默整整四十五分鐘，下課拿著課本直接走人。 |
| 核心衝突 | 怕衝突的同儕用「冷暴力罷講」發洩對導師排程的不滿，讓導師直到學生跑來告狀才知道那節課出事了。 |
| 導師困境 | 立刻去辦公室低姿態向他賠不是並保證以後活動不排他前一節，等於默認他可以用整節不講課來懲罰全班；跑去質疑他「不該因為生氣就放生一節正課」，這名最怕衝突又早就不滿你的同事恐怕直接翻臉拒絕溝通。 |
| 故事獨特性 | 呈現教師之間「當面配合從不說破、卻在教室裡用沉默對學生發脾氣」的冷戰張力。 |
