## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 任課同事和導師放學試跑，才懂導師建議用平價鞋先練真正有效。他手邊只有一小段空檔，卻想勸導師別因鞋顏色張揚就放棄。 |
| 核心衝突 | 導師想為自己買雙好看的鞋，也怕被同事的實用建議一路推著買。 |
| 導師困境 | 可當天試完不下單、先跑一段再選，或承認顏色本來就是自己在意的理由。 |
| 故事獨特性 | 一位教會別人怎樣起步的人，不必照同樣的實用品味消費。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：試跑才繞一小段，同事就拍拍自己那雙平價鞋：「你上次說先跑再挑，真的有差。」他預算不多，原先一直等著買齊裝備才動。今晚可跑的空檔也短，走到店窗前仍想勸你看看一雙二手跑鞋。鞋況尚須確認，顏色卻亮得讓你先退半步。「你教學生起步那套很實在，」他說，「只是這顏色……你真有那麼討厭？」你其實只是想買一雙自己喜歡看的。

| B | 暫不換鞋，先確認手上鞋子安全合用，再安排日後購買 | false | 導師已暫不換鞋，先確認手上鞋子安全合用，再安排日後購買 | 新鮮感少一些，現有鞋也可能已不適合 |
| C | 你突然捨不得穿慣的那雙，請店家評估能否安全保養延用，費用合適才委託，今天不急著買新鞋 | true | 導師已向店家提出現有鞋況與可行保養的正式評估需求，先確認費用，安全不合用便不繼續穿跑 | 要付合理且先確認的保養費，也可能被告知舊鞋根本不宜再用 |
