## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 幾名學生每天經過同一條巷子，看同伴餵狗便跟著帶食物，一回被狗跟到校門，開始分成想保護牠和怕牠的人。發起的學生先向導師說自己有參與。 |
| 核心衝突 | 照顧動物的善意遇到校門人流與同學恐懼，責罵餵食者也可能讓學生把動物往更隱蔽處帶。 |
| 導師困境 | 導師先交由校方安全窗口處理，再決定怎樣讓學生停止現場餵食、由有權單位評估，或安排不接觸動物的後續關心。 |
| 故事獨特性 | 對動物的善意成為同學之間一場勇敢與膽小的爭辯。 |
