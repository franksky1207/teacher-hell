## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生好勝心極強，一心要在全校學科競賽拿第一（`4-1`），但這學期同時參加社團、補習與培訓，自身任務負荷已經爆表（`11-1`）。他平常基本認同導師訂的「上課不寫別科作業」班規（`9-1`），但因為上週導師當場沒收過一次他偷寫的競賽題而一直心存不滿（`5-4`）。這天他遵守班規沒在課堂寫別科，卻把精神全部拿去準備自己想贏的比賽，對導師交代的基礎學習單完全敷衍草草亂填交差；導師找他來問時，他竟然語氣帶刺地頂回來：「老師我已經照你的規定上課沒偷寫別科了，我現在事情這麼多，學習單有寫完交出去還不行嗎？」 |
| 核心衝突 | 過勞好勝又心懷舊怨的學生用「形式上遵守班規、實質上敷衍基本作業」進行消極對抗，讓導師在「退回重寫加重他負荷」與「放行敷衍作業」之間拉扯。 |
| 導師困境 | 嚴格要求他把敷衍亂寫的學習單拿回去重寫完整才算數，這名已經負荷爆表又本就不滿老師沒收競賽題的學生恐怕徹底炸開、甚至乾脆連競賽一起擺爛；體諒他最近任務太多而口頭提醒兩句就放過這次學習單，班上其他乖乖認真寫完學習單的同學多半覺得「只要去比賽就可以亂寫作業」。 |
| 故事獨特性 | 學生沒有違反他最認同的那條上課班規，而是精準地用「消極敷衍作業」來對抗心存不滿的老師，呈現真實的高中生叛逆防線。 |
