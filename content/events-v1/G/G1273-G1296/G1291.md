## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生在班上極具號召力（`6-1`），這週下課大家想去打球卻發現教室後方籃球沒氣、羽球拍線斷了兩支，他先帶頭揪了幾個男生跑進辦公室質問導師為何學校配發的新球具一直沒下文（`12-4`）。得知總務與體育組的年度採購補發流程還要等兩週後，這名原本有點衝的學生立刻展現協商彈性（`10-3`），並自願投入課餘勞力（`11-3`）：「那沒關係老師！我們幾個男生自己出力去借打氣筒、整理好壞球拍建一個班內小修理與登記角，但你能不能先幫我們跟體育組借一顆公用備用球頂這兩週？」 |
| 核心衝突 | 有號召力又肯出力的學生從「質問抱怨」轉向「建設性自救協商」，但替他去體育組借公用球並讓學生自管修補角，導師得承擔球具遺失與體育組交涉的人情責任。 |
| 導師困境 | 順著他的積極協商親自跑一趟體育組幫忙簽借一顆備用球並支持他們設立班內修補登記角（鼓勵學生自治且解決下課沒球打的悶氣，但萬一球踢丟或球拍被玩壞，體育組追責的是簽借的導師）；告訴他們公用器材不能這樣跨處室個人簽借、乖乖等兩週後總務統一補發（完全零風險省事，卻當場澆熄了這群原本難得願意動手維護公物的少年熱情）。 |
| 故事獨特性 | 沒有惡意損毀公物，寫出青春期男生從「帶頭抱怨沒球打」在老師解釋後立刻轉彎成「我們自己來修、老師幫忙借一顆」的可愛自治協商。 |
