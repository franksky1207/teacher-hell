## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生和導師親近，跟著好朋友在班內猜謎練習押同一個趣味題，私下卻希望導師改選另一題給全班玩。導師說時間只夠一題，他願意讓朋友設計提示、只改結尾。 |
| 核心衝突 | 他不想讓朋友知道自己沒那麼喜歡原題，又想保留朋友真的做得好的部分。 |
| 導師困境 | 可由導師提出一題中性替代，讓兩邊都少一項擅長的內容；或讓學生親自邀朋友合做提示，得承認原先跟著說喜歡是順勢附和。 |
| 故事獨特性 | 當著朋友押題，背後改的不是票，而是彼此以為一樣的喜好。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：剛才大家在教室投票選班內猜謎題目時，student_a還大力舉手跟死黨押同一題。結果才剛下課，他就溜來辦公桌旁小聲改口。
- **P02｜student_a**：老師，其實我覺得那一題沒那麼好玩，你可不可以偷偷幫我選另一題給全班玩啊？如果時間只夠一題，不然讓我朋友設計提示、結尾改用我那題的嘛……
- **P03｜旁白**：他既不想讓死黨發現自己剛剛只是順勢附和，又捨不得把朋友最擅長的部分整個抹掉。
