## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生家裡有可用的工作室和完整剪輯工具，同組因此要求把所有人帶進去反覆剪。學生信導師答應可自主選媒材，先傳了一鏡到底的試拍，說不願因家裡有設備就要請家人整晚讓出工作室。 |
| 核心衝突 | 一鏡到底保留了練習重點，美術加工仍有人想做；拒絕提供家庭空間不能等於永遠禁止他人剪輯。 |
| 導師困境 | 可按同一點驗證內容、分開保留兩種版本，或要求需要重剪的人用已有合法校內時段完成。 |
| 故事獨特性 | 家庭條件好使同學把私人空間當小組資產，學生藉可實測的替代方案拿回選擇。 |
