## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師這週同時扛著學期活動籌備與班務資料，校務負荷吃重（`11-1`），家裡長輩這幾天還需要定時接送復健（`7-2`），每天放學都得掐著時間走。這天他值勤經過校門口施工圍籬時發現一處鐵片翹起（`9-4`），自認有責任守在現場等總務技工過來圍妥、確認安全再離校（`1-1`），結果一等就是四十分鐘，不僅來不及親自接長輩得臨時拜託家人趕去頂替，原本要趕在下班前寄出的年級共同通知與家長聯絡事項也整個延誤，隔天一早接連被幾位家長與年級同事追問。 |
| 核心衝突 | 導師在家庭接送負擔與校務高壓下選擇守住校園安全現場，卻得自己吞下私人時間透支與班務延誤的連鎖代價。 |
| 導師困境 | 隔天早自習前先趕工補發年級通知並逐一向家長致歉說明延誤，整個上午都被迫壓縮備課與休息時間；把責任推給昨晚在門口臨時支援總務處太久，聽在沒看到現場的同事與家長耳裡又像在找藉口推託。 |
| 故事獨特性 | 導師本人親自面對「現場安全守候」與「家庭照顧＋班務進度同時崩盤」的真實時間代價，沒有反派主管施壓。 |
