## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長一直非常支持導師「維護教室舒適安靜學習環境」的立場（`10-1`），上個月還主動將自家合法購置、運轉正常的全新靜音空氣清淨機搬來借給班上使用（`11-4`）。不料昨天自習課導師覺得機器開到最強風速時風聲有點干擾講話，隨手把插頭拔掉沒再開，孩子回家轉述後家長當場火大（`2-1`），今天一早打電話來正式問責導師（`12-4`）：「老師我支持你才把機器搬去給全班吹，你覺得太吵跟我講調小風就好，怎麼直接拔掉放著生灰塵？」 |
| 核心衝突 | 支持導師又大方出借自有電器的家長感到心意被糟蹋，而導師在教室實際授課時確實有噪音干擾的考量。 |
| 導師困境 | 立刻連聲致歉並保證今天起整天開著、只調到靜音檔，但老舊教室窗戶大開時靜音檔根本濾不到什麼空氣、還得特別小心別被學生踢倒；坦白告訴家長那台機器開強風真的太吵影響早自習聽力測驗、要不乾脆請家長搬回去，這名原本最挺你的家長恐怕當場寒心。 |
| 故事獨特性 | 沒有附加條件也沒有強制規定，寫出「家長好意借電器進教室後，因日常開關管理與使用期待不同」產生的親師摩擦。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜家長**：我不是要你謝我，嫌吵調小就好，為什麼直接拔掉？
- **P02｜旁白**：你望著教室角落那台白色機器。昨天講話被風聲蓋住，你一拔插頭就忘了，今天先照實向家長說明，也確認沒損壞。電話那頭，他吸了一口氣。
- **P03｜家長**：我支持你想讓教室舒服，才搬新的去。孩子說你還說放著比較安靜。
- **P04｜導師**：那句是我說的。
- **P05｜旁白**：他沒有立刻接話。機器旁的說明書還裝在透明袋裡，你翻到風速那頁，他問以後到底打算怎麼用。

| 選項ID | 玩家可見短句 | emotional | 教師已完成的客觀行動 | 優點及代價（不顯示玩家） |

| A | 我願做一張可翻面的使用牌，提醒自己依約開關。 | false | 教師自製不含健康資料的使用提示工具，設定仍待合意，不讓學生負責判斷風險。 | 花準備時間，可能仍忘。 |
| B | 另蒐集同學自願提出的噪音感受，不收健康資料。 | false | 提出一般設備使用感受徵詢，不代多數強迫少數承受不適。 | 占課間，意見可能分歧。 |
| C | 問他是否願意終止借用，由合適成人安排歸還。 | false | 提出合意終止本次借用及後續歸還協調，不擅丟或強迫物主續借。 | 少設備，安排搬運。 |
| D | 我被質問得有點刺，還是想把機器搬到自己授課看得見的地方，這回讓我承擔那點聲音。 | true | 提出本人授課時將設備置於合規可視位置的合意試用建議，不代他科同意，不自行占通道。 | 自己承受聲音且要協調。 |
