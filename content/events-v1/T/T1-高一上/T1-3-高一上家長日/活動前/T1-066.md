| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生把暑輔以來熟悉的教室角落畫成家長日導覽圖，家長希望加上「升學戰鬥區」等鼓勵文字，作者卻想留下生活細節。 |
| 核心衝突 | 家長重視學習期待，學生希望被看見真實生活；導師背書哪種版本會改變誰能代表班級。 |
| 導師困境 | 導師要邀兩方各寫註解、保留學生原圖，或改用不代表全班的自願展示？ |
| 故事獨特性 | 用具體作品協商校園形象，非宣傳單修稿或影像同意的翻版。 |
