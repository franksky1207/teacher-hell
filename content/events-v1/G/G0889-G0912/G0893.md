## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這天下午剛好沒課、時間餘裕充裕的本班任課教師，其實因為連日早起監考累積了不少疲勞。他平常都很配合導師安排的調課時段、傳達訊息又很主動，這天想趁空堂先把下下週的換課搞定，便熱心地在教師群組主動公告「導師班下週自習已跟我調換完成」，卻因疲勞恍神寫錯了週次。 |
| 核心衝突 | 配合度高又熱心的同事因疲勞記錯日期，在公開群組裡發出錯誤的調課訊息，讓兩邊課表瞬間錯亂。 |
| 導師困境 | 立刻在群組裡直接標記他更正成下下週，怕讓這位剛熱心幫忙發通知的疲憊同事當眾尷尬；私下敲他請他自己收回改字，這幾分鐘內別班或教務處可能已經把錯誤調課記進課表。 |
| 故事獨特性 | 沒有任何推託或擺爛，純粹是「太配合又想早點處理掉」的老師累到看錯行事曆。 |
