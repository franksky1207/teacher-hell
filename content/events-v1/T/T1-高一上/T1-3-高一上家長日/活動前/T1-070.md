## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 本班家長希望在家長日製作自我介紹名牌，預留私人通訊帳號讓大家互加，有人回條勾不想公開，提議者請導師代問理由。 |
| 核心衝突 | 建立家庭互助網有益，但不參加私人社交不等於拒絕校務聯絡。 |
| 導師困境 | 導師要將正式通知與自願認識的名牌分開，還是先縮減可公開欄位，保留活動後自行交換？ |
| 故事獨特性 | 是家長彼此建立網絡的選擇權，非教師群組管理。 |

### 開場（依自然閱讀長度分頁）

- **P01｜旁白**：有位家長想在家長日做自我介紹名牌，還提議大家把私人通訊帳號寫上去，之後好互相幫忙。提議的家長回訊說：「我只是想讓大家有機會認識，沒有要逼誰啦。」但聯絡方式印在名牌上，拒絕反而變得很顯眼。
- **P02｜旁白**：另一戶在回條勾選「不願公開」，提議者便來問你能不能代問原因。
- **P03｜旁白**：家長互助是好事，但學校正式通知跟私人交友是兩回事，不想交換帳號也不代表不關心班級。

## 5｜R1～R8共用結果、結算與4×8因果矩陣

### R1｜名牌只留稱呼

- **玩家可見結果**：家長同意先把名牌縮成自願使用的稱呼，不預先印出帳號。原本不想公開資料的人願意參與自我介紹。兩邊還是可以認識彼此，不用拿私人聯絡方式當入場條件。一位家長看完簡化後的名牌說：「這樣我願意戴，至少不會有人直接拿到我的私人帳號。」
- **客觀後果**：家長同意先把名牌縮成自願使用的稱呼，不預先印出帳號。
- **合法底層增減**：guardian_a:5-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-1,-1,-2

### R2｜有人不想說為什麼

- **玩家可見結果**：提議的家長問另一戶為什麼不公開，對方只說想留點私人空間。你沒替對方解釋家裡狀況，只提醒個人選擇不需要向全班交代理由。拒絕的那戶只寫了「謝謝理解」，沒有多寫理由；提議的家長也還是照常跟對方打招呼。
- **客觀後果**：提議者詢問另一戶不公開的原因，對方只表示想保留私人空間。
- **合法底層增減**：guardian_b:6-3:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,-2,1

### R3｜家長先交換的是經驗

- **玩家可見結果**：兩位家長開始討論孩子適應高中作息的方法，後來才自行決定是否要留私人聯絡方式。你沒要求把這些帳號交給導師保管。兩人聊起不同的通勤方式，有人說：「我們可以先認識，不一定要現在就加好友。」
- **客觀後果**：兩位家長開始討論孩子適應高中作息的方法，後來才自行決定是否要留私人聯絡方式。
- **合法底層增減**：guardian_a:8-4:+2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,-2,1

### R4｜正式通知仍須正常收到

- **玩家可見結果**：有人擔心不參加私人群組就收不到校務消息。你把學校正式通知跟家長自願交友分開講清楚，沒加私人群組的家庭也照樣收得到正式公告，不用靠交換帳號來換取消息。
- **客觀後果**：有人擔心不參加私人群組就收不到校務消息。
- **合法底層增減**：guardian_b:9-1:-2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,2,1

### R5｜名牌被拍照轉傳

- **玩家可見結果**：有人把尚在規劃、寫著私人帳號的名牌樣張拍照轉傳，原主人擔心正式活動時會被不認識的人加好友。提議的家長趕緊幫忙撤掉，這才發現公開出去就不只這間教室看得到。樣張撤下後，原本的主人還是問：「那已經拍到流出去的照片怎麼辦？」
- **客觀後果**：有人把尚在規劃、寫著私人帳號的名牌樣張拍照轉傳，原主人擔心正式活動時會被不認識的人加好友。
- **合法底層增減**：guardian_a:5-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-2,1,0

### R6｜提議者開始懷疑自己

- **玩家可見結果**：家長發現有人不願交換聯絡方式，以為自己的互助想法不受歡迎。你肯定想促進交流的好意，也說明不參加不代表反對。提議的家長回訊：「我想保留大家聊天的機會，只是不再把寫帳號當成報到的一部分。」
- **客觀後果**：家長發現有人不願交換聯絡方式，以為自己的互助想法不受歡迎。
- **合法底層增減**：guardian_b:6-3:+2
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,1,0,-1

### R7｜催加好友讓人尷尬

- **玩家可見結果**：討論時有人在公開場合催促每戶互加，拒絕的家長很快成為被注視的人。提議的家長也覺得像在推銷。你重新說明私人交流完全自願、不影響正式聯繫後，那位被催促的家長才說：「我願意聊孩子的事，但聯絡方式想留給自己決定。」
- **客觀後果**：討論時有人在公開場合催促每戶互加，拒絕的家長很快成為被注視的人。
- **合法底層增減**：guardian_a:8-4:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,1,-1,-2

### R8｜認識不需要通訊名單

- **玩家可見結果**：家長最後準備簡單自我介紹，不再建立全班私人帳號表。願意繼續交流的人可以自行交換方式，不願的人仍能參加活動。你留著正式校務窗口，讓每個家庭都能安心參加。有人提議名牌活動結束就收起來，不用另外建一份私人聯絡名單。
- **客觀後果**：家長最後準備簡單自我介紹，不再建立全班私人帳號表。
- **合法底層增減**：guardian_b:9-1:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：2,0,-1,-2
