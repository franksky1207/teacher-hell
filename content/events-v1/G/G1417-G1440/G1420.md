## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長背後有整個大家庭（配偶、長輩與親戚）共同支援孩子教育（`7-1`），本人責任感極高（`1-1`），每天都仔細盯著導師在班群與聯絡管道發出的每則動態（`12-2`）。最近導師在班群分享了一份階段性讀書與複習節奏建議，這名家長跟家族幾個親戚討論過後，對導師只排基礎練習量的作法抱持專業質疑（`8-2`），出於高度責任感（`1-1`），今天特地整理了一整份「我們全家人一起開會擬好的加量週計畫表」私訊導師，質問為什麼班上不照這樣加強訓練。 |
| 核心衝突 | 受大家族全力支持的盡責家長把家庭內部會議的標準拿來質疑導師的帶班節奏，導師必須在捍衛專業判斷與回應家長高度投入之間拿捏。 |
| 導師困境 | 逐條耐心向家長解釋目前班上整體吸收度與不同程度學生的負荷考量，堅定守住既定復習節奏（展現教師專業自信與全班均衡，但這名責任感爆表又緊盯動態的家長未必買單、可能繼續追問）；還是適度挑出計畫表中一兩項合適的補充題型給他家孩子當額外選做練習（肯定家長用心並安撫專業質疑，卻可能讓這個大家族覺得「只要開會質疑老師就會配合調整」）。 |
| 故事獨特性 | 不是家長放任或只問成績排名，而是「全家總動員開會寫出一份讀書計畫表來挑戰導師專業」的私校親師互動寫實感。 |

- **P02｜旁白**：週計畫排到半小時一格，備註欄還寫了叔叔和阿姨各自的看法。
