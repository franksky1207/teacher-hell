## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校園安全意識極高、平時也同理導師帶班辛苦的校安同仁，上週發現走廊一塊地磚微翹後已先貼了暫時警示線並報修。今天他經過時看見導師班學生照樣在那裡追跑，雖然立刻提醒大家安靜，事後仍來找導師督促宣導進度並正式問責：「我知道你忙，但這宣導落實成這樣，真的絆倒怎麼辦？」 |
| 核心衝突 | 同理導師的校安同事在未施工完成前的空窗期抓到學生違規，逼使導師必須為行政報修延遲背起管教責任。 |
| 導師困境 | 立刻全班罰站檢討安全意識，學生會抱怨「明明是學校地磚壞了一個禮拜沒修」；把報修進度慢推回給總務端，又會惹惱眼前這位好心提醒的校安同事。 |
| 故事獨特性 | 把「校舍修繕空窗期」與「學生日常愛跑」疊在一起，讓導師夾在安全問責與硬體未修之間。 |
