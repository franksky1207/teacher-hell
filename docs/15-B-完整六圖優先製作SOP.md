# 《教師荒謬地獄》學生立繪｜完整六圖製作 SOP v1.8

> 唯一有效的學生美術製作與驗收 SOP（2026-11-09）。參考：[40 人外貌名冊](./15-B-40位學生外貌設計名冊.md)｜[美術進度簿](./15-B-美術素材命名與製作進度簿.md)。

## 1. 產出與不可違反規格

- **40 位美術原型、每人 5 個服裝分類，共 200 張 PNG**；男生 `student-001～020`、女生 `student-021～040`。每人每套只交付 **一張真正透明 RGBA PNG**，內含 **3 欄 × 2 列、六格完整人物立繪**；**不另製 calm 母圖、局部臉部貼片、定位 JSON 或六張分圖**。
- **製圖第一優先：真正透明 RGBA**，從原始產圖提示就要求人物以外全透明、無實色或漸層底色、無假棋盤格，不將事後去背視為預設做法。**第二優先：原始構圖直接對準 1536×2304、3×2 六格，每格 512×1152**。若產圖工具不支援直接指定此像素，必須如實註明原圖限制，交付前完成尺寸轉換、檢查細節與透明度，絕不可虛稱原生尺寸符合。其後才是安全分格、人物與服裝細節。產後仍須實測尺寸、RGBA 和深淺背景，不能單憑提示判定通過。
- **依體型預先分格構圖**：先建立透明 `1536×2304` 畫布、固定 3×2 六格（每格 `512×1152`），**在各格安全範圍內直接畫完整人物，不是先畫滿後硬裁**。依外貌名冊的身形、肩寬、手臂及當套服裝（冬季外套可能更寬），在產圖提示中預先安排人物佔格比例與姿勢：寬壯型（如 002、007、020）起始人物稍小、左右留較大透明間距；寬肩型（如 013、016）適度預留；一般／纖細型採正常大小但仍須留安全距離。**調整的是整個人物在格內的大小，絕不把寬肩畫窄、壯碩畫瘦**。六格高度、頭身比例及視覺大小應盡量接近；姿勢過寬時先預留空間或調整手勢；若仍局部越界，依第 4 節從**未裁切原圖**單格縮小後再裁切，避免明顯大小落差。手掌、手肘、頭髮與軀幹須在**繪製當下就完整置於所屬格內**，不得跨格、重疊或靠硬裁造成截肢；人物從頭部至**明確可見的下半身／褲裝或裙裝**，取景深度可隨體型自然不同。格線只供規劃，成品不可出現。
- **制服／運動服四類**六格順序：上排 **calm 平靜｜happy 開心｜angry 生氣**；下排 **sad 難過｜surprised 驚訝｜embarrassed 害羞**。**便服是單張六情境圖集**，每格不同衣服、不同開心姿勢，按下節固定活動順序，非六種情緒。
- **人物以外全透明**：不准用純色／棋盤格冒充透明，不要背景、場景、邊框、格線、文字、規劃圖、資訊圖、標籤或水印。**全部新製素材固定 1536×2304 px，每格 512×1152 px**；3×2 等分裁切，不得因角色或服裝改變畫布尺寸。人物體型與身高感可自然不同，但六格取景尺度、頭身比例及出場位置須協調。產圖工具若無法直接輸出此尺寸，應於交付前調整為指定像素並檢查品質、透明度與裁切，不得把不符尺寸的圖當作完成品。
- **同一人同套六格（制服／運動服）**：臉型、五官、膚色、體型／年齡感、服裝款式與配件設定一致。配件可完全沒有；如有，同款同色與持有狀態須連貫，可隨姿勢自然移動，不得憑空消失或換款。不同套服裝可換髮型整理、裝扮與配件，只要辨識得出同一人。
- **偏寫實動漫畫風、40 人有辨識度**：每次依外貌名冊重新鎖定該生的臉型、五官、體型與髮型；「可愛」指外貌而非 Q 版，「偏寫實」也不等於尖臉瘦高。名冊不綁姓名或劇情；細微特徵可彈性處理，但不可把人物類型畫錯。**不同學生的六表情應依人物外貌氣質與情緒自然變化，不能只換臉或直接複製前一位的整組動作；女生 021～040 尤其注重表情、手勢、頭部角度、身體姿態與髮絲動態的豐富度，和男生呈現明顯的整體演出差異，但不限定固定動作、不刻意女性化，也不限制後續四類服裝的自然姿勢；允許個別姿勢自然重複。**

### 強制：每一次製圖前明確強調服裝三項

- **無論新畫、重製、局部修正或同角色改做下一套服裝，都必須在產圖前**先核對學生性別與當次服裝類型，再**逐項寫出／重述上表對應的三項完整規格**，並在實際產圖提示中再次寫明，不能僅說「照之前制服」「沿用 SOP」或只強調人物外貌。
- **四套校服與運動服的服裝規格是硬限制**；已核准的夏季制服 PNG 是該生臉、髮型、體型的外貌基準，而不是讓模型自行複製舊圖錯誤的服裝細節。若兩者有衝突，人物外貌依核准圖、服裝款式與配色依此表。
- **產後自檢也須逐項核對相同三條**，特別檢查冬季有外套、運動服沒有多餘拼接／線條、制服／運動服六表情服裝一致，便服六格則各自不同且皆為開心；服裝重大錯誤須修正。
- 回頭檢驗 001～020 時，以此版夏季制服規格作為共同檢核標準；僅修正明確錯誤，不因正常色差或皺褶而強制全部重畫。

## 3. 唯一製作順序

1. **第一階段已完成**：40 人的夏季制服六圖皆經核准，分別作為每位學生的**唯一外貌基準**。原有核准進度及個別修圖紀錄保留於進度簿，並非第二階段的重製任務。
2. **第二階段逐人補四類**：從 001 起，依冬季制服 → 夏季運動服 → 冬季運動服 → 便服的順序，逐張製作與核准，該生其餘四張全部完成後，再換 002，直到 040。**每套都直接參照該人第一階段核准的夏季制服原始六圖**，絕不逐套傳遞外貌，也不誤用別人的圖。
3. 美術編號**不等於座號或姓名**。已完成的初始 40 人正式劇情接線依開局固定名冊對應美術 001～040；若未來另行實作同組不重複隨機配對，必須保證三年穩定且先確認存檔相容，不能把規劃冒充現行功能。

## 4. 每次產圖：確認 → 製圖 → 全項自檢 → 分類修正 → 交付

1. **產前先鎖透明與尺寸，再核對服裝、先分格（必做）**：先在提示中要求真正透明 RGBA、無背景與假棋盤格，並直接設定 1536×2304 的 3×2 安全構圖；無法原生輸出指定尺寸時須依第 1 節處理。每次重新讀取該生外貌名冊，確認臉型、體型、髮型與偏寫實動漫畫風；四套校服／運動服必須**先逐項寫出第 2 節的三項規格，並在實際產圖要求重述**。依第 1 節先定好 1536×2304 的 3×2 六格與相應體型安全空間，六個人物**一開始就分開、置中並留左右透明間距**，在格內規劃完整人物與可見下半身；四類制服／運動服各有六表情，便服則為六種不同衣服與歡樂姿勢；不得先擠滿畫面再分割。同步要求真正透明、無背景、無格線。
2. **產後全項自檢**：**首先實際確認 PNG 尺寸 1536×2304、RGBA 與人物外透明 Alpha**，再確認六個人物各自完整且分離，再實際裁出六格，逐格核對外貌、表情、服裝與配件、手肘／手掌／頭髮是否原本就被截斷、下半身、尺寸、裁切及**鄰格是否殘留其他人物碎片**；**邊界留白不能代替肢體完整性檢查**。除確認 PNG 的 Alpha 真透明，還須將**每格實際合成至深色與淺色背景目視檢查**，特別檢查頭髮、耳側、手臂與身體之間的白邊、棋盤格、殘留底色或雜點；不能只憑 Alpha 數值宣告合格。**每次重試仍要全部重檢**，不能只檢查前次缺陷。
3. **依問題範圍修正，其他正常格不動**：若只是**單格人物靠近邊界或少量跨格**，且未裁切原圖仍保有完整手掌、手肘、頭髮等部位，**先從未裁切原圖取得該格的完整人物，單格小幅等比例縮小、重新置中後才裁切，僅替換問題格；其餘五格完全不動**。不可先裁掉肢體再縮小，也不可只拉開六格距離。同步清除鄰格先前越界留下的殘片，確認沒有傷到鄰格原人物；六格大小仍須接近。單一手指或邊緣小瑕疵可局部修；若**原圖人物已斷肢、無完整輪廓可取，或人物類型錯誤、假透明／大面積背景殘留、多格重疊、整體構圖失敗**，則重新繪製受影響的完整人物或整張六圖，不得把失敗圖簡單換提示冒充重製。若同一瑕疵持續存在，改判根因及修法，不設定機械式重試次數。
4. **重大缺陷嚴格、細節彈性驗收，但不冒充成功**：人物類型錯誤、假透明／明顯白邊、肢體截斷、人物重疊等重大缺陷必須自行修正後才能交付，不要求使用者反覆催「繼續」；只要表情與個性合理，**個別手勢與原規劃略有不同**，以及細微色差、皺褶等，不必無限返工。工具確實不可用或持續失敗時說明阻礙，不虛報合格，也不無限制重試。
5. **交付一張正式命名 PNG 下載連結＋對應 `student-XXX/` 專屬 GitHub 資料夾**，不可只給總目錄；不提供 ZIP／分圖／JSON，先確認檔案存在。
