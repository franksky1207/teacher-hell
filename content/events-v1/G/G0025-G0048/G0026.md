## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平日有家長入班參觀，協助接待的行政同事累得把一名正趴桌休息的學生叫起來代表全班歡迎。學生坐著沒動，教室突然安靜。 |
| 核心衝突 | 同事想撐住私校接待的場面，學生卻覺得平常不愛說話也不該臨時拿來證明班級有精神。 |
| 導師困境 | 導師可自己接話、在其他人自願時換人，或直接把參觀轉回觀察平常上課，須當下保護學生與同事的面子。 |
| 故事獨特性 | 接待向外展示班級氣氛，學生用沉默讓表演停住。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「來，請這位同學說一句歡迎。」接待同事笑著指向趴桌的人，學生抬眼，沒有站起來。來訪家長的笑容停住，同事又要開口，你先說休息可以繼續。這是普通日核准的個別參訪，並不是全班排好的接待。他揉揉眉心，低聲向搭檔說不要再點人，又轉向你：「下次是不是先問誰願意？我今天真的累到沒看見他在休息。」場面尚未接回，學生的沉默卻不該變成需要被修正的表現。
