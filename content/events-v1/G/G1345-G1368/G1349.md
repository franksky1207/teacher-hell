## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 生活安穩、經營小型攝影工作室的家長（`7-4`）誤信親子社團宣稱學習歷程一定要有專業器材才有說服力（`8-3`），願意無償借孩子自有的專業相機及工作室（`11-4`）。他認同導師不強迫購買器材、重視本人創作的班級規範（`9-1`），因此沒有替孩子拍攝。孩子卻選擇用手機拍家裡一台早已故障的老相機，訪談家長當年如何靠它接到第一份工作。家長看完孩子願意分享的草稿，困惑自己準備的高級器材竟完全沒派上用場，來問導師這樣的作品是否真的有價值。 |
| 核心衝突 | 家長願意提供專業資源且尊重孩子創作，卻受網路升學焦慮影響而低估家庭舊物所承載的故事；孩子選擇的素材與家長想像的優勢不同。 |
| 導師困境 | 依既有作品要求說明器材價格不是評量依據，再選擇花時間與家長討論老相機訪談如何呈現孩子的觀察與家庭記憶，可能讓家長放下對器材的執念；或簡短說明規準後請家長直接與孩子交流，避免導師變成升學作品顧問，但家長可能仍不理解自己提供的資源為何沒有被使用。 |
| 故事獨特性 | 家庭資源沒有變成班級贈品或特殊名額，而是孩子主動放棄使用高階設備，重新發現家長自己的生活故事。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：家長給我看的第一張是專業相機，第二張卻是孩子拍的老相機，皮套邊已裂開。
- **P02｜parent_a**：我連工作室都空給他了，他偏拍這個，還問我第一次接案。這樣真的有用？
- **P03｜導師**：價格不是規準，重點是他自己的觀察。
- **P04｜parent_a**：社團都說專業才有說服力。我沒有替他拍，可準備那些，好像一點忙都沒幫上。
- **P05｜旁白**：草稿最後一行寫著『那天你害怕嗎』。他把那行放大了。
