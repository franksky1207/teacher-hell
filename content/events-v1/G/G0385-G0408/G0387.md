## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長平日接受親屬接送支援，近來孩子不再願聽親屬對課業的評論。家長又怕別人說自己沒教好，繞過孩子直接請導師指定他去道謝。 |
| 核心衝突 | 親人的協助值得感謝，不能拿班導的權威要求孩子接受關係中的每句話。 |
| 導師困境 | 可拒絕指派、幫家長區分道謝與接受評論，或讓孩子自己說出合適的回應。 |
| 故事獨特性 | 家長想證明自己仍被老師視為合格，才把家庭的小分歧帶進學校。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「你叫他去謝一下，他會聽。」家長說這句時還先看你的表情。親屬一直幫忙接送，孩子卻不想再聽對方評論課業；她怕被說沒教好，又不敢直接和親人談，才繞來找你指定道謝。你已明說不會用老師身分命令孩子接受家庭評論，也不替親人判誰乖。「可是兩邊都說他以前很乖。」她把語氣放軟，仍像在等一個能帶回去的教師答案。
