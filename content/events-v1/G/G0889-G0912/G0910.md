## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家裡氣氛溫暖支持、很有同理心的本班學生，見同學請病假好幾天沒拿到考前重點，不僅主動拍筆記傳訊息過去，放學前還親自來找導師出力幫忙：「老師他家住我隔壁巷子，我順路幫他把這疊實體講義丟信箱！」結果導師這才想起，自己五分鐘前才剛把那份講義裡的兩題錯題改掉、還沒來得及重印。 |
| 核心衝突 | 學生出於同儕情誼的極高行動力，快過了教師還沒來得及同步的教材修正。 |
| 導師困境 | 請他明天再送、等老師印好新版，怕澆熄這孩子難得的熱心與順路方便；讓他先把舊版送去、晚上再傳訊叫病假同學自己改題目，生病在家的人對著滿頁塗改只會更霧煞煞。 |
| 故事獨特性 | 沒有人做錯事，純粹是「熱心學生比老師的勘誤速度還快」的溫暖小插曲。 |

- **P01｜旁白與當場對話**：「隔壁巷而已，我順路。」他連袋子都拿好，見同學病假幾天就想幫，家裡也總鼓勵多照顧別人，筆記早主動傳了。你五分鐘前才改掉兩題，先把舊稿停住、正確內容告知該知道的人，沒有讓他替你送錯。放學隊伍動起來，他還拿著空袋：「那現在，還有什麼是真的能幫？」
