## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 剛進學校不久的學務處系統職員雖然因業務繁雜疲勞不堪（`2-3`），但學習適應力極快（`3-4`）且對數位化推動極負責任（`1-1`）。他剛把校內新版請假系統測試完畢，看見導師還在用紙本登記早自習缺席，便沒先通知導師就直接介入班務點名決策（`12-3`），在後台提前替導師班開通了「學生手機即時線上請假」權限，害導師隔天早自習突然收到十幾張學生自己在被窩裡按的病假單。 |
| 核心衝突 | 追求效率的行政新血越過導師直接開放線上請假權限，瞬間瓦解導師原本用來把關出缺勤的家長確認防線。 |
| 導師困境 | 立刻要求他把導師班的權限先關回原狀、堅持還是要家長電話或紙本確認，這名加班弄好系統的新同事多半大受打擊；硬著頭皮全盤接受線上假單再自己一個個打給家長核對，工作量反而變成原本的兩倍。 |
| 故事獨特性 | 聚焦「行政系統數位化過快、沒跟第一線導師對接權限」造成的早自習請假大亂。 |
