## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生在家備受父母支持（常鼓勵他「覺得規定不合理就要勇敢講出來」），個性外向愛交朋友，因為對導師最近限制社團練習時間很不滿，下課和外班朋友聊完一時衝動，隨手拍了導師站在辦公室門口的背影發限時動態抱怨「某班導師管很寬」，卻忘了自己帳號設成公開，五分鐘後被別班同學轉傳給導師看。 |
| 核心衝突 | 學生把對導師的不滿化作公開社群抱怨並附上背影照，衝動發完才發現已經傳回導師手機裡。 |
| 導師困境 | 直接把學生叫出來要求刪文並檢討，會讓這個被家裡鼓勵「敢言」的學生覺得自己因說真話被報復；若裝作沒看見冷處理，沒設隱私的背影照已經在各班同學間傳開。 |
| 故事獨特性 | 不是實體走廊模仿秀，而是高中生「忘記切摯友名單」的社群衝動抱怨在同儕轉傳下當場翻車。 |
