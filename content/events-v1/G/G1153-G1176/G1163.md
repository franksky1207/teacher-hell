## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名個性開朗（`2-4`）的學生昨晚在社群平台輕信一則被轉發的「集滿一百個乾淨寶特瓶蓋寄給某飲料品牌，週五前就免費送全班客製紀念班服」貼文（`8-3`），沒發現那其實是好幾年前早已截止的過期活動截圖。今天一早他興奮地投入課餘體力與時間（`11-3`），跑去回收區翻出幾十個瓶蓋一個個沖洗擦乾，抱進教室想暫放講台旁號召全班一起湊數。導師見桌上滴著水珠且活動連結看起來很可疑，便提醒他教室不宜堆放濕瓶蓋、也得先查證真偽，沒想到他展現極高協商彈性（`10-3`）立刻退讓：「沒關係老師，我不堆在教室佔位子！我先用自己的防水袋裝起來、午休再去問別班，只要你下課幫我掃一下這張截圖的網址看來得及趕週五嗎就好！」 |
| 核心衝突 | 開朗熱血又輕信過期網路貼文的學生已經投入實質勞力洗好幾十個瓶蓋，並靠高彈性協調不斷避開老師的場地顧慮；導師打開網址一查確認活動早已結束多年，真正的兩難在於如何接住這名興沖沖忙了一早上孩子的失落感。 |
| 導師困境 | 趁早自習後直接坦白點破那是好幾年前早就截止的過期活動、現在寄去什麼也換不到，雖然及時止損不讓他繼續白忙，這名開朗又已經忙了一早上的孩子當場笑臉垮下來、覺得自己像個傻瓜；不忍心當場潑他冷水而先陪他想辦法把這幾十個洗乾淨的瓶蓋轉送給美術社做拼貼材料、再委婉帶出活動過期的事實，雖然護住他的心情與這份勞力的去處，導師又得多花自己的課餘時間幫他牽線收拾。 |
| 故事獨特性 | 完全不涉及修改任何班規或縮小試辦範圍，也沒花錢買任何網紅商品，寫出開朗高中生誤信過期網路集點貼文、洗了一袋瓶蓋興沖沖來找老師確認網址的可愛烏龍。 |
