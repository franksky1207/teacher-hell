## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位校內承辦校內徵文／或小論文推廣的教師同事好勝心極強，一心想衝出亮眼的年度投稿業績（`4-1`），平常社交極度主動（`6-3`）又超會講話（`3-1`）。這週他連續三天大下課都端著茶杯笑咪咪晃到導師桌邊聊天（`6-3`），表面寒暄、實則天天督促導師班的繳交件數（`10-2`），今天甚至用超流利的口才暗示導師（`3-1`）：「老師啊，你們班再幫我湊五篇嘛，叫同學把上學期寫過的舊報告改個標題就能交了，先求有再求好，我們全校數字才好看！」（`4-1`） |
| 核心衝突 | 同事用極佳的社交手腕把「業績催交」包裝成日常寒暄，還明示導師配合灌水湊數，導師在「拒絕灌水守住學術誠信」與「不想在辦公室徹底撕破臉」間拿捏。 |
| 導師困境 | 笑著但堅定地回絕「改標題交舊稿」的做法，明確告訴他班上會依真實意願交件、有幾篇算幾篇（守住教育誠信與學生作業尊嚴，但拚業績的同事當場笑容僵掉）；還是先接住他的焦慮，答應幫他在班上再口頭鼓勵一次「真正有興趣寫新題目的同學」，但絕不要求學生拿舊稿充數（維持職場禮貌並尊重學生自主，卻仍可能無法達到他要的件數）。 |
| 故事獨特性 | 寫出私校行政與業績壓力下，同事拿著業績指標「笑著每天來督促你陪他一起灌水」的真實職場荒謬。 |
