## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 班務學生留意導師進班前總畫角落，試過完整圖效果不好，改畫半個，主動邀同學補完；老師翌日不知這是全桌合畫。 |
| 核心衝突 | 署名與共享的快樂都是真的。 |

| 故事獨特性 | 少畫一半反而讓更多人有事可做。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：黑板角落的太陽只畫半個，剩下半邊筆觸卻換了好幾種。你剛以為都是值日學生畫的，他趕快指向整桌：「後面是他們補的。」他常看你進班前畫角落，自己第一回畫滿卻沒人接，改成半個後主動邀人，反而完成了。你把單人歸功補正，他笑著擦掉一小段多餘線：「現在要寫誰？我本來只想留位置給人畫。」幾個作者的粉筆還沒放下。

| A | 請發起者自願說明怎麼從一人變全桌，不排誰畫最好。 | false | 導師已發出限定創作過程分享邀請，未要求公開個人心理或排名。 | 要占班務時間 |
| B | 我也想留半個太陽，自己在私人本子畫，不占他們的角落。 | true | 導師已以自有材料獨立畫私人太陽小圖，不複製學生特定構圖或要求署名給教師。 | 花自己的空檔，也可能不好看 |
| C | 徵詢全桌是否願意在班內合署，不強迫每個人寫名。 | false | 導師已向各作者提出限定範圍合署邀請，未將多數同意代替個人。 | 需逐一確認 |
