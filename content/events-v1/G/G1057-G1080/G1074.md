## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師這週同時支援跨年級代課與命題業務累到不行（`2-3`），但他對學生學習極負責任（`1-1`），也一向配合導師的班務安排（`9-2`）。今天導師班兩名因代表學校比賽請公假落後進度的學生回來，他二話不說主動留下來放學後投入免費人力一對一補教（`11-3`）。不料教到一半他臉色蒼白手發抖、出現明顯頭暈站不穩的身體不適（他自己忙到都沒吃午餐），把導師和兩名學生都嚇了一大跳。導師不自行臆測病因，當場立刻中斷補課、請兩名學生先回家，並堅持護送他至健康中心由校護接手照護評估及聯絡家屬。 |
| 核心衝突 | 導師果斷守住「身體不適立刻停課送健康中心並通知家屬」的安全底線，且在該師未確認恢復及評估前絕不再排補課；但這名責任感極重又好強的同事卻因此面臨「考前最後兩題沒教完」的強烈自責與工作尊嚴壓力。 |
| 導師困境 | 同事仍愧疚未兌現補課承諾。導師可先取得學生同意，整理尚未解決的兩題與學習困難，若具同科專業及授課資格且安排獲准便協助解題，否則協調合適的同科教師接手；這可能讓同事覺得自己的承諾被取代。另一方向是與學生及教務處協調替代學習資源與補課時程，讓同事恢復並經必要評估後再決定是否參與，卻須承擔考前進度空窗及協調成本。 |
| 故事獨特性 | 不讓導師自行做醫療診斷，也不讓未恢復的同事硬撐復課，把情感張力集中於「代為補課、重新協調工作分配」與「守護過度負責同事的自尊與承諾」。 |

### 開場
- **P01｜旁白**：同事坐到健康中心椅子上，還問最後兩題怎麼辦。你已停止補課，交給校護評估，也接好家屬聯繫與學生返程，沒有猜只是餓了。
- **P02｜同事**：他們比賽回來少那段，我答應今天講完。現在走，不就是我又沒做到？
- **P03｜旁白**：你說必要學習會找合適方式接續，不讓他現在站回講台。他將課本放在腿上，手仍停在沒講完的頁角，連水杯都忘了接。
