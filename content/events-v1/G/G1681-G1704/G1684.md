## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生平日照家裡固定交班習慣會逐項記自己的事，這次跟著同學只用縮寫寫道具去向。他主動把草稿送導師，才發現同一個縮寫被三人拿去寫三件不同道具，於是要求以後每次交接先讀一遍全名。 |
| 核心衝突 | 為求合群改掉的習慣，反而是班務最缺的東西。 |
| 導師困境 | 可讓學生找經手人各自補全名，交接變慢但本人知道怎麼查；或由導師帶著實物逐件叫名配對，當天結得快，原本只有學生掌握的紀錄方法不會留下。 |
| 故事獨特性 | 一張短到誰都看得懂的表，其實需要三個人各念一段。 |
