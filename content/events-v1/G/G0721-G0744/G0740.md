## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生在父母分居後常被要求各帶一套餐盒給另一邊，覺得一吃飯就被拿來做人情。他親近導師，認同老師原訂的午餐約定是不拿別人的食物開評比，向兩位午餐幹部協調把剩餐集中只按菜名分，不比較來源，卻一眼認出自己最想吃的是另一個家帶來的那份。 |
| 核心衝突 | 學生設計好一種不用表態的吃法，自己吃第一口就想替一道菜說話。 |
| 導師困境 | 導師能讓他說菜的味道，冒全班聽成家長較勁；或照他原先協調的規矩分完，讓這份想念沒有一句自己的話。 |
| 故事獨特性 | 餐盒被學生拿來抹去來源，卻是最不可能認錯的味道。 |
