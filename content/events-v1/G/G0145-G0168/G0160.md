## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師與熟識任課同事放學常去一家小吃店，這天同事熱情替兩人先點平時的套餐，導師卻想奢侈點一道沒吃過的；店家說已下鍋，兩人都愣了。 |
| 核心衝突 | 維持老習慣可省錢也省心，但導師不想每回都在別人替他點完後才想起自己其實有偏好。 |
| 導師困境 | 可認領自己的新菜並承擔多付一份、照吃但說清下次由自己點，或問能否由同事帶回多的一份。 |
| 故事獨特性 | 點菜失誤很小，熟朋友卻要學會把熟悉和替對方做主分開。 |
