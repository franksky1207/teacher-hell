## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長理解孩子不願總被叫去接手家務，家中臨時照料又真的緊。他要求導師說明為何已告知孩子可中途離開練習，後來願只談合規時段。 |
| 核心衝突 | 讓家庭自理不等於教師先替學生安排，孩子也不應被兩邊同時指派。 |
| 導師困境 | 可收回單方面安排、保留原練習或依合法請假程序。 |
| 故事獨特性 | 成人抱怨的是老師替自己作的決定，不只有學生失去課。 |
