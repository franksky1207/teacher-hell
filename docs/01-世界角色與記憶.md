# 世界、角色與記憶
> 設計草案：核心方向已定，詳細參數仍待決定。

## 世界範圍
班級、完整高中校園（校長、各處室、教師、其他班級、家長）與校外教育環境（教育主管機關、媒體、社群、民意代表、家長團體）。半自主世界可發生玩家未參與的事件，但不是所有小事都要變成全國新聞。

## 人物組成
採固定核心人物與隨機配角；核心人物的背景、性格與身分有連續性，但其未來依遊戲發展而改變。一般配角可因事件發展成持續追蹤人物。

## 人物的內在狀態（建議）
- 長期性格、價值觀、個人目標與顧慮。
- 短期壓力、情緒與目前掌握的資訊。
- 對不同人物的信任、尊重、依賴與不滿（可以同時存在）。
- 事件記憶、情緒記憶與關係記憶。

## 三種不可混淆的歷史
1. 客觀發生的事實及證據。
2. 各角色認為發生了什麼，可能誤解或記錯。
3. 玩家目前已經知道、可以在筆記查閱的資訊。

角色不能憑空知道未接觸的資訊；重大事件記憶可長期保留，小摩擦與情緒可自然淡化。世界外部事件應有傳播來源與時序。
