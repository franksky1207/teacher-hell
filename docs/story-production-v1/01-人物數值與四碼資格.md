## 一、狀態、範圍與維護責任

- **已定案的故事製作資格**：合法常駐數值人物、30個人碼／18個NPC→導師定向關係碼、持碼群組、四碼合法性、家庭人數、學生曝光與零曝光優先；不得從退役的35類矩陣倒推。
- **已選方向但未接線**：依四碼實際高低做NPC選角及本班學生曝光抑制公式；按客觀身分、在籍／在場／知情與權責排除候選。
- **V1創作稿硬限制但未三年平衡驗收**：每篇只用原四碼結算合法持有人，另可直接結算玩家四狀態；單R數值幅度與八R等權平均詳[05驗收契約](./05-故事品質與驗收契約.md)，**本文件不維護第二套數值上下限**。
- **尚未工程實作／待驗證候選**：六能力V2的各來源權重、18關係初值建議範圍與三角分布、難度與長期平衡、舊世界／存檔欄位遷移。原研究保留原處，不能偷升格。
- **退役不可復活**：35類×18碼持有矩陣、400具名NPC／其他班100名具名學生、其他重要親屬固定36碼、NPC對NPC主觀好感、無數值臨時人物跨篇續作、強制每個發言者都持四碼。

## 二、合法人物層級與必要客觀事實（已定案設計）

1. **玩家導師本人**：單一玩家人物，不建立自己→自己的關係值，沒有必須具名建檔的教師家人／朋友。
2. **本屆導師班學生**：開局固定40人；正式轉入後的學生依實際合法學籍納入。原學生即使轉出仍可依歷史保留客觀紀錄，但非現任班員不得假裝在場或參與現任班選角。
3. **校內常駐教職員與校園支援人員**：只有實際聘任／任務／職權合理、正式建檔者；參與本班規範的任課教師是合法的較完整持碼子型。
4. **本班學生家長或實際照顧者**：只對當前本班學生的合法雙親與必要實際照顧者建檔；主要聯絡人`primaryContact`與實際家庭身分`familyRole`分開，不以聯絡多寡決定是否刪除人物。
5. **其他班、其他年級、其他班家長、校外人士、教師私生活偶爾出現的人**：一律**無姓名、無正式人物ID、無48碼、無關係／性別欄位、無跨篇曝光紀錄**的文字情境角色。可以有台詞、行為和必要文字性別／身分，但不得參與四碼數值抽選、結算或未來人物延續。

**開局家庭固定人數（已定案）**：40名學生中，**36名**建立父母雙方（72名）、**3名**各建立父或母單方（3名）、**1名**建立其他實際照顧者（1名），共**76名**常駐家長／照顧者。落在哪位學生可於開局隨機並保存，不能按性格、學業決定家庭好壞；合法轉入／異動另依事實處理，**不為維持固定開局比例重新洗家庭**。

**客觀身分與數值不可混淆**：親屬、監護、學籍、班別、職稱、正式權責、是否知情、已完成通報或教師行動、班級幹部職務均是獨立客觀事實。關係數值高不代表事情發生過、不代表有法定監督權，亦不能憑空產生故事已知資訊。學生幹部可每學期變換，不另建行政輪調或家長會換屆模擬。

## 三、48項底層碼的所有權（已定案設計）

**48＝30項個人碼＋18項「NPC→玩家導師」定向關係碼。** 有效持碼須依本人合法類型確定，未持有不是0、不是`null`待啟用，更不能借別人的值。

### 30項個人碼

- **28個普遍個人碼**，所有真正合法建檔的常駐人物都有：`1-1～1-4`、`2-1～2-4`、`3-1～3-4`、`4-1～4-4`、`6-1～6-4`、`7-1～7-4`、`8-3～8-4`、`11-1～11-2`。
- **9-3 班務參與度**：只屬玩家導師及**當前合法在本導師班**的學生；其他教職員、家長、其他班學生不持有。
- **9-4 校園安全意識**：屬玩家導師、當前合法在校的本班學生、以及合法在校的**常駐教職員／校園支援**；家長與校外臨時文字人物不持有。
- 最新已核對語意：`4-4 認同依賴度`是**反向**，`8-4 資訊傳達主動性`及`9-4 校園安全意識`是**正向**。6-3（社交主動性）、6-4（衝突迴避傾向）、11-1（任務負荷）及11-2（時間餘裕）沿用18C B節記錄的個人碼語意。其餘方向待選角接線時對帳，不拿舊引擎字典取代V1定義。

### 18項關係碼的定向語意（已定案）

18碼**一律由符合資格的常駐NPC持有，方向為該NPC對玩家導師**；不由學校／班級／社會持有，也不是導師自己的分數。這些碼彼此獨立，不能簡化成總好感或把正負碼強制互補。

## 四、單篇四碼、角色與合法結算

1. **先故事後選角**：從[唯一固定四碼種子表](../事件四數值三層平衡種子2400組.md)選**未占用**的S編號，四碼屬四個不同大類，必須每一碼真正作用於故事起因、衝突、人物反應或結果。
2. **分兩種人物槽位**：常駐數值槽位列明合法人物群組、必要同班／監護／職權／性別／知情／在籍條件；無數值文字角色只描述本篇必要身分／在場／知情與台詞，不產生ID或數值。
3. **完整持碼檢查**：任何要以自身四碼數值參加NPC抽選或承受結果結算的常駐人物，**本人須同時合法持有四個碼**；每碼至少能找到一個合法持有人與實際因果用途。作者不可拿只持部分碼的人冒充數值槽位，不能借文字角色填缺碼。
4. **玩家導師是不同結算規則**：只更新本篇四碼中屬其30個個人碼的欄位，不能把18個NPC→導師關係碼寫進玩家自己的資料，也不能為保留四碼而無因果地修改路人。
5. **R結算**：僅可動原四碼、且只動受情節影響的合法持有人；另可改四項玩家直接狀態。教師選項本身只形成**已執行的客觀行動**與R機率差異，不能先直接修改底層；抽到一個R後一次結算並保存。詳細幅度由05驗收，不在本檔重定。
6. **身份與紀錄**：對話、申訴、通報、家庭、學業的制度進度依客觀事實與知情保存；原T/G故事**單篇獨立**，不建跨日故事續篇或臨時人物跨篇追蹤。

## 五、已選NPC選角與40位本班學生曝光規則（尚未接線）

**四碼實際高低只影響合資格NPC選角，**不影響R1～R8的抽中機率；玩家的選項結果只依[05](./05-故事品質與驗收契約.md)所述4／2／1／0的因果矩陣。故事作者可以選**偏正向或偏負向的選角方向**，這和**已取消的事件K倍率及正／中／負開場分類完全不同**。

```text
對四碼中每一碼先正向化：
  正向特質 v = x
  反向特質 v = 100 - x

S = (v1 + v2 + v3 + v4) / 4
故事選角方向：
  偏正向 D = S
  偏負向 D = 100 - S

對合法的本班學生候選：
  N = 三年累計有效主角＋配角實質出場次數
  Nmin = 班上當前學生最低實質出場次數
  W = (10 + D) × exp[-0.25 × (N - Nmin)]
```

1. **先資格、再權重**：當前在班、合法四碼、職權、情節必要性、在場、知情、性別（僅必要時）都是**硬門檻**；公式只在真正合格池中用於機率抽選，不是指定最高／最低，也不是強迫角色平均。
2. **正式曝光才累計**：同一篇／同一人只計一次主／配角實質出場；路過、提名、背景名字、未完成候選均不計。保存主／配角次數、最近日期與故事ID；重載、重繪與已結算事件不重複加。
3. **高三零曝光優先**：高三開始後，若該學生位置的合法現任班候選中仍有`N=0`者，**先在這些合格零曝光者中按權重抽選**；真正完成一次有效出場後才取消優先。高三不得新增轉入生；已合法轉入者按現任資格處理，不能為保底違反法律、學籍或故事條件。
4. **性別不刻板設定**：開局本班學生001～020男性、021～040女性；只在本篇情節確有必要時才限性別，且要對照本人實際資料。不因成績、幹部、打架、個性等先入為主指定。
5. **其他NPC**按合法持碼資格與故事角色位置選角；不能把只對本班學生確認的40人曝光保底誤擴張成全校公平配額。公式是否已在舊引擎接線，必須另做工程稽核。
