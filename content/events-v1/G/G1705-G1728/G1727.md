## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生放學得按時代家人接手照顧，平常願意親自幫導師將各組的展示標籤交接。這天他先核對順序，發現最後那桌缺的其實是一項只由自己持有的備註；若照座次到最後才交，對方會空等到他必須離校。他陪導師找出那張備註，提出日後先交依賴他人資料的那桌，而不是讓最早完成者一律先走。 |
| 核心衝突 | 看似提早放人，其實卡住的是有一桌已完成大多數工作，卻少一項只有他知道的事。讓該桌當眾先交，又可能使人以為全組最慢。 |
| 導師困境 | 可由師生先私下把備註交給該桌，仍維持原展示座次，需補一個小交接；或不改總流程，只讓學生依規離校前把備註交導師，由教師於最後一輪補上，學生準時回家但該桌還要多等。 |
| 故事獨特性 | 改的不是誰值得先受注意，而是哪桌的下一步有一項會隨學生離校一同消失的資料。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：放學前只剩十來分鐘，student_a待會兒得準時回家替家人接手照顧工作，平常這段時間他都會先幫我把各組的展示標籤交接好。今天他拿著順序表核對到一半，突然皺著眉頭走到我桌邊。
- **P02｜student_a**：老師，最後那一桌其實早就做好大部分了，只是缺一張只有我這裡才有的備註……如果照原本座次等前面幾組交完才輪到他們，我時間到要走了，他們會一直空等。
- **P03｜旁白**：他把那張備註紙抽出來看了一眼手錶：「可是現在直接叫最後一桌先上來交，前面完成的人又會以為是他們拖最慢……以後能不能先交需要別人資料的那桌啊？」

| A | 「請最後那桌派一個代表過來跟你對五分鐘，把你那張備註抄一份給他們，其他桌照舊，對完你就立刻去整理書包。」 | false | 請該桌代表前來與student_a快速抄錄交接備註後準時放行，其餘桌次維持原序。 | 不用改全班順序就能讓兩邊都順利進行，但那位代表得跑一趟抄寫。 |
| B | 「今天總流程先不改，你在離校時間前把備註交給我，最後一輪由我親自補上去，你準時回家照顧家裡。」 | false | 不更動現行流程，請student_a於合法離校前將備註交付導師，由教師於末輪代為補交。 | 照顧家人的學生能準時離校，但最後那桌還是得多等前面幾組交完。 |
| C | 我直接向全班講明：「最後一桌不是做最慢，是缺一張只有student_a保管的資料，所以我們先幫這桌交完讓他趕著回家。」 | false | 公開向全班說明原因為資料依賴而非組別進度慢，隨後優先交接該桌並準時放行student_a。 | 同時保住了最後那桌的名聲與student_a的離校時間，但得公開解釋一小段。 |
| D | 看他一邊盯著順序表算時間怕耽誤照顧家人、一邊還替最後那桌擔心被誤會最慢，我心裡一陣心疼，伸手把那張備註抽過來：「別算了，離校時間快到了！你現在直接跟我去最後那桌把這張交給他們，老師幫你跟他們講清楚——交完馬上回家！」 | true | 因心疼學生兼顧家庭與班務之體貼，導師親自陪同前往最後那桌完成備註交付與說明後立即放行。 | 保住了他的準時離校與該桌體面，但其他組在旁看著得等這兩分鐘。 |
