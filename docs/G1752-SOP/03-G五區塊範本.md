## 4｜玩家可見開場與四個行動
**全篇唯一AVG演出標記，必須在 `### 開場` 之前**：
```avg
{
  "opening": {
    "P01": {"scene": "school:classroom", "enter": ["student_a"]}
  },
  "results": {
    "R1": {"pages": [{"text": "【本篇R1自然對話正文】", "speaker": "student_a"}]},
    "R2": {"pages": [{"text": "【本篇R2自然對話正文】", "speaker": "student_a"}]},
    "R3": {"pages": [{"text": "【本篇R3自然對話正文】", "speaker": "student_a"}]},
    "R4": {"pages": [{"text": "【本篇R4自然對話正文】", "speaker": "student_a"}]}

```
