## 檔案與分支界線

```text
content/events-production-v1
  └ content/events-v1/{T,G,P}/*.md  ← 唯一故事原稿與 AVG 演出
          │
          ▼
 scripts/export-story-reader.mjs + story-reader-publish.yml
          │
          ▼
 gh-pages/stories/data/index.json
 gh-pages/stories/data/stories/<ID>.json
          │   sourceCommit / sourceBranch 版本必須對上
          ▼
 https://franksky1207.github.io/teacher-hell/preview/
          │
          ▼
 內容、畫面與實際操作驗收 → 主題驗收紀錄
```

**分支底線**：日常故事與 SOP 修訂在現行故事工作分支進行；未獲使用者明確授權不得合併／覆寫 `main`、不得建立 PR。故事 JSON 是生成物，不能直接手改；只跑受影響的定向檢查。正式帳本／歷史證據屬另一管理界線，不因故事 MD 存在就自稱已鎖定或正式遊戲已上線。

## 何謂「全部完成」

依 05 的分級狀態：原稿核准、AVG 腳本完成、內容與定向技術驗證、故事公開版本一致、真實瀏覽器演出驗收、正式遊戲整合。**缺任一層就只報實際已完成的層級**，不要再讓使用者逐頁截圖才發現接線錯誤。
