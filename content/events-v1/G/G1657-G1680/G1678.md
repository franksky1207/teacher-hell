## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長有一段空檔，未查網傳「老師坐後排才聽得清楚學生」，一直注意導師課堂分享照片的座位。他認同導師原本不為拍照重演課程的規矩，私下問是不是有哪一堂導師真的曾挪到後方，孩子回家說不想作被特別照顧的人。 |
| 核心衝突 | 家長擔心的是孩子到底有沒有被聽見，照片恰巧給了他一個最不可靠的證據。 |
| 導師困境 | 可只和家長交談現行看顧與回饋，代價是家長仍想要一個具體例；或徵詢學生意願後帶著一則不含他生內容的回饋一起談，家長能看見孩子知道的事但孩子須參與。 |
| 故事獨特性 | 越尊重日常不擺拍的家長，越把有限照片當成唯一能看到的日常。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：下課剛滑開家長訊息，parent_a傳來的問句客氣卻盯得很細——他平常最認同我們不為拍照擺拍的規矩，這幾天有空把課堂分享照片翻過一輪後卻私訊問我。
- **P02｜parent_a訊息**：老師我這幾天有空看照片，看文章說老師要坐去後排才聽得清楚孩子講話……但我看每張照片你都在前頭耶？是不是哪一堂你其實有坐過去只是沒拍到？
- **P03｜旁白**：他其實是擔心自己家孩子有沒有被聽見，偏偏他家孩子昨天才跟同學說最討厭老師特地坐過來當成被特別照顧。單看幾張隨手拍的照片，本來就看不出平常誰說過什麼。
