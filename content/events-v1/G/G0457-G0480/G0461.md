## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 親屬陪學生縫過衣物，學生想用自己選的線色做班級實作；第一版太粗，改縫後只願接受導師要邊界清楚的建議。 |
| 核心衝突 | 統一色可降低教學成本，自選也不能跳過會不會縫的證明。 |
| 導師困境 | 可驗相同技法、保留自選但縮成一小段，或讓本人放棄裝飾只試接縫。 |
| 故事獨特性 | 家人支持帶來的是能選的手藝，不是要複製他們的品味。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：線色一字排開，學生把第二次試縫拿給你看。「這次沒那麼粗了。」親屬陪他練過，他先前失手後已重縫，卻不想連顏色也照你指定。「邊界清楚可以，全部換成同一色就不要。」你先確認工具、操作與材料都符合安全要求；他把願意縮小的裝飾範圍圈出來，留下自己選的兩色。「這一小段夠不夠看會不會縫？」其他人仍在等實作標準怎麼說。

| B | 安排正常課內的同技法示範，不以這名學生的家庭陪練當全班前提。 | false | 導師已安排正常課內的同技法示範，不以這名學生的家庭陪練當全班前提。 | 讓沒練過的人有起點，也用掉課程時間 |
| C | 我偏愛的那個顏色留給自己，另外縫一塊自己的樣布。 | true | 導師已於自身可用時間用自有安全材料縫個人樣布，不要求學生照色、代工或把樣布當唯一評量樣式。 | 自己花材料與時間，也可能縫得不好 |
