## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長家裡經濟負擔不輕（`7-2`），平時處事講原則、對每筆花費都算得很仔細（`1-4`），他非常肯定導師的教學專業（`8-1`），也每天緊盯導師在班群發布的每一條訊息（`12-2`）。昨晚導師在班群公布一份自願選購的補充練習本通知，定價只要兩百元；這名家長看完立刻打電話來，語氣客氣卻原則性地問清楚（`1-4`、`8-1`）：「老師我完全相信你的教學，但我們家每筆開銷都要看實際需要（`7-2`），這本到底考不考？如果不買會不會影響平時成績？」 |
| 核心衝突 | 家長並沒有質疑導師推銷或收錢，而是出於家庭實際負擔與原則，要求導師對「自由選購教材是否變相影響成績」給出明確承諾。 |
| 導師困境 | 明確向他保證該教材純屬進階選購、平時考與段考絕不會從裡面出題（徹底保障未購買學生的公平與減輕家庭壓力，但可能讓已經勾選購買的其他同學覺得這本買得有點多餘）；還是誠實說明這本確實有不錯的題型整理、若家裡暫時不想多花錢可讓孩子下課來辦公室借導師的樣書參考（兼顧學習資源與家計體諒，卻得小心別讓其他家長誤會可以都不用買直接借看）。 |
| 故事獨特性 | 不是為了大筆營隊費吵架，而是兩百元的小額選購教材在「家長精打細算＋肯定老師專業」下引發的誠實教學邊界對話。 |
