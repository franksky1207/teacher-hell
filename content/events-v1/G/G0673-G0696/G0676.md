## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 球賽剪輯練習要補拍失誤，學生想讓球隊學長認可自己的演技，卻因知道向後跌容易撞到後腦，用很清楚的分鏡說服隊友改為先坐地再取景，並找導師商量能否把交片改為音效版。學長堅稱觀眾看得出是假摔，乾脆在還沒開拍時故意嘲笑他。 |
| 核心衝突 | 參賽作品要有可信的意外，尷尬卻已真的發生在拍攝現場。 |
| 導師困境 | 導師能讓他剪入演員笑場，代價是全組失去原來的得意橋段；也能取消這段，留下學長對他膽小的評價。 |
| 故事獨特性 | 安全判斷改變表演技法，引出想得到學長肯定的人的面子問題。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「先坐下，鏡頭再切，不用真的往後倒。」他拿分鏡說得清楚，連音效版怎麼交都想好了。想被學長說一句演得像，他仍知道後腦不能拿來試。學長在還沒開拍時先笑他膽小，他的分鏡紙立刻揉出一角。你停住嘲笑和真摔，讓大家留在安全取景區。沒人受傷，臉上的尷尬卻已經拍不到假裝。「音效版真的也算嗎？」他問。
