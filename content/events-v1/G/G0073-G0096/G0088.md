## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長聽說孩子專注力不好，照導師說的陪坐，卻誤讀成應全程盯著寫。後來照顧親屬在旁把自己的書拿反，孩子第一次笑著把書翻正，家長才看見安靜陪伴可以不同。 |
| 核心衝突 | 家長不滿導師的建議讓家裡一度更僵，孩子願意有人在旁卻不想一直被看。 |
| 導師困境 | 可以承認建議太籠統、請家人先讓學生示範要的距離，或另討論孩子可獨立開始的作業。 |
| 故事獨特性 | 親屬笨拙的陪讀比督促更有用，讓家長有理由要求老師解釋。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「你叫我陪坐，我就一直盯著，結果更僵。」家長不滿，要求你說明。那天親屬把自己的書拿反，孩子笑著替他翻正，家長才發現陪伴不一定是監看。你先承認原建議太籠統，撤回把全程盯寫當必要方法。他說家裡確有人願意陪，可孩子不想每一筆被看。「我現在是退遠一點，還是乾脆不坐？」你不能隔著電話替一家人排位置，更不能把一次好笑的親屬互動變成新的標準處方。
