# T1-031～060｜六個普通候選、隨機中選及正式位置紀錄

> 本檔是故事創作過程的候選紀錄，非正式三層驗收的核准證據。E代表另外產生的情緒選項。每篇採六普通候選抽三個，再與情緒項隨機排列。故事正文只保留最終四個行動。

## T1-31

1. 先撤掉性格標籤
2. 比對教材發放與交件日期
3. 限定幫手只查兩筆
4. 容許本人附上異議
5. 另建未領教材欄位
6. 暫停轉發這份名單

- **中選普通候選**：1、5、4
- **A～D 映射**：A=5；B=1；C=E；D=4

## T1-32

1. 標出每欄所屬科目
2. 請學生回查最早的收件說明
3. 向全班聲明這不是通則
4. 向相關科任逐科詢問
5. 先刪去無來源的項目
6. 讓學生自己說明修正版

- **中選普通候選**：3、5、2
- **A～D 映射**：A=5；B=E；C=3；D=2

## T1-33

1. 核對站牌及公開班次
2. 協助規劃不用等人的離校動線
3. 向課務窗口確認結束時刻
4. 讓他比較兩條合法返家路線
5. 協助下課前做好物品準備
6. 確認是否需要交通安全支援

- **中選普通候選**：3、4、5
- **A～D 映射**：A=5；B=4；C=3；D=E

## T1-034

1. 先說明目前不能推估升學落點
2. 詢問科任出題的本來用途
3. 把問題改成目前能幫什麼
4. 列清楚尚不存在的正式資料
5. 提供正確本科求助窗口
6. 約定用更長期證據再討論

- **中選普通候選**：4、1、5
- **A～D 映射**：A=4；B=E；C=1；D=5

## T1-035

1. 保留原稿只供原用途
2. 逐段詢問哪些能公開
3. 邀請另寫經授權的公開摘要
4. 請承辦先說明刊登管道
5. 只提供不具名的共通題材
6. 讓作者自行聯絡承辦提出條件

- **中選普通候選**：5、3、2
- **A～D 映射**：A=3；B=2；C=E；D=5

## T1-036

1. 撤掉未確認的長期排程
2. 安排一次可拒絕的交接
3. 核對真正需要擦板的時段
4. 開放同學自願選短期工作
5. 讓本人自行說明可做到哪天
6. 由導師先接當次空缺

- **中選普通候選**：6、4、2
- **A～D 映射**：A=6；B=4；C=2；D=E
