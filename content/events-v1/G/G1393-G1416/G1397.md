## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校內常駐校護（或生輔職員）安全意識敏銳（`9-4`），平時非常信任導師（`5-1`），也習慣主動回報班上狀況（`8-4`）。這幾天她發現導師班上一名平時安靜乖巧的學生，連續兩次放學後獨自躲在頂樓樓梯間角落講電話哭泣；她基於安全考量還是第一時間跑來私下告知導師（`8-4`、`9-4`），但同時又因為極度同理那個孩子怕被貼標籤的脆弱心情（`1-3`），反過來拜託導師「這幾天先別直接去約談或通知家長，免得孩子覺得連最後一個躲起來哭的地方都沒了」。 |
| 核心衝突 | 職員基於信任將關鍵隱憂交給導師，卻又因同理心希望導師先按兵不動；但頂樓梯間與連續情緒低落涉及高風險關懷界線，導師不能真的什麼都不確認就放著不管。 |
| 導師困境 | 先確認頂樓門禁安全巡檢無虞，並在不直接點破「有人看見你在頂樓哭」的前提下，以一般課業或生活近況關心名義主動約學生聊聊並評估是否須轉介輔導室或通知監護人（守住學生關懷與安全底線，但敏感的學生可能還是會猜到被通報而對校護產生防備）；還是先請輔導室或原職員從旁溫和接觸、確認這兩天放學都有順利搭車返家而不由導師親自出面點破（給學生最大的緩衝隱私，卻讓導師承受未第一時間直接介入了解的心理壓力）。 |
| 故事獨特性 | 不涉及運動擦傷或隱瞞就醫，寫出校園角落情緒警訊下，知情同事既想通報盡責又怕傷害學生自尊的矛盾。 |
