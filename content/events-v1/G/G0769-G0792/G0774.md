## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生有可用的家中備用球，認同導師長期實施不按技術選最後一人的規則，仍想自行決定在哪個半場練，便願親自帶球教第一次到場的同學開球。對方講完謝謝竟轉去挑同一區他最想留的對手。 |
| 核心衝突 | 學生靠自選場地找到一位新球友，自己最喜歡的對手卻被他教會的人選走。 |
| 導師困境 | 導師可讓初學者維持第一次自己的邀約，或取出自己的球加入，代價是他也得接受這場變成自己最不擅長的雙打。 |
| 故事獨特性 | 拒絕把初學者剩到最後的人第一次體會看著自己被剩下。 |

### 開場
- **P01｜旁白與當場對話**：他帶的備用球一落地就彈得很響。「不能每次都把不會的剩最後，這不是老師說的？」他願意先教新同學開球，自己挑了喜歡的半場。新同學學會，立刻跑去問他最想找的對手。他站在邊線把球轉半圈：「喔，可以啊。」說完卻沒有走去另一邊，手還壓在那顆球上。
