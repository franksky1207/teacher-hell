## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生知道照顧者將出席首次正式家長日，請導師安排對方坐到最後面，免得每次發言都成為焦點；家長卻覺得前排才聽得清楚。 |
| 核心衝突 | 尊重學生不想被代言的界線與照顧者實際參與需求並存，座位不能被當成限制合法發言的工具。 |
| 導師困境 | 如何會前先了解兩方需求，調整共同發言與個別會談方式，而不是暗中把家長藏到後排？ |
| 故事獨特性 | 重點不是教室座位視線，而是學生希望控制家庭在公開場合如何代表自己的界線。 |

- **玩家可見結果**：家長解釋自己只是想坐前面一點才聽得清楚，沒有打算在全班面前談孩子的私事。原來坐哪裡跟會不會公開講家裡的事，是兩回事。我先問清楚家人想聽什麼，再一起講好哪些話題只能私下談。不過如果現場有人問到我的私事，我可以先不回答嗎？
