## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 本班學生校園安全意識高、執行力強，宣導週前夕主動揪了幾位外班朋友一起出力幫導師拍防災短片，原意是設計一幕「同學慌張想翻矮窗，他立刻衝上前攔下並帶往安全門」的反面教材劇。但為了趕進度與追求流量趣味，他剪輯時把後面勸阻與正確逃生的畫面剪得太短、前面翻窗動作又配了歡樂音效，導師一看發現發出去一定會被誤當成鼓勵爬窗。 |
| 核心衝突 | 學生出於安全意識與高執行力投入拍攝，卻因為剪輯節奏誤判讓「反面教材」看起來像「搞笑示範」。 |
| 導師困境 | 立刻要求全部重剪補拍清楚勸阻與安全門動線，會讓熬夜剪完這支片的學生群超洩氣；直接剪掉翻窗段落發出去，整支片劇情接不起來、學生寧願乾脆不發。 |
| 故事獨特性 | 學生不是沒有安全常識，而是為了戲劇張力設計反面橋段時在剪輯節奏上失手翻車。 |
