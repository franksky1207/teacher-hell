## 5｜R1～R8共用結果、結算與4×8因果矩陣
### R1｜熟人拒絕透露內情
- **玩家可見結果**：家長聯絡那位熟人後，對方表示無權提供不公開的評分細節，原本說得很可靠的人脈頓時派不上用場。「我以為有人認識就能幫孩子多準備一點，沒想到根本不是那回事。」家長改為核對正式公告和程序說明，不再追問個別評審的喜好。雖然還是會擔心，但至少不再把私人關係當成必備的優勢。
- **客觀後果**：家長轉而核對正式公告與程序說明，停止追問個別評審喜好。焦慮沒有立刻消失，至少沒有再把私人關係當成取得優勢的必要條件。
- **合法底層增減**：`guardian_a:6-2:-1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-1, -2, 1, 0`

### R2｜公開資料反而回答了問題
- **玩家可見結果**：家長仔細閱讀招生公開說明，發現孩子真正沒弄懂的是面試形式與攜帶資料，不是什麼神祕的評審偏好。「原來最需要的資訊上面都寫著了，我們一直在問錯方向。」家長把能確認的事項交給孩子自己準備，還有不清楚的地方再透過正式窗口詢問。這樣的幫忙不碰私下內情，也不用替孩子硬找人脈。
- **客觀後果**：家長把能確認的事項交給孩子自行準備，仍有不明白的部分才透過正式窗口詢問。這份支援不涉及非公開內情，也不需要替考生編造人脈。
- **合法底層增減**：`guardian_a:8-1:+1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`1, 0, -1, -2`

### R3｜偏好傳聞相互矛盾
- **玩家可見結果**：家長收到兩位親友傳來完全不同的「內幕」，一方說要活潑，一方卻說越沉穩越好，孩子因此不知道要相信誰。「如果每個人都說自己知道，反而讓孩子不知道怎麼準備。」家長先停下打聽和猜測，回頭看查得到的面試規則。雖然沒有問到什麼神祕答案，卻也明白沒證實過的「好意」反而會讓孩子更慌。
- **客觀後果**：家長先停下傳訊與猜測，回到可查的面試規則。這次沒有揭開任何神祕答案，卻讓家庭看見未經證實的善意也可能增加壓力。
- **合法底層增減**：`guardian_a:11-4:+1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`0, -1, -2, 1`

### R4｜孩子不希望家長私下打探
- **玩家可見結果**：學生得知家長打算問熟人後，明確表示不願被別人認為靠關係取得資訊，親子之間一度僵住。「我只是想幫忙，怎麼變成他覺得我不尊重他的努力？」家長願意先聽孩子真正需要什麼幫忙，先不去找那些身分不明的人。兩人對準備到什麼程度還是有不同看法，但面試畢竟是孩子要親自上場的事，不能全由大人的焦慮做主。
- **客觀後果**：家長願意先聽孩子真正需要哪種協助，暫停聯絡不明身分者。兩人仍有對準備程度的不同看法，但面試是孩子要親自面對的事，不該被成人的焦慮完全接管。
- **合法底層增減**：`guardian_a:12-4:-1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-2, 1, 0, -1`

### R5｜傳聞變成準備方向的陷阱
- **玩家可見結果**：家長堅持某位評審只重視特定活動，想讓孩子臨時調整自介，卻發現那段話沒有可公開核對的來源。「如果這句是錯的，我反而是在害他把本來準備好的內容全推翻。」家長放棄用猜測去改孩子的經歷，回頭對照正式要求和原本的成果。收回這個建議不代表不關心，只是明白幫忙也要有根據。
- **客觀後果**：家長放棄用猜測改造學生的經歷，重新整理正式要求與真實成果。這次收回一個建議並不表示家長不關心，而是承認支援也需要證據。
- **合法底層增減**：`guardian_a:6-2:+1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`1, -1, -1, -2`

### R6｜有人暗示可交換資源
- **玩家可見結果**：家長聽到模糊訊息，似乎有人願意以提供協助為由要求額外好處，他驚覺這已不是單純詢問公開程序。「我想幫孩子，不代表我願意做不清不楚的交換。」家長不再接觸那個可疑管道，改從官方窗口確認該準備的資訊。孩子的面試資格不該拿來換取私下利益，導師也沒有替這種做法背書。
- **客觀後果**：家長沒有繼續接觸可疑管道，改從官方窗口確認必要資訊。孩子的面試資格不應被拿來換私人利益，導師也沒有替這類接觸背書。
- **合法底層增減**：`guardian_a:8-1:+1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-1, -1, 2, 1`

### R7｜親友轉來其他考生資料
- **玩家可見結果**：家長收到一份聲稱有助準備的資料，裡面卻出現其他學生的個別資訊，讓他開始懷疑來源與取得方式。「別人的資料不該拿來當我們家的捷徑。」他不再轉傳或使用那些內容，改看正當公開的資訊。這個決定沒辦法替孩子多出什麼捷徑，卻避免把自己的焦慮變成別人的隱私風險。
- **客觀後果**：他不再轉傳或使用那些內容，轉向合法公開資訊。這項決定沒有替孩子增加任何神奇優勢，卻避免把自身焦慮變成其他人的隱私風險。
- **合法底層增減**：`guardian_a:11-4:-1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-2, 1, -1, -2`
