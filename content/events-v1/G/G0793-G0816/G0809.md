## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生在家備受保護支持、做事講原則但也很在意自己不要在班上惹禍上身。這天他負責開班級匿名意見箱，堅持「不偷看內容」的原則，卻在倒出紙條時不小心看見一張沒折好的紙條上寫著針對某位同學的惡意攻擊，頓時不知道該直接交給導師還是裝作沒看見。 |
| 核心衝突 | 守原則交出字條怕被同學誤會是他寫的或打小報告；若私下壓下又怕班上真的出事。 |
| 導師困境 | 當場接手字條並在班上追查，等於讓這名本來就怕被貼標籤的學生暴露在同儕猜疑裡；若先冷處理只私下提醒他，惡意攻擊的對象可能還在承受壓力。 |
| 故事獨特性 | 焦點不在抓誰寫字條，而在一個「只想安穩把班務做完」的守規矩學生突然被塞進燙手山芋。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：他倒出意見箱，故意不看，沒折好的那張卻正對著眼睛。爸媽常說照規矩就好，他也堅持只收不讀，現在手指停在紙邊：「如果我交，會不會以為我寫的？」你已保密接手並接好必要保護，沒有讓他再碰內容。他看著空箱，像那幾個字還在裡面，等他明天再開一次。

| 選項ID | 玩家可見短句 | emotional | 教師已完成的客觀行動 | 優點及代價（不顯示玩家） |

| A | 只向全班重申投件不得攻擊個人，不引用這張字句或時間。 | false | 導師已作不含個案線索的有限一般性班級提醒，不代替必要個案處理。 | 效果不一定明顯 |
| B | 之後由原合法成人直接收箱，他本次班務到這裡。 | false | 導師已在本人班務權限內接回原收件工作，維持必要處理與保密。 | 他可能覺得被撤職 |
| C | 他若願，只私下確認今天被看見的範圍，不追問同學猜測。 | false | 導師已提出限保護需要的有限私人暴露範圍確認，不公開身份或逼供。 | 可能還是怕被捲入 |
