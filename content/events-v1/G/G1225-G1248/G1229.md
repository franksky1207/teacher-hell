## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長這學期主動投入人力擔任班級活動攝影與紀錄整理的熱心志工（`11-3`）。今天他打開導師昨晚先選進班級成果簡報裡的幾張生活合照時，發現其中一張全班大合照邊緣剛好把自家孩子裁到只剩半張臉，護子心切的他一時衝動（`1-2`）沒先看清楚就打電話來要個說法（`12-4`）：「老師我出這麼多力幫忙拍活動照，怎麼你挑進簡報的合照剛好把我們家孩子切掉一半？是不是故意挑這張？」等導師打開電腦說明那只是簡報版型自動縮圖裁切、原圖完全正常後，這名家長這才不好意思地連忙彈性協商（`10-3`）改請導師把原圖傳給他微調。 |
| 核心衝突 | 熱心出力的家長因一時衝動誤會導師偏心裁圖而直白追問，雖然誤會解開後願意彈性調整，卻已讓導師面對「辛苦整理簡報還要被質疑針對」的委屈。 |
| 導師困境 | 笑著把原圖檔傳給這名志工家長請他自己幫孩子調好構圖再回傳、自己重貼進簡報，雖然順利圓場並保住這位熱心志工的人力支援，但剛被衝動指責一頓的委屈得自己吞下；稍微嚴肅提醒對方以後先問清楚原檔再指責、別動不動懷疑老師針對，這名剛覺得理虧又熱心出力的家長恐怕面子掛不住、下次乾脆不再幫忙拍照。 |
| 故事獨特性 | 沒有誰想排擠孩子，寫出數位簡報自動縮圖裁切引起的「半張臉烏龍」，呈現熱心志工家長衝動要說法後秒軟化協商的真實可愛反差。 |
