## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生住在校車首站旁、多年來固定早起搭第一班車最早到校開門窗（`7-4`），同時擔任本班事務股長負責開門與早自習環境檢查（`9-3`），平時對導師非常信任（`5-1`）。今天一早他照常開門，卻看見昨晚借用教室練舞或自習的人把飲料杯與便當盒堆滿後方垃圾桶還沒倒，當場火大（`2-1`），拿著掃把直接衝進導師室：「老師我信任你才每天早起顧教室，但我不是來幫昨晚的人收爛攤子的！」 |
| 核心衝突 | 盡責又早到的固定開門股長被昨晚的善後漏洞激怒，要求信任的導師立刻查明並替他討回公道。 |
| 導師困境 | 立刻去調走廊監視器並追究昨晚留校的人，早自習前全班大概都在看熱鬧且可能發現是外班社團借用；先安撫他並陪他一起把垃圾清掉趕上早自習，這名受委屈的股長以後大概再也不想最早來開門。 |
| 故事獨特性 | 把「住家通勤首班車的穩定作息」跟「早起顧教室卻幫人擦屁股的委屈怒火」結合，寫出早自習前十分鐘的真實爆點。 |
