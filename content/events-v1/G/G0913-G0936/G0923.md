## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 同時扛著校慶、社團評鑑與外賓接待的學務處職員任務負荷過重（`11-1`）、累到快撐不住（`2-3`），但他不願跟風學校往年「把全校班級硬塞進禮堂排排站兩小時做表面功夫」的套路（`6-2`）。這天他私下跑來找導師協商彈性方案（`10-3`）：「高層只是要看成果照，你挑十個最會上鏡的同學來穿堂拍個短訪交差就好，其他人在教室自習省事！」 |
| 核心衝突 | 過勞且務實的行政人員私下邀請導師一起「簡化作秀程序」，卻讓沒被挑上的學生覺得校內活動只剩門面表演。 |
| 導師困境 | 配合他的彈性提案只派十個學生去當樣板，既幫同事減壓又讓全班省下時間自習，但之後班上難免傳「老師只挑長得好看的去代表」；堅持全班依原計畫參與，這名快累垮的職員得自己加班搭全場。 |
| 故事獨特性 | 行政人員不是來加壓作秀，而是累到主動找導師串通「把形式主義縮水到最小」。 |
