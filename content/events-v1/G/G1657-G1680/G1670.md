| 固定欄位 | 故事摘要 |

| 事件起因 | 家長長期處理兄弟共同照護分歧，對導師上次說「你們自己講好」還有怨，沒查就信群組傳的教師會面新規只能講一分鐘。他到校仍支持導師先聽孩子開口，輪到自己時卻把三頁筆記抓成一張，差點略過唯一要談的事。 |
| 核心衝突 | 他最怕被指為愛管，卻在刻意縮短時又讓孩子以為他不在乎。 |
| 導師困境 | 可把那張筆記留到孩子說完再分段談，時間比較長；或請家長只讀真正想問的一句，讓其餘內容改循既有聯絡方式，當下可能沒有答案。 |
| 故事獨特性 | 家長早已很會壓縮家庭會議，這次一分鐘壓掉的偏偏是關心。 |
