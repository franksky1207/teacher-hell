## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生認同導師指定閱讀從每章開頭開始、不能偷翻結局的規定，卻擔心自己當天要進度分享，越讀越覺得導師只教大家記情節，沒有教人辨敘事者。他每次下課都追問導師讀到倒數第二頁了沒，盼老師自己看出那頁藏著不同筆跡。輪到他上台，才發現同桌已用便條把全書所有那種筆跡都標出來，連他最怕自己漏看的也在。 |
| 核心衝突 | 一直催老師的人最怕被同學看出他自己沒有讀懂全本，眼前的現成答案卻是他最需要的。 |
| 導師困境 | 導師可讓兩人當場各讀一種筆跡，接受整堂不再按預排順序走；也可先讓學生講自己的版本，代價是他可能因怕錯只剩情節可背。 |
| 故事獨特性 | 學生從遵守不偷翻的讀法發現破綻，卻在突破教法前先被另一個遵守規則的人追過。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「老師讀到倒數第二頁了嗎？」他連著下課都來催，說只記情節看不懂誰在講話，又一直守著不偷翻結局的規定。今天該他分享，他的手卻停在同桌便條上：那種筆跡不只一頁，全被標出來了。他忽然不再催你，先問同桌：「你連這裡也有看？」原本準備指給你看的那頁還夾在他手指間。
