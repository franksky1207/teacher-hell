# 《教師荒謬地獄》學生立繪｜完整六圖製作 SOP v1.4

> 生效：2026-11-08。**完整六圖是唯一現行學生美術方案**，舊雙圖流程、原「立繪預覽」入口及 001 舊 PNG／JSON 均已依使用者決定移除；歷史可查 Git 紀錄。參考：[40 人外貌名冊](./15-B-40位學生外貌設計名冊.md)｜[美術進度簿](./15-B-美術素材命名與製作進度簿.md)。

## 1. 產出與不可違反規格

- **40 位美術原型、每人 8 套**，合計預計 **320 張 PNG**；男生 `student-001～020`、女生 `student-021～040`。每人每套只交付 **一張真正透明 RGBA PNG**，內含 **3 欄 × 2 列、六格完整人物立繪**；**不另製 calm 母圖、局部臉部貼片、定位 JSON 或六張分圖**。
- **構圖與六格獨立性**：先建立透明 `1536×2304` 畫布並分為 3×2，每格 `512×1152`；**在每格內先以置中的約 `488×1152` 範圍規劃完整人物輪廓**，488 px 僅供起始參考。**完整人物優先於固定格線裁切**：須先確認六個姿勢的手臂、手肘、手掌、頭髮與軀幹本身畫得完整、彼此分離，再分格或調整位置；超界時縮小或微調構圖，**禁止硬切肢體後因裁切邊界留白就誤判合格**。人物從頭部延伸至**明確可見的下半身／褲裝或裙裝**即可，取景深度因體型而異，不必一律精確到大腿同一高度；下方可自然收在腿部，六格尺度與比例需協調，且不得有鄰格殘片、跨格肢體或頭手身體側邊不自然截斷。
- 六格順序固定：上排 **calm 平靜｜happy 開心｜angry 生氣**；下排 **sad 難過｜surprised 驚訝｜embarrassed 害羞**。
- **人物以外全透明**：不准用純色／棋盤格冒充透明，不要背景、場景、邊框、格線、文字、規劃圖、資訊圖、標籤或水印。**全部新製素材固定 1536×2304 px，每格 512×1152 px**；3×2 等分裁切，不得因角色或服裝改變畫布尺寸。人物體型與身高感可自然不同，但六格取景尺度、頭身比例及出場位置須協調。產圖工具若無法直接輸出此尺寸，應於交付前調整為指定像素並檢查品質、透明度與裁切，不得把不符尺寸的圖當作完成品。
- **同一人同套六格**：臉型、五官、膚色、體型／年齡感、服裝款式與配件設定一致。配件可完全沒有；如有，同款同色與持有狀態須連貫，可隨姿勢自然移動，不得憑空消失或換款。不同套服裝可換髮型整理、裝扮與配件，只要辨識得出同一人。
- **偏寫實動漫畫風、40 人有辨識度**：每次依外貌名冊重新鎖定該生的臉型、五官、體型與髮型；「可愛」指外貌而非 Q 版，「偏寫實」也不等於尖臉瘦高。名冊不綁姓名或劇情；細微特徵可彈性處理，但不可把人物類型畫錯。**不同學生的六表情姿勢應依人物體型、氣質與情緒自然設計，不得直接複製前一位學生的整組動作；允許個別姿勢自然重複，不強求 40 人每個動作都不同。**

## 3. 唯一製作順序

1. **第一階段僅製 40 人夏季制服六圖**：先男生 001→020，再女生 021→040。每位與先前已核准的人物比對整體外貌，由使用者核准後，該張夏季制服 PNG 才成為此人**唯一外貌基準**；40 人都核准前，不開始第二階段。
2. **第二階段逐人補七套**：從 001 起，依上表第 2～8 套連續完成後，再換 002，直到 040。**每套都直接參照該人第一階段核准的夏季制服原始六圖**，絕不逐套傳遞外貌，也不誤用別人的圖。
3. 美術編號**不等於座號或姓名**。新存檔內男女各 20 張原型應於同性別組內不重複隨機配對 NPC，配對固定三年；**僅為設計規則，未因本次文件修改而實作程式**。

## 4. 每次產圖：確認 → 製圖 → 全項自檢 → 分類修正 → 交付

1. **產前完整核對**：每次重新讀取該生原始外貌名冊，確認臉型、體型、髮型、偏寫實動漫畫風及服裝；先建立透明 1536×2304 畫布、分 3×2 六格，每格約 488×1152 置中構圖。**逐格安排六種表情及自然不同的姿勢**，須有明確下半身；同步要求真正透明、無背景。
2. **產後全項自檢**：先確認六個人物各自完整且分離，再實際裁出六格，逐格核對外貌、表情、服裝與配件、手肘／手掌／頭髮是否原本就被截斷、下半身、尺寸及裁切；**邊界留白不能代替肢體完整性檢查**。除確認 PNG 的 Alpha 真透明，還須將**每格實際合成至深色與淺色背景目視檢查**，特別檢查頭髮、耳側、手臂與身體之間的白邊、棋盤格、殘留底色或雜點；不能只憑 Alpha 數值宣告合格。**每次重試仍要全部重檢**，不能只檢查前次缺陷。
3. **先分類再修正**：單一手指、局部邊緣等範圍明確的小瑕疵才局部修；**人物類型錯誤、假透明／大面積背景殘留、多格肢體截斷或重疊、整體輪廓損壞或構圖失敗，優先整張重製**，從名冊重新建立完整六格要求，涵蓋姿勢、畫風、服裝、尺寸與透明度，**不得只沿用失敗構圖、換幾句提示就稱作重製**。若相同瑕疵修後仍明顯存在，停止重複無效修法，重新判斷根因及是否重製；不設定機械式重試次數。
4. **重大缺陷嚴格、細節彈性驗收，但不冒充成功**：人物類型錯誤、假透明／明顯白邊、肢體截斷、人物重疊等重大缺陷必須自行修正後才能交付，不要求使用者反覆催「繼續」；只要表情與個性合理，**個別手勢與原規劃略有不同**，以及細微色差、皺褶等，不必無限返工。工具確實不可用或持續失敗時說明阻礙，不虛報合格，也不無限制重試。
5. **交付一張正式命名 PNG 下載連結＋對應 `student-XXX/` 專屬 GitHub 資料夾**，不可只給總目錄；不提供 ZIP／分圖／JSON，先確認檔案存在。

## 5. 檔案、預覽與核准界線

- 目錄沿用 `web/assets/characters/students/student-XXX/`；檔名固定 `student-XXX-full-sheet-{outfit}.png`（例如 `student-001-full-sheet-uniform-summer.png`）。 **修正或重製同一素材也必須沿用相同正式檔名，直接覆蓋舊版；禁止加上 `-corrected`、`-v2`、日期等後綴。** **只採 `full-sheet-*` 圖集；不再建立或保留舊母圖／貼片／JSON。**
- 核對 PNG 已存在 GitHub，再確認實際內容。**上傳不等於准許接入預覽**；只有使用者明確下令，才修改或部署既有網站。
- **唯一給使用者的預覽網址**：https://franksky1207.github.io/teacher-hell/preview/ 。使用原站「完整六圖測試」入口、學生 001～040 與八套服裝下拉選單、六個表情按鈕；缺圖顯示未製作。**不得提供版本參數、追蹤參數、另開測試網址**；部署時確認 `gh-pages:preview/index.html` 真正載入對應新模組與素材。
- 六格是**劇情觸發的瞬間表情／姿勢切換**，不是連續動畫；**不交叉淡化**，避免重影。維持角色出場位置、尺度合理。
- 進度簿須區分：**候選產生及自檢 → 使用者核准夏季外貌基準 → GitHub 已上傳 → 預覽已接入 → 使用者實際預覽核准六表情 → 正式劇情接線測試**。各階段不互相冒充，**使用者未核准不能標記新模式通過**。
- `student-001-full-sheet-uniform-summer.png` 已由使用者在正式預覽網站確認「可以了」，列為 **001 夏季制服正式外貌基準**；尚未接入遊戲正式劇情。下一位是男生 002。
