## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生家中改為輪流住兩邊，不同門鈴讓他近日漏接包裹，學會靠短長聲辨認再應門。在班上他把新學會的節奏轉成音樂練習，因同學起鬨按手機音效做成門鈴惡作劇，他氣得叫全班每個人都按一次讓導師猜，其他人竟全照做。 |
| 核心衝突 | 他罵的是別人拿聲音捉弄人，自己卻是最能使惡作劇四面響起的人。 |
| 導師困境 | 導師可當場收起聲源，讓所有人只記得被罵；也可以留下大家最猜不出的兩個節奏，拿已經造成的混亂做唱拍練習。 |
| 故事獨特性 | 對聲音變敏銳的人把本應停止的狀況推到誰也聽不清。 |
