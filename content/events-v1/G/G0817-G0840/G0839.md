## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 個性隨和愉悅、極度信任導師的爸爸，平常最怕在家裡跟孩子吵架，跟導師商量事情也向來很有彈性。這天他笑呵呵地傳訊告訴導師，孩子偷刷了家裡信用卡買遊戲點數，「我不擅長扮黑臉，這件事就全權拜託老師在學校幫我勸勸，看要罰抄還是留校我都配合」。 |
| 核心衝突 | 家長出於信任與逃避家庭衝突，把屬於家庭金錢與網路消費管教的責任整個外包給導師。 |
| 導師困境 | 嚴正提醒家長這是家庭財務管教問題、學校不便代罰，怕傷了這位隨和爸爸的信任；順口接下來幫他訓話，等於幫家長當免費的黑臉工具人。 |
| 故事獨特性 | 家長態度好到無可挑剔，卻用「隨和、信任、全權配合」把最棘手的家庭管教丟進學校。 |
