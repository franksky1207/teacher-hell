## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班副班長（`9-3`）平時觀察力敏銳，憑這幾週留意大家下課動向的經驗（`3-2`），早看出班上有兩名同學午休剛結束就習慣輪流藉故去頂樓樓梯轉角偷滑備用手機，平時一向主動向導師回報班上狀況（`8-4`）。今天午休他又看見那兩人一前一後溜出教室，立刻跑來辦公室告訴導師，還當場急著督促導師（`10-2`）：「老師我已經連兩天跟你講了，現在距上課還有五分鐘，你立刻跟我走過去現場抓他們，不然鐘響他們又把手機塞回襪子裝沒事！」 |
| 核心衝突 | 敏銳又負責的幹部把「當場人贓俱獲」的壓力推給正準備下一節課的導師，要求導師立刻放下手邊事務起身跨區抓違規。 |
| 導師困境 | 立刻跟這名副班長衝去頂樓樓梯間現場抓人，就算真的抓到違規手機、讓副班長覺得老師有魄力，但也可能讓那兩名同學猜到是副班長打小報告而在班上孤立他，且導師自己下一節進班開課時間被壓縮；先按兵不動請副班長回去上課、等放學後導師再找那兩人私下談，這名連續兩天主動回報又經驗準確的幹部當場洩氣，認為老師對違規視而不見。 |
| 故事獨特性 | 沒有搜索個人書包，焦點在於幹部「要求導師趁這五分鐘馬上過去抓現場」的即時行動壓力與保護通報者的兩難。 |

### 開場
- **P01｜學生**：五分鐘！我連兩天講了，你現在跟我走，他們就塞不回襪子。
- **P02｜旁白**：副班長把時間算得很緊，幾週看人進出已看出規律。你先接回必要查明，不讓他跟人或搜東西，也沒把觀察直接寫成已證實違規。
- **P03｜學生**：我不是亂說，你每次說知道了，他們照樣去。
- **P04｜導師**：知道線索和當場抓到不是同一件事。
- **P05｜旁白**：他望著樓梯方向，像只要再等一分鐘就全白費。鐘還沒響，他卻已把自己的課間交給那兩個背影。
