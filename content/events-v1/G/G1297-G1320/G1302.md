## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班任課教師平時十分認同導師整體班級規範（`9-1`），但個性最怕跟同事正面起爭執（`6-4`）。導師這兩週配合分組活動把教室課桌椅排成「四人小組併桌」，這名科任卻私下對這種桌型抱持專業質疑（`8-2`），認為學生斜坐容易分心聊天。不敢跟導師當面講的他，竟然連續三天一進班上課就直接介入座位配置決策（`12-3`），叫全班「花兩分鐘把桌子拉回單人直排，下課你們自己再推回去」，搞得下一節的老師跟學生每天搬桌子搬到怨聲載道。 |
| 核心衝突 | 認同導師卻極度迴避衝突的科任教師用「自己上課偷偷叫學生搬桌」來消極抵制小組桌型，導師必須出面協調教室動線卻又怕點破後讓這名怕吵架的同事當場下不了台。 |
| 導師困境 | 乾脆順著這名科任的專業質疑把全班桌椅改回固定單人直排、只有班會需要討論時再搬（消除每日搬桌混亂與同事摩擦，卻犧牲掉平時小組共學便利）；私下找這名怕衝突的同事溫和溝通並說明課間搬桌影響下堂課銜接（守住教室秩序與教學共識，這名極怕正面衝突的同事恐怕整個人緊繃僵硬、以後進班更不自在）。 |
| 故事獨特性 | 寫出教師之間最常見的「不敢當面講卻用學生當搬桌工具人」的教室空間無聲拉鋸。 |

- **P03｜旁白**：我先和當堂老師停下這趟來回搬動，留好通道，才回辦公室找那位科任。
