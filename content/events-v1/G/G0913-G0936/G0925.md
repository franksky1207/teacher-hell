## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生父母與姊姊平時很支持他做專題，還教他簡報排版技巧並開放家中電腦與彩印設備讓他使用（`7-1`）。他自己本身怕同學吵架（`6-4`）又容易擔心報告開天窗（`2-2`），這次兩位組員為了題目僵持不下，他便主動找導師協調分工（`10-4`），提議把題目拆成兩份子題並靠家裡的設備優勢把兩邊的簡報排版一次做好。導師還沒確定評分怎麼拆，他隔天就抱著印好的兩份成果來問「這樣算不算我們這組都交了」。 |
| 核心衝突 | 家庭資源與技能支援讓學生有能力獨力扛下兩邊工作來避開組內爭執，卻讓導師在「依實際貢獻拆開打分」與「維持原分組整組計分」間失去客觀依據。 |
| 導師困境 | 要求三人寫明各自貢獻比例再照實給分，兩位原本沒做什麼的組員可能抱怨當初是這名學生自己搶著做完；照整組同分一起過關，下回分組作業大家只會更理所當然把事推給設備好又怕吵架的人。 |
| 故事獨特性 | 家庭支持體現在具體的排版技能與居家列印支援上，讓學生意外成了幫組員「代工換和平」的雙面主角。 |
