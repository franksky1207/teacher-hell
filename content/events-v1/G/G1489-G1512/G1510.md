## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生背後有家庭支持他遵守校規（`7-1`），環境適應能力不錯（`3-4`），平時高度認同班上「午休關燈拉簾安靜休息」的規範（`9-1`），做人處事極講原則（`1-4`）。本校確實設有午休開放、可以登記並由值勤師長全程看顧的圖書館靜態自習室，須依規申請離班。今天午休大家剛趴下，他看見窗邊同學偷偷撥開窗簾縫隙借光複習下午第五節小考的筆記，立刻大聲制止（`1-4`、`9-1`），反而吵醒全班，兩人差點吵起來。 |
| 核心衝突 | 守規學生堅持午休全暗班規有其道理，但大聲糾舉反而破壞全班休息；另一名學生的考前複習需求可以利用學校確實設置且有看顧的自習室處理，導師需在共同作息與依規提供個別需求間取得平衡。 |
| 導師困境 | 先請借光看書的同學尊重大家午休全暗休息的規定立即收起書本拉回窗簾、專心趴下休息，同時私下提醒這名講原則的學生「遇到小事輕聲示意或交給老師，別大聲吵醒大家」（守住教室全員共同作息與班規原則，但借光同學少掉考前最後複習時間，講原則的學生也覺得被要求說話方式很委屈）；還是維持教室內「全員關燈拉簾休息」的既有班規不動，依校方既有的「午休圖書館／自習室靜態自習登記與值勤師長看顧規定」替這名急著準備下午第五節小考的同學開立午休離班單、請他安靜前往該看顧自習室讀書直到午休結束鐘響（在完全符合校規與師長看顧前提下解決個別急迫需求，卻讓這名講原則又守規矩的學生覺得午休時間出現例外還是不太公平）。 |
| 故事獨特性 | 沒有誰想偷懶吵鬧，寫出午休教室裡「堅持全暗睡眠原則的守規學生」與「想趁午休複習下午小考同學」的真實生活摩擦，以及有看顧前提下共同作息與個別需求的取捨。 |
