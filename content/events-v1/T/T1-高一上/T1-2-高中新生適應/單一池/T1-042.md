## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 第一週跟著隊伍移動到專科教室的學生，第二週自願帶路，卻省略臨時施工封閉處的正式提醒。 |
| 核心衝突 | 熟悉一次路線不代表能取代更新後的安全指引；否定帶路好意也會讓學生不敢再協助。 |
| 導師困境 | 如何即時補足封路資訊，並決定由學生示範還是請權責人員說明更動？ |
| 故事獨特性 | 不同於首池迷路；問題是一次成功經驗造成對更新資訊的省略。 |
