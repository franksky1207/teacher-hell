## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 帶頭學生發現導師取消班會自選歌單後，把他的提案連同其他人投的票都略過，氣得帶半班不唱；又要求重訂提案得先說明淘汰原因。 |
| 核心衝突 | 導師不必播放不合適歌曲，也不能假裝沒人曾投票。 |
| 導師困境 | 可堅持停歌並逐項說明、讓合規替案重投，或把班會時間改作別的活動。 |
| 故事獨特性 | 號召罷唱的人真正想拿回的是導師看過自己提案的承認。 |
