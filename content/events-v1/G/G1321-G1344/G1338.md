## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 開朗樂觀（`2-4`）且有號召力（`6-1`）的學生相信網路貼文宣稱「互虧才是真正的好朋友」（`8-3`），午休帶動幾位同學交換自嘲小故事，並在取得口頭同意後把其中幾段寫進尚未公開的班級回顧草稿。原本笑得最大聲的同學看見文字才發現自己不想留下那段玩笑，私下要求撤掉。學生立即刪除該段，卻發現自己也曾同意被寫進去，現在同樣後悔，於是希望導師把原本交稿即定稿的班級回顧程序改成公開前由當事人再次確認（`12-1`）。 |
| 核心衝突 | 熱鬧當下的同意與事後看見文字的感受不同；帶頭學生自己也想撤回玩笑，開始理解同學的尷尬，並提出重新確認的程序。 |
| 導師困境 | 先確保未公開草稿中不願保留的內容已撤除；接著可讓本次回顧延後定稿，逐段由當事人重新確認並保留願意分享的趣事，代價是重排版面及多花時間；或縮減為不涉及個人玩笑的班級共同回憶，準時完成卻失去原本生動的個人聲音，讓帶頭學生感到可惜。 |
| 故事獨特性 | 學生不是動員同學要求試辦網路理論，而是自己也成為玩笑的當事人，從熱鬧到後悔才提出程序變更。 |
