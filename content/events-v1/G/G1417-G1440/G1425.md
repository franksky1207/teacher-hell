## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 玩家導師近期因為老家臨時一筆需要分攤的家用修繕開銷而手頭預算吃緊（`7-2`），平時很習慣自己安排下班生活節奏、不喜歡被人左右（`4-3`）。某個普通上課日下班後，導師原本打算安靜買個平價便當回家休息，卻在捷運站出口巧遇幾名久未聯絡的大學同學正要去聚餐；愛熱鬧的社交主動性一上來（`6-3`），又因為不想在老同學面前顯得窘迫、想保住自己的面子與自主決定（`4-3`），一時衝動（`1-2`）竟豪氣喊出「那我跟你們去，第一輪飲料我請！」——結果走進店裡一翻菜單，才發現是間單杯飲料動輒兩三百元的餐酒館。 |
| 核心衝突 | 成年人想在老同學面前維持大方與社交熱情，卻撞上自己近期真實的家庭經濟負擔，進退兩難。 |
| 導師困境 | 趁大家還沒點完餐前坦白笑說最近家裡有筆開銷預算緊、這攤改為各付各的（立刻止損荷包保住生活預算，但當眾收回自己剛喊出的請客話實在很丟臉）；還是咬牙硬撐把這輪帳單吞下來、接下來兩週自己每天帶便當省吃儉用補洞（守住社交面子與自主承諾，卻讓原本吃緊的財務壓力雪上加霜）。 |
| 故事獨特性 | 完全屬於教師下班後的獨立社交與經濟窘境，寫出大人「死要面子衝動喊請客、看到菜單瞬間後悔」的真實人間清醒時刻。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：我本來只要買便當。捷運口一遇見大學同學，嘴巴比腦袋快：『第一輪我請！』
- **P02｜同學**：真的？太久沒見，今天賺到。
- **P03｜旁白**：店裡的菜單一翻開，飲料單杯兩三百。老家修繕剛分攤完，我這週連外送費都算過。
- **P04｜導師**：你們先等等，還沒點對吧？
- **P05｜旁白**：三個人一起抬頭。我把菜單翻回封面，封面並沒有變便宜。
