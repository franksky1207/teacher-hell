## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長最近連續上大夜班累到快虛脫（`2-3`），雖然家裡還有配偶與長輩幫忙撐著（`7-1`），但他本人性格極講原則（`1-4`）。今天早上他打電話來，口氣疲憊卻很強硬地要求導師修改班上「晚自習請假必須提前一天交家長簽名紙條」的規定（`12-1`）：「老師，我們大人也要上班休息（`2-3`），這規定太死板了！以後孩子臨時要回家，我直接用LINE傳訊息給你算數，這才合情合理嘛！（`1-4`）」但私校晚自習與門禁點名有嚴格安全流程，若當天傍晚家長才傳LINE，導師下班或上課沒看見就可能發生學生已離校卻沒人確認的漏洞。 |
| 核心衝突 | 疲憊又講求效率的家長認為「紙本提前簽名」不合時宜，導師必須守住「即時安全確認」的門禁底線，卻也理解雙薪輪班家庭的辛苦。 |
| 導師困境 | 堅定說明「當天傍晚導師未必能即時看LINE、有安全風險」，婉拒隨意改用LINE請假，改提醒他可由家裡另一位同住家人提前一天代簽（守住校園離校安全程序，但累壞的家長覺得學校規定太不體諒勞工）；還是明確婉拒當天臨時LINE請假，但去向學務處確認能否使用「學校官方點名系統／或警衛室登記專線」作為緊急當日補假管道（在合規安全前提下給出替代出口，卻得額外處理跨處室確認）。 |
| 故事獨特性 | 沒有誰想偷懶，寫出輪班制勞工家長與學校紙本安全流程之間真實的「疲勞時差」碰撞。 |
