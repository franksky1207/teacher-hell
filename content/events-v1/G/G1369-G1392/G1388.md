## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長近期白天時間餘裕非常充足（`11-2`），每天密切關注導師班群的每則訊息（`12-2`），但上個月因導師依規記了他孩子一次遲到而一直對導師心存不滿（`5-4`）。今天早上孩子出門忘記帶體育服（其實上午第二節的體育課已經結束了），這名有空的家長十一點半卻還是傳訊來彈性協商（`10-3`）：「老師我知道上午體育課過了、警衛室早上才收補送物品；但反正我有空，我中午十二點半送去警衛室讓孩子下午社團準備穿舒服一點好不好？你別再說我們不配合規定了喔！」 |
| 核心衝突 | 有空閒卻帶著舊怨的家長在早課結束後仍要求破例中午補送衣物，言語間隱隱帶著「看老師是不是故意刁難」的試探，而學校警衛室中午正值交接休息時段、原則上僅於早自習後代收急件。 |
| 導師困境 | 體諒家長有空跑一趟並為了化解上月舊怨而特地向警衛室打招呼幫忙收這袋中午衣物（避免家長覺得導師故意記仇刁難，卻讓警衛室同事抱怨非急件中午還要代收）；依警衛室中午不收非急件衣物的規定婉拒並請孩子穿原本制服即可（守住校規與警衛室休息，這名本就心存不滿的家長更認定導師是刻意針對他）。 |
| 故事獨特性 | 沒有誰真的急需用物，寫出帶著小怨氣的有空家長「上午體育課都上完了還硬要中午補送體育服」的親師試探角力。 |
