## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 任課同事疲倦到帶錯階段教材，平日號召力強，曾帶動幾位同事同意整理共用教具。他願提供可處分的舊收納盒，看到導師已把教具按年度分開後問為何不用按常用程度分；這樣自己最常拿錯的一箱仍要去最上層找。 |
| 核心衝突 | 資源不是制止拿錯，而是先讓同事承認誰最常拿錯。 |
| 導師困境 | 可用自願提供的盒子改常用組，承擔原分類要再核一次；或維持年度分類、另做清楚取用卡，較不費力但同事仍須跨層找。 |
| 故事獨特性 | 有影響力的人想先把方便藏在一份禮物裡，最後還是得說自己取用不便。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：subject_teacher這陣子累到連續兩次抱錯不同年級的教具進班。今天他捧著一個自己家裡清出來、還很乾淨的舊收納盒走進來，看我已經把共用架按年度一箱箱貼好，眉頭微皺地站住。
- **P02｜subject_teacher**：欸，這盒子我先拿來放這兒……可是你怎麼全按年度排啊？這樣我最常拿錯的那一箱還是得伸手去最上層找，為什麼不乾脆按常用程度分一分？
- **P03｜旁白**：他嘴上講的是大家取用方便，手裡的收納盒卻還沒放下來，顯然也是想替自己常拿錯那箱找個順手位置。
