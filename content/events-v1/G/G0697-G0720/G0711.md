## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生用家中平板學會逐格加字幕，分組放映前臨時失去投影，他堅持同組聽不清楚的同學也要看懂，把熟悉的逐格寫法改成手持字牌，不斷追催掌握最後版台詞的導師交稿。字牌發到最後才發現，導師口頭刪過的笑話還留在紙上。 |
| 核心衝突 | 臨時自救保存了作品，也讓一句原本不想正式講的話有了巨大字體。 |
| 導師困境 | 導師可自己拿錯版字牌承認改句，或請大家把最後一段即席改詞，承擔作品演不完。 |
| 故事獨特性 | 失去字幕設備的人又靠字幕取得比演員更響亮的聲音。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：投影一黑，他沒有等，拿家裡平板原檔裡學會的逐格寫法改成大字牌。「聽不清楚也要看得懂。」明亮教室裡，設備已由成人接手，他又跑來催你最後版台詞，前後問了好幾次。牌發到末張，那句你口頭刪過的笑話卻寫得特別大。你先停用錯版、把必要改句交清楚。他握著牌邊：「那這一段還要演嗎？不要又只改嘴巴。」
