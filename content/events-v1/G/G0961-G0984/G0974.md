## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生父母非常支持他參加各類學科競賽，平常只要他開口就會幫他找齊絕版原文書與參考資料（`7-1`）。他自己好勝心強（`4-1`）又對全班共學風氣很有責任感（`1-1`），考前大方把自己合法買來的一套絕版精裝題解借給班上同學輪流印（`11-4`），結果兩天後拿回來發現書脊被壓斷、裡面好幾頁還沾了早餐蛋餅油漬，他氣得眼眶泛紅跑來找導師。 |
| 核心衝突 | 大方分享自有學習資源的好學生遭受實質財產毀損，卻因為當初是集體輪流傳閱而找不到究竟是誰弄髒的。 |
| 導師困境 | 立刻在班上追查最後幾個經手的同學並要求共同賠買一本，偏偏這本書已經絕版根本買不到全新的；安慰他算了下次別借整本，這名原本熱心分享的學生以後只會把書鎖得緊緊的。 |
| 故事獨特性 | 沒有捐贈給學校，而是學生之間「慷慨借出自有絕版書」卻遇上沒公德心的傳閱者。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：學生翻到那頁解答，油漬正好透過最後一行。書脊張開，封面再也合不平。
- **P02｜學生**：我爸找三家舊書店才找到。說好只翻附錄那幾頁，怎麼早餐也放上來？
- **P03｜旁白**：你先將書留給物主保管，記下已知經手情況。他用面紙碰了碰紙角，又立刻縮手。
- **P04｜學生**：我想大家一起考好，不是要大家一起把它弄爛。現在每個人都說拿到就這樣。
- **P05｜旁白**：桌旁幾個同學望著書，誰也沒再提想借下一冊。
