## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 本班學生平常其實非常信任導師（`5-1`），這天卻在網路匿名校園版看到一張斷章取義的聊天截圖，指稱「某班導師偷偷把期末平時分數標準調高、故意想當人」（`8-3`）。學生信以為真後又氣又覺得被背叛（`2-1`），一時衝動（`1-2`）沒先問清楚就衝進辦公室當面質問：「老師我平常那麼相信你，為什麼網路上都在傳你故意要當掉大家？」 |
| 核心衝突 | 正因為平時信任導師，學生輕信網路假截圖後的憤怒與受傷感更為猛烈，當場在辦公室爆發衝突。 |
| 導師困境 | 立刻打開自己的計分表自證清白並叫他別亂信匿名版，等於被一張來源不明的網路截圖牽著鼻子走、還要向學生交代細節；嚴厲責備他沒查證就衝進辦公室咆哮，又會徹底打碎這個原本信任你的學生心裡的信賴感。 |
| 故事獨特性 | 不是敵對學生找碴，而是「平常最信任你的學生」因為被網路匿名截圖騙到而情緒決堤。 |
