## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生佩服導師用逐步提示教同學，見導師以最快同學的答案判全桌懂了，想到同桌剛才差點哭，又怕自己下輪也被這樣叫起來，氣得當場打斷。 |
| 核心衝突 | 專業肯定和當面發火同時成立，學生想知道那套好教法還肯不肯用到自己這桌。 |
| 導師困境 | 可從原例重教，代價是最快的一桌須等；或讓每桌先寫自己卡住的一處，導師再只教重疊處，但仍有人須個別補問。 |
| 故事獨特性 | 學生不是討厭導師在教，而是第一次對教不到自己這桌生氣。 |
