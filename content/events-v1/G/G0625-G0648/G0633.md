## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生有可調式家庭燈具，前夜疲倦時把燈調太亮拍下走道照，以為可以證明暗處照樣看得清。次日有人說照那張圖就可自己走近，他辨出照片的亮區遮掉背光中的階差，找導師一起標出「看不見的地方」。 |
| 核心衝突 | 圖可作光線教材，當作通行保證會讓人忽略眼睛適應。 |
| 導師困境 | 可撤回圖、由成人拍供比較的安全示意，或保留照片但註記拍攝條件。 |
| 故事獨特性 | 最亮的一張圖恰好隱藏了最多資訊。 |

### 開場
- **P01｜旁白與當場對話**：「不要照那張走，這裡根本看不見。」學生指著照片最黑的一角，平常最亮的地方反而白成一片。昨晚累了，家裡那盞可調燈一轉亮，他就以為走道都拍到了。今天有人拿照片當可以靠近的理由，他才發現階差消失在背光裡。你說：「先別照這張走，要看校方的通知。」他把筆放在照片旁：「我們可以把看不到的標出來，不用再去那裡吧？」
