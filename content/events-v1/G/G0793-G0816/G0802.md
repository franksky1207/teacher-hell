## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 器材室管理員住處長期安定，家中也有固定可收貨的地址。導師班遺失借用的轉接線後，他基於公物保管責任暫停該班借用，但查到原廠零件必須等貨；他願意協商用相容品替代，並提出先把自己家中閒置、確定可用的同型轉接線借給導師短期救急，等正式補件到貨再取回。導師卻發現這樣會讓學生以為遺失公物毫無後果。 |
| 核心衝突 | 管理員願意用自己的備品救急，卻不願把私人借用當成公物遺失已結案；學生可能混淆兩件事。 |
| 導師困境 | 接受短期私人借用並向學生交代公物仍待尋回或依校規處理，會增加管理與歸還責任；若先改用不用投影的教法，則須重整已準備的教材，但不讓私人援助掩蓋遺失責任。 |
| 故事獨特性 | 暫停公物借用的人反而願意借出自己的備品，私人救急與公物責任形成反差。 |
