## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生留意導師每天在走廊看練習，信同伴說老師因此已決定某人領先。真的被問到時他只肯找導師確認，怕自己先傳出去害人。 |
| 核心衝突 | 否認傳聞很快，直接說出誰傳又可能使同學轉而追究說話的人。 |
| 導師困境 | 可針對不存在的決定簡短澄清、只告知原受影響小組，或等正式練習回饋再處理。 |
| 故事獨特性 | 目光被當成判決，真正觀察導師的人最早發現不是。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「你只是看，不是說誰第一，對吧？」他到辦公室只敢問這一句。每天見你在走廊看練習，同伴便說某人已經被判領先，他原先也信了，輪到要轉告卻突然怕害人。你先明確確認沒有那個決定，不讓等待澄清變成流言繼續成立；實際練習回饋仍按原安排。他鬆口氣，又問：「那我要怎麼說，才不會大家又去找說的人？」他信你會先核實，沒有帶一串同學名字來。
