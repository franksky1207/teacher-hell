## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 私校高度重視零客訴，負責彙整家長意見與教師考核的行政職員十分焦慮高層追究（`2-2`），為保住自己部門在董事會前的安全過關（`4-2`），一直質疑導師處理轉學生適應問題時不夠圓融（`8-2`）。這天他直接拿著一張家長匿名意見單來正式問責導師（`12-4`）：「這張如果送進高層會影響你這學期續聘評比，你現在跟我解釋當初為什麼不照家長意思安撫？」 |
| 核心衝突 | 私校行政把「家長滿意度」與「教師續聘考核」直接掛鉤，逼導師在教育原則與職場飯碗間低頭。 |
| 導師困境 | 當場寫一份低姿態檢討說明讓職員好向上交差，雖然保住考核分數卻得承認自己原本正確的處置有錯；硬起來反駁匿名意見單斷章取義，這名怕被連累的職員恐怕真的照實上呈給高層。 |
| 故事獨特性 | 直擊私校特有的「家長意見即考核籌碼」制度壓力，沒有任何表單催辦，全是赤裸的職場權力現實。 |
