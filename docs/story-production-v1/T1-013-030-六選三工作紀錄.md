# T1-013～030｜六個普通候選與中選三個工作紀錄

> 本文件保存每篇六個普通候選短句、隨機中選編號與最終 A～D 位置；E 是獨立的情緒候選，不屬六選三。選項映射須與五區塊正式稿一致。此處為創作過程紀錄，**並非七項正式內容驗收、32 格逐格因果核准或機械檢查器的通過證據**。

## T1-013

1. 先讓兩人互說一句再決定
2. 開放自願上台並保留書面分享
3. 先讓每人用小卡交換認識
4. 讓每組輪流交換一個共同興趣
5. 先徵詢誰想為別人讀卡片
6. 只給願意的人一個自由發言時段

- **實際中選三個普通候選**：3、4、5
- **最終 A～D 映射**：A=5；B=4；C=E；D=3

## T1-014

1. 課後私下問他有沒有不舒服
2. 先把玩笑收回，承認說得不妥
3. 換成由大家自願說自己的第一印象
4. 開放寫匿名回饋給導師
5. 公開說明以後不猜測別人的表情
6. 讓當事人自行決定是否繼續分享

- **實際中選三個普通候選**：1、2、5
- **最終 A～D 映射**：A=5；B=E；C=1；D=2

## T1-015

1. 先讓全班各選可負擔的工作
2. 先請本人停下說明身體感受
3. 把重物改成兩人協力
4. 提供短暫喝水休息後再決定
5. 改由導師處理重箱並留輕工作
6. 讓兩人各自確認能做哪一項

- **實際中選三個普通候選**：2、4、5
- **最終 A～D 映射**：A=4；B=E；C=5；D=2

## T1-016

1. 先核對學生當時放在哪裡
2. 徵得同意後詢問任課教師
3. 陪學生整理要向科任說的話
4. 保留作業原稿並記錄交件說法
5. 請科任提供當堂收件說明
6. 協助確認合法補交方式

- **實際中選三個普通候選**：2、3、6
- **最終 A～D 映射**：A=6；B=3；C=2；D=E

## T1-017

1. 先向全班說明詢問窗口
2. 請他把不同科目的問題分類
3. 先處理同學說他在抱怨的誤會
4. 讓學生匿名列出三個最常見疑問
5. 先選今天必須弄清的事項
6. 請學生自行對照正式公告

- **實際中選三個普通候選**：2、3、4
- **最終 A～D 映射**：A=3；B=E；C=4；D=2

## T1-018

1. 先查清教材未到的原因
2. 請兩人說清楚能否繼續共用
3. 向科任詢問可行的暫行方式
4. 先提供可合法借用的備用教材
5. 釐清同桌借閱的時間界線
6. 讓缺書者先整理需要補學的頁面

- **實際中選三個普通候選**：2、3、6
- **最終 A～D 映射**：A=2；B=3；C=E；D=6

## T1-019

1. 先私下問他希望怎麼加入
2. 改採抽籤形成當次短期小組
3. 邀請各組自願開放一個位置
4. 把活動先改成短時間合作
5. 讓大家先選自己想負責的任務
6. 核對各組實際人數再協調

- **實際中選三個普通候選**：4、5、6
- **最終 A～D 映射**：A=6；B=5；C=E；D=4

## T1-020

1. 讓同學自由留下鼓勵，不安排工作
2. 向留紙條的人道謝並私下回覆
3. 說清楚哪些班務可以自願幫忙
4. 明確說老師的職責不交給學生
5. 示範可以自願協助的一件小事
6. 邀請自願寫班務改善建議

- **實際中選三個普通候選**：2、3、6
- **最終 A～D 映射**：A=2；B=6；C=E；D=3

## T1-021

1. 先問這套筆記實際怎麼幫助理解
2. 私下提醒評論者用提問代替嘲笑
3. 邀請有意願的人交換整理方法
4. 先讓學生試用原筆記一週再評估
5. 說明不同科目的筆記需求可能不同
6. 先停止拿筆記外觀比較

- **實際中選三個普通候選**：2、5、6
- **最終 A～D 映射**：A=E；B=6；C=2；D=5

## T1-022

1. 請通報者陪同到不受圍觀處確認
2. 先低聲確認本人是否需要立即協助
3. 說明有不適可私下告知的管道
4. 安排可接受的短暫休息並觀察
5. 請通報者只提供親眼看到的事實
6. 先請同學保持空間不圍觀

- **實際中選三個普通候選**：3、4、6
- **最終 A～D 映射**：A=3；B=4；C=6；D=E

## T1-023

1. 請他自己用正常稱呼再問一次
2. 徵得同意後向科任簡短說明
3. 先問科任是否真的聽見
4. 讓學生先練習一次正常提問
5. 在班級一般性介紹各科任稱呼
6. 不再放大舊事，先照常上課

- **實際中選三個普通候選**：1、5、6
- **最終 A～D 映射**：A=5；B=1；C=E；D=6

## T1-024

1. 只分享不具名的共同主題
2. 先停下所有展示並重新確認意願
3. 開放自願重寫公開版本
4. 讓每人重新勾選是否願意展示
5. 原稿保留給導師閱讀，不做任何展示
6. 讓學生可收回並改寫學習期待單

- **實際中選三個普通候選**：1、2、3
- **最終 A～D 映射**：A=E；B=1；C=2；D=3

## T1-025

1. 先讓他在校內地圖標出走過的路
2. 請有職責的處室人員確認服務位置
3. 改在適當時段帶他走一次
4. 請學生指出沿路可辨識的地標
5. 先電話確認處室今天是否受理
6. 詢問本人是否願由熟悉校園者帶路

## T1-026

1. 請全班討論如何描述學習困難
2. 提醒不要用自己的標準評斷別人
3. 私下詢問兩人對結果的真實感受
4. 讓兩名學生各自選一題整理錯因
5. 明確說明不必公開個人成績
6. 設不具名的提問紙條

## T1-027

1. 先和他整理一個可做的小目標
2. 說明保密界線並約定下次談話
3. 先問他真正擔心的是哪一部分
4. 提供學生自願使用的學習資源
5. 協助草擬對家長說明的內容但不送出
6. 允許先保留不公開的期待單

## T1-028

1. 先私下問分享者剛才的感受
2. 請願意的人說明掌聲的意思
3. 給全班多一種回饋選項
4. 先讓分享者選擇要不要繼續參與
5. 先不公開指認鼓掌者或分享者
6. 邀請大家自選回饋符號並說明用途

## T1-029

1. 私下問送水的人是否願意被公開提起
2. 請大家提出不花錢的互助辦法
3. 當面感謝並說明這只是個人心意
4. 先詢問收水者是否覺得需要回禮
5. 直接澄清班上沒有輪流付款規定
6. 讓學生自然分享而不設班級規範

- **實際中選三個普通候選**：1、2、3
- **最終 A～D 映射**：A=2；B=3；C=1；D=E

## T1-030

1. 協助全班訂出本週可行學習目標
2. 先拿出正式課務資料說明
3. 請兩人分別說出自己的擔憂
4. 依正式公告將課務資訊張貼教室
5. 邀請學生分開整理上課與適應時段
6. 先澄清出缺席規則不能靠傳聞

- **實際中選三個普通候選**：1、4、5
- **最終 A～D 映射**：A=4；B=E；C=1；D=5
