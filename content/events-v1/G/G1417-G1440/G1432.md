## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長對孩子教育責任感極高（`1-1`），平時也非常敬重導師的為人（`5-3`）與帶班專業（`8-1`）。最近他發現自己孩子放學後常跟班上某位熱愛線上遊戲的同學一起討論攻略，雖然那位同學在學校表現正常也沒帶壞別人，這名負責過頭的家長卻客氣有禮地來電介入導師的座位決策（`12-3`），不斷稱讚「老師我最信任你的專業，只是下週換座位時能不能悄悄幫個忙，把我們家孩子跟那位同學排遠一點？」 |
| 核心衝突 | 家長越是客氣敬重，導師越難一口回絕；但僅因單一家長的主觀擔憂就刻意拆散兩個沒有違規的好友，對另一位無辜學生不公平，也侵犯了座位專業權責。 |
| 導師困境 | 委婉但堅定地說明換座位須依視力、身高與學習均衡整體規劃，婉拒依指定名單拆散同學、只承諾會留意孩子上課專注度（守住教師專業權責與公平，卻讓這名敬重你的家長覺得有點失望）；還是順著下週例行輪換時依正常抽籤或視力原則自然調整位置、但不向家長承認是配合指定（表面維持了和氣也沒破例，但導師自己心裡清楚這多少受了家長介入的影響）。 |
| 故事獨特性 | 不是怒氣沖沖威脅投訴，而是用「極度客氣與高度專業肯定」包裝的私人指定座位介入，考驗導師的柔軟拒絕對策。 |
