## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師這週難得下班後約了幾位校外老朋友聚餐，原本導師對自己的時間分配很有判斷力（`3-2`），也打定主意週末要留給自己獨處充電（`4-3`）。偏偏在聚餐桌上導師社交主動帶動氣氛（`6-3`），聽見其中一名老友哭訴最近被主管刁難又失戀，導師同理心瞬間大爆發（`1-3`），脫口答應「那明天週六我陪你去北海岸散心一整天啦！」回到家洗完澡冷靜下來一看書桌（`3-2`），才想起自己原本預留週六要批改完的四十本週記還疊在那裡，自己也非常需要獨處喘口氣（`4-3`）。 |
| 核心衝突 | 導師私人生活裡對老友的義氣承諾，跟自己原本需要的獨處充電與下週一要交還的週記正面衝突。 |
| 導師困境 | 守住對老友的承諾、明天一早照約定陪他散心一整天，週記則留到週日晚上硬著頭皮熬夜趕完（顧全朋友情義與私人社交，但週末完全失去獨處空間且週日會累翻）；還是早上誠實傳訊跟老友商量把整天行程改成「中午吃頓飯聊兩個小時」，下午準時回家改週記並好好睡個午覺（兼顧朋友關心、自己獨處需求與工作進度，但重義氣的導師心裡還是有點怕朋友失落）。 |
| 故事獨特性 | 完全聚焦導師的校外私人友情與周末時間拉扯，沒有任何校內人物或教學說教。 |
