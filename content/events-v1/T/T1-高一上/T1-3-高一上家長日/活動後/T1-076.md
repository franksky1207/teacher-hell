## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長在家長日帶回一張供參考的時間安排範例，週末照表要求孩子執行；學生返校說與自己通勤及家庭作息不合。 |
| 核心衝突 | 範例可提供新方向，卻不能冒充所有家庭的硬性作息；導師也不能擅自介入家庭每小時安排。 |
| 導師困境 | 如何補清參考用途，讓家長與學生挑選可用部分，同時修正紙本上容易被當成命令的標示？ |
| 故事獨特性 | 是集中說明的範例被升格為個別指令，不重複課表版本或單次服裝許可。 |

## 5｜R1～R8共用結果、結算與4×8因果矩陣

### R1｜光把通勤畫上去讀書那格就整個不見

- **玩家可見結果**：「光把通勤畫上去，讀書那格就整個不見了。」學生算出衝突時段，準備用事實與家人討論。你沒有替他決定家裡的作息，卻讓原先只能說做不到的抱怨有了具體依據。學生自己在空白處寫下通勤時間，不再只把整張表推回家說不可能。對方是否同意尚未可知，至少討論有了真正的起點。
- **客觀後果**：學生算出衝突時段，準備用事實與家人討論。
- **合法底層增減**：student_a:3-4:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,1,0

### R2｜我媽以為是老師規定才不相信我

- **玩家可見結果**：「我媽以為是老師規定，才不相信我。」你澄清範例用途，家長則質問為何紙本沒註明。你承認標示不夠清楚，補上正式說明；家庭是否立刻採納調整，仍由雙方繼續商量。家長要求補一份清楚寫著『參考』的版本。你答應修正文案，不把錯誤理解全部歸咎於學生或家庭。
- **客觀後果**：你澄清範例用途，家長則質問為何紙本沒註明。
- **合法底層增減**：student_a:5-4:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,1,-1

### R3｜那我可不可以先把睡覺和搭車的時間

- **玩家可見結果**：「那我可不可以先把睡覺和搭車的時間標出來？」學生先圈出兩個無法任意壓縮的時段。家長沒有答應所有要求，卻願意從最難執行的部分談起，冰箱上的表第一次留出修改痕跡。他挑了最容易實行的一項先做，原先被塗紅的時段逐漸減少。孩子沒有得到完全自由，卻第一次能參與安排自己的時間。
- **客觀後果**：學生先圈出兩個無法任意壓縮的時段。
- **合法底層增減**：student_a:8-1:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,2,0,-1

### R4｜別人都做得到我是不是很差

- **玩家可見結果**：「別人都做得到，我是不是很差？」你說明範例不是評量標準，其他科目的正式要求也不會由它取代。他收起畫滿叉號的紙，仍有挫折，卻不再把一份示例當成能力判決。學生說最難受的是別人拿表格比較誰比較努力。你不替其他家庭評分，也不讓這張示例成為班級新的排名工具。
- **客觀後果**：你說明範例不是評量標準，其他科目的正式要求也不會由它取代。
- **合法底層增減**：student_a:9-2:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,0,-1,-1
