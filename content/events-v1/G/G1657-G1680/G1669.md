## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生同時做兩件班內成果，想以一件獲清楚肯定，敬重導師以往不把努力當禮貌獎。宣布結果時因只聽見自己被叫上台替別人鼓掌而火大。 |
| 核心衝突 | 他能接受輸，不想被老師拿來表演服輸。 |
| 導師困境 | 可改由導師自己帶掌聲且讓他離開舞台，可能被視為臨時偏袒；或改成各組自行說作品一個得意點，代價是拿第一的人少了原先的慶祝。 |
| 故事獨特性 | 被要求做得大方的人，真正需要的是一次不必表演的失落。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：班內非正式成果展示宣布名次時，我順口叫了同時做了兩件成果卻沒拿第一的student_a上台一起替冠軍組鼓掌。
- **P02｜旁白**：他平常最敬重我不亂發廉價安慰獎，這次卻在講台邊直接停住腳步、把剛拿在手裡的展示卡往桌上一放，聲音壓得低卻滿是火氣。
- **P03｜student_a**：老師，我輸了可以認，但你不要叫我上台表演替第二名還是第一名拍手給大家看好不好……

### 四個最終教師選項

| B | 我直接在台上公開講一句「做兩件本來就比做一件吃力，今天大家坐在位子上替所有做完的組鼓掌就好」，取消單獨點名上台。 | false | 將掌聲改為全班在座共同肯定所有完成作品組別，避免特定落選者被單獨點名陪襯。 | 臨時改規則雖然救了他的自尊，第一名組別卻覺得勝利感被稀釋了。 |
| C | 我聽到他那句「不要叫我表演服輸」瞬間被點醒，立刻擺手說「對不起是我叫錯了！輸贏不用演給別人看，你回座位坐著，掌聲我來帶就好」。 | true | 當場致歉並撤回上台要求，由導師獨自帶領掌聲尊重其真實失落。 | 公開向一個剛發火的學生說對不起，台下幾個同學面面相覷。 |
| D | 我改由我自己帶頭替得獎組鼓掌，直接讓student_a回自己座位休息，不強迫他站上台表演大方。 | false | 免除student_a上台陪襯鼓掌要求，由導師自行主持掌聲並尊重其失落情緒。 | 其他同學看到他中途直接走回座位，可能會以為老師在臨時偏袒他。 |
