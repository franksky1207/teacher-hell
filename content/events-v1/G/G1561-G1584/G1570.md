## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生好勝心極強（`4-1`），平常班務參與度也很高（`9-3`），非常信任導師（`5-1`），家裡爸媽對他的各項表現更是全力支持（`7-1`）。這週校內舉辦普通的班際環境海報或反菸毒宣導徵稿，這名學生自告奮勇代表班上畫主視覺（`9-3`），想拿全校第一（`4-1`）。今天早上他開開心心交出一張構圖與配色精準到像專業設計公司的作品，導師一問才發現，他爸媽昨晚特地請做設計的親戚幫他把線稿和配色全打好了（`7-1`），他還很天真地跟導師說：「老師我這麼信任你才老實講（`5-1`），只是親戚幫忙打個草稿應該沒關係吧？」 |
| 核心衝突 | 學生與家庭把「大人代打構圖」當成正常的資源支持，若交出去對其他自己畫的同學極不公平，若直接退件又會讓這名信任導師、老實招認的學生覺得誠實反而吃虧。 |
| 導師困境 | 肯定他願意對導師坦白這份信任，但明確退回這張有大人代筆的作品、請他用剩下課間自己從頭畫一張純學生手繪版交件（守住競賽公平與原創底線，但好勝又誠實的他當場急得眼眶紅）；還是只讓他參考那張作品的配色概念、整張畫面全部重新由他自己在教室裡畫過一遍給導師看過再交（兼顧原創要求與他的好勝心，卻得花額外課間盯著他重畫）。 |
| 故事獨特性 | 學生沒有想騙老師，反而是因為太信任導師而自己招出「全家動員請親戚打草稿」，考驗導師對誠實與公平的拿捏。 |
