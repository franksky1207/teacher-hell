## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生對身體健康與氣味刺激防護意識極高（`4-2`），平時十分信任導師（`5-1`），也非常肯定導師處理班上大小事的專業手腕（`8-1`），但個性極怕跟同班同學起衝突或害人沒面子（`6-4`）。最近這名學生只要坐在座位上就隱約頭暈想吐，觀察兩天才發現原來是鄰座那名剛開始注重外表的男同學天天噴極為濃烈的古龍水與止汗噴霧。怕講出來讓對方難堪翻臉的他，趁下課偷偷跑來辦公室求助：「老師我相信你最會處理這種事，你可不可以明天找個藉口幫我們這排『全班無聲抽籤微調座位』，但千萬別提到味道兩個字？」 |
| 核心衝突 | 信任導師又怕衝突的過敏學生把「個人氣味不適」交給導師用「無聲全排調位」來掩護，但全排無故被調動一定會引起其他同學抱怨，且不講明原因那名噴濃香水的同學也不會知道自己造成他人困擾。 |
| 導師困境 | 順著這名學生的請求隨便編個理由把整排座位重新抽籤調開，雖然不動聲色救了他遠離氣味刺激，其他原本坐得好好的同學肯定抗議「為什麼突然亂調我們這排」；坦白私下提醒那名愛乾淨噴香水的同學注意校內濃烈氣味分寸、別動整排座位，那名同學就算不確定是誰反映的，回座位後難免猜疑旁邊的人、氣氛照樣僵硬。 |
| 故事獨特性 | 結合青少年開始噴香水／止汗劑的校園日常與嗅覺敏感困擾，寫出「想躲開味道又怕傷同學自尊」的細膩青春期人際難題。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：學生在辦公室門邊深吸一口氣，說總算沒那股味道。必要的健康協助已接上，他仍握著書包帶不放。
- **P02｜student_a**：老師，你最會處理這種事了。明天就說抽籤，把整排調一調，不提味道，可以嗎？
- **P03｜導師**：不用等明天才避開刺激，但我不能假裝這是原本排好的抽籤。
- **P04｜student_a**：那他就知道是旁邊的人啊。我真的不想害他沒面子。
- **P05｜旁白**：鄰座的男生在走廊整衣領，學生聽見腳步聲，又往辦公室裡退了一步。
