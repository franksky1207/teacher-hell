| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這週校內任務負荷超重、腦袋快當機的導師，下班回到自己固定生活的社區超商領網購包裹，憑著太習慣的日常節奏一時衝動沒看手機簡訊，就用極為流暢篤定的溝通語氣向店員報出末三碼「一定昨天到了」，結果店員翻遍貨架十幾分鐘才發現導師自己記錯門市。 |
| 核心衝突 | 導師過度自信的職業級口條讓店員深信不疑，結果自己搞出一個排隊人龍都在等的大烏龍。 |
| 導師困境 | 當場笑著舉手向後面排隊的鄰居與店員大聲賠不是並趕緊結帳離開，超級丟臉；想再多買兩杯咖啡請店員賠罪，又怕耽誤後面結帳時間更尷尬。 |
| 故事獨特性 | 純粹寫老師下班累到腦袋打結的日常出糗，沒有任何說教或校務。 |
