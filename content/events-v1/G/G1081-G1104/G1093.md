## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長多年住在學校附近同一社區、對學區周邊巷弄車流變化十分熟悉（`7-4`）。這兩天他發現校門口後側馬路紅綠燈號誌剛調整過、行人綠燈秒數縮短而轉彎車變急，立刻在家長群組主動貼出實地路口觀察示警訊息（`8-4`），接著自己跑到學務處與導師室表態願意親自投入人力每週兩天來當路口導護志工（`11-3`），同時要求導師修改本班「放學排隊統一走後門過斑馬線」的既有集隊程序（`12-1`），改繞遠一點走前門天橋。 |
| 核心衝突 | 熟門熟路又願意出力當志工的家長對校外路口提出實質安全訴求，卻直接打亂學校原本各班分流的放學集隊動線。 |
| 導師困境 | 支持他的安全考量並幫他向學務處反映改道走天橋，原本走後門搭校車與接送的家長馬上抱怨多繞五分鐘路害接送打結；婉拒改動集隊路線只請同學過馬路走快一點，這名連導護志工都願意當的在地家長恐怕覺得學校拿學生安全開玩笑。 |
| 故事獨特性 | 家長不是在群組製造恐慌，而是拿出具體的「在地路口秒數變化」並親自投入志工人力要求改放學路線。 |
