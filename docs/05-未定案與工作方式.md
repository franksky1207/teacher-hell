## 文件管理原則
1. 只有使用者明確確認的選項才能更新至「已定案」。
2. 助理提供的範例、假設數值及推薦不等於使用者已同意。
3. 修改既有決策時需說明取代內容與原因，保留 Git 歷史。
4. 設計階段不自行啟用網站、部署、CI，也不寫遊戲程式。
5. 後續可在 ChatGPT 討論後更新相關文件，不要求每次重寫全部規格。

## 新一輪已確認設計（2026-10-29）
- **困境是絕對核心**，全面完美走向稀少；每個 3～8 單選決策**至少一個情緒選項**，但不設情緒必敗。
- **三年帶班中途不換導師**；畢業後才進行新一屆班級分配。不可自由挑班，可拒絕／異議／協商；校方依歷史與自身需求判斷並保留機率。
- 每屆**40名學生起始**，姓名與個性可合理微調；全員有實質困境及導師互動，出場比例與三年時點隨機，不採固定年度劇情覆蓋額度。
- 學生的互動不限於本班；學生、家長、同事、行政及跨班校外人物彼此互動，形成多方利益、責任、認知及制度困境。
- 年資不直接加好感；長期行動與結果影響能力、聲譽、家長口碑傳播及校方信任。好風評可提升自主性，但沒有保證、不是永久免責。
- **不介入也是一種行動**，可在合理情境下延後、拒絕、轉交等；世界持續進展，效果依情境及機率，非固定懲罰。
- **待技術細化**：40人故事覆蓋如何在不設逐年配額下保持自然、長期風評傳播及跨班人物資料如何節制成本、事件並行排程方式。
