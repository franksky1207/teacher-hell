## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生平時由家人幫忙顧家中店面，才擠得出三分鐘在導師面前把口頭報告練一遍，結果報告開場像街坊叫賣，講到第三句全班都在笑。 |
| 核心衝突 | 熟悉的生活節奏能讓報告更自然，但笑聲會把本人轉回不敢使用原聲的狀態。 |
| 導師困境 | 可示範如何保留節奏而轉變情境、請本人再試一種開頭，或把笑聲先停在全班都知道的安全範圍。 |
| 故事獨特性 | 生活裡會的說話方式，搬進教室竟同時成為強項和笑點。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：學生連講三句，節奏像街坊叫賣，全班笑起來。他靠家人幫顧店，才擠出短短時間練過，準備很快就用上，現在卻想改念得像課本。你止住取笑個人生活，沒問店在哪。這是一般課堂練習，他還肯照建議先試一段，但才開口便看台下。「這樣真的不行喔？」他把下一句唸得特別慢，自己也卡住，翻了兩次稿才找到位置。
