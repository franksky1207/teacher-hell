## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 今天下班時間餘裕充足（`11-2`），經濟寬裕（`7-3`）的導師順路去逛社區黃昏手作市集買了不少熟食與水果。離開攤位走遠了兩條街後，頭腦條理分明（`3-1`）的導師心算一對帳，才發現那位忙得手忙腳亂的老闆爺爺剛才少算了一盒兩百元——偏偏此時天空剛好飄起細雨、導師兩手都提滿重袋子，但出於對辛苦擺攤長輩的同理心（`1-3`），想到兩百元對小攤商不是小數目，腳步立刻停在路口猶豫。 |
| 核心衝突 | 完全離開教師身分的下班私人散步裡，導師面對「提著重物冒雨走回頭兩條街還兩百元」與「心裡過意不去卻懶得折返」的良心小考驗。 |
| 導師困境 | 咬牙提著兩大袋東西冒著細雨走回頭兩條街把兩百元親手補還給爺爺（當場結清帳目完全對得起良心與同理心，但回到家全身微濕又手臂痠痛）；先拍下攤位招牌與編號或記下市集主辦聯絡方式、決定明天一早精神好時再專程或託主辦聯繫把確切這兩百元補還到位（避免今晚提重物淋雨折返，心裡卻還是擔心老闆今晚收攤對帳發現少兩百元會先懊惱一晚）。 |
| 故事獨特性 | 完全不涉及任何學校與師生人物，寫出普通成年人在黃昏市集走遠後才心算出「老闆少收兩百元」時最真實的善良猶豫。 |

### 開場
- **P01｜旁白**：走遠兩條街，我才把那盒兩百元算進去。袋子兩手都滿，雨落在手背上。
- **P02｜導師**：少算了。
- **P03｜旁白**：老闆剛才一邊找錢一邊裝袋，連自己的晚飯都擱在旁邊。我今晚其實有空，也不差這兩百，偏偏現在一想到提回頭，手指就更酸。
- **P04｜旁白**：路口有騎樓，我先站進去看收據。攤位的名字印得很小，卻還看得清楚。
