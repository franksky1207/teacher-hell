## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生這學期沒參加校隊或晚間社團，放學後的課餘時間餘裕充足（`11-2`），平時對導師非常信任（`5-1`），但越接近本週單元小考複習越對成績感到焦慮（`2-2`）。他在班上極有號召力（`6-1`），今天普通上課日依規定準時放學離校後，沒先問過導師就在班群一呼百應揪了十幾個同樣焦慮的同學去學校附近咖啡廳一起刷題，還信心滿滿地跟大家打包票：「老師平常這麼信任我們，我們等下把不會的題目拍照傳班群，老師今晚八點半一定會在線上幫我們解題！」結果晚上八點半導師手機瞬間湧入三十幾張題目照片與催問訊息。 |
| 核心衝突 | 太信任導師會挺學生的焦慮小領袖於普通上課日放學後先斬後奏發起校外讀書會，並替導師開出「今晚線上免費解題」支票，直接把導師下班後的私人休息時間捲進無預警加班。 |
| 導師困境 | 咬牙打開手機花兩個小時把三十幾題一一寫詳解傳回群組，不僅今晚下班休息全泡湯，明天一早還得疲憊進班上課，之後大家恐怕把「老師晚上隨傳隨解」當成常態；直接回訊說下班時段不處理線上解題、請明天到校再問，這名原本滿心相信老師會支持他們努力讀書的學生當場在十幾個同學面前下不了台。 |
| 故事獨特性 | 寫出普通上課日放學離校後，學生在附近咖啡廳靠「對老師的過度信任」先斬後奏開出當晚夜間線上解題支票的下班焦慮與荒謬感。 |

### 開場
