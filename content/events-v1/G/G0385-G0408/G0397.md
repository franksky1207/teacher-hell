## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 值日學生同情一位手上動作慢的同伴，怕導師不肯定自己的善意，趁同伴轉身把那區全部掃完。導師稱讚他「很會救場」，同伴卻氣得把未掃的畚斗推還，學生也火了，覺得自己被說成故意搶功。 |
| 核心衝突 | 接受好意與保有自己完成工作的資格都重要，把區域立即掃完也可能奪走後者。 |
| 導師困境 | 可請原值日生自行決定還要完成哪一步、承認教師獎錯事，或依當日需要先結束掃除並留另一回給他自己做。 |
| 故事獨特性 | 衝突來自搶做他人的班務，表面無私也能使被幫的人失去位置。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：畚斗被放回牆邊，撞得掃把一起滑下來。「我只是看他還沒來，先幫他掃啊。」學生蹲下去撿，聲音比剛才大。另一個人指著已經空掉的區域：「那我現在要做什麼？等你再被誇一次？」你剛才那句「還好有人救場」還沒有人忘記。先掃的人抬頭看你，像是等你說他沒有做錯；原本負責的人站著沒動，手裡還握著一根掃把。
