## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生一度相信網上轉傳的無障礙地圖，想讓導師發給外來訪客，後來實地比對才判出路口斜坡畫在另一側。他原堅持整張替換，聽導師說訪客已拿到紙，改提由接待者在轉角補指引。 |
| 核心衝突 | 重印看起來乾淨，卻補不到已經發出的那份。 |
| 導師困境 | 先聯絡校方接待並更換錯圖，損失準備時間；或在校方同意下把正確走向交現場接待人員，原圖暫停發放，但訪客仍須多問一次。 |
| 故事獨特性 | 現場最有用的不是最漂亮的地圖，而是有人知道錯在哪一個轉角。 |
