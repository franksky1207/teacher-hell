## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師這週校務負荷大到爆表，但內心很想在主管與家長眼中證明自己「帶班一樣無懈可擊」，於是行政端一宣布教室佈置觀摩，他立刻發揮超強執行力，不假手他人自己留校剪貼海報搞班務到晚上八點，結果隔天早自習累到神智不清，當場把班長叫成別班的名字、連聯絡簿重點都講反。 |
| 核心衝突 | 導師為了博取「完美班經」的外部認可而親自包辦所有班務，反而拖垮了隔天最基本的教學現場。 |
| 導師困境 | 笑著自嘲昨晚剪海報太拚、順勢把剩下收尾分給學生做，等於親手拆掉自己昨晚想撐出來的「完美導師」形象；硬撐著裝作沒叫錯名字繼續往下講，全班一臉困惑反而沒人敢問。 |
| 故事獨特性 | 導師自己製造的困境——把「班級經營」當成個人手工藝比賽，最後累倒在講台上。 |
