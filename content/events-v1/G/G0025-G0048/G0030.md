## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一名學生揉著眼睛交出加做的習題，被同學問昨晚念到幾點，原先是苦笑，轉眼變成比誰最晚睡。 |
| 核心衝突 | 努力有值得被看見的部分，集體把少睡當作勳章之後，學生不好意思承認自己需要休息。 |
| 導師困境 | 導師可先回應學生真正卡住的學習處、把加練改成限時示範，或私下追問睡眠是否已影響生活，避免公開比較誰更辛苦。 |
| 故事獨特性 | 同學用玩笑把疲倦變成競賽，導師要把值得肯定的努力和耗損拆開。 |

### 開場
- **P01｜旁白與當場對話**：「我兩點。」「那還好，我三點半。」原本一句苦笑，轉眼成了教室裡的紀錄挑戰。帶頭的學生把加做題本交來，連熟悉的一步都算錯，卻急著指出多寫了幾頁。他旁邊又有人說今晚也要追上。你停止少睡排名，確認沒有需即時照護的不適，先讓疲倦的學生休息。「我不是想少做，」他說，「只是每科都還有。」你要留下努力被看見的地方，又不能讓睡得少變成班級的新獎狀。
