## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 開早點攤多年、生活與營業作息極度穩定的本班家長，每天清晨四點起床備料累到快虛脫，但他非常敬重導師的為人。因為孩子日前在班上與同學起衝突被記警告，這位父親連續三天早上七點半送完貨便強撐著疲憊身軀守在警衛室外，客氣卻堅定地催問進度：「老師我敬重你，但你說要找對方家長談的和解到底約到哪天？」 |
| 核心衝突 | 敬重導師的疲憊家長被自己固定早市作息綁死，每天只能趁交班空檔在門口盯著導師問和解進度。 |
| 導師困境 | 為了讓他早點回去補眠而答應今天先跟對方家長隨便約個時間，其實對方家長根本還沒點頭；請他先回家等電話，明天早上七點半這位撐著眼皮的父親還是會準時出現在校門口。 |
| 故事獨特性 | 沒有任何行政表單，把早餐業家長的固定作息、疲勞與對親師約定的執著寫成校門口的無聲壓力。 |
