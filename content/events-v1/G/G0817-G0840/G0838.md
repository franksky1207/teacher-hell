## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生父母每天晚上都誇他「當老師小幫手最能幹」、還會固定問他今天幫老師收完東西沒，在家庭高度支持與鼓勵下他更把「成為最可靠幫手」當成證明自己的來源。主動接下聯絡簿與回條班務後，只要導師還沒批改完，他每節下課就跑來追問，甚至連導師去洗手間都在走廊等著問「老師你改好了嗎」。 |
| 核心衝突 | 學生出於家庭期許與渴求認同的極致盡責，變成了讓導師連喘口氣都沒辦法的緊迫盯人。 |
| 導師困境 | 直接叫他沒事別一直來問，怕重傷這個被家裡誇獎、又依賴老師肯定的孩子自尊；每次都立刻停下手邊的事先滿足他的進度表，導師自己的節奏全被他牽著走。 |
| 故事獨特性 | 平常都是老師追著學生催交作業，這回反過來是幹部追著老師催批改。 |
