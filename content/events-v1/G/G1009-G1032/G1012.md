## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位資深本班任課教師最近被多班課務壓得疲勞不堪（`2-3`），憑多年教學經驗判斷導師班最近幾週晚自習成效不佳（`3-2`），其實心裡一直質疑導師只讓學生在教室自己背單字、沒做系統題型練習太沒效率（`8-2`）。這天他直接抱了一疊自己多年合法編寫、擁有完整著作權的自用複習題本原稿塞給導師（`11-4`）：「我最近累到沒空進班盯，但我看你們班這樣自習不行，這套我自己編的你拿去印給他們寫。」 |
| 核心衝突 | 疲憊的資深同事出於好意無償提供自有題本，同時卻毫不留情地否定導師原有的晚自習安排。 |
| 導師困境 | 立刻照他的建議拿去印發給全班在晚自習寫，既省下出題時間又得實惠，但等於默認自己原本的自習規劃真的沒用；婉拒這份心意並維持學生自主複習，下回段考成績沒起色時這位同事多半拿這件事數落回來。 |
| 故事獨特性 | 沒有誰想偷懶，純粹是資深同事用「合法自編教材贈與」來實質否定導師的自習設計。 |

- **P02｜同事**：你們晚自習那樣背，沒效率。我沒力氣再進班盯，這個你拿去用。
