## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 班會前，一名熟悉付費設計軟體又熱心班務的學生拿自己的私人投票網站演示動畫，用假票一路把畫面刷到爆滿。同學認熟他替班上做工具，跟著起鬨要用來選幹部。導師問到後台才知道只有製作者的個人帳號可存取，也未確認是否記錄身分或能防重投。 |
| 核心衝突 | 全班一面倒喜歡新潮有趣的數位投票，導師若直接禁用顯得古板，若全面採用則會讓班級正式表決的公信力綁在單一學生個人帳號上。 |
| 導師困境 | 正式議案照既有規則辦理，例如合規的紙本無記名表決。知悉私人頁面的資料流向與投票限制前，不讓全班掃碼送資料。導師可在班務結束後用離線假票展示動畫，讓製作者保住表演機會但沒有真實票數；也可取消當天演示，把時間留給議案，邀他把版面另做成不收資料的展示。若學校已有合規數位表決工具，才由權責人員確認匿名、存取與防重複投票後使用；開後台或安排監票員無法補足這些條件。 |
| 故事獨特性 | 沒有惡意作票，寫出高中班級裡「炫技網頁太好玩、全班一窩蜂想把正式民主程序遊戲化」的青春現場。 |
