## 1. 產出與不可違反規格

- **40 位美術原型、每人 8 套**，合計預計 **320 張 PNG**；男生 `student-001～020`、女生 `student-021～040`。每人每套只交付 **一張真正透明 RGBA PNG**，內含 **3 欄 × 2 列、六格完整人物立繪**；**不另製 calm 母圖、局部臉部貼片、定位 JSON 或六張分圖**。
- **大腿立繪是產圖前必須明確指定的主要構圖**：從頭部至大腿附近，必須看得到足以辨識的褲裝／裙裝，不是胸像或腰部以上半身像，也不要求鞋子或全身。六格人物尺度、頭身比例與畫面位置相近；不同表情可有自然、甚至明顯的手勢／姿勢變化，但不能因姿勢導致畫面截斷或比例失控。
- 六格順序固定：上排 **calm 平靜｜happy 開心｜angry 生氣**；下排 **sad 難過｜surprised 驚訝｜embarrassed 害羞**。
- **人物以外全透明**：不准用純色／棋盤格冒充透明，不要背景、場景、邊框、格線、文字、規劃圖、資訊圖、標籤或水印。**全部新製素材固定 1536×2304 px，每格 512×1152 px**；3×2 等分裁切，不得因角色或服裝改變畫布尺寸。人物體型與身高感可自然不同，但六格取景尺度、頭身比例及出場位置須協調。產圖工具若無法直接輸出此尺寸，應於交付前調整為指定像素並檢查品質、透明度與裁切，不得把不符尺寸的圖當作完成品。
- **同一人同套六格**：臉型、五官、膚色、體型／年齡感、服裝款式與配件設定一致。配件可完全沒有；如有，同款同色與持有狀態須連貫，可隨姿勢自然移動，不得憑空消失或換款。不同套服裝可換髮型整理、裝扮與配件，只要辨識得出同一人。
- **畫風統一、40 人有整體辨識度**：外貌名冊僅供彈性參考，不綁姓名、座號、性格或故事，也不是逐項驗收清單。與已核准其他學生過於相似才調整；不為單一髮絲、眼形或文字特徵不符返工。

## 3. 唯一製作順序

1. **第一階段僅製 40 人夏季制服六圖**：先男生 001→020，再女生 021→040。每位與先前已核准的人物比對整體外貌，由使用者核准後，該張夏季制服 PNG 才成為此人**唯一外貌基準**；40 人都核准前，不開始第二階段。
2. **第二階段逐人補七套**：從 001 起，依上表第 2～8 套連續完成後，再換 002，直到 040。**每套都直接參照該人第一階段核准的夏季制服原始六圖**，絕不逐套傳遞外貌，也不誤用別人的圖。
3. 美術編號**不等於座號或姓名**。新存檔內男女各 20 張原型應於同性別組內不重複隨機配對 NPC，配對固定三年；**僅為設計規則，未因本次文件修改而實作程式**。

## 4. 每次產圖必須執行：先確認 → 產圖 → 自檢 → 修正 → 交付

1. **產圖前先核對**：正確學生及其外貌基準、服裝款式、**六格全是頭至大腿構圖**、固定 1536×2304 px、3×2 表情順序、真正透明、同套服裝／配件一致。將這些明確放進製圖要求，**不是產出錯誤的半身圖後才想到大腿規格**。
2. **產後自行檢查整張與六格**：固定像素與每格尺寸、大腿範圍是否真正呈現、頭手髮絲有無意外截斷、比例位置、六種表情、同人同衣同配件、校服配色、Alpha 透明、嚴重五官／肢體破圖及裁切可用性。不可只看生成成功就當作合格；技術檢查不能取代目視。
3. **重大不合格就立即自行修正或重新產圖，再檢查，不得因首次失敗停住或要求使用者再次說「繼續」**。例如只畫到腰部、缺少大腿、假透明、六格錯序、明顯變臉／換衣、嚴重破圖。**重做前針對根因修正提示／構圖方式，不原封不動重複同一失敗操作**；能局部修就不必全部重畫。
4. **寬鬆通過**：正常遊玩可用、整體自然可辨識即可交付；細微色差、髮絲、皺褶、小配件細節與名冊略有不同，不是重製理由。**不為像素完美無限返工**。若工具確實不可用、持續技術失敗或必須由使用者決定設計方向，才停止並清楚交代已做的檢查與阻礙；不得謊稱已完成。此規則不保證工具一定能成功，也不要求無限制重試。
5. **交付僅一張正式命名 PNG 的實際可下載連結＋該學生 GitHub 資料夾網址**；不提供 ZIP／分圖／新 JSON，也不新增資料夾。下載檔確實存在才能提供連結。

## 5. 檔案、預覽與核准界線

- 目錄沿用 `web/assets/characters/students/student-XXX/`；檔名固定 `student-XXX-full-sheet-{outfit}.png`（例如 `student-001-full-sheet-uniform-summer.png`）。**舊 `base-*`、`face-sheet-*` PNG／JSON 保留，不覆蓋或刪除**。
- 使用者自行上傳 GitHub 後再核對實際 PNG。**上傳不等於准許接入預覽**；只有使用者明確下令，才修改或部署既有網站。
- **唯一給使用者的預覽網址**：https://franksky1207.github.io/teacher-hell/preview/ 。使用原站「完整六圖測試」入口、學生 001～040 與八套服裝下拉選單、六個表情按鈕；缺圖顯示未製作，不用雙圖冒充。**不得提供版本參數、追蹤參數、另開測試網址**；部署時確認 `gh-pages:preview/index.html` 真正載入對應新模組與素材。
- 六格是**劇情觸發的瞬間表情／姿勢切換**，不是連續動畫；**不交叉淡化**，避免重影。維持角色出場位置、尺度合理。
- 進度簿須區分：**候選產生及自檢 → 使用者核准夏季外貌基準 → GitHub 已上傳 → 預覽已接入 → 使用者實際預覽核准六表情 → 正式劇情接線測試**。各階段不互相冒充，**使用者未核准不能標記新模式通過**。
- 目前 `student-001` 已有**待重製的完整六圖夏季制服測試候選**，接入預覽不代表正式核准；新版上傳時可直接替換，不另安排搬移舊候選。舊雙圖已核准四套（夏冬制服、夏冬運動服）及其預覽功能仍保留。**此次只修訂 SOP，不產圖、不改程式、不部署**。
