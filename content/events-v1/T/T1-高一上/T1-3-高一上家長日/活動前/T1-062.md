## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生知道照顧者將出席首次正式家長日，請導師安排對方坐到最後面，免得每次發言都成為焦點；家長卻覺得前排才聽得清楚。 |
| 核心衝突 | 尊重學生不想被代言的界線與照顧者實際參與需求並存，座位不能被當成限制合法發言的工具。 |
| 導師困境 | 如何會前先了解兩方需求，調整共同發言與個別會談方式，而不是暗中把家長藏到後排？ |
| 故事獨特性 | 不重複首池座位視線；此處是學生對家庭公開代表自己的不安。 |

### 開場（依自然閱讀長度分頁）

- **P01｜旁白**：{{student_a.name}}在午休時攔住你，問星期六能不能讓照顧者坐在最後一排，也不要叫他公開談自己的生活。
- **P02｜旁白**：原來學生擔心家裡的事情被提起，可家長回條卻特別註明：「我想坐前面才聽得清楚。」
- **P03｜旁白**：你發現真正的問題不是誰坐哪裡，而是兩個人對發言和參與有不同期待。
