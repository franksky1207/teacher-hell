## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位單親且兼負家計與照顧重擔的家長（`7-2`），平時其實非常認可導師的帶班專業（`8-1`），也總要求自己就算再忙也不能在老師面前被看輕，內心極渴望獲得「單親依然把孩子教得很好」的肯定（`4-4`）。昨天孩子少交了一次週記，導師只是照例在聯絡簿寫了一句「請家長協助留意孩子睡前作業完成狀況」，這句無心提醒卻狠狠刺中了家長敏感的自尊，家長當場火大（`2-1`）打電話來：「老師我這麼認可你的專業才全聽你的，但我每天忙到半夜還盯功課，你寫這句是覺得我沒在盡責嗎？」 |
| 核心衝突 | 導師例行性的親師聯絡用語意外觸發了弱勢單親家長深層的「怕被貼上失職標籤」的自尊防衛與怒火。 |
| 導師困境 | 立刻誠懇向家長致歉解釋自己只是純粹提醒作業漏交、絕對肯定家長平日辛苦把孩子教得很好，雖然能撫平對方傷痛卻得小心翼翼哄著講話；堅持自己只是照班務常規記錄事實、沒有指責之意，這名又累又敏銳的家長恐怕從此認定導師在心裡看不起單親家庭。 |
| 故事獨特性 | 沒有誰提出無理要求，寫出親師溝通裡「導師一句尋常例行提醒，如何無意間踩痛辛苦家庭最敏感的自尊」。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜家長**：我每天忙到半夜還看，你那句是不是說我沒盡責？
- **P02｜旁白**：你翻到『請協助留意睡前作業』，先說清楚不是在評他的家庭，也照實接續孩子少交的支持。家長卻還停在『睡前』。
- **P03｜家長**：我那麼認可你，孩子的事都配合。你知道我睡前還有多少事？
- **P04｜旁白**：你沒有列他的辛苦當稱讚，電話另一端也沒有安靜。他問能不能別再用一樣的句子，把整晚都塞到一個人身上。筆尖在空白聯絡簿停著，下一次提醒還沒寫。
