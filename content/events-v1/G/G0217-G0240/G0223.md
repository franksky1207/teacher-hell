## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 班務學生提議在平日替同學慶生，家境使他只能出一半，別人聽到便笑說由他別買。 |
| 核心衝突 | 他生氣的是先被拉去揪團，再被當成付不起的人。 |
| 導師困境 | 可取消集資、讓慶祝改不花錢，或請主辦者自行承擔可合法支出的版本。 |
| 故事獨特性 | 不肯退出的人未必想買，他想留在大家一起祝福的場合。 |

### 開場
- **P01｜旁白與當場對話**：「那你就不要買啊。」笑聲剛過，他把慶生安排單往桌上一放：「是你們先叫我揪的。」他主動聯絡同學，也真的負責幾項班務；家裡能給的錢只有一半，不是想趁機退出祝福。「不要拿這個笑人。」你止住聲音，「這筆不是一定得出，班費也不能沒照規定就拿來補。」蛋糕還沒訂，錢尚未收。他站在原地，沒有把自己的名字劃掉。
