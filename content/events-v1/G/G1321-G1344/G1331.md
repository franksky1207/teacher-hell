## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長平日全家支持他投入班級聯絡事務（`7-1`），但這週連續忙家裡與工作累到臉色蒼白（`2-3`），內心仍非常渴望在導師與其他家長眼中獲得「最專業盡責」的肯定（`4-4`）。今天原本只是四位家長約好放學後在會談室花十五分鐘簽領營隊文件的小時段，這名累壞的家長卻沒先跟導師對過，便直接介入會談議程決策（`12-3`），自己印了十份包含「晚自習管教、手機罰則、補考標準」三大爭議項目的「班級改善提案討論單」，一進門就興沖沖發給在座家長說：「我趁昨晚趕出來的！既然大家都來了，我們順便開個四十五分鐘座談討論一下吧！」 |
| 核心衝突 | 疲憊又渴望被誇讚的熱心家長未經同意擅自替短時簽領會加開爭議座談議程，讓原本只留十五分鐘、後面還有校務要處理的導師在現場與其他家長面前進退兩難。 |
| 導師困境 | 溫和但明確說明今天僅排定十五分鐘簽領文件、不適合臨時進入三大爭議議題討論，請大家先收起討論單改日班親會再議（守住時間與議程秩序，但這名熬夜趕印表單想表現得最稱職的疲憊家長當場下不了台）；勉強擠出時間先聽在座幾位家長就這份單子聊個半小時再說（接住這名累壞家長的苦心，卻直接把原本十五分鐘的領件流程拖成四十五分鐘拉鋸、害導師後續整晚工作大塞車）。 |
| 故事獨特性 | 完全不涉及任何飲食茶點，寫出熬夜趕出十份提案單的熱心家長，如何在十五分鐘領件小聚裡瞬間把現場變成大型辯論會。 |
