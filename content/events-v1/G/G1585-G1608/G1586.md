## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長對孩子學業有極高的成就期待（`4-1`），全家也很支持孩子衝刺升學（`7-1`），平時對導師的班級規範非常認同（`9-1`）。偏偏這名家長最近公司專案多到工作負荷爆表（`11-1`），晚上根本沒力氣自己盯孩子複習。今天他打電話來，客氣地拜託導師：「老師我最認同你的嚴格規範（`9-1`），我們家也全力支持（`7-1`），只是我最近真的忙到翻掉（`11-1`），你能不能每週五幫我孩子另外多出一張進階加強卷讓他帶回家寫、週一再順便幫我改一下？（`4-1`）」 |
| 核心衝突 | 家長出於對導師的認同與自身過勞，把「額外家教式出題與批改」當成導師可順便提供的服務，接下會累死自己且對其他學生不公。 |
| 導師困境 | 溫和但明確地婉拒為單一學生客製額外出題與批改，改推薦他幾本市售優良參考書或校內現有的共編題庫讓孩子自練（守住教師合理工時與公平性，但焦頭爛額的家長有點無助）；還是婉拒額外出卷批改、但從自己手邊現有的舊題庫抽出一份附詳解的練習卷讓他帶回家由家人對答案（兼顧公平與家長的急迫需求，卻仍得提醒自己下不為例）。 |
| 故事獨特性 | 家長沒有抱怨學校教不好，而是因為自己加班過勞又太信任私校導師，誠懇提出「順便幫我一對一加練」的超載請求。 |
