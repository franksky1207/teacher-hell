## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 校內輔導或特教助理人員因家中長輩需定時照顧而只排半天班（`7-2`），反而在職的空檔時間較為充裕（`11-2`）。他對工作極負責任（`1-1`），也非常肯定導師帶班的細心專業（`8-1`），這天趁空檔主動把導師班幾位需關懷學生的日常觀察整理成一份詳細報告送來，導師翻開卻發現裡面夾雜了不少他自己聽來的「聽說他爸媽好像在鬧分居」等未經證實家庭隱私猜測。 |
| 核心衝突 | 盡責且有空檔的支援同仁出於好意幫導師整理資料，卻把主觀八卦當成正式輔導觀察寫進書面文件。 |
| 導師困境 | 直接把報告退回並當面指出他寫了太多未證實隱私，怕傷了這位既負責又認可你的同仁熱忱；默默收進抽屜當作沒看過不歸檔，萬一之後輔導室或主管調閱紀錄時又說不清為何沒交接。 |
| 故事獨特性 | 聚焦校內輔助人力「熱心過度、分不清客觀觀察與主觀猜測」的紀錄風險。 |
