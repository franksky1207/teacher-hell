## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生父母平常很鼓勵他參與班級公共事務與公民表達，還陪他練習過簡報與溝通技巧（`7-1`）。他自己口條極有條理（`3-1`）、在班上頗有號召力（`6-1`）。這週校內學生會發起「調整合作社販售品項與社團借場地規則」校內連署，他用極具說服力的講解帶動全班三分之二同學簽名，接著抱著連署書跑來找導師協調（`10-4`）：「老師我們都照學生會規定連署過半了，這週班會能不能借十分鐘讓我上台報告並請全班表決我們班的共同提案？」 |
| 核心衝突 | 受家庭鼓勵練習公民參與的學生把正式連署程序搬進班會，卻讓導師夾在「支持學生自治」與「校方不樂見導師班變成校務倡議中心」之間。 |
| 導師困境 | 同意他在班會上台宣講並表決班級共同提案，學務處主管知道後恐怕關切導師為何放任班會時間變成跨班連署動員；以班會原訂議程已滿婉拒、請他改利用下課時間私下收件，這名口條清晰又嚴守程序的學生難免質疑連老師都在阻擋合法自治。 |
| 故事獨特性 | 沒有違規抗爭，呈現高中生把完整的民主連署與溝通能力用在班會協調上時，私校導師面對的真實制度壓力。 |
