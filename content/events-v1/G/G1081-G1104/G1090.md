## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位單親輪班、平時常半夜才回家（`7-2`）的家長，工作上天天使用數位系統而對線上工具上手極快（`3-4`）。他一直質疑學校還要求家長每天在紙本聯絡簿手寫簽名既沒效率又常漏看（`8-2`），這天直接找進導師室試圖介入班級聯絡方式決策（`12-3`）：「老師我都幫你試算過了，用 Google 表單或線上勾選一分鐘就能搞定，我家孩子書包常常忘記拿出來，以後我們家改線上簽名就好、別再拿紙本聯絡簿記他沒簽好不好？」 |
| 核心衝突 | 數位適應力強的忙碌家長用「合理效率」要求個別豁免紙本簽名，撞上學校統一保留紙本親師簽核紀錄的常規。 |
| 導師困境 | 破例答應只有他這一家改用線上表單確認、其他三十九人照舊簽紙本，導師每天得同時對兩套系統、還容易被其他家長要求比照；堅持全班統一使用學校發的紙本聯絡簿，這名半夜才下班的輪班家長恐怕覺得學校硬要逼死忙碌父母。 |
| 故事獨特性 | 沒有誰反對科技，呈現「數位化時代的親師聯絡」在面對傳統紙本聯絡簿制度時的真實斷層。 |

- **P02｜家長**：我半夜回家他睡了，早上他走我又睡了。你看，一分鐘，何必每天寫沒簽？
- **P03｜導師**：我不會把你輪班當孩子不配合。可是這個不能直接收全班資料。
