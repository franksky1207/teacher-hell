## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生午休剩不到五分鐘，很開心自己終於把教科書的一段改成簡短白話，急著主動傳給同桌，又留言希望導師看見他這次做得對。別組把它當成正式講義，依照他漏寫的一句開始答題。 |
| 核心衝突 | 教師若急著稱讚清楚，可能讓錯誤走得更遠；若只說錯，學生會把一次可修正的嘗試當成公開丟臉。 |
| 導師困境 | 可先停用並讓本人補清關鍵句、由導師用同一例子示範如何標出試稿，或暫只留給已看過的人更正。 |
| 故事獨特性 | 想被肯定的對象是自己整理懂了的證據，傳播後果卻落在別人的答題上。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「這樣是不是好懂很多？」學生把改寫的那頁放到你面前，標題畫了一顆笑臉。他趁下課傳給同學，還沒五分鐘，另一組已拿著它對答案。你看到第三行少了一個條件，先請收到的人別拿這頁當正式講義，該補正的也得補上。他看著你圈出的地方，小聲說：「那我前面那些也都不能用了嗎？」走廊的鐘快響了，他的筆還壓在那顆笑臉旁。
