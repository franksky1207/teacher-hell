## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 照顧教室盆栽的學生發現假期過後植株已枯死，仍每日照表澆空盆，因為班務票選中這盆植物曾是全班一起承諾照顧的東西。 |
| 核心衝突 | 有人主張馬上換一盆維持班務，學生承諾的卻是照顧這株；若仍按表操作，也會讓其他人誤以為活著。 |
| 導師困境 | 導師可先結束現行輪值，再決定讓學生提出告別與清理方式、將經驗用於下一次任務、或暫不補植以減輕維護負擔。 |
| 故事獨特性 | 班務完成條件原本沒有寫進計畫，得在任務終止後處理承諾及記憶。 |
