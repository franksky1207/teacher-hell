## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 通勤成本高的學生看同學說校外書店可免預約拿參考資料，留在校門邊猶豫要不要搭一趟車，手上剩的只是那天能自由用的一小段時間。 |
| 核心衝突 | 真的去一趟可能找到所需，若消息有誤就同時浪費錢與回家時間。 |
| 導師困境 | 導師可陪學生向店家核實、請他比較校內可用的資料，或讓學生先用現有版本開始。 |
| 故事獨特性 | 能不能求證本身取決於學生有沒有可浪費的一趟路。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：學生在校門邊算兩次車資，說同學聽聞書店不用預約就能拿參考資料，想多搭一趟。你陪他打電話，問清有哪份、能不能直接領，也核對今天回家方式。資料確有能用的部分，卻不一定比手上那份完整。他收手機問：「現在不去，是不是白問？」剩下能自己用的時間不多了，錢也只夠幾趟。他把手上資料翻到正在用的那頁，將一個邊角對折。
