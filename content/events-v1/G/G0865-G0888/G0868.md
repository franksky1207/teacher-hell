## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 經濟寬裕且很會操作新科技的家長，輕信網路假新聞說「私校下學期要全面改用平板無紙化教學，現在不練以後會跟不上」，因為他支持導師平時要求「做好課前預習與筆記」的立場，乾脆自己花錢幫孩子買了頂規平板與觸控筆，還教孩子上課直接用相機拍黑板與錄音整理重點，害科任老師在課堂上以為學生在偷拍而當場沒收。 |
| 核心衝突 | 家長誤信網路資訊並動用自家資源「超前部署」，結果讓孩子在課堂上踩到禁用電子設備與偷拍疑慮的紅線。 |
| 導師困境 | 依校規暫時扣留平板並請家長別信網路傳言，家長會反問「老師你不是也叫大家要認真做筆記嗎」；幫學生向科任老師求情只當作特例還回去，其他沒買平板的同學馬上會有樣學樣拿手機出來拍黑板。 |
| 故事獨特性 | 沒有捐贈軟體給全班，而是家長砸錢替自家孩子武裝新科技後，直接撞上課堂電子產品管制。 |
