## 5｜R1～R8共用結果、結算與4×8因果矩陣
### R1｜表格撤下
- **玩家可見結果**：製表學生把榜單從群組撤下，承認數字有些是從閒聊拼湊，沒有逐一取得本人同意。「我以為沒人反對，就是大家不介意。」他在群組說明錯誤，仍知道舊截圖可能留存；班上開始改談哪些資訊能公開、怎麼分享才妥當，而非勝負名次。他還主動取消雲端共用權限，知道只刪掉群組訊息不等於資料已安全。
- **客觀後果**：他在群組說明錯誤，仍知道舊截圖可能留存；班上開始改談共享公開程序，而非勝負名次。
- **合法底層增減**：`student_a:4-3:1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`1, -2, -1, 1`

### R2｜截圖跑得更快
- **玩家可見結果**：榜單才刪掉，就有人把舊截圖傳到別的群組，製表學生慌得要求你全部收回。「我明明刪了，怎麼還有人看到？」你們只能處理能聯絡到的轉傳及澄清，不能保證每張副本消失；受影響者暫不公開更多私人資訊。他記下目前知道的轉傳群組，準備逐一請求撤圖，不再追問受影響者的實際結果。
- **客觀後果**：你們只能處理能聯絡到的轉傳及澄清，不能保證每張副本消失；受影響者暫不公開更多私人資訊。
- **合法底層增減**：`student_a:8-1:-1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`1, 0, -1, -1`

### R3｜正確也不能查
- **玩家可見結果**：有人質疑榜單數字不準，製表學生想請你提供真正的篩選結果以還他清白。「如果不是用來排名，只是校對也不行嗎？」他這才明白導師不能拿別人的個資來幫他補救，這份榜單也不可能有老師的背書。他把原本要向導師問的資料欄刪掉，沒再做出另一張表。
- **客觀後果**：他發現導師不能用另一輪個資揭露補救第一輪錯誤，這份榜單沒有取得官方背書。
- **合法底層增減**：`student_a:9-2:1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-1, -1, -1, -1`

### R4｜不想被叫最後一名
- **玩家可見結果**：一名學生私下說，自己並不怕人知道沒過，只是不願被排成班上第幾名。「我把大家當成數字，沒想到人家還在消化。」做表的同學沒有再追問對方的實際結果，對方不想公開本來就不用先解釋什麼。
- **客觀後果**：製表者停止追問對方的實際結果；當事人不需要先證明清白，才能保留不公開的權利。
- **合法底層增減**：`student_a:11-2:-2; student_b:4-3:+1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-2, 0, -1, -2`

### R5｜分享方法比較有用
- **玩家可見結果**：班群有人提議改放「怎麼查正式通知」清單，不附姓名與通過數；製表學生第一次認真查資料來源。「這樣真的比較能幫到人。」他標出各項程序待確認處，不再替同學排名；仍有人想比較，卻多了一份不需要個資的工具。這份清單附有來源與查詢方式，沒有保留任何被撤下的私人排名。
- **客觀後果**：他標出各項程序待確認處，不再替同學排名；仍有人想比較，卻多了一份不需要個資的工具。
- **合法底層增減**：`student_a:4-3:2`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`1, 1, 2, 1`

### R6｜私訊仍在追問
- **玩家可見結果**：榜單撤下後，仍有同學私訊製表者，問誰通過最多、誰沒過。「我現在知道不能替他們回答，可是大家一直問。」他拒絕再報出別人的數字，也告訴被點名的同學不用勉強回覆。私下比較雖然還沒消失，幾個追問就這樣停在未讀，他第一次知道不回答也是一種負責。
- **客觀後果**：他拒絕提供新的私人數字，也告訴受影響者可以不回覆；比較沒有消失，沉默卻不再等於默許。
- **合法底層增減**：`student_a:8-1:-1; student_b:4-3:+1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-2, -1, -1, -1`

### R7｜道歉也需要時間
- **玩家可見結果**：製表學生在群組承認沒問過每個人是否同意，請大家停止轉傳；有人接受，也有人一字不回。「我不能說了對不起，就要大家當沒發生。」他盡力處理還能收回的訊息，也沒要求被影響的同學公開原諒他；道歉時他沒附上任何人的名字，避免變成第二次公開點名。
- **客觀後果**：他仍願處理可控制的訊息，沒有要求被影響者公開原諒；玩笑不再是免責理由。
- **合法底層增減**：`student_a:9-2:2`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`-2, 1, -1, 0`

### R8｜沒有導師認證
- **玩家可見結果**：有人堅持導師應替榜單核實結果，製表學生等著你的回答，最後自己把表收起。「算了，就算老師也不能幫我查別人的事。」他關掉試算表，改分享大家都能自己查的官方連結；事情不會因為刪表就當沒發生，至少沒再多一次隱私外流。
- **客觀後果**：他改分享各人自行查詢的方式；事情不會憑一句「無效」就消失，但也沒有再多一次隱私侵犯。
- **合法底層增減**：`student_a:11-2:1`
- **玩家四狀態**（精神、熱忱、情緒、掌控）：`0, -2, 0, -1`
