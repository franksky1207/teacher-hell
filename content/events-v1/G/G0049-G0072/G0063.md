## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 本班教師為改善口頭回饋，請學生輪流試當示範評閱者。一名學生發現自己必須給坐在旁邊的好友回饋，想改用自己的作品示範。 |
| 核心衝突 | 對示例說出判斷有學習價值，朋友互評會讓評語被視為私人立場；改成只評自己又缺少理解不同作法的機會。 |
| 導師困境 | 導師可把評語改成匿名短件、示範由教師先作或保留學生自評並讓別人自願補充，須處理教學時間及評閱公平。 |
| 故事獨特性 | 學生反對的是被安排評閱已知好友，不是反對接觸同儕作品。 |
