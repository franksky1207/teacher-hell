## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家境寬裕的學生（`7-3`）與導師私下關係親近（`5-2`），平時也完全認同導師訂下的「考前週禁止帶漫畫與掌上遊戲機到校」班規（`9-1`）。但他本人自主需求極強（`4-3`），這天在自習課拿出家裡買的高階純黑白電子書閱讀器看課外歷史小說，被導師提醒時還理直氣壯地笑著爭辯：「老師我有遵守規定沒帶漫畫跟遊戲機啊，這我自己花錢買的看字機器，我有權決定自習課怎麼放鬆吧？」 |
| 核心衝突 | 認同班規字面的學生用財力與科技產品鑽出規則灰色地帶，跟親近的導師展開「何謂違禁娛樂品」的語意辯論。 |
| 導師困境 | 當場認定電子書閱讀器也算電子娛樂產品一律收走，這名一直守規矩的學生難免覺得老師自己無限上綱；放行讓他繼續看，下週全班大概就會出現十台平板說裡面也只放了電子書。 |
| 故事獨特性 | 沒有偷藏手機，而是用「不違法但擦邊的電子書閱讀器」挑戰傳統紙本時代訂出來的班規條文。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「這是看字機器。」他笑著把黑白頁翻給你看，家裡買得起，也跟你熟，原來禁漫畫遊戲機的約定他很認同。偏偏一到自己的歷史小說，就要自己決定。你已核清原規範，不拿沒寫的字臨時罰人，也沒有讓高價變特許。他手放在翻頁鍵上：「那我現在能繼續讀嗎？」自習鐘還在走。
