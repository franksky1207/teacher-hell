## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長理解孩子不願總被叫去接手家務，家中臨時照料又真的緊。他要求導師說明為何已告知孩子可中途離開練習，後來願只談合規時段。 |
| 核心衝突 | 讓家庭自理不等於教師先替學生安排，孩子也不應被兩邊同時指派。 |
| 導師困境 | 可收回單方面安排、保留原練習或依合法請假程序。 |
| 故事獨特性 | 成人抱怨的是老師替自己作的決定，不只有學生失去課。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「你已經跟他說可以走了，怎麼沒先問？」家長不是不知道孩子不想再接家務，家裡今天的照料卻真的缺人。他願意把原來一整串要求縮成合法時段，只是還想知道你為什麼替他決定。你已收回單方面允諾，原出勤與接送交原流程確認，沒讓孩子夾在兩通電話間。「我可以談請假，不是叫你直接把他送回來。」他把手機放下，等你把練習安排講清楚。
