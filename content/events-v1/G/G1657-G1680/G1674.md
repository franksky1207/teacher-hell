## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生贊成導師原本要求不同意須說清楚，看到朋友都沒舉手便跟著不舉，一分析才發現大家是在等領頭者出聲。他原想重做整次班內遊戲規則選擇，聽老師說時間不足，改提只重問唯一有歧見的一條。 |
| 核心衝突 | 程序照舊，群體卻把同時安靜當成了共同意見。 |
| 導師困境 | 可重新命名雙方方案後只重問一條，消耗剩餘遊戲時間；也可本次依既有規則不改，下次等各自先想完再議，代價是這回有選擇的人仍沒被聽到。 |
| 故事獨特性 | 學生從自己的沉默推斷班上全員可能都在等。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：剛才商議班內小遊戲規則時，我問了一句「有沒有不同意的請舉手」，全班安靜五秒沒人動，我正準備喊照案通過，student_a卻突然舉手。
- **P02｜student_a**：老師，我們剛才不是真的沒意見啦……我也是看旁邊都沒舉手才不敢舉，大家其實都在等誰先出聲！時間不夠的話，不然我們只重問第三條有吵過的那條好不好？
- **P03｜旁白**：這場遊戲規則雖然沒有正式效力，但剛才把一片安靜直接算成大家同意，確實讓有想法的人全吞回去了。
