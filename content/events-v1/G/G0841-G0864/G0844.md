## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日加班疲憊不堪的組長原則性極強，今天評鑑抽查前整理檔案時，發現導師班上一份已經核章存檔的活動紀錄表少了一個學生簽名。他一方面抱著檔案夾來要求導師解釋為什麼當時沒核對清楚，一方面也已經主動幫忙把其餘九成表格先歸檔，並跟導師協調補救分工：「我先幫你壓住送件時間，你現在找學生補簽或先用家長電子確認替代，下午三點前我們一起把這頁換掉！」 |
| 核心衝突 | 行政端在極度疲勞與評鑑壓力下，既主動幫導師協調出補救窗口、同時又對已存檔的小漏格正式問責。 |
| 導師困境 | 立刻配合他的協調去找學生補簽結案，能趕在死線前一起過關但得先認下這筆行政疏失問責；反問對方「當初你們核章時不也沒看到」，只會讓原本願意幫忙壓件的組長當場把檔案退回重走全套流程。 |
| 故事獨特性 | 私校評鑑前的「翻舊帳式抓漏」，疲勞、原則、問責與私下協調幫你壓件同時發生在同一個行政主管身上。 |
