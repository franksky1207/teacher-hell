## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 暑輔第一週，有學生在導師時間拿出國中沿用的彩色筆記，問自己是不是得全部重做；原來同學看見後說『高中還這樣記喔』。 |
| 核心衝突 | 新生可以嘗試更有效率的學習方法，但同儕一句話不該逼他否定原本有用的方式；導師不必憑單一學科的專業標準，替學生評斷筆記方法的好壞。 |
| 導師困境 | 導師要讓學生自己判斷筆記是否有幫助、分享不同整理方式、回應同學評論，或請任課教師就本科需求提供建議？ |
| 故事獨特性 | 聚焦國中學習習慣與新班同儕眼光，不以特定科目的解題方式或專業內容作為故事前提。 |
