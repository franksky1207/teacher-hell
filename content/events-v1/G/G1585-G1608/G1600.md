## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生這兩週面臨重要檢定或段考，心裡焦慮得睡不好（`2-2`），性格又容易衝動（`1-2`），平時很愛在群組分享資源（`8-4`）。昨晚半夜他在網路拍賣看到有人兜售號稱「名師外流必考濃縮題庫電子檔」，焦慮之下沒多想就衝動刷卡買下來（`1-2`、`2-2`），今天早上覺得好東西不能獨享，立刻把檔案連結丟進班群大方提供給全班下載（`11-4`、`8-4`）：「大家快印！我花錢買的！」導師滑手機一看，那份檔案根本是掃描盜版的補習班講義，裡面還夾雜好幾題舊課綱錯題。 |
| 核心衝突 | 焦慮學生好心出錢分享資源，卻無意間在班群散播盜版且有錯題的教材，導師必須立刻攔截下架，又怕這名焦慮的學生被當成犯罪者嚇壞。 |
| 導師困境 | 立刻在班群與教室通知大家「該檔案有版權與錯題問題、請立刻刪除勿印製」，再私下找這名學生溫和講清楚網路買盜版檔案的法律與錯題風險（守住著作權與教學正確性，但一片好心又花了錢的焦慮學生當場嚇哭）；還是先請他自己立刻把班群連結收回、由導師在教室統一說明「來路不明的網路題庫常有舊課綱錯誤，大家還是以課本與學校講義為主」而不點名是他買的（保住他的面子並及時止損，但沒讓全班清楚意識到買盜版電子檔的嚴重性）。 |
| 故事獨特性 | 沒有誰想違法牟利，寫出考前焦慮學生「半夜衝動網購盜版秘笈還大方分享給全班」的現代數位學習踩雷。 |
