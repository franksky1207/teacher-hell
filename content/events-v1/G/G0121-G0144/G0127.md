## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 班上一群人放學約在校門口等同伴，有人嫌等太久起鬨先走。帶頭的學生口頭跟著起鬨，真正落單的人出來時他卻留在原地。 |
| 核心衝突 | 他理解校門不可久留的規範，也不願讓最後出來的人以為被故意遺下。 |
| 導師困境 | 可移到可合法停留的地方、讓本人先同行一段，或協助談清楚日後約等的限度。 |
| 故事獨特性 | 留在原地是一項尷尬的友善，學生不必同時為整群人的相處負責。 |
