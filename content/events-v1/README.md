# 故事製作目錄

| 目錄 | 分類 |
| --- | --- |
| [T](./T/) | 六學期 → 20 主題 → 28 故事池 |
| [G](./G/) | 按批次，G01～G11 為可重疊的故事標籤 |
| [P](./P/) | P1～P6，沿用獨立日型與結算規格 |

每篇以正式 ID 命名，例如 `T1-013.md`，第一區填正式 ID、`seed_id`、主題、故事池、配額歸屬日與其餘基本資料，第三區填原四碼。新增、修訂或全面重寫皆使用同一範本。T1 首批沿用[預選清單](../../data/story-production-selected-seeds-T1-001-030.json)的種子與分配。各池 README 及時段創作引導說明原有資格。

依[單篇創作 SOP](../../docs/story-production-v1/03-故事創作精簡SOP.md)使用[五區塊範本](../../docs/story-production-v1/04-五區塊故事稿範本.md)。推送到 `content/events-production-v1` 後，Pages 自動更新。往後直接改同一份 Markdown，待發布完成後重新整理[故事預覽](https://franksky1207.github.io/teacher-hell/stories/)。

[正式驗收](../../docs/story-production-v1/05-故事品質與驗收契約.md)獨立執行。目錄篇數表示目前有稿的故事數。以 `npm run content:production -- status` 查詢種子占用、配額與標籤分布。
