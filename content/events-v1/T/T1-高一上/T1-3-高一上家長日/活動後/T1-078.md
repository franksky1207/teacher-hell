## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長日氣氛熱絡，家長當時不好意思打斷；會後連續送來幾則短訊，每則都問同一件尚未問完的事，又說怕耽誤導師。 |
| 核心衝突 | 即時追問可理解，導師可用時間有限；單回一句又可能引來更多片段補問。 |
| 導師困境 | 如何邀家長把問題整理成可回覆的一組、約定適當回覆時間，兼顧親近感與工作邊界？ |
| 故事獨特性 | 問題源於一次短暫接觸留下未完成議題，非一般家長要求全天候回訊。 |

### R1｜如果能一次講清楚我就不用一直補訊

- **玩家可見結果**：「如果能一次講清楚，我就不用一直補訊息了。」家長把三則內容整理成一組問題，你確認需要查證的部分後約定回覆時間。等待仍在，卻不再被每隔幾分鐘的一個新問號切碎。約好時間後家長又傳了一句『這樣我就不用一直看手機』。你也把尚未確認的問題記下，免得下次談話又從頭猜。
- **客觀後果**：家長把三則內容整理成一組問題，你確認需要查證的部分後約定回覆時間。
- **合法底層增減**：guardian_a:1-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,2,0,-1

### R2｜我原本怕老師覺得我很煩才每次只敢

- **玩家可見結果**：「我原本怕老師覺得我很煩，才每次只敢問一點。」你先確認對方真正擔心的事，家長坦承當天會場匆忙，沒有找到適合開口的時刻。問題被完整說出後反而縮小了，彼此都少猜了一層意思。他翻出當天匆忙記下的筆記，才發現真正想問的只有一項。對話變短不是被敷衍，而是終於找到重點。
- **客觀後果**：你先確認對方真正擔心的事，家長坦承當天會場匆忙，沒有找到適合開口的時刻。
- **合法底層增減**：guardian_a:5-2:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-2,0,-1,-1

### R3｜那件事今天就得處理另一件可以下週

- **玩家可見結果**：「那件事今天就得處理，另一件可以下週再說。」兩項追問分流後，你先提供可立即確認的資訊，需查核的內容另留紀錄。家長知道急事有入口，也明白一般討論不必靠深夜催訊才會被看見。另一項需要核實的事情明確留下回覆窗口。家長知道什麼尚未確認，就不再把暫時沒答案當成老師不願理會。
- **客觀後果**：兩項追問分流後，你先提供可立即確認的資訊，需查核的內容另留紀錄。
- **合法底層增減**：guardian_a:10-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-1,-2

### R4｜你說會回覆我就以為每次想到都能馬

- **玩家可見結果**：「你說會回覆，我就以為每次想到都能馬上問。」家長把友善口吻誤讀成即時承諾，直到確認可用時間才意識到兩者不同。對方有些失望，但願意改成一次整理，不必由導師為每個零碎念頭停下工作。你沒有否定自己願意溝通的意思，只補足時間與範圍。這讓親近感仍能留著，不必用即時在線維持。
- **客觀後果**：家長把友善口吻誤讀成即時承諾，直到確認可用時間才意識到兩者不同。
- **合法底層增減**：guardian_a:11-2:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：1,-1,-1,-2

### R5｜我已經傳這麼多是不是現在撤回就算

- **玩家可見結果**：「我已經傳這麼多，是不是現在撤回就算了？」你沒有把大量訊息直接定性騷擾，也未要求家長吞回疑問。對方改挑一個最重要的點，其餘暫記在手機裡，終於不再因為沒一次說完而持續內疚。家長刪掉幾則重複草稿，保留一個能說清楚的提問。你也知道若對方真的遇到緊急事情，仍需依正式程序分流。
- **客觀後果**：你沒有把大量訊息直接定性騷擾，也未要求家長吞回疑問。
- **合法底層增減**：guardian_a:1-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-1,-1,2

### R6｜可不可以有一個簡短的紀錄免得下次

- **玩家可見結果**：「可不可以有一個簡短的紀錄，免得下次又問重複的？」家長同意記下已確認事項與仍待查證的部分，不要求老師保留不必要的私密訊息。下次聯繫有共同起點，卻沒有因此產生無限期的回覆義務。雙方只記錄經確認的事項，沒有把未查證的猜測寫成結論。這份短記錄讓下次談話可以往前走，而非循環同一個問號。
- **客觀後果**：家長同意記下已確認事項與仍待查證的部分，不要求老師保留不必要的私密訊息。
- **合法底層增減**：guardian_a:5-2:-1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：0,-1,-2,1

### R7｜我怕週六沒問到就代表以後都不能再

- **玩家可見結果**：「我怕週六沒問到，就代表以後都不能再問。」你說明可在合理時段繼續溝通，並非家長日一過便關閉窗口。家長安心一些，也開始接受每件問題不可能都在同一通訊息裡立刻結案。他說當天原本就想問，卻看到門外還有人等。你沒有責怪他錯過時機，也沒有承諾從此隨時能再開一次家長日。
- **客觀後果**：你說明可在合理時段繼續溝通，並非家長日一過便關閉窗口。
- **合法底層增減**：guardian_a:10-2:+1
- **玩家四狀態**（精神、熱忱、情緒、掌控）：-1,-1,1,0

### R8｜那我先把問題寫好等約好的時間再談

- **玩家可見結果**：「那我先把問題寫好，等約好的時間再談。」家長自己選擇適合的聯絡方式，將三則片段收成完整提問。週六匆忙留下的空白沒有消失，卻有了可以繼續處理、也容許教師保有工作時間的形式。原本連續響起的通知終於停下，家長則把手機放到一旁準備工作。新的方式同時保留了問題和彼此的生活。
- **客觀後果**：家長自己選擇適合的聯絡方式，將三則片段收成完整提問。
- **合法底層增減**：guardian_a:11-2:-1
