## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 連日監考與改卷累到極點的本班任課教師，平時很願意親自出力幫大家彙整雜務，在辦公室也頗有群體影響力。這天行政端臨時要各班交一份「跨科教學檢討表」，他累極之下衝動在辦公室提議「大家直接湊一份公版文字套一套交差」，一句話帶動好幾位同事跟進，導師班的實際進度卻根本套不進去。 |
| 核心衝突 | 過勞同儕帶頭發起「集體公版應付行政」風潮，讓想照實寫或進度不同的導師被推到邊緣。 |
| 導師困境 | 順水推舟一起套用同事幫忙寫好的公版交差最省事，萬一教務處抽查發現內容跟班上實際進度兜不攏會很尷尬；堅持自己重寫一份真實檢討，又怕被剛剛出力幫忙的同事當成不合群。 |
| 故事獨特性 | 寫出私校教師高壓下常見的「集體公版應付行政表格」現場，導師要在省力合群與真實紀錄間抉擇。 |
