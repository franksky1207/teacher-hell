## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 體育組或校安職員對導師為人非常敬重（`5-3`），平時也很願意與導師協調活動場地（`10-4`），校園安全意識極高（`9-4`）。這天大隊接力預演前，他看見導師班幾個學生沒換運動鞋就直接穿著硬底皮鞋踩上剛下過雨的濕滑跑道衝刺，一時衝動（`1-2`）直接拿大聲公當眾喝止並把人請出場外。事後他覺得對導師不好意思，趕緊跑來導師室一起協調補救（`10-4`）：「老師我怕他們滑斷腿才喊那麼大聲，下午第四節我幫你另外開一段空場讓他們換鞋補測！」 |
| 核心衝突 | 安全職員出於防傷本能當眾喝止學生，雖然事後積極協調補測時段，卻已經讓被當眾喊停的學生又氣又委屈。 |
| 導師困境 | 接受他的協調並叫學生下午換鞋再去補測一次，學生心裡對剛才當眾被大聲公喝斥的火氣還沒消；替學生抱怨職員當場太兇，又對不起這位確實幫你擋掉摔傷風險又主動補時段的同事。 |
| 故事獨特性 | 呈現「安全攔阻很正確、但當眾喝止很傷自尊」後，職員與導師共同善後的真實職場互動。 |
