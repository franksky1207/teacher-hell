## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生天生極有同理心（`1-3`），對導師的安排一向配合（`9-2`），只是這週補習加考試讓他已經疲勞到極點（`2-3`），偏偏他又非常渴望被大家喜歡、極度害怕拒絕別人會讓人失望（`4-4`）。今天下午班會課後需要留兩名同學幫忙整理公佈欄，原本輪值的同學臨時請病假，導師剛問了一句「有沒有人方便幫忙補一下？」，這名明明眼皮都在打架的學生看到全班安靜沒人舉手，出於同理心與怕冷場（`1-3`、`4-4`），立刻硬撐著舉手說「老師我配合你，我來！」（`9-2`）結果才剛開始剪紙就手滑差點打瞌睡（`2-3`）。 |
| 核心衝突 | 導師一眼看出他根本撐不住了，但若當場叫他回去休息又怕這個高認同依賴的孩子誤以為自己「派不上用場、被討厭了」。 |
| 導師困境 | 兩方向都立即停止剪紙與佈置，安全收走工具，留成人照看並按狀況聯繫健康中心評估。可把他已做好的紙樣留著，等有空的同學照樣接手，代價是要多協調交接；也可取消今天的佈置並讓大家按原放學安排離開，自己等健康處置完成，代價是半成品得撤下、學生可能覺得自己的努力沒用。 |
| 故事獨特性 | 沒有誰欺負他，寫出高中生裡最常見的「累到快暈倒還因為怕冷場、怕老師失望而第一個舉手」的討好型疲勞。 |
