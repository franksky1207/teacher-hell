## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位同科任課同事這學期課表較鬆、時間餘裕很充足（`11-2`），平常非常渴望獲得學生與主管肯定（`4-4`），但心裡一直對上次導師沒採納他設計的共題版本留有一點不滿（`5-4`）。今天上午他利用連續兩節空堂（`11-2`），一時衝動自己整理了一份「終極考前重點大綱」（`1-2`），沒先跟導師打招呼就直接轉發給導師班的同學群組，還刻意附上一句「這份比原本發的講義更有系統，歡迎大家拿去用」（`5-4`、`4-4`）。結果導師班學生立刻跑來問到底要背哪一份。 |
| 核心衝突 | 同事越過導師與同科共備默契、用個人版講義博取學生好感，兩份重點編排順序不同已經讓學生無所適從。 |
| 導師困境 | 私下找這位同事把同科教學步調溝通清楚，同時在班上委婉說明兩份資料的定位、以原定課堂進度為主（守住教學一致性與職場界線，但本就不滿又愛面子的同事覺得導師在防他搶風頭）；還是順水推舟稱讚他整理得很用心、直接把他的重點大綱併入本週複習參考（保住辦公室表面和氣與學生資源，卻等於默認以後誰有空就能隨意插手教學節奏）。 |
| 故事獨特性 | 沒有誰擺爛，寫出私校同科教師間因為「空堂多＋想被肯定＋一點小舊怨」而私自加發講義搶話語權的微妙較勁。 |
