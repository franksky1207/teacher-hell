## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家境寬裕的本班家長（`7-3`）平時十分敬重導師正派辦學的為人（`5-3`），在家長圈也極有號召力（`6-1`）。前天他在家長聊天群一呼百應揪了十幾位家長聊起冬天想替孩子做一件保暖班級外穿帽踢，還沒等班會討論也沒有先經導師同意，他已經請熟識廠商免費打好樣衣並直接介入班級服裝決策（`12-3`），今天帶來辦公室請導師拍板下週統一採購（尚未向任何家長收費）。 |
| 核心衝突 | 敬重導師又有號召力的寬裕家長「先做好樣衣、先揪好十幾個家長」才來請導師採用，若直接採用等於沒給班上其他家庭（特別是預算較緊者）討論與選擇的空間。 |
| 導師困境 | 順著這名敬重你的家長與那十幾人的期待直接把樣衣送進班會表決採用（展現高效率，卻讓班上家境普通的學生面臨「一件好幾百元不買好像不合群」的隱形壓力）；感謝他的熱心並堅持依班務規範須從頭在班會討論「到底要不要做班服與預算上限」、不能直接採用現成高價樣衣（守住程序與全班荷包，這名滿心想替老師跟班上長臉的家長當場尷尬下不了台）。 |
| 故事獨特性 | 家長尚未私下收錢且敬重導師，焦點落在「少數寬裕家長先打好樣衣揪團」對全班集體消費決策造成的既成事實壓力。 |
