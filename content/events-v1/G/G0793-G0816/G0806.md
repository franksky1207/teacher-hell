## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一位平常要顧店又照顧長輩、家庭負擔沉重的家長，因為輕信親戚說「高中某科被當就不能考大學」，特地請假跑來學校客氣跟導師溝通，表示自己雖然忙，但願意每晚下班趕來校門口陪孩子留校讀書、甚至想替班上買講義。 |
| 核心衝突 | 家長背著沉重生活負擔擠出人力想救孩子，出發點卻是一個完全錯誤的升學傳聞。 |
| 導師困境 | 直接戳破親戚亂講話並請他別白跑，怕傷了這位辛苦父親的自尊與苦心；若順口答應讓他偶爾來校陪讀，又會無端增加他本就吃緊的家庭時間壓力。 |
| 故事獨特性 | 把家庭負擔與誤信謠言結合，呈現弱勢或忙碌家長「越焦急越容易被外行情報嚇到」的真實無奈。 |
