## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長自家經營多年的設計印刷工作室作息與客源長年安穩（`7-4`），內心十分渴望在孩子與全班同學眼中被認可為「最挺班級又懂年輕人的神隊友家長」（`4-4`）。本週班上正在更新教室後方生活公約與閱讀角海報，他得知後先合法提供自家工作室的免費高磅數海報紙（`11-4`），卻在看過學生自己畫的草稿後直接介入班級佈置決策（`12-3`）：「老師，孩子們那張手繪稿太像小學生了，我順手幫他們重新排了一版設計師級的並印好了，你們直接貼我這版比較體面！」 |
| 核心衝突 | 想被學生認可又事業安穩的家長用免費專業成品直接取代學生的原創手繪，讓導師在「成品體面與大人面子」和「保護學生動手成就感」之間抉擇。 |
| 導師困境 | 收下這張已經印好的專業海報貼上牆，原本熬了兩個午休畫草稿的幾名學生當場氣餒覺得「反正大人重做比較快」；婉拒這份已經印出來的高磅數成品、堅持貼回學生的稚嫩手繪版，這名想幫班上爭面子又渴望被誇獎的家長恐怕覺得自己一片苦心被當場嫌棄。 |
| 故事獨特性 | 家長沒有附帶商業推銷，純粹是設計業大人看不慣孩子作品不夠精緻、熱心「代勞升級」卻不小心剝奪了學生的主導感。 |
