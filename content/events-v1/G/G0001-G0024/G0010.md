## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長臨時替孩子送餐，看到班規要求中午不要為取餐離開樓層，便希望導師讓自己的孩子在樓梯口領取。 |
| 核心衝突 | 家長在意餐點可食及照顧安排；學生既想接受照顧，也不想讓同桌認為私人請託能跳過共同規則。 |
| 導師困境 | 導師可依校內收件流程、核對必要例外或與家長找下次可持續的交接方式，眼前餐點與安排公平都需顧及。 |
| 故事獨特性 | 親師對規則的爭議起於交付路徑，不涉及餐費或餐點評比。 |
