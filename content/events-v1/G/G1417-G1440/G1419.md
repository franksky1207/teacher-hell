## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這週學校事務與備課讓玩家導師任務負荷爆表（`11-1`），遠在老家的家人非常支持與心疼導師（`7-1`），特地低溫宅配了一大箱需要當天冰進冰箱的限量家鄉熟食與滷味來慰勞。偏偏導師這人平常社交主動性超高（`6-3`），下班在社區管理室領完一大箱後，剛好在巷口遇到常光顧的小吃店老闆和鄰居熟人，一時衝動熱情上頭（`1-2`），直接當場拆箱分送了大半出去還順口約大家下週聚餐——回到住處一掀箱底才看見家人手寫的小紙條：「這幾盒特別留給你這週加班當宵夜吃的」，結果早已全送光、還多約了一場根本沒空的飯局。 |
| 核心衝突 | 想藉社交熱情展現大方，卻在極高工作負荷下犯了沒看清楚就衝動全部分送的烏龍，讓自己既辜負家人心意又平白少掉本週加班補給。 |
| 導師困境 | 乾脆笑著認了這場大方烏龍、自己煮泡麵配白飯度過加班夜，改天再找時間履行那場衝動約出來的飯局（保住成年人的社交體面與熟人關係，卻讓高負荷的自己得硬撐著沒宵夜可吃、還欠下一場時間債）；還是趁對方剛走沒多久硬著頭皮傳訊息坦白說剛剛沒看到家人紙條、厚臉皮拿回一盒（救回家人特別準備的補給，卻讓自己在巷口熟人面前尷尬到想鑽進地洞）。 |
| 故事獨特性 | 完全不涉及學校校務或學生，寫出高負荷上班族「拆包裹沒看底層紙條就衝動分送光」的成人生活荒謬與懊惱。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：我把空了大半的箱子放下，箱底才露出家人的字：『這幾盒特別留給你加班當宵夜。』那幾盒現在全在巷口熟人手裡。
- **P02｜導師**：我到底在大方什麼。
- **P03｜旁白**：群組裡還有自己剛打的『下週找一天吃飯！』。待辦清單長到我連今天晚餐都還沒買。
- **P04｜家人**：有拿到嗎？先冰起來，不用省著吃。
- **P05｜旁白**：我先如實回了分送的事，把剩下的妥善收好。那句不用省著吃，看起來突然很貴。

### 四個最終教師選項

| 選項ID | 玩家可見短句 | emotional | 教師已完成的客觀行動 | 優點及代價（不顯示玩家） |

| A | 我捨不得家人的那幾盒；我願自費買一份熟人也願意的替代晚餐，提出交換安全未開封那盒，對方不答應就算了。 | true | 因想追回家人心意，先向成人提出自願交換，確認對方意願與食安後才購買交付，不把送出食物當仍屬自己。 | 增加採買與可能實際餐費，熟人可能覺得大費周章。 |

| C | 我今晚先用既有安全食物簡單吃好，將群組靜音到必要聯絡以外，明天再核對飯局。 | false | 維持正常飲食與必要勤務聯絡，延後非必要社交回覆，不假稱聚餐已取消。 | 時間債未解，熟人可能繼續熱烈討論。 |
| D | 我向熟人坦白這週真沒空，取消自己提出的聚餐，食物就留給他們。 | false | 及時收回真實本人邀約，尊重各人既有安排，不討物或強迫同意。 | 失信面子，可能讓熟人掃興。 |
