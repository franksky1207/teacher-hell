# G1752 專屬 SOP｜07 每批24篇故事主題與摘要規劃

> 先規劃，再依[02](./02-G故事創作主流程.md)正式創作。每批既有`故事主題與摘要規劃.md`是規劃來源，未規劃條目僅預填故事ID、固定種子及四碼；已完成規劃也**不是正式故事或驗收**。G不設T的創作時段引導、活動前後池、特定日配額。

## 一、每批規劃前

1. 打開本批規劃MD，依[`data/g1752-fixed-seed-assignments.json`](../../data/g1752-fixed-seed-assignments.json)核對24個`Gxxxx`及原四碼；**種子唯一權威是JSON**，規劃MD中四碼只是唯讀副本。
2. 讀既有題材索引的`planningEstimate`及[正式標籤帳本](../../data/g1752-tag-statistics.json)的固定T、目標區間，依[06](./06-T648固定標籤基準與G動態統計.md)使用T＋全部已規劃／已核准G的最新有效標籤預估比例引導題材，不設每批配額。
3. 利用題材索引初篩本批新增／修正故事與既有T/G的核心衝突、教師處置及結果特色；疑似重複才讀對應原文。不接受換皮、制式化、脫離真實臺灣私立高中生活或為四碼硬湊的故事；不將題材比例合理等同於內容不重複。

### 唯一題材索引及預估累計

[`data/g1752-story-topic-index.json`](../../data/g1752-story-topic-index.json)已建立，根層為`schemaVersion: 2`、`planningEstimate`與`stories`。原規劃MD／正式Markdown仍是內容來源，索引是可重建的衍生資料，不另維護第二套故事。

- `stories`保留既有七個欄位：`storyId`、`status`（T為`t-baseline`，G為`planned`或`accepted`）、`coreConflict`、`teacherFocus`、`distinctiveness`、`tags`、`sourcePath`。每個ID只允許一筆；T648凍結，正式G核准後原位替換為最新核准內容及正式Markdown來源。
- `planningEstimate`只保存`gStoryCount`、`gLabelOccurrenceCount`、`gTagCounts`、`combinedStoryCount`、`combinedLabelOccurrenceCount`、`combinedTagCounts`、`combinedTagPercentages`；各類計數為G01～G11，百分比以標籤總次數為分母。這是含所有有效規劃／核准G的全庫預估，不是正式核准帳本。
- 依[06增量更新規則](./06-T648固定標籤基準與G動態統計.md)，每批新增或修正只更新受影響條目及標籤差額，同步保存規劃MD與索引；標籤未變不重新統計。正式核准取代原規劃條目，不重複加篇數。一般施工不重掃舊故事、不每批從所有明細重新統計，也不讓所有舊故事彼此重新查重；例外完整稽核條件只依06。

## 二、每篇規劃MD必備內容

| 欄位 | 需要真正寫出的內容 |
|---|---|
| 故事ID／固定種子／四碼 | 從唯一映射讀取，禁止為劇情需要重新配對 |
| 預定標題、事件起因 | 可具體發生的臺灣高中導師生活事件，不依賴T專屬時間節點 |
| 核心衝突、導師困境 | 真正相衝的立場、代價與可供教師選擇的不同處置 |
| 故事獨特性 | 明確指出與其他T/G的區別，不是制式模板換皮 |
| 四碼因果 | 四個種子碼各自合法的持有人及如何在人物／行動／後果發揮作用 |
| 人物配置 | 需要的常駐數值NPC槽位、各自立場／權限／知情／在籍條件；情境人物不硬建立持碼槽位 |
| 必要前提／演出限制 | 只在合格上課／寒暑輔日成立；必要年級、身分及知情另列，不寫T活動日期歸屬 |
| 規劃題材標籤／狀態 | G01～G11預估標籤、待複核或規劃通過；**不得冒充正式故事驗收** |

本批24篇先全部填入真實摘要與人物構思、逐篇核對固定四碼，並做一次**本批與跨批查重**；不合理就改主題與情節，**不換S種子、不強制配類別**。全部1752篇規劃先完成並經使用者確認後，才依05授權進入正式試產與創作；規劃階段不執行六選三、四R、AVG、58庫等正式創作工作。

## 三、規劃、正式故事及驗收的界線

- 規劃資料與正式故事分開：`故事主題與摘要規劃.md`只能放摘要與角色／四碼用途；不預先生成空白`Gxxxx.md`，也不把規劃標籤計入正式帳本。
- 正式五區塊格式以[03](./03-G五區塊範本.md)為準；內容與兩網站發布驗收只依[04](./04-G品質與驗收.md)；批次及首批四篇試產只依[05](./05-G種子批次與試產.md)。
- 正式創作依已完成規劃展開；若核准內容改變核心摘要或人物條件，同步修訂受影響規劃MD，並依06原位更新索引及預估、正式統計。尚未核准的正式草稿不覆蓋既有有效條目；不因摘要調整更換ID或固定種子。
