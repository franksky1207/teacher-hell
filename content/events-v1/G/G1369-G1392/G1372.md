## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位家長近期時間餘裕非常充足（`11-2`），平時對導師十分信任（`5-1`），做事說做就做執行力極強（`3-3`）。前天他接送時遠遠看見導師班教室窗台空蕩蕩的，竟沒先問過導師便直接介入教室環境佈置決策（`12-3`），今天早自習前在警衛室依規登記後，沒等導師點頭就急著想直接送進教學區把兩大盆及一小盆黃金葛擺上教室後方窗台（`12-3`）。導師聞訊趕到警衛室旁會面點接待他，一眼就看出三盆根本沒附接水底盤、一旦擺上教室窄窗台不僅會卡住後方氣窗推拉鎖扣，澆水更可能滴濕下方同學書本（且校外家長不得無陪同擅進教室教學區）。 |
| 核心衝突 | 信任導師又好心出力的有空家長帶著三盆植物想直衝教室「突襲綠化」，導師必須守住「家長不擅進教室、不擋氣窗鎖扣、必備接水底盤」三道安全線，又得安撫這名一早興沖沖搬花來的信任派家長。 |
| 導師困境 | 導師明確不讓家長無陪同進入教室，也絕不先把盆栽擺在警衛室花台等公共區域再通知總務；在確認校方允許班級收受少量安全盆栽且教室講桌角另有安全空間（並須先確認自願照顧人、加裝底盤及正式收受程序）的前提下，兩難在於：僅收下其中一盆不擋氣窗且已補齊底盤且確認照顧人的小盆栽帶回講桌角、請家長帶回其餘兩大盆（守住門禁、氣窗安全與後續照顧負荷，但這名一早高高興興搬三盆來的信任派家長當場有點失落）；還是依未事前向總務處申請公共花台擺放與未確認照顧人之程序，請家長今天先整批搬回家（程序與管理毫無瑕疵，卻讓這名想替班上添綠意的信任派家長整趟白跑抱回）。 |
| 故事獨特性 | 沒有誰想違規，寫出有空又熱心的家長一早抱三大盆沒附底盤的黃金葛到警衛室「替教室添綠意」，撞上門禁、氣窗安全與照顧責任的真實尷尬。 |
