## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位資深科任教師住處離校極近、多年來與家中長輩維持固定中午十二點零五分準時回家吃熱飯午休的穩定生活步調（`7-4`）。他對導師為人原則非常敬重，也總是配合導師排定的補考與收件時段，但只要導師口頭說好「週三中午給你缺席補考名單」，十二點零五分一到，他便準時背好包包客氣卻堅定地站在導師桌旁督促：「老師，名單我可以帶走了嗎？」 |
| 核心衝突 | 沒有任何敵意的前輩為了守住自己多年的居家午休穩定節奏，用分秒不差的準時出現讓被學生纏住的導師冷汗直流。 |
| 導師困境 | 請前輩先回家吃飯、自己下午一點再送過去，前輩雖然禮貌點頭但大概會坐在對面一直等；立刻放下手邊還沒處理完的學生衝突先印名單，現場學生又得晾在旁邊。 |
| 故事獨特性 | 沒有催命連環扣也沒有指責，純粹是一位極度守時、必須準點回家維持生活步調的前輩造成的無聲時間壓力。 |
