## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生學習適應力極快（`3-4`），成就動機很高（`4-1`），平時十分信任導師（`5-1`），也全力支持導師在班上推動的新活動（`10-1`）。導師最近剛開辦一項「每週短文互評」練習，多數同學還在摸索怎麼寫回饋，這名適應飛快的學生（`3-4`）不僅自己寫得極好，今天下課還興奮地跑來找導師（`5-1`）：「老師我超支持你辦這個活動的（`10-1`）！我看大家寫得都還很生疏，不如以後每週同學交上來的短文先由我幫忙初審打分數再交給你，這樣既幫你省時間我也能多練手感（`4-1`）！」 |
| 核心衝突 | 學生出於信任與學習熱情想幫老師分擔批改，但讓單一學生替同儕作品打分數會立刻製造班級權力不對等與同儕怨言。 |
| 導師困境 | 溫和婉拒讓他替同學打分數、改邀請他寫一篇示範回饋貼在班上當範例（守住教師評量權責與同儕平等，但這名充滿幹勁的高成就學生當場覺得大材小用有點失落）；還是讓他擔任純粹的「收件與格式核對小幫手」、絕不碰任何評語或分數（給足他參與舞台又守住界線，卻得小心別讓其他同學誤會他在對大家作品指指點點）。 |
| 故事獨特性 | 寫出熱心又優秀的學生「把老師的信任與自己的成就動機結合，想升格當同學的初審評分員」的可愛越界。 |
