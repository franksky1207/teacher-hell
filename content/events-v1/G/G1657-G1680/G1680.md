## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 小活動結束後，學生替導師實際收好散落道具，照例有人喊下次也拜託他。因渴望被肯定又怕讓人掃興，他先笑，等大家走到門口才把道具交給導師，說自己這週只幫這一次，並提出往後先問全班是否有人願意，別念到他的名字才問他有沒有空。這時仍在教室的同學已順口在白板寫了他負責下次。 |
| 核心衝突 | 完成的工作得到一陣謝謝，也被格外自然地外推成未來責任。下次的人手尚無著落，但導師若不擦掉白板，已有人會照那張表算。 |
| 導師困境 | 導師可立即撤掉預填的名字，由自己在下次徵到人前保留收尾責任，學生的拒絕不用當眾示範，教師卻多了一件實際工作；或在本人願意時由兩人把白板拆成已完成和待徵兩欄，當場接受其他人自願分段，學生要面對同學追問這次為什麼不接。 |
| 故事獨特性 | 問題出在禮貌地結束一次幫忙時，別人順手替他開始了下一次。 |
