## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 極度怕跟人起正面衝突的學生，積極參與收發作業的小老師班務，但內心其實質疑導師講解這單元的方法太繞遠路。昨天整理作業時，他一時衝動沒先問過導師，就直接在班級群組貼出「我自己寫的比較好懂版本」給全班對答案，結果裡面有一步跳太快且觀念其實有漏洞，今天進班前他躲在座位不敢抬頭。 |
| 核心衝突 | 小老師出於班務熱心與對教法的質疑擅自上網發解法，既挑戰了教學權威又害部分同學對錯觀念。 |
| 導師困境 | 當全班面直接指出他發的群組解法有漏洞，怕這名極怕衝突又熱心當小老師的學生當場羞愧辭職；私下叫他自己發更正訊息，已經照著寫完的同學還是會抱怨老師沒講清楚。 |
| 故事獨特性 | 小老師不是惡意搗蛋，而是「嫌老師教太慢、自己衝動發群組」後又不敢面對老師的青春期尷尬。 |
