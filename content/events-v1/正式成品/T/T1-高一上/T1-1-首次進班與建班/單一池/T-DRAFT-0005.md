## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 暑輔第一週有人想留下班級第一張合照，另一人提議把照片貼在公開頁面，還希望在每張臉旁標姓名；原本只是紀念，轉眼變成涉及公開身分的決定。 |
| 核心衝突 | 班級歸屬感不靠所有人交出照片與姓名才能成立；拍攝、留存、標名與公開發布是不同層次的同意，家長關切又不能完全取代學生自己的意願。 |
| 導師困境 | 導師要在想留下共同記憶的熱情與個人影像使用界線之間做安排，過度保護可能讓活動失去參與感，過度承諾又讓學生承受公開壓力。 |
| 故事獨特性 | 新班第一次紀念照尚未拍攝時，真正爭議是要不要把辨識姓名一起公開；學生與家長對『能拍』和『能被其他人認出』可能有不同理解。 |

- **P01｜旁白**：暑輔第一週有人舉起手機，提議在正式班級活動開始前拍一張『全員到齊』的合照。

- **P03｜旁白**：其他人開始討論要不要標姓名，甚至有人已經打開班級公開帳號的草稿畫面。快門還沒按下，公開與否倒先成為話題。
- **P04｜{{guardian_a.name}}**：孩子剛問我照片能不能給全校看。我想先知道拍攝、班內保存和公開，是不是能分開決定？
