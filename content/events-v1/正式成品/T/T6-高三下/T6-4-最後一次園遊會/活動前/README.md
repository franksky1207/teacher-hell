# T6-4｜最後一次園遊會｜活動前

- **正式T主題**：`T6-4`（高三下）
- **正式故事池ID**：`T6-4:before`，稿件的 `required_window` 必須填這個ID。
- **本池合法日數**：1 日。核定日期請直接查 `docs/T1-T6-特定故事20主題與觸發日期.md` 的來源表；本目錄**不複製第二份日期清單**。
- **創作配額**：`--date` 需是本池合法配額歸屬日；同一天不同T主題共用6篇額度。配額歸屬日**不是唯一可播放日**。
- **重要限制**：仍須逐篇確認合法日期、角色在場、知情與教師權限。
- **狀態**：目錄初始化；尚無正式故事。只有通過既有SOP、內容審查、CLI `lock` 的完整稿才算進度。

正式稿與同名 `*.review.json` 必須放在**鎖定前就確定**的路徑。鎖定後不改名、不搬移、不覆寫；正式故事ID由根目錄的唯一帳本配號。

- 創作前閱讀：[時段創作引導 V0.2](./時段創作引導.md)。
