## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 導師下班後喜歡完全照自己想放鬆的節奏找地方看小說（`4-3`）。今晚他輕信一篇美食部落客寫的「巷弄隱藏版極簡咖啡館：免排隊、冷氣超涼、安靜到能聽見翻書聲」（`8-3`），特地多轉一站公車走過去。不料剛點完一杯兩百元的單品咖啡並結完帳坐下，才發現店裡擠滿十幾名拿著補光燈直播拍照的客人、旁邊冷氣還在滴水根本不涼，導師看著自己被耽誤的夜晚火氣直冒（`2-1`），但下班最不想跟店員或陌生客人當眾理論吵架（`6-4`）。 |
| 核心衝突 | 導師在私人休閒時段被網紅文青攻略坑進名不副實的店家，卡在自己一肚子火卻又極力迴避與人正面衝突的憋屈裡。 |
| 導師困境 | 忍住怒火不去理論、勉強在悶熱又吵雜的角落硬把這杯兩百元咖啡喝完撐滿一小時，整個下班放鬆的夜晚徹底毀掉還越坐越悶；默默把咖啡打包成外帶杯一句話不說認賠走人，不僅兩百元跟車程全打水漂，心裡總覺得連一句公道都沒討回來。 |
| 故事獨特性 | 完全離開校園與教師身分的純粹私人消費踩雷日常，寫出不愛吵架的成年人遇到網紅假食記時那口吞不下去的悶氣。 |

- **P02｜店員**：今天比較熱，人也比較多。
