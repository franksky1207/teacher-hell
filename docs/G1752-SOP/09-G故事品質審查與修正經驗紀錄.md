# G1752｜09 故事品質審查與修正經驗紀錄

本文件是供後續 ChatGPT／Agent 參考的歷史品質經驗，不是新故事規格、驗收門檻、題材禁令或施工授權。正式權威仍依00～07，指令產出依08。歷史審查結論只適用當時版本；規劃複核通過不等於正式故事核准。實際進度以遠端分支及資料為準。

## 適用階段與經驗傳承

09涵蓋G1752全製作流程：摘要規劃、階段一（開場與選項）、階段二（結局與數值）、階段三（AVG演出、正式驗收）及後續修稿。規劃階段的經驗直接供後續橫向階段參考，不因階段切換歸零。

- 規劃：避免題材骨架重複、持碼人物錯置及摘要因果硬湊。
- 階段一（開場與選項）：將上述經驗延伸到人物口吻、行為動機、敘事節奏、實質選擇及四條後果可行方向；避免四個選項淪為三個愚蠢選項配一個標準答案，或同一處置換句話說。
- 階段二（結局與數值）：確保R1～R4各有可區別的實際事實或關係變化，符合人物立場、知情與自主性，不推翻已完成行動或為數值倒編情節；依現行01～07及共用規格處理，不改固定結果機制。
- 階段三（AVG演出、驗收及修稿）：參考人物關係、情緒及事件節奏，依既有素材契約與演出規格檢視表情、姿勢、背景、人物切換等是否自然，避免各故事套用相同演出套路；累積實際閱讀與遊玩發現的問題、有效改善方法、複驗結論及版本，沿用04既有驗收與雙預覽同步要求。

以上為歷史經驗的延伸方向，不是新增的欄位、流程、驗收門檻或工程實作成果。目前只有規劃審查實例；階段一～三正式創作與驗收的實際經驗，待該階段真正進行後增量記錄，不預先宣稱已驗證。

## 一、跨輪共通經驗

- 最大風險不是沒有創意，而是找到一種符合數值的情境後反覆使用。固定的是數值語意，不是情節。構思時探索同碼在不同人物、生活條件、動機及後果中的自然作用；不把一個碼綁成一種情境。
- 查重比較因果骨架、核心衝突、導師面臨的實質處置及代價，不能只比標題或物品。相同題材可以有不同故事；不同題材也可能只是換皮。先用既有索引初篩，疑似重複才讀原文。
- 四碼因果要在摘要中有實際作用，由合法持碼人物本人承擔；不可在數值說明才補入無關條件，或把別人的動機、負擔當成持碼者的數值。
- 人物可以是問題製造者，導師也會誤判、偏心、疲累、任性；不必每篇都走向私下詢問、協調、尊重意願、程序公平等理想化處置。私立高中制度特色不等於行政人物出場；私人生活不必回到校務。
- 修正以保留好故事、局部修正或重新構思的實際需要為準，不要求固定篇數。若是群聚模板問題，採群組式修正；若僅少數具體缺陷，採定向修正。不要修掉一種模板又大量製造另一種。
- 標籤比例是全庫方向，不是單批配額；數量增加不代表內容更多元。以06、07現有統計機制增量更新，不為本紀錄重算全庫。
- 下列案例是歷史參考，不是永久禁用題材、指定題材配額或新的量產模板。正式創作仍依現行規格重新檢視。
