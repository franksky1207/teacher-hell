## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平常須照顧家人的學生這天難得有親戚幫忙，多了一段可參加趣味賽的時間。他一直想跟那幾位同學同組，到了登記處才見四個名額已滿，氣得跑來說自己被故意跳過。導師只知道這組已滿，還不知道他是否在報名前表達過意願，也不知道組員怎麼想。 |
| 核心衝突 | 學生把額滿聽成朋友不想要他，導師既要正視他的委屈，也要弄清他想要參賽還是想和特定同學同組。 |
| 導師困境 | 先私下查報名時間、方式和相關當事人意願，不揭露家務。若是名額已滿而有其他合法名額，可依學生意願幫他聯絡，代價是可能參得了賽卻不能和朋友同組；若他在意的是與那幾人相處，可等情緒穩定後讓願意的當事人談各自以為的報名方式，保留原有名單，但今天可能參加不了。有排擠線索時另循校方程序。 |
| 故事獨特性 | 難得有空時，學生真正想加入的可能是一段友情，而不是任何一隊。 |
