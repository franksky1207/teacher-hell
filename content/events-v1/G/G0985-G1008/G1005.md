## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學校健康中心校護這天心情開朗愉快（`2-4`），平時對導師十分信任（`5-1`），但對傷病紀錄與校園安全意識極高（`9-4`），死守「學生反覆同部位受傷必須建立書面追蹤」的原則（`1-4`）。午休導師班一位學生打球擦傷去保健室擦藥，校護查閱紀錄發現他其實上週才同隻腳踝扭傷過卻沒告訴導師，雖然全程笑咪咪地幫他包紮完，卻堅持依原則立刻把導師請來簽核「運動傷害追蹤與家長告知單」。 |
| 核心衝突 | 笑臉迎人的專業校護用毫不退讓的安全原則，把導師拉進原本學生想隱瞞的運動舊傷追蹤程序。 |
| 導師困境 | 立刻配合簽單並打電話通知家長，學生當場哀嚎「我只是小擦傷，回家多半會被我媽禁止打球」；替學生求情說這次只是皮外傷先別建檔，這名信任你的校護依然笑著把筆遞過來：「老師，安全紀錄不能少喔。」 |
| 故事獨特性 | 沒有嚴厲指責，呈現校護在「愉快信任的合作氛圍」下依然寸步不讓的醫療安全底線。 |

- **P01｜旁白**：校護一面收紗布，一面笑著把追蹤單轉向你。學生想溜下椅子，她輕輕點了點上週那筆腳踝扭傷紀錄。
- **P02｜校護**：同一隻腳，上次你說老師不知道。這次我們要接起來，老師會幫忙的。
