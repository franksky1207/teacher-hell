## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名學生家裡經濟與照顧負擔不輕（`7-2`），平時跟導師關係親近（`5-2`），個人自主意識很強（`4-3`），判斷事情也比同齡人冷靜實際（`3-2`）。最近班上同學討論要自費訂做一件紀念T恤或班服，這名學生自己冷靜盤算過家裡的開銷後決定不買（`3-2`、`7-2`），卻被幾個好朋友一直半開玩笑地說「不買大家合照怎麼辦」。這名親近導師的學生私下跑來找導師確認，語氣裡帶著早熟的防備（`4-3`）：「老師，這筆錢對我家來說真的沒必要花，你不會也覺得我不配合大家吧？」 |
| 核心衝突 | 早熟學生在家庭經濟與自主判斷下做了務實選擇，卻仍敵不過同儕的集體壓力，導師必須在不揭露他家境的前提下給他足夠的支持。 |
| 導師困境 | 立刻明確表態「完全不需要買、老師完全支持你的決定」，並在下午班會上公開重申這件事純屬自由意願、合照穿校服一樣很好看（徹底替他擋掉同儕壓力，但要拿捏語氣別讓熱心設計班服的幹部覺得老師在潑冷水）；還是先私下大力肯定他替家裡精打細算的成熟判斷，並幫他想好一個自然不尷尬的說法回應同學（小心保護了他的家庭隱私，卻可能讓這名親近你的學生覺得「連老師都默認不買有點難對外說出口」）。 |
| 故事獨特性 | 沒有家長出面哭窮或要求減免，純粹寫出青春期孩子「自己冷靜算過家計決定不花錢、卻還是會怕被同儕排擠」的敏感自尊。 |
