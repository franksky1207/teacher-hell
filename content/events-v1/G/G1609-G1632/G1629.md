## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長家裡要同時照料長輩與弟妹、家庭負擔非常沉重（`7-2`），對孩子放學獨自搭車的安全感需求又極高（`4-2`），平常非常支持導師的各項主張（`10-1`），也習慣在班群主動發消息（`8-4`）。前幾天導師曾順口提過「住同區的同學放學可以結伴走去搭車比較安全」，這名家長立刻力挺（`10-1`、`4-2`），偏偏因為自己真的抽不出空接送（`7-2`），昨晚竟然直接在班級家長群組公開貼文徵求同區有開車的家長「每天順便免費載我家孩子一程」（`8-4`），還標記導師：「老師你前幾天也說大家互相照顧最好對不對？」讓同區幾位有開車的家長瞬間已讀不回、氣氛尷尬到極點。 |
| 核心衝突 | 家長把導師的「結伴步行安全建議」曲解成「導師支持大家免費順風車接送」，更把導師拖進班群裡幫他背書徵車，引發其他家長的隱形人情壓力。 |
| 導師困境 | 立刻在班群公開回覆澄清「老師上次是建議同學結伴搭大眾運輸或走大路，私家車接送涉及保險與各家庭作息，不建議在群裡公開配對」，並私訊提供他學校校車路線（快速替同區家長解圍並守住安全界線，但這名原本挺老師的家長當場超尷尬）；還是先私下打電話跟這位家長溝通請他自己收回那則公開徵車貼文、再幫他一起查校車或安心公車路線（保住他在班群的面子，但那幾個已經看到貼文的同區家長心裡還是覺得怪怪的）。 |
| 故事獨特性 | 沒有誰佔便宜惡意，寫出「忙到沒辦法接送又擔心安全的家長在班群公開徵免費順風車、還標記老師背書」的現代家長群組社死現場。 |

- **P02｜群組貼文**：@導師 老師前幾天也說住同區互相照顧最好對不對？我們家還要顧阿嬤真的抽不出空，同區有順路的爸爸媽媽請私訊我喔！
- **P03｜旁白**：前幾天我明明只是建議學生結伴走去搭公車，他這一標記等於把導師拖去替免費順風車背書，同區那幾位有開車的家長現在全裝死已讀不回。
