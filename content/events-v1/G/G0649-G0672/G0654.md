| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生認同輪流舉手，見導師讓同一人插話兩次便生氣，比較幾種後果後試圖請教師指定還沒講的同伴先講。 |
| 核心衝突 | 被偏愛的人不必挨罵，還沒講者也未必願被補點。 |
| 導師困境 | 可只停止插話、留全員書寫段，或恢復次序但讓本人可跳過。 |
| 故事獨特性 | 要求修補規矩的人也差點替別人決定發言。 |
