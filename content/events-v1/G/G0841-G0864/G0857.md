## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平常總是乖乖配合導師安排的學生，極度在意老師與同學對他的認可。這天他照導師安排幫忙去教務處搬考卷，在樓梯間被別班同學嘲笑「怎麼又是你當免費苦力」，他氣到不行，回來立刻條理分明地向導師抗議自己配合度這麼高卻被當成工具人。 |
| 核心衝突 | 最配合導師的學生因為外人的一句嘲笑感到受辱，讓原本順暢的班級協助關係出現裂痕。 |
| 導師困境 | 安撫他別理會別班酸言酸語並加記嘉獎，反而像是用獎賞坐實「真的在請他當苦力」；立刻把差事換給別的同學做，他又覺得老師是不是嫌他愛計較。 |
| 故事獨特性 | 學生不是累或不想做，而是「配合老師」這件事被同儕貼上工具人標籤後的自尊反撲。 |
