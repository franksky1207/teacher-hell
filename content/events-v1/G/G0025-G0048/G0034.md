## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長發現孩子會拿筷子排出課堂的小練習，一時很樂，想請導師每節都用這套，順勢要求孩子現場再做。孩子反而把筷子收了。 |
| 核心衝突 | 家長是真心驕傲，也會讓孩子覺得拿手的事變成表演；教學法未必每課適用。 |
| 導師困境 | 導師可和家長談孩子何時願意示範、分享想法供家庭自由玩，或請孩子另挑一次想展示的東西。 |
| 故事獨特性 | 孩子把學習帶進晚餐，親師介入後卻差一點把遊戲變作業。 |
