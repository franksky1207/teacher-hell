## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班學藝股長（`9-3`）平時與導師關係親近（`5-2`），本人好勝心極強（`4-1`）。看到下個月校內將舉辦班際國語文朗讀／海報比賽，他不甘心導師過去為了省事常採「意願者抽籤」決定班級代表、結果抽到沒準備的人去墊底，這天主動找導師要求修改班級代表推派程序（`12-1`），主張改在班會辦一場正式海選評比，由他幫忙收件計分——但同時他自己也早早寫好稿子準備報名參賽。 |
| 核心衝突 | 好勝又親近導師的幹部想用「實力海選」提升班級競賽名次，卻在程序設計與「自己也想參賽」之間踩進公平疑慮。 |
| 導師困境 | 同意改辦班內海選初賽，不只要額外挪用班會與自習時間評選，落選同學多半私下質疑他這個主辦幹部「球員兼裁判」；維持原本簡單的抽籤或輪流制度，這名認真練習又親近導師的學藝股長難免覺得有實力卻沒機會出頭。 |
| 故事獨特性 | 沒有舞弊，純粹是「想幫班上贏又自己想上場」的高中幹部與導師在選拔公平性上的角力。 |
