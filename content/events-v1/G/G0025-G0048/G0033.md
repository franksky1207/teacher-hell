## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一名學生多次配合換值日，家中近期輪班使他只能在原日留下。新一輪點名時才說以往口頭互換不等於這次也可以。 |
| 核心衝突 | 班上已依過往做法排出便利的組合；尊重變動需要重新分配其中一段工作，公開原因會暴露家庭時間。 |
| 導師困境 | 導師可重開自願交換、將部分值日移到班內時間或由班務小組依無個資條件重排，需保留學生拒絕再交換的權利。 |
| 故事獨特性 | 困境不是一直請同一人救急，而是規則把可變的私人時程當成固定欄。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：「這次真的不能換，原來那天我會做。」值日生急著補完後半句。幾個同學已照以前的默契排好，一聽便問他怎麼反悔。他把家裡輪班通知壓進課本：「不要一直問那個好不好？」你說沒答應的交換不能直接算上，也不用當眾交代家裡時程。他還願意做原來的班務，只是這回沒辦法換。旁邊同學拿著筆指黑板：「可是我們這裡都排了，現在誰補？」他低頭，沒再接話。
