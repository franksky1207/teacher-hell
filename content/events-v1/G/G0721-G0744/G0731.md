## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生累到錄音試讀時發出一長一短兩聲怪咳，別人都跟著留下自己的版本當彩蛋，他也隨眾沒刪。聽到回放後他才發現第二聲接在朋友一句口誤後像在嘲笑，便很清楚地解釋聲軌重疊點，要求導師往後先給當事人聽完整段再留彩蛋。 |
| 核心衝突 | 原先好玩的是大家一起出糗，現在自己刪錯一聲就像要所有人收起笑容。 |
| 導師困境 | 導師能和學生重錄假咳保住節奏，得承受朋友聽出刻意；也能砍掉整個彩蛋，損失一起工作的意外笑點。 |
| 故事獨特性 | 疲勞造成的聲音被當成演出，連計較它的人自己也曾跟著玩。 |
