## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 生活步調穩定、對學生很有同理心的資深科任教師，平常就願意親自多留校幫學生看題目。段考前夕他發現導師班有三位體育或藝術特長生進度落後太多，出於同理心他直接找導師介入留校安排決策：「老師這三個禮拜五放學留我教室我親自盯他們算題目，你就別再排他們去原來那組自習了。」 |
| 核心衝突 | 熱心科任老師無償投入人力照顧弱科學生，卻直接抽走了導師原本排好的班級自習分組名單。 |
| 導師困境 | 開心答應讓他們過去免費補救，原本跟這三人同組互助的同學進度表會被打亂、還得跟家長重報位置；婉拒並維持原班統一自習，又顯得導師不領這位資深同事無償加班的美意。 |
| 故事獨特性 | 沒有任何私心或搶績效，純粹是一位作息穩定又好心的老前輩「直接幫你接走三個學生」引發的調度小難題。 |

### 開場
- **P01｜旁白與當場對話**：他平常留校看題目很肯出力，家裡晚飯和休息也總排得穩。這次見三個特長生落後，就直接把自己教室圈出來，說週五我盯，不用去原自習。你先核清意願與留校條件，沒有讓學生被一句善意改了去處。他把三題基礎例攤給你：「我想真的陪他們弄懂，不是再發一份。」你班的原安排仍有效。
