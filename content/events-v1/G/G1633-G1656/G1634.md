## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 家長長期獨力處理家中就醫與家務，聽孩子在課堂訪談練習把自己模仿成只會發號施令的人，氣得質疑導師是否教會學生區分引述與戲仿，想把這段改成雙方互演。 |
| 核心衝突 | 被模仿的人要求重新上場，原作者卻未必願放棄自己的視角。 |
| 導師困境 | 可改用虛構家庭練辨認觀點，原成品失去情緒張力；也可在雙方願意下並列各自版本，課堂要多花時間說明兩種觀點。 |
| 故事獨特性 | 家長不是要求藏起家醜，而是想扮一次眼中的孩子。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：下課剛接起電話，parent_a那頭的聲音又啞又衝，聽得出是剛從醫院或家務裡抽空打來的。
- **P02｜parent_a**：老師，我一個人扛家裡看病跟家事這麼久，昨天聽孩子練那個課堂訪談，他居然把我演成一個只會發號施令的大人！你到底有沒有教學生區分引述跟戲仿？我想把這段改成兩邊互演！
- **P03｜旁白**：那份訪談練習其實還沒公開展示，可孩子確實是用略帶誇張的口吻寫出自己眼裡的壓力，要他放棄原視角他未必願意。
