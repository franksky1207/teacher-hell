## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生看同桌害怕把回饋紙交出去，親手幫忙完成無姓名的重點整理。常留意導師課間交流的位置，連續來催老師何時能讀，等老師準備當面回答時，才發現同桌根本不想知道答案由誰講。 |
| 核心衝突 | 幫忙的人以為要快，真正提出問題的人只想安靜拿到一句回覆。 |
| 導師困境 | 可經本人意願將回覆寫在非公開紙上，放掉一場可能有用的口頭交流；或在另一次自願會談讓本人自己問，代價是今天仍無解答。 |
| 故事獨特性 | 最會替他人跑腿的人第一次面對自己的速度也會讓人沒有喘息。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：這兩天課間不管我走到哪，student_a總會準時出現，手裡拿著一張他替同桌整理好的無姓名重點紙，連著問我三次「老師什麼時候能當面回我們」。
- **P02｜旁白**：剛才我終於空出十分鐘準備直接開口回答，一回頭卻看見他的同桌遠遠躲在走廊柱子後面擺手，壓根不想過來。student_a愣了一下，才抓抓頭反應過來。
- **P03｜student_a**：啊……他好像根本不想被任何人看到是他問的，連老師當面講他都不敢聽……那我幫他整理這張紙，現在要怎麼辦？

| B | 看student_a一臉好心跑了三趟催我回答、結果回頭才發現同桌怕得縮回去，我又無奈又心疼這個熱心過頭的小幫手，乾脆拿起便利貼寫下兩行字折成小方塊塞進他手心：「跑這麼多趟辛苦了，這張別拆放他桌角就好——以後別替人催那麼緊，留點空氣給他！」 | true | 因無奈又心疼熱心過頭的學生，導師折好匿名回覆便利貼交其靜置桌角，並溫和提醒留給同儕喘息空間。 | 同時安撫了跑腿者並護住同桌隱私，但兩行字條沒能當面解開更深的疑問。 |
| C | 「student_a你先別一直跑來催進度了，今天先退後一步留點時間給同桌，等他喘過氣自己拿紙來找我。」 | false | 請student_a暫停代為催促與傳話，將發問與求助的主動權退還給同桌本人。 | 提醒熱心學生給別人留呼吸空間，但熱心跑腿的student_a可能有點失落。 |
| D | 「既然他今天還沒準備好當面問，我們就別逼他過來了，改約另一場完全自願的小段時間等他自己想問再說。」 | false | 暫緩本次口頭回答，保留日後同桌本人自願前來個別詢問之空間。 | 完全尊重當事人步調與安全感，但代價是今天這題暫時沒有解答。 |
