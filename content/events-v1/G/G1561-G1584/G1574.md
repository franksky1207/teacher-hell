## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生其實判斷力不錯（`3-2`），平時對校園安全也有基本認識（`9-4`），但前幾天因為申請社團公假未符合資格被導師駁回，心裡對導師積了一肚子不滿（`5-4`）。今天下午校內進行例行性的教室安全與逃生動線檢查，他明明知道檢查滅火器跟淨空走道很重要（`3-2`、`9-4`），卻因為正在跟導師賭氣（`5-4`），加上旁邊兩個愛鬧的同學偷笑起哄，他便跟著大家用誇張戲謔的語氣大聲起鬨唱反調（`6-2`），讓現場來檢查的教官或安全人員臉色瞬間沉下來。 |
| 核心衝突 | 學生明明懂事也知道安全重要，純粹是因為對導師有私怨加上同儕起鬨，把嚴肅的安全檢查搞成鬧劇，甚至可能連累全班秩序扣分。 |
| 導師困境 | 當場先用眼神與簡短指令壓住起鬨、配合安全人員完成所有檢查項目後，下課再單獨把他叫來辦公室算總帳（當場給足安全人員與程序尊重，但那幾個起鬨的同學以為老師沒生氣）；還是當場就冷靜但嚴肅地指出「安全檢查不能拿來開玩笑」，請他示範把剛剛亂擺的物品歸位後再繼續（立刻立下安全紀律，但心懷不滿的他當場在同學面前覺得超沒面子、怨氣更深）。 |
| 故事獨特性 | 沒有真的發生危險，寫出青少年「明明知道這件事很重要，但因為不爽老師就故意在安全檢查時演鬧劇」的彆扭心理。 |
