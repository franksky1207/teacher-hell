## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一名學生看到同學在缺課原因欄停筆，出於照應先替他寫下家庭有事；本人回來才說不想讓同學替他說。 |
| 核心衝突 | 學生自認幫忙師生節省等待，同學要保有自述權，導師也得維持正式紀錄的本人確認。 |
| 導師困境 | 導師可把未確認文字退回作廢、私下分別談清可代辦範圍、或改提供更少揭露的正式入口；不可延誤必要出缺勤流程。 |
| 故事獨特性 | 要保護的是本人對理由的敘述權，代送與代填的界線決定衝突。 |
