## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 圖書股長想讓長久沒人借的難書出現在借閱紀錄裡，想起導師帶共讀時曾教人圈出第一個讀不懂的句子。他從自己的試讀便條找出棄讀頁，把書擺到圖書角，另寫「我第三行就走了，有人能比我多一行嗎」。同學真的翻開書，卻開始猜哪個平常很會讀書的人也沒看完，甚至把一張未授權的同桌便條取來對照。他原先想照例把全組便條一起展出，導師指出未授權的風險後，他願意只留下自己或同意提供的內容。 |
| 核心衝突 | 被推薦的是那本難書，失敗便條只是入口。借閱有了起色，但猜作者已蓋過了討論，公開同桌便條會讓本人被記成連三行都讀不完。 |
| 導師困境 | 先把未授權便條還給同桌。導師可讓股長自願留下有署名的自身便條，配一段短讀，讓大家知道熟手也會卡住，股長則承擔被拿閱讀程度開玩笑；或掛上按頁碼分類的匿名自願便條，讀者可從三處不同難點進書，代價是股長要管理便條而無法把借閱增加算成自己那次推薦的成果。 |
| 故事獨特性 | 讀者競爭的是能不能多讀一行，推薦若變成人物排行榜就失去原來的邀請。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白**：下課剛走到教室後方圖書角，那本從沒人借過的厚磚頭書旁貼了張便條：「我第三行就走了，有人能比我多一行嗎？」，書前面真的圍了四五個同學在翻。
- **P02｜旁白**：可旁邊幾個人正笑著把一張寫滿字跡的同桌便條拿起來對筆跡，圖書股長student_a聽我提醒未授權風險後也趕緊把那張按住。
- **P03｜student_a**：老師我原本只是想照以前那樣把整組試讀便條貼出來，沒想到大家開始猜哪個學霸也沒看完……現在這張還給同桌後，圖書角剩的便條怎麼辦？

| C | 歸還未授權便條並跟全班說「這活動比的是能不能多讀一行、不是在猜誰沒看完」，其餘全組有簽同意書的才留。 | false | 歸還未授權物並向班級重申活動本意，僅保留明確取得同意之便條。 | 這下班上原本愛湊熱鬧猜人的同學覺得沒趣，人潮散了一半。 |
| D | 先把未授權便條還給同桌，我讓student_a自願留下有署名的他自己便條並配一段短讀，讓大家知道熟手也會卡住。 | false | 立即歸還未授權同桌便條，由student_a自願保留自身具名便條並輔以短段導讀。 | 股長得自己承擔被同學拿閱讀程度開玩笑的風險。 |
