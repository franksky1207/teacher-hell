# 《教師荒謬地獄》15-B｜成人 NPC 18 種通用剪影六姿勢製作 SOP v1.0

> 定案日期：2026-11-13。適用於之後新製作的成人通用剪影。此文件**獨立於** `docs/15-B-完整六圖優先製作SOP.md`（學生六表情／便服六情境），不修改學生素材、學生的六格語義或其已核准成果。
>
> 專案基準：`main`；正式素材唯一來源：`web/assets/characters/adults/`。此文件為**製作及預覽規格**，不代表 18 張已製成、正式圖已核准，或正式遊戲已完成接線。

## 一、定位與規模

1. 成人 NPC（家長、監護人、教師、行政、校長、親友、校外人士等）以**可重複使用的近黑色實心剪影**呈現；剪影不代表善惡、可疑、重要程度或人物內在情緒。玩家導師維持第一人稱，通常不顯示立繪；電話遠端人物不顯示立繪，均沿用既有劇情規範。
2. 基本結構：**青年／中年／年長 × 男／女 × 三種外貌體型＝18 種原型**。每種原型**只有一張 3 欄 × 2 列的六姿勢 PNG**，總計 **18 張正式 PNG、108 個姿勢格位**；108 格不是 108 個不同人物。
3. 三種原型以「纖細修長／標準勻稱／厚實寬闊」作主要區別，但**不是純粹瘦、中、胖**；還須結合頭型、髮際線、髮型、肩頸、骨架與服裝外輪廓。年齡層為美術觀感分組，不是身分、實際歲數或個性的硬門檻。
4. **同一 NPC 固定一個原型**，可依劇情切換該原型六種姿勢；絕不可讓換姿勢造成髮型、體型、衣著或年齡觀感改變。不同 NPC 可共用同一原型；經常同場的人物優先避免相同輪廓。配對須穩定，重新整理頁面、讀檔或跨日不可重抽；資料映射／舊檔相容屬 15-D 接線事項，不在本 SOP 改存檔 schema。
5. **畢業生不一律套用這 18 種通用模板**：需保留原學生可辨識特徵的成年剪影，沿用既有 `characters/graduates/` 規劃。身分尚未揭露者不可因圖片、檔名或替代文字提前洩漏真相。

## 三、固定六姿勢格位（不是六表情）

| 格位 | 姿勢代碼 | 名稱 | 輪廓與使用原則 |
|---|---|---|---|
| 上排左 1 | `neutral` | 自然站立 | 正面或微轉、雙臂自然垂放並保留合理手臂輪廓；安全預設 |
| 上排中 2 | `side` | 微側身 | 身體與肩線微轉、頭部自然朝向交談對象；不是換人或全側面 |
| 上排右 3 | `hand-on-hip` | 單手叉腰 | 一側手肘向外形成自然三角形，不要過度挑釁或戲劇化 |
| 下排左 4 | `arms-open` | 雙臂自然微張 | 雙臂略離軀幹，保留自然負空間；不是誇張攤手、聳肩或質問 |
| 下排中 5 | `gesture` | 單手示意 | 一手自然抬起，適用於解說／交談，不使用指責性強的指人動作 |
| 下排右 6 | `weight-shift` | 偏重心站姿 | 身體自然重心偏移、肩線略有變化；**不必交叉雙腿或踮腳** |

1. **六格是同一人、同一套衣著、同一髮型、同一骨架的六個姿勢**，不是六種情緒、六個人、六套服裝，也不對應學生的 `calm/happy/angry/sad/surprised/embarrassed`。
2. **全格空手且無道具**：不得持文件、手機、杯子、包包、拐杖等；不畫桌椅、背景或職業標誌。姿勢須能跨教室、辦公室、住家及校外情境共用。
3. 全黑剪影下，胸前抱手、腹前交握、背手等很容易融入軀幹，**不列為固定六格**。優先使用能由外輪廓或自然透明空隙辨認的動作；不另挖不合理的透明線條來模擬手臂。
4. 六格順序與用途固定，但不同性別、年齡、身形可自然微調幅度；不可僵硬照抄、極端扭轉關節或刻意誇大姿勢。站姿都保持一般日常感，不把單一姿勢綁定生氣、威脅、害羞等情緒。
5. **劇情演出**：初次出場優先自然站立；一般對話沿用原姿勢，不需要逐句輪換；只有當頁可觀察的對話／動作意圖合理時才切換。**場景不直接決定姿勢**，也不靠隱藏心理與事件真相選格。缺少適合姿勢時回退自然站立。正式對應與接線屬 15-D，不能把成人六姿勢誤用為學生六表情索引。

## 四、剪影顏色與外框（固定進 PNG，不需動態判斷）

1. **主體**：統一單色近黑 `#101014`；人物不畫五官、衣服內部紋理、彩色配件或內部明暗。保留髮型、頭型、頸肩、衣袖／領口及體態的**外部輪廓**。
2. **外緣**：統一淡灰白 `#D4D5DC` 細描邊，**不發光、不加暈光、不用粗白貼紙邊**。沿人物與透明區域的實際邊界描繪（包括自然形成的手臂空隙），不要畫內部分割線或五官。
3. 外框直接繪入每格正式透明 PNG。白天靠黑色主體辨識，夜間靠固定淡灰白輪廓維持可見；**不另設按背景明暗判斷是否加外框的程式**，不做不同日夜版本。
4. 外框線寬在 18 張採一致製作標準，以實際縮小到預覽顯示大小仍可辨識、又不顯粗重為準。正式首張檢查後固定採用，不只看原始大圖。若特定圖在深／淺背景不清楚，先修素材輪廓或線寬，不擅增動態顯示特效。

## 五、完整圖集、裁切與等高校正

1. **每張正式檔案**：真正透明 RGBA PNG、**1536×2304 px**、**3×2 六格**，每格 **512×1152 px**。只有人物與固定外框；**不含**白底、棋盤格、場景、文字、標籤、水印、格線或陰影地板。參考示意圖可以有背景與字，但**不可直接當正式素材**。
2. 每格以與學生相容的**頭部至大腿**取景，人物置中，維持自然頭身比例及可見的手臂／大腿輪廓。全六格先以保守比例配置（可沿用學生約 80～85% 滿格構圖的起始參考），較寬肩或較大手勢的格子再等比例縮小，四周均留安全距離，不必強制原始六格一樣大。
3. 頭髮、手掌、手肘、衣角、外框均不得越過格線、被裁斷或殘留到鄰格。若**完整未裁切原圖**太大，先等比例縮小並置中，再安全裁切；**原圖已斷肢或被截斷不能靠縮小冒充修好**。不扭曲縮放、不縮窄骨架來塞格。
4. 預覽與正式劇情**共用既有學生身高校正公式與可用的校正流程**：先按各格真正可見人物的上下邊界校正六姿勢高度，再套用本 SOP 第二節各原型相對最高學生 100% 的固定目標高度；不因單格為防跨格先縮小，而讓顯示時忽大忽小。
5. **等高指同一成人原型六姿勢的目標顯示高度一致，不是 18 種成人都一樣高。** 保留表內 85%～97% 的個別差異；不用改動學生既有 100% 基準與學生校正資料。姿勢頭部側轉或重心變化可有自然視覺差，不能出現明顯大小跳動。
6. 如既有校正工具不支援新成人類型，僅在日後預覽／15-D 接線時做**必要的最小相容接線**，不為此改寫學生公式、另建第二套圖片庫或重跑全專案。

## 六、服裝輪廓、人物一致性與適用範圍

1. 每個原型只設計**一套中性的日常衣著外輪廓**；六格完全一致，不因姿勢改變袖長、領口、衣襬或鞋履款式。避免警服、醫師白袍、誇張制服、明顯婚禮服裝等特定身分造型。
2. 不要求所有 18 個原型穿一模一樣的衣著輪廓，可自然區分上衣輪廓或外套，但**不要藉服裝推定職業、財富、個性或身分**。衣著與身形辨識應以外緣為主；不增加內部服裝線條。
3. 年長人物可有髮際線、髮量、頸肩與站姿的自然年齡感，**不要求所有長者駝背或顯得脆弱**；不同體型男女角色同樣保持自然合理。
4. 角色配對依已知人物資訊（例如實際年齡、外觀設定）與穩定識別鍵，不應因「主任」「反派家長」「警察」等身分而硬指定某張。相同原型撞圖時，先在合法候選原型間分散，不製作每位家長或每個職務的專屬圖片。
5. 此 SOP 不擴充玩家導師立繪；畢業生成年輪廓特徵與辨識／揭露規則仍由既有故事、美術規劃約束，必要時另在 `graduates/` 處理。

## 七、製作、檢查、預覽與核准流程

1. **先做一張原型試作**：以 `MM-02`（中年男性標準勻稱型）的六姿勢確認純黑＋細外框的輪廓辨識、自然度、大小與深淺背景可見度，再依核准的共同規格製作其餘 17 張；已在討論中產出的白底或深淺背景比對示意圖**僅為方向參考，不算正式 PNG 或正式核准**。
2. **每張產圖先自檢**：六格是否明確是同一人、六姿勢正確且自然；是否有斷手、斷腳、畸形肢體、黏連過度、髮型或服裝突變、跨格殘片；原型與其他 17 種是否有主要可辨識差異。
3. **進正式檔前檢查**：實測 PNG 尺寸 1536×2304、RGBA 真透明、六個 512×1152 格位完整；分別放到明亮與深色背景看主體、淡灰白外框、白邊／黑邊、雜點、透明殘影以及遊戲縮圖大小的辨識度。若有重大缺陷先修正，不以展示大圖取代實際尺寸檢查。
4. **高度檢查**：確認 18 種個別目標比例及單人六格等高校正。伸手格可在原始格內縮小，但正式預覽不能因此比該人其他姿勢矮一截。雙人同場、明暗背景、手機直式與桌機橫式沿用既有相關的輕量預覽檢查；不要求全學期、三年或全站驗收。
5. **核准階段要分開記錄**：候選產生 → 自檢通過 → 使用者確認可用 → GitHub 正式檔已提交 → 預覽已接入 → 使用者於正式預覽核准 → 日後正式劇情接線。**產圖完成、上傳完成、預覽接入及使用者正式核准均不可混為一談**。未經要求不自行接線、部署或合併。
6. **單一正式來源**：18 張直接存放 `web/assets/characters/adults/`，不拆青年／中年／年長／男女／體型子目錄，也不建立 `preview/`、`test/`、`backup/` 等平行正式圖片庫；預覽直接引用正式資源。
7. 候選、失敗圖、裁切中間檔先留在 Git 追蹤外；**先修到可用再一次提交**。已正式核准圖片若修正，沿用相同檔名覆蓋，不新增 `-v2`、`-final` 等版本。注意同名覆蓋**不會清除 Git 歷史舊 blob**，因此避免反覆提交未核准的大型 PNG。
8. 提交前只做該批受影響素材的輕量差異及重複檔案檢查；不清理學生舊圖、不重寫 Git 歷史、不跑大型遊戲模擬。資源來源與授權記錄遵照既有第 15 批規格。

## 八、與學生 SOP／正式劇情的分界

- **學生**：40 個外貌原型、各自五分類圖集；制服／運動服六格是六表情，便服六格是六活動情境，依原學生 SOP；本文件不改任何學生圖片、姿勢、表情索引、預覽入口或核准進度。
- **成人**：18 個共用原型、每原型一張六姿勢圖集，六格是自然無道具動作，不代表情緒，不能套用學生的六表情語義。
- **共同**：正式圖集格式、透明背景、安全分格、尺寸檢查、共用身高校正原理、穩定身分配對及低成本按需載入。
- **後續 15-D**：根據已公開劇情動作意圖選取成人姿勢，正確處理存檔穩定映射、讀檔、缺圖回退與正式劇情接線；不在 15-B 美術製作時擅改事件資料模型或學生六表情邏輯。
