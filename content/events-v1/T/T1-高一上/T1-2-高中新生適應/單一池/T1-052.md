| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生帶回第二週要自行準備的清單，家長才發現第一週自己替孩子查時刻、裝教材，孩子並不會；家長想繼續包辦以免再漏。 |
| 核心衝突 | 過渡支援有必要，但把所有準備都代做會掩蓋學生真正需要練習的部分。 |
| 導師困境 | 導師要協助拆出學生能自己完成的小步驟，還是先讓家庭保留有效支援，避免一次撤光造成挫折？ |
| 故事獨特性 | 不是家長不放手的道德評斷，而是初週成功究竟由誰完成。 |
