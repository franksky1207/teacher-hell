## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這位本班家長家中長輩與配偶都非常重視飲食安全、全家一致支持孩子少碰加工食品的習慣（`7-1`），他平時也絕不跟風其他家長隨手買含糖飲料犒賞孩子的做法（`6-2`）。昨晚他在地方媽媽社群輕信一則幾年前就已闢謠的假消息——宣稱「學校合作社販售的某款知名鋁箔包麥茶檢出非法防腐劑」（`8-3`）。今天一早他直接抱著手機截圖跑到辦公室要求導師給個交代（`12-4`）：「我們全家都把關這麼嚴了，學校合作社竟然還賣這種問題飲料，你身為導師怎麼沒有先提醒全班不准買？」 |
| 核心衝突 | 家庭食安共識高又不從眾的家長因誤信網路舊謠言而向導師討說法，但合作社進貨屬全校總務／員生社權責，且該消息早已證實為不實謠言。 |
| 導師困境 | 當場拿出官方食安闢謠公告澄清並說明合作社進貨由校方把關非導師權責，這名護子心切又在家長群素有食安達人形象的家長當場下不了台、甚至質疑「官方說法可信嗎」；為了安撫他的焦慮而答應替他轉交檢驗質疑給總務處並先口頭勸學生少喝鋁箔包，又等於替一則假謠言背書、平白影響合法合作社商譽。 |
| 故事獨特性 | 沒有食物中毒事件，寫出不從眾且全家重視食安的家長如何被陳年網路假食安文誤導，進而把合作社把關責任算到導師頭上。 |
