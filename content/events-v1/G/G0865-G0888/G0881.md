## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平常非常信任導師、也肯定導師帶班專業的本班任課教師，今天在課堂上被幾個故意交白卷又嘻皮笑臉的學生氣到快腦溢血，下課衝進導師室直接拿著寫好的獎懲單介入決策：「老師我信得過你的原則，但這幾個我今天非記他們警告不可，你等下簽名欄直接幫我蓋章背書送學務處！」 |
| 核心衝突 | 信任導師的同事在氣頭上直接填好懲處單要求導師蓋章，把原本該經導師了解前因後果的班級管教變成純粹背書程序。 |
| 導師困境 | 二話不說直接蓋章替氣頭上的同事撐腰，學生肯定炸鍋並覺得導師連問都不問就跟著罰；先把單子壓下來問清楚原因，剛被氣到發抖的同事會覺得「我這麼相信你你還不挺我」。 |
| 故事獨特性 | 沒有排座位衝突，而是「太信任你的同事」在盛怒之下把你拉進即時懲處背書戰線。 |
