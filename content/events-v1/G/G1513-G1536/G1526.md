## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生一向敬重導師珍惜舊書的態度，又盼大家稱讚自己會挑書。父親固定在家整理攝影雜誌，學生熟知每期位置，也有一冊父親早已送給他、可自行處分的重複刊。他把自己的那冊和父親的珍藏一併帶到學校，想擺進閱讀角；同學正要伸手拿時，導師問清楚才知道，父親從未同意出借那幾本珍藏。 |
| 核心衝突 | 學生已跟同學誇口有一整套；能作主的只有自己的那一冊。 |
| 導師困境 | 珍藏立即撤下裝回學生書袋，由學生依父親確認的方式帶回，若需要暫管則依校內授權辦理。導師可私下與他重訂借展範圍、只展他願出借的自有那冊，讓同學看見承諾縮水；也可讓他暫取消整套展覽，待他事先得到所有權人明示同意並確認保管安排後另提，代價是錯過這次展示。 |
| 故事獨特性 | 不是家裡有錢捐贈，而是規律家庭裡的孩子為了討老師與同學歡心，擅自把爸爸的寶貝收藏搬來當共享資源。 |
