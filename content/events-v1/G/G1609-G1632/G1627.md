## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生口才極佳（`3-1`），平常對導師十分敬重（`5-3`），內心超級渴望獲得導師的肯定（`4-4`），也總是緊盯著導師的一舉一動（`12-2`）。剛才大下課導師在走廊上順口誇了隔壁班一位學生「筆記整理得真清楚」，這名一直盯著導師看的本班學生看在眼裡心裡超吃味（`12-2`、`4-4`），下一節下課立刻抱著自己的筆記本衝進辦公室，用超有禮貌又流利的口才展開「自薦報告」（`3-1`、`5-3`）：「老師您辛苦了！我剛好也整理好這週的重點，您要不要順便看一下？大家都說我這份也寫得不輸別班喔！」 |
| 核心衝突 | 沒有惡意也沒有鬧脾氣，純粹是一個太在意老師眼光的高中生上演「現場吃醋爭寵」，偏偏導師手邊還有一疊正事要趕著處理。 |
| 導師困境 | 放下手邊工作花三分鐘認真翻看他的筆記、給他一個具體又真誠的稱讚「比剛剛走廊看到的那份還細心」（立刻滿足他的被認同感並收服這個可愛的孩子，但導師自己的備課進度被耽誤且以後他可能天天來討誇獎）；還是笑著收下筆記先放桌上、溫和告訴他「老師晚上再仔細看，你這麼努力老師一直都知道，不用跟隔壁班比啦」（點破他的小比較心態並守住工作時間，但沒當場聽到誇獎的他難免有點小失落）。 |
| 故事獨特性 | 寫出高中師生關係裡最生活化也最可愛的一面——學生因為太敬重老師而對別班同學吃醋、跑來辦公室現寶求誇獎。 |
