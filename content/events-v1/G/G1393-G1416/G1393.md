## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名本班學生平時在班上很有號召力（`6-1`），也相當肯定導師帶班與教學的專業表現（`8-1`），但校園安全意識極高（`9-4`）。今天中午教室悶熱，導師自己搬一疊考卷進出時圖方便，順手拿一本厚參考書卡住走廊末端的常閉式安全門方便通風；這名學生經過看見後當場氣得發火（`2-1`），在幾名圍觀同學面前直接大聲質疑：「老師你自己都拿書卡安全門，以後我們宣導消防動線誰還會聽！」（`6-1`）。 |
| 核心衝突 | 導師自己圖一時方便違反安全規定被學生當場抓包，必須立刻移除書本恢復門扇關閉；但事後如何面對這名平常高度肯定你、此刻卻在同學面前氣到不給台階的風雲學生，考驗師生面子與榜樣界線。 |
| 導師困境 | 導師立刻把書本拿開並關好安全門（必要安全處置先完成）；接著的兩難在於：趁下午班會課或課間在全班面前坦率承認自己剛剛示範錯誤、並公開肯定他即時糾正（樹立誠實與安全優先榜樣，但導師在學生面前的威信多少有點掛不住、也可能讓該生以後習慣當眾直接嗆老師）；還是當場先認錯收書、下課後單獨找他致謝並提醒下次可先私下告知（顧及公開場合的師長體面，卻讓這名重視安全的學生覺得老師想把糗事低調壓過去、對你的專業肯定打了折）。 |
| 故事獨特性 | 不是學生違規被導師抓，而是導師自己圖方便踩線被平常很挺老師的安全派學生當眾抓包，寫出大人犯錯後如何收場的真實尷尬。 |
