## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 氣窗已由權責人員修復並確認可恢復使用。這位連日做修繕盤點的常駐支援職員累到把完成單一度夾進待辦，直到看見原本的封條仍在，才發現班上一直以為還沒修好。他把完成訊息交給導師，導師答應換告示。他怕直接責怪導師漏看通知，又在意學生別自行爬高查看，連著兩天來問導師何時能換掉舊告示、把復用訊息說給學生聽。 |
| 核心衝突 | 修繕與安全確認已完成，卡住的是復用資訊。職員一直追的是導師曾答應更新的班級提醒，卻客氣到連導師也以為他在問修理進度。 |
| 導師困境 | 向權責窗口確認現行復用方式後，可由導師立即更新班級告示、說清舊封條何時失效，代價是得另挪課間；也可請職員在不影響課務的時段與導師一起把完成交接講給學生聽，釐清往後如何識別停用與復用，代價是兩人須再排時段。學生不爬高或代驗設備。 |
| 故事獨特性 | 職員追的是導師答應更新的復用告示，說起來卻像每天在追自己處室的修理進度。 |
