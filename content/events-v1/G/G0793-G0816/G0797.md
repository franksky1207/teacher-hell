## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 一位家中需照料臥床長輩的單親家長，特地請假擠出時間親自開車載送學生並幫忙搬運校外參訪器材，但他其實一直留意導師有沒有把好表現的機會都留給特定幹部，事後更連續三天打電話緊盯進度，追問導師何時核發孩子的「服務時數與幹部加分證明」。 |
| 核心衝突 | 家庭負擔沉重的家長願意親自出力當志工，背後卻帶著對公平性的高度戒備與急切的時數回報要求。 |
| 導師困境 | 立刻照他的標準多開一點服務時數讓這名辛苦家長安心，其他只搭車沒出力的家長或同學一定質疑標準不一；按實際時數核實開立，他又覺得自己請假出力卻被導師斤斤計較。 |
| 故事獨特性 | 把家長的家庭時間成本、志工出力與「盯著老師是否偏心」的功利期待綁在一起。 |
