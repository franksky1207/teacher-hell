## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 這名現任本班副班長或總務股長（`9-3`），父母在家極為支持他透過擔任班級幹部學會扛責任（`7-1`）。這週他自己同時趕著英檢報名、報告與連日補習，累到眼皮都快抬不起來（`2-3`），卻還是照常自告奮勇投入體力幫導師把全班新發的運動服或實作習作從總務處搬回教室（`11-3`）。原本照規定他應該按座號核對尺碼再逐一發放，但累到撐不住的他圖省事把整箱打開喊一聲「大家自己來拿！」，結果好幾個同學拿錯尺碼還當場用奇異筆寫上名字，發完才發現整批亂成一團。 |
| 核心衝突 | 受家庭鼓勵扛責又過度疲勞的小幹部在搬運發放時圖快省略核對步驟，造成全班物品尺碼錯亂與已寫名無法退換的善後難題。 |
| 導師困境 | 立刻自己花一整節午休幫全班重新登記錯領尺碼、打電話向廠商或總務處拜託協調交換，雖然保住這名累壞學生的自尊卻得自己吞下全班份善後工時；要求這名幹部自己去逐桌收回重對並向沒拿到正確尺碼的同學道歉，這名受家裡期待扛好班務的學生自尊心與責任感瞬間受挫。 |
| 故事獨特性 | 沒有潑水也沒有意外摔落，純粹是「太累想省一個核對步驟卻害全班自取領錯還寫上名字」的班務發放烏龍。 |

- **P01｜旁白**：運動服箱裡只剩幾個尺寸，桌上已經有人把名字寫得很大。總務股長揉眼睛，說自己搬完真的撐不住，才叫大家先拿。
- **P02｜學生**：我爸媽一直叫我有責任就扛，可是我昨晚也在趕報告。現在寫名的不能換怎麼辦？
