## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 本班任課教師對被誤會作弊的學生很有同理心，一聽到他班老師與行政端沒查證時間線就直接扣帽子記處分當場火大，竟自己主動找了當時在場的其他同學與監考人員逐一還原經過，接著拿著整理好的時間線來找導師協調合作：「我人證都問好了，現在就差你這班的座位紀錄，我們一起去跟主任翻案！」 |
| 核心衝突 | 熱血同事為了替學生洗刷冤屈主動查證並找導師聯手，卻把原本行政端已經草草結案的懲處重新掀成跨處室翻案戰。 |
| 導師困境 | 立刻拿著座位紀錄跟同事一起衝進主任室要求撤銷處分，會把當初草率結案的監考與行政主管得罪光；勸同事別把事情鬧大、私下幫學生補救就好，這位氣頭上的同事一定認為導師太軟弱不挺自己班學生。 |
| 故事獨特性 | 重點不是抱怨同事或串聯對付家長，而是同事為了替學生翻案主動查證後，拉導師一起挑戰行政既定處分。 |
