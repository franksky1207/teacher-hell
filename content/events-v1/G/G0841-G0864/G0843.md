## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 平常很配合導師交件時段、也樂於協調合作的總務或會計職員，這天收到廠商寄來的班級訂購收據抬頭全錯、加上對帳單被別班搞亂，氣到邊拍桌邊用超有條理的語速找導師逐筆核對每一張班費單據，要求今天一定要一起抓出哪一筆沒對上。 |
| 核心衝突 | 行政同事不是針對導師發脾氣，但他的高分貝怒氣與精準對帳壓力全落在導師桌上。 |
| 導師困境 | 先停下全部課務陪他逐張核對完，能維持合作關係但下一節課差點遲到；請他把單據放著晚點再說，氣頭上的同事恐怕直接把錯帳先算到導師頭上。 |
| 故事獨特性 | 寫出「邊生氣邊精準溝通」的職場對帳現場，氣歸氣、合作還是要繼續。 |

### 開場
- **P01｜旁白與當場對話**：她拍桌一下，接著一口氣把每張抬頭、金額、日期說得清清楚楚。「不是全部都你的，這張才是。」平常你晚幾分鐘交，她總會配合重排，今天還主動劃好兩人分工，氣的卻是廠商抬頭全錯、別班帳又混進來。該更正和回報的已接上，她把分開的單據推來：「你先看哪一疊？今天不能再一起糊過去。」
