## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 學生親近導師又有號召力，實際負責教室垃圾分類，見導師總站著陪他便讓幾個同學合力將安全乾淨的紙箱做成給老師的座位模型，自己協調誰寫字誰找板。完成時，大家紛紛指著它說「老師今天要坐資源回收」。 |
| 核心衝突 | 一群人本來想讓老師有地方歇一下，做好之後自己最愛的是老師捨不捨得坐過去。 |
| 導師困境 | 導師可坐旁邊照相陪全班演完話，接受暱稱傳開；也可讓模型拆回回收品，保住教室空間卻讓同學第一次協力的東西沒留過一節課。 |
| 故事獨特性 | 班務可以由關係出發，收尾卻是好意被參與者故意做成一句罵人的話。 |

## 4｜玩家可見開場與四個行動

【待填：階段三AVG】

### 開場
- **P01｜旁白與當場對話**：他嫌你一直站著，招呼幾個人拿乾淨紙箱，分誰寫字、誰找板，手上還照做原本的分類工作。模型做完，有人指著正面笑：「老師今天坐資源回收！」你已說清這個不能承重，誰也沒往上壓。他靠著真椅子讓出位置，笑得像想看你會不會連旁邊都不肯坐。
