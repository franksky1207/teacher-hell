## 2｜四欄創意摘要

| 固定欄位 | 故事摘要 |
| --- | --- |
| 事件起因 | 現任本班學藝股長（`9-3`）對班級榮譽極負責任（`1-1`），但好勝心極強、一心想拿下這學期全校教室佈置比賽第一名（`4-1`）。昨天他嫌兩名負責繪圖的同學畫得太慢又略顯稚嫩，沒先問過導師與那兩名同學便直接介入海報定稿決策（`12-3`），今天一早自己用電腦排版印出大字報直接蓋貼上去。那兩名熬夜畫底稿的同學早自習進班一看心血全被蓋掉，氣得眼眶泛紅找導師評理。 |
| 核心衝突 | 好勝又負責的學藝幹部為了贏得比賽第一名而抹煞同伴的手繪心血，讓導師在「追求比賽視覺名次」與「守護班級共創尊重」之間必須做出裁決。 |
| 導師困境 | 要求這名學藝股長當場撕下大字報、把同學的手繪底稿露出來並向兩人道歉（守住團隊尊重與公平，但這名好勝又負責的股長當場委屈覺得「我也是為了幫班上拿第一名啊」）；乾脆保留大字報並安撫那兩名同學說「比賽講求整體效果、你們的構圖有幫上忙」（保住比賽賣相，卻徹底寒了那兩名熬夜畫圖學生的心）。 |
| 故事獨特性 | 沒有誰想偷懶，衝突完全來自「好勝幹部嫌夥伴畫得不夠贏面、自己動手取代」的團體創作尊嚴摩擦。 |
