# 《教師荒謬地獄》學生立繪｜完整六圖製作 SOP v1.9

> 唯一有效的學生美術製作與驗收 SOP（2026-11-10）。參考：[40 人外貌名冊](./15-B-40位學生外貌設計名冊.md)｜[美術進度簿](./15-B-美術素材命名與製作進度簿.md)。

## 1. 產出與不可違反規格

- **40 位美術原型、每人 5 個服裝分類，共 200 張 PNG**；男生 `student-001～020`、女生 `student-021～040`。每人每套只交付 **一張真正透明 RGBA PNG**，內含 **3 欄 × 2 列、六格完整人物立繪**；**不另製 calm 母圖、局部臉部貼片、定位 JSON 或六張分圖**。
- **製圖與驗收優先序（由高至低）**：①**真正透明 RGBA**（原始產圖即要求全透明，無白底、假棋盤格及白邊；實測 Alpha 並在深／淺底檢查）→②**正式規格**（1536×2304 px、3×2 六格、每格 512×1152；原生尺寸不足須如實說明，轉換並檢查後才交付）→③**完整、安全分格**（肢體不斷裂、無跨格殘片）→④**同人外貌與服裝正確**→⑤**姿勢多樣與自然細節**。高優先項目不合格，不以低優先項目掩蓋。
- **所有學生預先縮小構圖**：不分體型，六格一開始即以約滿格構圖的 **80～85% 作參考**，各格人物完整、置中並保留透明安全區；寬肩、寬壯或手勢伸展者再縮小，不改瘦體型或壓窄肩膀。以**頭至大腿、可見下半身服裝**為主，保持合理頭身比例；不追求填滿格子。靠近邊界時，先從**未裁切原圖縮小完整單格人物**再裁切；若原圖本來斷手／斷肘則須重畫，不能縮小殘圖冒充修復。
- **制服／運動服四類**六格順序：上排 **calm 平靜｜happy 開心｜angry 生氣**；下排 **sad 難過｜surprised 驚訝｜embarrassed 害羞**。**便服是單張六情境圖集**，每格不同衣服、不同開心姿勢，按下節固定活動順序，非六種情緒。
- **成品禁止背景及雜物**：人物外全透明，不得有場景、底色、假棋盤格、邊框、格線、文字、標籤或水印；全套固定 1536×2304、3×2 六格，不另換尺寸。六格取景與位置協調，安全留白優先於人物填滿畫面。
- **同一人四套制服／運動服**：每套六格臉型、五官、體型／年齡感、款式與配件一致；可保留部分自然動作習慣，**但每套須重新安排六表情姿勢，不得整組複製上一套或其他學生**。髮型整理與配件可隨服裝合理變化，仍須辨識出同一人。
- **偏寫實動漫畫風、40 人有辨識度**：依名冊及已核准夏季制服鎖定五官、髮型、膚色、肩寬與體型，不畫成 Q 版或錯誤人物類型；**外貌不決定個性**。不同學生的六格不可套用相同整組動作模板，需變化站姿、手勢、頭部角度、視線與情緒強度；容許自然的個別動作重複，不為求不同而畫出不自然姿勢。

### 強制：每一次製圖前明確強調服裝三項

- **無論新畫、重製、局部修正或同角色改做下一套服裝，都必須在產圖前**先核對學生性別與當次服裝類型，再**逐項寫出／重述上表對應的三項完整規格**，並在實際產圖提示中再次寫明，不能僅說「照之前制服」「沿用 SOP」或只強調人物外貌。
- **四套校服與運動服的服裝規格是硬限制**；已核准的夏季制服 PNG 是該生臉、髮型、體型的外貌基準，而不是讓模型自行複製舊圖錯誤的服裝細節。若兩者有衝突，人物外貌依核准圖、服裝款式與配色依此表。
- **產後自檢也須逐項核對相同三條**，特別檢查冬季有外套、運動服沒有多餘拼接／線條、制服／運動服六表情服裝一致，便服六格則各自不同且皆為開心；服裝重大錯誤須修正。
- 回頭檢驗 001～020 時，以此版夏季制服規格作為共同檢核標準；僅修正明確錯誤，不因正常色差或皺褶而強制全部重畫。

## 3. 唯一製作順序

1. **第一階段已完成**：40 人的夏季制服六圖皆經核准，分別作為每位學生的**唯一外貌基準**。原有核准進度及個別修圖紀錄保留於進度簿，並非第二階段的重製任務。
2. **第二階段逐人補四類**：從 001 起，依冬季制服 → 夏季運動服 → 冬季運動服 → 便服的順序，逐張製作與核准，該生其餘四張全部完成後，再換 002，直到 040。**每套都必須重新從 GitHub 讀取該人第一階段已核准的夏季制服完整六表情 PNG，並同時讀取 40 人外貌名冊中該生的原型設定**；不能只憑記憶、前次對話、其他服裝的成品或別位學生的圖片推測長相，也不能逐套傳遞外貌。
3. 美術編號**不等於座號或姓名**。已完成的初始 40 人正式劇情接線依開局固定名冊對應美術 001～040；若未來另行實作同組不重複隨機配對，必須保證三年穩定且先確認存檔相容，不能把規劃冒充現行功能。

### 第二階段強制同一人物檢查

- **產圖前先確認參考來源**：必須實際開啟 GitHub `main` 的 `web/assets/characters/students/student-XXX/student-XXX-full-sheet-uniform-summer.png`，逐格觀察已核准六表情的人物，並讀取 `docs/15-B-40位學生外貌設計名冊.md` 對應編號的外貌原型、體型與辨識特徵。以**實際核准的夏季制服 PNG 作為外貌主要依據**，名冊用於輔助辨識；兩者不能拿另一位學生或新生成圖替代。
- **成圖後逐格與母本直接對照**：新服裝六格都要與同一位學生的夏季制服六表情比對臉型及五官比例、眼睛／眉毛／鼻口特徵、膚色、主要髮型與髮色、頭身比例、肩寬與整體體型、年齡感和獨特辨識特徵。冬季外套造成的視覺厚度、服裝差異、自然髮型整理、表情與姿勢改變可以存在，但不得因此把人畫成不同的臉或不同的體型。
- **判定標準是「明確看得出同一人」**：極小的線條、眼形、髮絲、光影或細節差異可以接受，不要求逐像素完全相同；**但只要整體看起來不像夏季制服中的同一人，就是重大缺陷，必須修正或重製，不能自動標為通過、上傳當作核准版本或開始下一套。** 每次修正後重新檢查整張六格的人物一致性與原有技術 SOP。
- **此為第二階段的執行與驗收強化，不變更原有製圖技術**：透明 RGBA、1536×2304、六格安全區、服裝三項硬規格、肢體及去背檢查、局部修正與正式檔名全部照既有 SOP。

## 4. 每次產圖：確認 → 製圖 → 全項自檢 → 分類修正 → 交付

1. **產前按優先序鎖定**：先要求真正透明 RGBA 與正式 1536×2304、3×2 規格；讀取該生核准夏季制服、名冊及本套服裝三項硬規格。**所有人六格先縮小、置中留安全距離，再裁切**；寬壯或動作較大的格子再縮。四套制服／運動服重新安排六表情姿勢；便服六情境對照已完成學生避免整組複製。不放背景、格線與文字。
2. **產後全項自檢**：**首先實際確認 PNG 尺寸 1536×2304、RGBA 與人物外透明 Alpha**，再確認六個人物各自完整且分離，再實際裁出六格，逐格核對外貌、表情、服裝與配件、手肘／手掌／頭髮是否原本就被截斷、下半身、尺寸、裁切及**鄰格是否殘留其他人物碎片**；**邊界留白不能代替肢體完整性檢查**。除確認 PNG 的 Alpha 真透明，還須將**每格實際合成至深色與淺色背景目視檢查**，特別檢查頭髮、耳側、手臂與身體之間的白邊、棋盤格、殘留底色或雜點；不能只憑 Alpha 數值宣告合格。**每次重試仍要全部重檢**，不能只檢查前次缺陷。
3. **先修最高優先缺陷，僅動問題格**：靠近格線但**未裁切原圖肢體完整**時，優先將該格等比例縮小、置中後再裁；其餘正常格不動，並清除鄰格殘片。不可縮小已被裁斷的人物。假透明、白邊、原圖斷肢、人物錯誤或多格重疊須修正／重製，不以留白數值假裝通過；反覆出錯應改查根因，不做機械式重試。
4. **重大缺陷嚴格、細節彈性驗收，但不冒充成功**：人物類型錯誤、假透明／明顯白邊、肢體截斷、人物重疊等重大缺陷必須自行修正後才能交付，不要求使用者反覆催「繼續」；只要表情與個性合理，**個別手勢與原規劃略有不同**，以及細微色差、皺褶等，不必無限返工。工具確實不可用或持續失敗時說明阻礙，不虛報合格，也不無限制重試。
5. **交付一張正式命名 PNG 下載連結＋對應 `student-XXX/` 專屬 GitHub 資料夾**，不可只給總目錄；不提供 ZIP／分圖／JSON，先確認檔案存在。
